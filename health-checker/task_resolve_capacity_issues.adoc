= Active IQ Unified Manager에서 용량 문제 해결
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이 워크플로는 용량 문제를 해결하는 방법을 보여주는 예시입니다. 이 시나리오에서 관리자 또는 운영자는 Unified ManagerDashboard 페이지에 접속하여 모니터링 중인 스토리지 오브젝트에 용량 문제가 있는지 확인합니다. 문제의 가능한 원인과 해결 방법을 파악하려고 합니다.

.시작하기 전에
운영자, 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

대시보드 페이지의 용량 패널에 있는 이벤트 드롭다운 목록에서 "`Volume Space Full`" 오류 이벤트를 찾습니다.

.단계
. *대시보드* 페이지의 *용량* 패널에서 Volume Space Full 오류 이벤트 이름을 클릭합니다.
+
오류에 대한 이벤트 세부 정보 페이지가 표시됩니다.

. *이벤트* 상세 정보 페이지에서 다음 작업 중 하나 이상을 수행할 수 있습니다:
+
** 원인 필드의 오류 메시지를 검토하고 권장 해결 조치 아래의 제안 사항을 클릭하여 가능한 해결 방법에 대한 설명을 확인하십시오.
** 소스 필드에서 오브젝트 이름(이 경우 볼륨)을 클릭하여 오브젝트에 대한 세부 정보를 확인하십시오.
** 이 이벤트에 대해 추가된 메모가 있는지 찾아보십시오.
** 이벤트에 메모를 추가합니다.
** 해당 이벤트를 다른 사용자에게 할당하세요.
** 이벤트를 확인하십시오.
** 해당 이벤트를 해결됨으로 표시하세요.
