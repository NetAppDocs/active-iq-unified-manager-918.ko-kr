= Active IQ Unified Manager의 그룹에 대한 그룹 규칙 작동 방식 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
그룹 규칙은 스토리지 오브젝트(볼륨, 클러스터 또는 SVM)를 특정 그룹에 포함시키기 위해 정의하는 기준입니다. 조건 그룹 또는 조건을 사용하여 그룹에 대한 그룹 규칙을 정의할 수 있습니다.

* 그룹에는 반드시 그룹 규칙을 연결해야 합니다.
* 그룹 규칙에는 반드시 오브젝트 유형을 연결해야 하며, 그룹 규칙에는 하나의 오브젝트 유형만 연결됩니다.
* 스토리지 오브젝트는 각 모니터링 주기 후 또는 규칙이 생성, 편집 또는 삭제될 때 그룹에 추가되거나 제거됩니다.
* 그룹 규칙은 하나 이상의 조건 그룹을 가질 수 있으며, 각 조건 그룹은 하나 이상의 조건을 가질 수 있습니다.
* 스토리지 오브젝트는 사용자가 생성한 그룹 규칙에 따라 여러 그룹에 속할 수 있습니다.




[[conditions]]
== 조건

여러 개의 조건 그룹을 생성할 수 있으며, 각 조건 그룹에는 하나 이상의 조건을 포함할 수 있습니다. 정의된 모든 조건 그룹을 그룹 규칙에 적용하여 그룹에 포함될 스토리지 오브젝트를 지정할 수 있습니다.

조건 그룹 내의 조건은 논리 AND를 사용하여 실행됩니다. 조건 그룹의 모든 조건이 충족되어야 합니다. 그룹 규칙을 생성하거나 수정할 때, 해당 조건 그룹의 모든 조건을 만족하는 스토리지 오브젝트만 적용, 선택 및 그룹화하는 조건이 생성됩니다. 그룹에 포함할 스토리지 오브젝트의 범위를 좁히려면 조건 그룹 내에 여러 조건을 사용할 수 있습니다.

다음 피연산자와 연산자를 사용하고 필요한 값을 지정하여 스토리지 오브젝트로 조건을 생성할 수 있습니다.

|===
| 스토리지 오브젝트 유형 | 적용 가능한 피연산자

|===
스토리지 오브젝트의 피연산자로 주석을 선택하면 "`Is`" 연산자를 사용할 수 있습니다. 다른 모든 피연산자의 경우 "`Is`" 또는 "`Contains`" 중 하나를 연산자로 선택할 수 있습니다.

* 피연산자
+
Unified Manager의 피연산자 목록은 선택한 오브젝트 유형에 따라 변경됩니다. 이 목록에는 오브젝트 이름, 소유 클러스터 이름, 소유 SVM 이름 및 Unified Manager에서 정의한 주석이 포함됩니다.

* 운영자
+
조건에 대해 선택된 피연산자에 따라 연산자 목록이 변경됩니다. Unified Manager에서 지원하는 연산자는 "`Is`"와 "`Contains`"입니다.

+
"`Is`" 연산자를 선택하면 피연산자 값이 선택된 피연산자에 대해 제공된 값과 정확히 일치하는지 조건이 평가됩니다.

+
"`Contains`" 연산자를 선택하면 다음 기준 중 하나를 충족하도록 조건이 평가됩니다.

+
** 피연산자 값은 선택된 피연산자에 대해 제공된 값과 정확히 일치합니다
** 피연산자 값에는 선택된 피연산자에 대해 제공된 값이 포함됩니다


* 가치
+
값 필드는 선택된 피연산자에 따라 변경됩니다.





[[example-of-a-group-rule-with-conditions]]
== 조건을 포함하는 그룹 규칙의 예

다음 두 가지 조건이 있는 볼륨에 대한 조건 그룹을 고려해 보십시오.

* 이름에 "`vol`" 포함
* SVM 이름은 "`data_svm`"입니다


이 조건 그룹은 이름에 "`vol`"이 포함되어 있고 "`data_svm`"이라는 이름의 SVM에서 호스팅되는 모든 볼륨을 선택합니다.



[[condition-groups]]
== 조건 그룹

조건 그룹은 논리 OR 연산을 사용하여 실행된 후 스토리지 오브젝트에 적용됩니다. 스토리지 오브젝트는 그룹에 포함되려면 조건 그룹 중 하나를 만족해야 합니다. 모든 조건 그룹의 스토리지 오브젝트가 결합됩니다. 조건 그룹을 사용하면 그룹에 포함할 스토리지 오브젝트의 범위를 확장할 수 있습니다.



[[example-of-a-group-rule-with-condition-groups]]
== 조건 그룹을 사용한 그룹 규칙의 예

볼륨에 대해 두 개의 조건 그룹을 고려해 보겠습니다. 각 그룹에는 다음 두 가지 조건이 포함됩니다.

* 조건 그룹 1
+
** 이름에 "`vol`" 포함
** SVM 이름은 "`data_svm`"입니다. 조건 그룹 1은 이름에 "`vol`"이 포함되어 있고 "`data_svm`"이라는 이름의 SVM에서 호스팅되는 모든 볼륨을 선택합니다.


* 조건 그룹 2
+
** 이름에 "`vol`" 포함
** data-priority의 주석 값은 "`critical`"입니다. 조건 그룹 2는 이름에 "`vol`"이 포함되어 있고 data-priority 주석 값이 "`critical`"로 주석 처리된 모든 볼륨을 선택합니다.




이 두 조건 그룹을 포함하는 그룹 규칙이 스토리지 오브젝트에 적용되면 다음 스토리지 오브젝트가 선택된 그룹에 추가됩니다:

* 이름에 "`vol`"이 포함되어 있고 "`data_svm`"이라는 이름의 SVM에 호스팅된 모든 볼륨.
* 이름에 "`vol`"이 포함되어 있고 데이터 우선순위 주석 값 "`critical`"이 지정된 모든 볼륨.
