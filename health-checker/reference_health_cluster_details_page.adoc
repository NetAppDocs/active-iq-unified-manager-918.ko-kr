= Active IQ Unified Manager에서 클러스터/상태 세부 정보 페이지 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
클러스터/상태 세부 정보 페이지에서는 상태, 용량 및 구성 세부 정보 등 선택한 클러스터에 대한 자세한 정보를 제공합니다. 또한 클러스터의 네트워크 인터페이스(LIF), 노드, 디스크, 관련 장치 및 관련 경고에 대한 정보도 볼 수 있습니다.

클러스터 이름 옆에 표시되는 상태(예: 양호)는 통신 상태, 즉 Unified Manager가 해당 클러스터와 통신할 수 있는지 여부를 나타냅니다. 이는 장애 조치 상태 또는 클러스터의 전체 상태를 나타내는 것은 아닙니다.



[[command-buttons]]
== 명령 버튼

명령 버튼을 사용하면 선택한 클러스터에 대해 다음과 같은 작업을 수행할 수 있습니다:

* *성능 보기로 전환*
+
클러스터/성능 세부 정보 페이지로 이동할 수 있습니다.

* *작업*
+
** 경고 추가: 선택한 클러스터에 경고를 추가할 수 있는 경고 추가 대화 상자를 엽니다.
** 재탐색: 클러스터의 수동 새로 고침을 시작하여 Unified Manager가 클러스터의 최근 변경 사항을 탐색할 수 있도록 합니다.
+
Unified Manager가 OnCommand Workflow Automation과 페어링된 경우, 재탐색 작업은 WFA에서 캐시된 데이터(있는 경우)도 다시 가져옵니다.

+
재탐색 작업이 시작되면 관련 작업 세부 정보 링크가 표시되어 작업 상태를 추적할 수 있습니다.

** 주석 달기: 선택한 클러스터에 주석을 달 수 있습니다.


* *클러스터 보기*
+
상태: 모든 클러스터 보기로 이동할 수 있습니다.





[[health-tab]]
== 상태 탭

노드, SVM, 애그리게이트 등 다양한 클러스터 오브젝트의 데이터 가용성 및 데이터 용량 문제에 대한 자세한 정보를 표시합니다. 가용성 문제는 클러스터 오브젝트의 데이터 제공 능력과 관련이 있습니다. 용량 문제는 클러스터 오브젝트의 데이터 저장 능력과 관련이 있습니다.

오브젝트의 그래프를 클릭하여 필터링된 오브젝트 목록을 볼 수 있습니다. 예를 들어, 경고가 표시되는 SVM 용량 그래프를 클릭하여 필터링된 SVM 목록을 볼 수 있습니다. 이 목록에는 심각도 수준이 경고인 용량 문제가 있는 볼륨 또는 qtree가 있는 SVM이 포함되어 있습니다. 또한 경고가 표시되는 SVM 가용성 그래프를 클릭하여 심각도 수준이 경고인 가용성 문제가 있는 SVM 목록을 볼 수 있습니다.



[[availability-issues]]
=== 가용성 문제

가용성 문제가 있는 오브젝트와 가용성 관련 문제가 없는 오브젝트를 포함하여 전체 오브젝트 수를 그래픽으로 표시합니다. 그래프의 색상은 문제의 다양한 심각도 수준을 나타냅니다. 그래프 아래의 정보는 클러스터의 데이터 가용성에 영향을 미칠 수 있거나 이미 영향을 미친 가용성 문제에 대한 세부 정보를 제공합니다. 예를 들어, 다운된 디스크 셸프 및 오프라인 상태인 애그리게이트에 대한 정보가 표시됩니다.

[NOTE]
====
SFO 막대 그래프에 표시되는 데이터는 노드의 HA 상태를 기반으로 합니다. 다른 모든 막대 그래프에 표시되는 데이터는 생성된 이벤트를 기반으로 계산됩니다.

====


[[capacity-issues]]
=== 용량 문제

용량 문제가 있는 오브젝트와 용량 관련 문제가 없는 오브젝트를 포함하여 전체 오브젝트 수를 그래픽으로 표시합니다. 그래프의 색상은 문제의 다양한 심각도 수준을 나타냅니다. 그래프 아래의 정보는 클러스터의 데이터 용량에 영향을 미칠 수 있거나 이미 영향을 미친 용량 문제에 대한 세부 정보를 제공합니다. 예를 들어, 설정된 임계값을 초과할 가능성이 있는 애그리게이트에 대한 정보가 표시됩니다.



[[capacity-tab]]
== 용량 탭

선택한 클러스터의 용량에 대한 자세한 정보를 표시합니다.



[[capacity]]
=== 용량

할당된 모든 애그리게이트의 사용 용량 및 사용 가능 용량에 대한 데이터 용량 그래프를 표시합니다:

* 사용된 논리적 공간
+
ONTAP 스토리지 효율성 기술 사용으로 인한 절감 효과를 적용하지 않았을 때, 이 클러스터의 모든 애그리게이트에 저장되는 실제 데이터 크기입니다. Snapshot 복사본은 포함되지 않습니다.

* 데이터 축소
+
Snapshot 복사본을 제외한 비율을 유효숫자 두 자리까지 표시합니다(예: 1.8 대 1). 이 비율은 구성된 ONTAP 스토리지 효율성 설정에 따라 계산됩니다.

* 사용됨
+
모든 애그리게이트의 데이터에서 사용되는 물리적 용량입니다. 여기에는 패리티, 적정 규모 조정 및 예약에 사용되는 용량은 포함되지 않습니다.

* 사용 가능
+
데이터 저장에 사용 가능한 용량을 표시합니다.

* 예비 부품
+
모든 예비 디스크에 저장 가능한 용량을 표시합니다.

* 프로비저닝됨
+
모든 하위 볼륨에 대해 프로비저닝된 용량을 표시합니다.





[[details]]
=== 세부 정보

사용 용량과 가용 용량에 대한 자세한 정보를 표시합니다. 이 계산에는 루트 애그리게이트 데이터가 제외됩니다.

* 총 용량
+
클러스터의 총 용량을 표시합니다. 여기에는 패리티에 할당된 용량은 포함되지 않습니다.

* 사용됨
+
데이터에 사용된 용량을 표시합니다. 여기에는 패리티, 적정 크기 조정 및 예약에 사용된 용량은 포함되지 않습니다.

* 사용 가능
+
데이터 저장에 사용 가능한 용량을 표시합니다.

* 프로비저닝됨
+
모든 하위 볼륨에 대해 프로비저닝된 용량을 표시합니다.

* 예비 부품
+
모든 예비 디스크에 저장 가능한 용량을 표시합니다.





[[cloud-tier]]
=== 클라우드 티어

클러스터에서 FabricPool이 활성화된 애그리게이트에 대해 사용된 총 클라우드 티어 용량과 연결된 각 클라우드 티어에 사용된 용량을 표시합니다. FabricPool은 라이선스가 있거나 없을 수 있습니다.



[[physical-capacity-breakout-by-disk-type]]
=== 디스크 유형별 물리적 용량 분석

디스크 유형별 물리적 용량 분석 영역에는 클러스터에 있는 다양한 디스크 유형의 용량에 대한 자세한 정보가 표시됩니다. 디스크 유형을 클릭하면 디스크 탭에서 해당 디스크 유형에 대한 자세한 정보를 볼 수 있습니다.

* 총 사용 가능 용량
+
데이터 디스크의 사용 가능한 용량과 여유 용량을 표시합니다.

* HDD
+
클러스터에 있는 모든 HDD 데이터 디스크의 사용 용량과 사용 가능 용량을 그래프로 표시합니다. 점선은 HDD 데이터 디스크의 여유 용량을 나타냅니다.

* 플래시
+
** SSD Data
+
클러스터 내 SSD 데이터 디스크의 사용 용량과 사용 가능 용량을 그래프로 표시합니다.

** SSD 캐시
+
클러스터 내 SSD 캐시 디스크의 저장 가능 용량을 그래프로 표시합니다.

** SSD 스페어
+
클러스터 내 SSD, 데이터 디스크 및 캐시 디스크의 여유 용량을 그래프로 표시합니다.



* 할당되지 않은 디스크
+
클러스터에서 할당되지 않은 디스크 수를 표시합니다.





[[aggregates-with-capacity-issues-list]]
=== 용량 문제가 있는 애그리게이트 목록

용량 위험 문제가 있는 애그리게이트의 사용 용량 및 사용 가능 용량에 대한 세부 정보를 표 형식으로 표시합니다.

* 상태
+
애그리게이트에 특정 심각도의 용량 관련 문제가 있음을 나타냅니다.

+
상태 위로 포인터를 이동하면 해당 애그리게이트에 대해 생성된 이벤트에 대한 자세한 정보를 볼 수 있습니다.

+
애그리게이트의 상태가 단일 이벤트에 의해 결정되는 경우, 이벤트 이름, 이벤트가 트리거된 시간 및 날짜, 이벤트가 할당된 관리자 이름, 이벤트 원인 등의 정보를 볼 수 있습니다. *View Details* 버튼을 클릭하면 이벤트에 대한 자세한 정보를 볼 수 있습니다.

+
애그리게이트의 상태가 동일한 심각도의 여러 이벤트로 인해 결정되는 경우, 이벤트 이름, 이벤트가 트리거된 시간 및 날짜, 이벤트가 할당된 관리자 이름 등의 정보와 함께 상위 3개의 이벤트가 표시됩니다. 이벤트 이름을 클릭하면 각 이벤트에 대한 자세한 내용을 볼 수 있습니다. 또한 *모든 이벤트 보기* 링크를 클릭하여 생성된 이벤트 목록을 볼 수 있습니다.

+
[NOTE]
====
애그리게이트에는 심각도가 동일하거나 서로 다른 여러 용량 관련 이벤트가 포함될 수 있습니다. 그러나 가장 높은 심각도만 표시됩니다. 예를 들어, 애그리게이트에 심각도 수준이 Error와 Critical인 이벤트가 두 개 있는 경우 Critical 심각도만 표시됩니다.

====
* 애그리게이트
+
애그리게이트의 이름을 표시합니다.

* 사용된 데이터 용량
+
애그리게이트 용량 사용률(백분율)에 대한 정보를 그래프로 표시합니다.

* 가득 찰 때까지 남은 일수
+
애그리게이트가 전체 용량에 도달하기까지 남은 예상 일수를 표시합니다.





[[configuration-tab]]
== 구성 탭

IP 주소, 연락처, 위치 등 선택한 클러스터에 대한 세부 정보를 표시합니다:



[[cluster-overview]]
=== 클러스터 개요

* 관리 인터페이스
+
Unified Manager가 클러스터에 연결하는 데 사용하는 클러스터 관리 LIF를 표시합니다. 인터페이스의 작동 상태도 표시됩니다.

* 호스트 이름 또는 IP 주소
+
Unified Manager가 클러스터에 연결하는 데 사용하는 클러스터 관리 LIF의 FQDN, 짧은 이름 또는 IP 주소를 표시합니다.

* FQDN
+
클러스터의 정규화된 도메인 이름(FQDN)을 표시합니다.

* OS 버전
+
클러스터에서 실행 중인 ONTAP 버전을 표시합니다. 클러스터의 노드에서 서로 다른 버전의 ONTAP을 실행 중인 경우 가장 이전의 ONTAP 버전이 표시됩니다.

* 연락처
+
클러스터 관련 문제가 발생했을 경우 연락해야 할 관리자에 대한 세부 정보를 표시합니다.

* 위치
+
클러스터의 위치를 표시합니다.

* 특성
+
이것이 All SAN Array로 구성된 클러스터인지 확인합니다.





[[remote-cluster-overview]]
=== 원격 클러스터 개요

MetroCluster 구성의 원격 클러스터에 대한 세부 정보를 제공합니다. 이 정보는 MetroCluster 구성에서만 표시됩니다.

* 클러스터
+
원격 클러스터의 이름을 표시합니다. 클러스터 이름을 클릭하면 해당 클러스터의 세부 정보 페이지로 이동할 수 있습니다.

* 호스트 이름 또는 IP 주소
+
원격 클러스터의 FQDN, 약칭 또는 IP 주소를 표시합니다.

* 위치
+
원격 클러스터의 위치를 표시합니다.





[[metrocluster-overview]]
=== MetroCluster 개요

FC 기반 MetroCluster 또는 IP 기반 MetroCluster 구성의 로컬 클러스터에 대한 세부 정보를 제공합니다. 이 정보는 FC 또는 IP 기반 MetroCluster 구성에 대해서만 표시됩니다.

* 유형
+
MetroCluster 유형이 2노드인지 4노드인지 표시합니다. IP 기반 MetroCluster의 경우 4노드만 지원됩니다.

* 구성
+
FC 및 IP를 통한 MetroCluster 구성을 표시하며, 다음과 같은 값을 가질 수 있습니다:



*FC용*

* SAS 케이블을 사용한 스트레치 구성
* FC-SAS 브리지를 사용한 스트레치 구성
* FC 스위치를 사용한 패브릭 구성
+
[NOTE]
====
4노드 MetroCluster의 경우 FC 스위치를 사용하는 패브릭 구성만 지원됩니다.

====


*IP용*

* 이더넷 스위치를 사용한 IP 구성(클러스터 구성 방식에 따라 L2 또는 L3)
+
** 자동 비계획 전환(AUSO)
+
로컬 클러스터에 대해 자동화된 계획되지 않은 전환이 활성화되어 있는지 여부를 표시합니다. 기본적으로 Unified Manager의 2노드 MetroCluster 구성에 있는 모든 클러스터에 대해 AUSO가 활성화되어 있습니다. 명령줄 인터페이스를 사용하여 AUSO 설정을 변경할 수 있습니다. 이 기능은 FC 기반 MetroCluster에서만 지원됩니다.

** 전환 모드
+
MetroCluster over IP 구성에 대한 스위치오버 모드를 표시합니다. 사용 가능한 값은  `Active`,  `Negotiated Switchover` 및  `Automatic Unplanned Switchover`입니다.

[[metrocluster-connectivity-tab]]
== MetroCluster 연결 탭

FC 기반 MetroCluster 구성에서 클러스터 구성 요소의 문제 및 연결 상태를 표시합니다. 클러스터의 재해 복구 파트너에 문제가 발생하면 해당 클러스터는 빨간색 상자로 표시됩니다.

[NOTE]
====
MetroCluster 연결 탭은 MetroCluster over FC 구성에 있는 클러스터에만 표시됩니다.

====
원격 클러스터의 이름을 클릭하여 원격 클러스터의 상세 페이지로 이동할 수 있습니다. 또한 구성 요소의 개수 링크를 클릭하여 구성 요소의 상세 정보를 볼 수도 있습니다. 예를 들어, 클러스터의 노드 개수 링크를 클릭하면 클러스터의 상세 페이지에 노드 탭이 표시됩니다. 원격 클러스터의 디스크 개수 링크를 클릭하면 원격 클러스터의 상세 페이지에 디스크 탭이 표시됩니다.

[NOTE]
====
8노드 MetroCluster 구성을 관리할 때 디스크 셸프 구성 요소의 개수 링크를 클릭하면 기본 HA 쌍의 로컬 셸프만 표시됩니다. 또한 다른 HA 쌍의 로컬 셸프를 표시할 방법이 없습니다.

====
구성 요소 위로 포인터를 이동하면 문제 발생 시 클러스터의 세부 정보와 연결 상태를 확인할 수 있으며, 문제와 관련하여 생성된 이벤트에 대한 자세한 정보도 볼 수 있습니다.

구성 요소 간 연결 문제 상태가 단일 이벤트로 결정되는 경우, 이벤트 이름, 이벤트가 트리거된 시간 및 날짜, 이벤트가 할당된 관리자 이름, 이벤트 원인 등의 정보를 확인할 수 있습니다. 세부 정보 보기 버튼은 이벤트에 대한 더 자세한 정보를 제공합니다.

구성 요소 간 연결 문제 상태가 동일한 심각도의 여러 이벤트로 결정되는 경우, 이벤트 이름, 이벤트 발생 시간 및 날짜, 이벤트가 할당된 관리자 이름 등의 정보와 함께 상위 3개의 이벤트가 표시됩니다. 이벤트 이름을 클릭하면 각 이벤트에 대한 자세한 내용을 볼 수 있습니다. 또한 *모든 이벤트 보기* 링크를 클릭하여 생성된 이벤트 목록을 확인할 수 있습니다.



[[metrocluster-replication-tab]]
== MetroCluster 복제 탭

FC 기반 MetroCluster 구성에서 복제 중인 데이터의 상태를 표시합니다. MetroCluster 복제 탭을 사용하여 이미 피어링된 클러스터와 데이터를 동기적으로 미러링하여 데이터 보호를 보장할 수 있습니다. 클러스터의 재해 복구 파트너에 문제가 발생하면 해당 클러스터는 빨간색 상자로 표시됩니다.

[NOTE]
====
MetroCluster 복제 탭은 MetroCluster over FC 구성에 있는 클러스터에만 표시됩니다.

====
MetroCluster 환경에서는 이 탭을 사용하여 로컬 클러스터와 원격 클러스터 간의 논리적 연결 및 피어링을 확인할 수 있습니다. 클러스터 구성 요소와 해당 논리적 연결을 객관적으로 시각화하여 볼 수 있습니다. 이를 통해 메타데이터 및 데이터 미러링 중에 발생할 수 있는 문제를 식별하는 데 도움이 됩니다.

MetroCluster 복제 탭에서 로컬 클러스터는 선택한 클러스터에 대한 자세한 그래픽 표현을 제공하며, MetroCluster 파트너는 원격 클러스터를 나타냅니다.

== 노드 탭

선택한 클러스터의 노드에 대한 정보를 표시합니다. HA 쌍, 디스크 쉘프 및 포트에 대한 자세한 정보를 볼 수 있습니다:



[[ha-details]]
=== HA 세부 정보

HA 상태와 HA 쌍을 구성하는 노드의 상태를 그림으로 보여줍니다. 노드의 상태는 다음과 같은 색상으로 표시됩니다.

* *녹색*
+
해당 노드는 정상 작동 상태입니다.

* *노란색*
+
해당 노드가 파트너 노드를 테이크오버했거나 환경적인 문제에 직면했습니다.

* *빨간색*
+
해당 노드가 다운되었습니다.



HA 페어의 가용성에 대한 정보를 확인하고 위험을 방지하기 위해 필요한 조치를 취할 수 있습니다. 예를 들어, 테이크오버 작업이 발생할 가능성이 있는 경우 다음 메시지가 표시됩니다. Storage failover possible.

팬, 전원 공급 장치, NVRAM 배터리, 플래시 카드, 서비스 프로세서 및 디스크 쉘프 연결 등 HA 쌍 및 해당 환경과 관련된 이벤트 목록을 볼 수 있습니다. 이벤트가 발생한 시간도 확인할 수 있습니다.

모델 번호 등 다른 노드 관련 정보를 확인할 수 있습니다.

단일 노드 클러스터가 있는 경우 노드에 대한 세부 정보도 볼 수 있습니다.



[[disk-shelves]]
=== 디스크 쉘프

HA 쌍의 디스크 쉘프에 대한 정보를 표시합니다.

디스크 쉘프 및 환경 구성 요소에 대해 생성된 이벤트와 이벤트가 발생한 시간도 확인할 수 있습니다.

* *쉘프 ID*
+
디스크가 위치한 쉘프의 ID를 표시합니다.

* *구성 요소 상태*
+
전원 공급 장치, 팬, 온도 센서, 전류 센서, 디스크 연결 상태, 전압 센서 등 디스크 쉘프의 환경 세부 정보를 표시합니다. 환경 세부 정보는 다음 색상의 아이콘으로 표시됩니다.

+
** *녹색*
+
환경 구성 요소가 제대로 작동하고 있습니다.

** *Grey*
+
환경 요소에 대한 데이터는 없습니다.

** *빨간색*
+
환경 구성 요소 중 일부가 다운되었습니다.



* *상태*
+
디스크 쉘프의 상태를 표시합니다. 가능한 상태는 오프라인, 온라인, 상태 없음, 초기화 필요, 누락, 알 수 없음입니다.

* *모델*
+
디스크 쉘프의 모델 번호를 표시합니다.

* *로컬 디스크 쉘프*
+
디스크 쉘프가 로컬 클러스터에 있는지 원격 클러스터에 있는지 여부를 나타냅니다. 이 열은 MetroCluster 구성의 클러스터에 대해서만 표시됩니다.

* *고유 ID*
+
디스크 쉘프의 고유 식별자를 표시합니다.

* *펌웨어 버전*
+
디스크 쉘프의 펌웨어 버전을 표시합니다.





[[ports]]
=== 포트

연결된 FC, FCoE 및 이더넷 포트에 대한 정보를 표시합니다. 포트 아이콘을 클릭하면 포트 및 연결된 LIF에 대한 세부 정보를 볼 수 있습니다.

포트에 대해 생성된 이벤트도 확인할 수 있습니다.

다음 포트 정보를 확인할 수 있습니다:

* 포트 ID
+
포트 이름을 표시합니다. 예를 들어 포트 이름은 e0M, e0a, e0b 등이 될 수 있습니다.

* 역할
+
포트의 역할을 표시합니다. 가능한 역할은 클러스터, 데이터, 클러스터 간, 노드 관리 및 정의되지 않음입니다.

* 유형
+
포트에 사용되는 물리 계층 프로토콜을 표시합니다. 가능한 유형은 이더넷, 파이버 채널 및 FCoE입니다.

* WWPN
+
포트의 World Wide Port Name(WWPN)을 표시합니다.

* 펌웨어 버전
+
FC/FCoE 포트의 펌웨어 버전을 표시합니다.

* 상태
+
포트의 현재 상태를 표시합니다. 가능한 상태는 Up, Down, Link Not Connected 또는 Unknown (image:../media/hastate_unknown.gif["HA 상태 아이콘 – 알 수 없음"])입니다.

+
이벤트 목록에서 포트 관련 이벤트를 확인할 수 있습니다. 또한 LIF 이름, 운영 상태, IP 주소 또는 WWPN, 프로토콜, LIF와 연결된 SVM 이름, 현재 포트, 페일오버 정책 및 페일오버 그룹 등 연결된 LIF 세부 정보를 확인할 수도 있습니다.





[[disks-tab]]
== 디스크 탭

선택한 클러스터의 디스크에 대한 세부 정보를 표시합니다. 사용 중인 디스크 수, 예비 디스크 수, 손상된 디스크 수, 할당되지 않은 디스크 수 등 디스크 관련 정보를 볼 수 있습니다. 또한 디스크 이름, 디스크 유형, 디스크의 소유자 노드 등 기타 세부 정보도 확인할 수 있습니다.



[[disk-pool-summary]]
=== 디스크 풀 요약

유효 유형(FCAL, SAS, SATA, MSATA, SSD, NVMe SSD, SSD CAP, Array LUN 및 VMDISK) 및 디스크 상태별로 분류된 디스크 수를 표시합니다. 또한 어그리게이트, 공유 디스크, 예비 디스크, 고장난 디스크, 할당되지 않은 디스크, 지원되지 않는 디스크의 수 등 기타 세부 정보도 확인할 수 있습니다. 유효 디스크 유형 개수 링크를 클릭하면 선택한 상태 및 유효 유형의 디스크가 표시됩니다. 예를 들어, 디스크 상태 Broken 및 유효 유형 SAS에 대한 개수 링크를 클릭하면 디스크 상태가 Broken이고 유효 유형이 SAS인 모든 디스크가 표시됩니다.



[[disk]]
=== 디스크

디스크 이름을 표시합니다.



[[raid-groups]]
=== RAID 그룹

RAID 그룹의 이름을 표시합니다.



[[owner-node]]
=== 소유자 노드

디스크가 속한 노드의 이름을 표시합니다. 디스크가 할당되지 않은 경우 이 열에는 값이 표시되지 않습니다.



[[state]]
=== 상태

디스크 상태(Aggregate, 공유, 스페어, 손상, 할당되지 않음, 지원되지 않음 또는 알 수 없음)를 표시합니다. 기본적으로 이 열은 손상, 할당되지 않음, 지원되지 않음, 스페어, Aggregate, 공유 순서로 정렬되어 표시됩니다.



[[local-disk]]
=== 로컬 디스크

디스크가 로컬 클러스터에 있는지 원격 클러스터에 있는지 여부를 예 또는 아니요로 표시합니다. 이 열은 MetroCluster 구성의 클러스터에만 표시됩니다.



[[position]]
=== 위치

디스크의 위치를 컨테이너 유형(예: 복사, 데이터 또는 패리티)에 따라 표시합니다. 이 열은 기본적으로 숨겨져 있습니다.



[[impacted-aggregates]]
=== 영향을 받는 애그리게이트

오류 발생 디스크로 인해 영향을 받는 애그리게이트 수를 표시합니다. 포인터를 개수 링크 위로 이동하면 영향을 받는 애그리게이트를 볼 수 있으며, 애그리게이트 이름을 클릭하면 해당 애그리게이트의 세부 정보를 볼 수 있습니다. 또한 애그리게이트 개수를 클릭하면 상태: 모든 애그리게이트 보기에서 영향을 받는 애그리게이트 목록을 볼 수 있습니다.

다음과 같은 경우에는 이 열에 값이 표시되지 않습니다:

* 이러한 디스크가 포함된 클러스터가 Unified Manager에 추가될 때의 손상된 디스크의 경우
* 오류 발생 디스크가 없을 경우




[[storage-pool]]
=== 스토리지 풀

SSD가 속한 스토리지 풀의 이름을 표시합니다. 스토리지 풀 이름 위로 포인터를 이동하여 스토리지 풀의 세부 정보를 확인할 수 있습니다.



[[storable-capacity]]
=== 저장 용량

사용 가능한 디스크 용량을 표시합니다.



[[raw-capacity]]
=== Raw 용량

적정 크기 조정 및 RAID 구성 이전의 포맷되지 않은 원시 디스크 용량을 표시합니다. 기본적으로 이 열은 숨겨져 있습니다.



[[type]]
=== 유형

ATA, SATA, FCAL 또는 VMDISK 등 디스크의 종류를 표시합니다.



[[effective-type]]
=== 유효 유형

ONTAP에서 할당한 디스크 유형을 표시합니다.

특정 ONTAP 디스크 유형은 애그리게이트 생성 및 추가, 예비 디스크 관리 목적상 동일한 것으로 간주됩니다. ONTAP은 각 디스크 유형에 대해 유효한 디스크 유형을 할당합니다.



[[spare-blocks-consumed]]
=== 예비 블록 소모 %

SSD 디스크에서 사용되는 예비 블록의 비율을 백분율로 표시합니다. SSD 디스크 이외의 디스크의 경우 이 열은 비어 있습니다.



[[rated-life-used]]
=== 정격 수명 사용 %

실제 SSD 사용량과 제조업체의 SSD 수명 예측치를 기반으로 추정한 SSD 수명 사용률을 백분율로 표시합니다. 99보다 큰 값은 예상 수명이 다했음을 나타내지만, SSD 고장을 의미하는 것은 아닙니다. 값을 알 수 없는 경우 해당 디스크는 생략됩니다.



[[firmware]]
=== 펌웨어

디스크의 펌웨어 버전을 표시합니다.



[[rpm]]
=== RPM

디스크의 분당 회전수(RPM)를 표시합니다. 기본적으로 이 열은 숨겨져 있습니다.



[[model]]
=== 모델

디스크의 모델 번호를 표시합니다. 기본적으로 이 열은 숨겨져 있습니다.



[[vendor]]
=== 공급업체

디스크 공급업체의 이름을 표시합니다. 기본적으로 이 열은 숨겨져 있습니다.



[[shelf-id]]
=== 쉘프 ID

디스크가 위치한 쉘프의 ID를 표시합니다.



[[bay]]
=== 베이

디스크가 위치한 베이의 ID를 표시합니다.



[[related-annotations-pane]]
== 관련 주석 창

선택한 클러스터와 관련된 주석 세부 정보를 볼 수 있습니다. 세부 정보에는 주석 이름과 클러스터에 적용된 주석 값이 포함됩니다. 관련 주석 창에서 수동 주석을 제거할 수도 있습니다.



[[related-devices-pane]]
== 관련 장치 창

선택한 클러스터와 연결된 장치 세부 정보를 볼 수 있습니다.

세부 정보에는 장치 유형, 크기, 개수, 상태 등 클러스터에 연결된 장치의 속성이 포함됩니다. 특정 장치에 대한 추가 분석을 위해 개수 링크를 클릭할 수 있습니다.

MetroCluster 파트너 창을 사용하여 노드, 애그리게이트, SVM 등 관련 클러스터 구성 요소와 함께 원격 MetroCluster 파트너에 대한 개수 및 세부 정보를 확인할 수 있습니다. MetroCluster 파트너 창은 MetroCluster 구성의 클러스터에만 표시됩니다.

관련 장치 창을 사용하면 클러스터와 관련된 노드, SVM 및 애그리게이트를 보고 탐색할 수 있습니다:



[[metrocluster-partner]]
=== MetroCluster 파트너

MetroCluster 파트너의 상태를 표시합니다. 카운트 링크를 사용하여 추가로 탐색하여 클러스터 구성 요소의 상태 및 용량에 대한 정보를 얻을 수 있습니다.



[[nodes]]
=== 노드

선택한 클러스터에 속한 노드의 개수, 용량 및 상태를 표시합니다. 용량은 가용 용량 대비 총 사용 가능한 용량을 나타냅니다.



[[storage-virtual-machines]]
=== 스토리지 가상 머신

선택한 클러스터에 속하는 SVM의 개수를 표시합니다.



[[aggregates]]
=== 애그리게이트

선택한 클러스터에 속하는 애그리게이트의 개수, 용량 및 상태를 표시합니다.



[[related-groups-pane]]
== 관련 그룹 창

선택한 클러스터가 포함된 그룹 목록을 볼 수 있습니다.



[[related-alerts-pane]]
== 관련 알림 창

관련 알림 창에서는 선택한 클러스터에 대한 알림 목록을 볼 수 있습니다. 알림 추가 링크를 클릭하여 알림을 추가하거나 알림 이름을 클릭하여 기존 알림을 편집할 수도 있습니다.
