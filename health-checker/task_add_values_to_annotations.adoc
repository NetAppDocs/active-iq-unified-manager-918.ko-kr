= Active IQ Unified Manager에서 주석에 값 추가
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
어노테이션에 값을 추가한 다음 특정 어노테이션 이름-값 쌍에 스토리지 오브젝트를 연결할 수 있습니다. 어노테이션에 값을 추가하면 스토리지 오브젝트를 더욱 효율적으로 관리할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

미리 정의된 어노테이션에 값을 추가할 수 없습니다.

.단계
. 왼쪽 탐색 창에서 *스토리지 관리* > *주석*을 클릭합니다.
. *주석* 페이지에서 값을 추가할 주석을 선택한 다음 *값* 섹션에서 *추가*를 클릭합니다.
. *주석 값 추가* 대화 상자에서 주석에 대한 값을 지정합니다.
+
지정하는 값은 선택한 주석에 대해 고유해야 합니다.

. *추가*를 클릭합니다.
