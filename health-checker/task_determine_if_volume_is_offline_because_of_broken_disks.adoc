= Active IQ Unified Manager에서 디스크 장애로 인해 볼륨이 오프라인 상태인지 확인합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 웹 UI를 사용하여 RAID 디스크 문제로 인해 호스트 애그리게이트가 오프라인 상태가 되어 볼륨이 오프라인 상태가 되었을 가능성을 확인하거나 배제할 수 있습니다.

.시작하기 전에
운영자, 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

호스팅 애그리게이트를 오프라인 상태로 만드는 RAID 디스크 문제로 인해 볼륨이 오프라인 상태가 되었는지 확인하려면 다음 작업을 수행하십시오.

.단계
. *볼륨 / 상태* 세부 정보 페이지의 *관련 장치* 창에서 애그리게이트 아래에 표시된 하이퍼텍스트 링크를 찾아 클릭합니다.
+
애그리게이트/상태 세부 정보 페이지에는 호스팅 애그리게이트의 온라인 또는 오프라인 상태가 표시됩니다. 애그리게이트 상태가 온라인인 경우 RAID 디스크 문제는 볼륨이 오프라인 상태인 원인이 아닙니다.

. 애그리게이트 상태가 오프라인인 경우 *디스크 정보*를 클릭하고 *디스크 정보* 탭의 *이벤트* 목록에서 손상된 디스크 이벤트를 찾으십시오.
. 손상된 디스크를 더 자세히 확인하려면 *관련 장치* 창의 노드 아래에 표시된 하이퍼텍스트 링크를 클릭하십시오.
+
클러스터/상태 세부 정보 페이지가 표시됩니다.

. *디스크*를 클릭한 다음 *필터* 창에서 *손상됨*을 선택하여 손상 상태인 모든 디스크 목록을 표시합니다.
+
디스크 손상으로 인해 호스트 애그리게이트가 오프라인 상태가 된 경우, 영향을 받은 애그리게이트 열에 해당 애그리게이트 이름이 표시됩니다.



볼륨 오프라인 상태가 RAID 디스크 손상 및 그로 인한 호스트 어그리게이트 오프라인 상태 때문임을 확인한 후, 담당 관리자 또는 운영자에게 연락하여 손상된 디스크를 수동으로 교체하고 어그리게이트를 다시 온라인 상태로 전환하십시오.
