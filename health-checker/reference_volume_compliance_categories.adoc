= Active IQ Unified Manager에서 볼륨 규정 준수 범주 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이 표는 Unified Manager가 볼륨의 데이터가 무단 사용자의 접근으로부터 적절하게 보호되는지 여부를 판단하기 위해 평가하는 볼륨 암호화 매개변수를 설명합니다.

참고로 볼륨 암호화 매개변수는 클러스터 또는 스토리지 VM의 규정 준수 여부에 영향을 미치지 않습니다.

[cols="2*"]
|===
| 매개변수 | 설명 


 a| 
소프트웨어 암호화
 a| 
NetApp 볼륨 암호화(NVE) 또는 NetApp 애그리게이트 암호화(NAE) 소프트웨어 암호화 솔루션을 사용하여 보호되는 볼륨 수를 표시합니다.



 a| 
하드웨어 암호화
 a| 
NetApp 스토리지 암호화(NSE) 하드웨어 암호화를 사용하여 보호되는 볼륨 수를 표시합니다.



 a| 
소프트웨어 및 하드웨어 암호화
 a| 
소프트웨어 및 하드웨어 암호화로 모두 보호되는 볼륨 수를 표시합니다.



 a| 
암호화되지 않음
 a| 
암호화되지 않은 볼륨 수를 표시합니다.

|===
