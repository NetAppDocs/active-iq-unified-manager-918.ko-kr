= AutoSupport 메시지를 Active IQ Unified Manager의 기술 지원에 전송합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AutoSupport 페이지를 사용하면 미리 정의되거나 필요에 따라 전송되는 AutoSupport 메시지를 기술 지원 팀에 보내 환경의 올바른 작동을 보장하고 환경의 무결성을 유지하는 데 도움을 받을 수 있습니다. AutoSupport는 기본적으로 활성화되어 있으며, NetAppActive IQ의 이점을 누리려면 비활성화해서는 안 됩니다.

필요에 따라 Unified Manager 서버에 대한 진단 시스템 정보 및 상세 데이터를 메시지로 전송하거나, 주기적으로 메시지를 전송하도록 예약하거나, 기술 지원 팀에 지원 번들을 생성하여 전송할 수도 있습니다.

[NOTE]
====
스토리지 관리자 역할을 가진 사용자는 필요에 따라 AutoSupport 메시지와 지원 번들을 생성하여 기술 지원에 보낼 수 있습니다. 그러나 관리자 또는 유지보수 사용자만 주기적인 AutoSupport를 설정 또는 해제하고 HTTP 프록시 서버 설정 섹션에 설명된 대로 HTTP 설정을 구성할 수 있습니다. HTTP 프록시 서버를 사용해야 하는 환경에서는 스토리지 관리자가 필요에 따라 AutoSupport 메시지와 지원 번들을 기술 지원에 보내기 전에 구성을 완료해야 합니다.

====


[[send-on-demand-autosupport-messages]]
== 온디맨드 AutoSupport 메시지 전송

기술 지원이나 지정된 이메일 수신자 또는 둘 다에게 온디맨드 메시지를 생성하여 보낼 수 있습니다.

.단계
. *일반* > *AutoSupport*(으)로 이동하여 다음 작업 중 하나 또는 둘 다를 수행하십시오:
. AutoSupport 메시지를 기술 지원에 보내려면 *기술 지원에 보내기* 확인란을 선택합니다.
. AutoSupport 메시지를 특정 이메일 수신자에게 보내려면 *이메일 수신자에게 보내기* 확인란을 선택하고 수신자의 이메일 주소를 입력하십시오.
. *저장*을 클릭합니다.
. *AutoSupport 생성 및 전송*을 클릭합니다.




[[enable-periodic-autosupport]]
== 주기적인 AutoSupport 활성화

문제 진단 및 해결을 위해 특정 사전 정의된 메시지를 기술 지원에 주기적으로 보낼 수 있습니다. 이 기능은 기본적으로 활성화되어 있습니다. 비활성화된 경우 관리자 또는 유지보수 사용자가 설정을 활성화할 수 있습니다.

.단계
. *일반* > *AutoSupport*로 이동합니다.
. 주기적 AutoSupport 섹션에서 *Active IQ로 주기적으로 AutoSupport 데이터 전송 활성화* 확인란을 선택합니다.
. 필요한 경우, HTTP 프록시 서버 설정 섹션에 설명된 대로 HTTP 프록시 서버의 이름, 포트 및 인증 정보를 정의하십시오.
. *저장*을 클릭합니다.




[[upload-on-demand-support-bundle]]
== 주문형 지원 번들 업로드

문제 해결 요구 사항에 따라 지원 번들을 생성하여 기술 지원에 전송할 수 있습니다. Unified Manager는 가장 최근에 생성된 지원 번들 두 개만 저장합니다. 오래된 지원 번들은 시스템에서 삭제됩니다.

일부 지원 데이터 유형은 클러스터 리소스를 많이 사용하거나 완료하는 데 오랜 시간이 걸릴 수 있으므로, 전체 지원 번들을 선택할 때 특정 데이터 유형을 포함하거나 제외하여 지원 번들 크기를 줄일 수 있습니다. 또한 성능 데이터, 수집 기록 파일 및 서버 힙 덤프를 제외하고 30일간의 로그 및 구성 데이터베이스 레코드만 포함하는 경량 지원 번들을 생성하는 옵션도 있습니다.

.단계
. *일반* > *AutoSupport*로 이동합니다.
. 온디맨드 지원 번들 섹션에서 *지원 번들 생성 및 전송*을 클릭합니다.
. 기술 지원에 간단한 지원 번들을 전송하려면 지원 번들 생성 및 전송 팝업에서 **간단한 지원 번들 생성** 확인란을 선택합니다.
. 또는 전체 지원 번들을 보내려면 *전체 지원 번들 생성* 확인란을 선택하십시오. 지원 번들에 포함하거나 제외할 특정 데이터 유형을 선택하십시오.
+
[NOTE]
====
데이터 유형을 선택하지 않더라도 지원 번들은 다른 Unified Manager 데이터와 함께 생성됩니다.

====
. 번들을 생성하여 기술 지원에 전송하려면 *기술 지원으로 번들 전송* 확인란을 선택합니다. 이 확인란을 선택하지 않으면 번들이 생성되어 Unified Manager 서버에 로컬로 저장됩니다. 생성된 지원 번들은 나중에 사용할 수 있도록 VMware 시스템의 경우 /support 디렉터리, Linux 시스템의 경우  `/opt/netapp/data/support/`, Windows 시스템의 경우  `ProgramData\NetApp\OnCommandAppData\ocum\support`에서 사용할 수 있습니다.
. *보내기*를 클릭합니다.




[[set-up-http-proxy-server]]
== HTTP 프록시 서버 설정

Unified Manager 서버에서 직접 액세스할 수 없는 환경의 경우, AutoSupport 콘텐츠를 지원팀에 전송하기 위해 인터넷 액세스를 제공하는 프록시를 지정할 수 있습니다. 이 섹션은 관리자 및 유지 관리 사용자만 사용할 수 있습니다.

* *HTTP 프록시 사용*
+
HTTP 프록시로 사용 중인 서버를 식별하려면 이 확인란을 선택하십시오.

+
프록시 서버의 호스트 이름 또는 IP 주소와 서버 연결에 사용되는 포트 번호를 입력하십시오.

* *인증 사용*
+
HTTP 프록시로 사용되는 서버에 액세스하기 위해 인증 정보를 제공해야 하는 경우 이 확인란을 선택합니다.

+
HTTP 프록시로 인증하는 데 필요한 사용자 이름과 암호를 입력하십시오.



[NOTE]
====
기본 인증만 제공하는 HTTP 프록시는 지원되지 않습니다.

====
