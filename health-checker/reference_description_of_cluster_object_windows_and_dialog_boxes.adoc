= Active IQ Unified Manager의 클러스터 오브젝트 창 및 대화 상자 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
각 스토리지 오브젝트 페이지에서 모든 클러스터와 클러스터 오브젝트를 볼 수 있습니다. 해당 스토리지 오브젝트 세부 정보 페이지에서 세부 정보도 확인할 수 있습니다. 이제 INVENTORY의 다음 STORAGE 및 PROTECTION 섹션에서 System Manager 사용자 인터페이스를 실행할 수 있습니다.

* 클러스터 인벤토리, 클러스터 상태 및 클러스터 성능 페이지
* 애그리게이트 인벤토리, 애그리게이트 상태 및 애그리게이트 성능 페이지
* 볼륨 인벤토리, 볼륨 상태 및 볼륨 성능 페이지
* 노드 인벤토리 및 노드 성능 페이지
* StorageVM 인벤토리, StorageVM 상태 및 StorageVM 성능 페이지
* 보호 관계 페이지
