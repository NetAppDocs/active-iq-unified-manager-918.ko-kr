= Active IQ Unified Manager에서 클러스터 및 스토리지 VM의 보안 상태를 봅니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager를 사용하면 인터페이스의 다양한 지점에서 환경 내 스토리지 오브젝트의 보안 상태를 확인할 수 있습니다. 정의된 매개변수를 기반으로 정보 및 보고서를 수집하고 분석할 수 있으며, 모니터링 대상 클러스터 및 스토리지 VM에서 의심스러운 동작이나 무단 시스템 변경을 감지할 수 있습니다.

보안 권장 사항은 다음을 참조하십시오. https://www.netapp.com/pdf.html?item=/media/10674-tr4569pdf.pdf["NetApp ONTAP 9 보안 강화 가이드"^]



[[view-object-level-security-status-on-security-page]]
== 보안 페이지에서 오브젝트 수준 보안 상태 보기

시스템 관리자로서 *보안* 페이지를 사용하여 데이터 센터 및 사이트 수준에서 ONTAP 클러스터와 스토리지 VM의 보안 수준을 확인할 수 있습니다. 지원되는 오브젝트는 클러스터, 스토리지 VM 및 볼륨입니다. 다음 단계를 따르십시오.

.단계
. 왼쪽 탐색 창에서 *대시보드*를 클릭합니다.
. 모니터링 대상 클러스터 전체의 보안 상태를 볼지, 아니면 특정 클러스터의 보안 상태를 볼지에 따라 *모든 클러스터*를 선택하거나 드롭다운 메뉴에서 특정 클러스터를 선택하십시오.
. *보안* 패널에서 오른쪽 화살표를 클릭합니다. 보안 페이지가 표시됩니다.


막대 그래프, 개수 및  `View Reports` 링크를 클릭하면 해당 볼륨, 클러스터 또는 스토리지 VM 페이지로 이동하여 필요에 따라 관련 세부 정보를 보거나 보고서를 생성할 수 있습니다.

보안 페이지에는 다음과 같은 패널이 표시됩니다:

* *클러스터 규정 준수*: 데이터 센터 내 모든 클러스터의 보안 상태(규정을 준수하는 클러스터와 준수하지 않는 클러스터의 수)
* *스토리지 VM 규정 준수*: 데이터 센터 내 모든 스토리지 VM의 보안 상태(규정을 준수하는 VM과 준수하지 않는 VM의 수)
* *볼륨 암호화*: 환경 내 모든 볼륨의 볼륨 암호화 상태(암호화되거나 암호화되지 않은 볼륨 수)
* *볼륨 랜섬웨어 방지 상태*: 환경 내 모든 볼륨의 보안 상태(랜섬웨어 방지 기능이 활성화 또는 비활성화된 볼륨 수)
* *클러스터 인증 및 인증서*: SAML, Active Directory, 인증서 및 로컬 인증 등 각 인증 방법을 사용하는 클러스터 수입니다. 이 패널에는 인증서가 만료되었거나 60일 이내에 만료될 예정인 클러스터 수도 표시됩니다.

== 클러스터 페이지에서 모든 클러스터의 보안 세부 정보 보기

*클러스터/보안* 세부 정보 페이지에서는 클러스터 수준의 보안 규정 준수 상태를 볼 수 있습니다.

.단계
. 왼쪽 탐색 창에서 *스토리지 > 클러스터*를 클릭합니다.
. *보기 > 보안 > 모든 클러스터*를 선택하십시오.


글로벌 FIPS, Telnet, 안전하지 않은 SSH 설정, 로그인 배너, 네트워크 시간 프로토콜, AutoSupport HTTPS 전송 및 클러스터 인증서 만료 상태 등 기본 보안 매개변수가 표시됩니다.

image:icon_kabob.gif["케밥 아이콘"] 추가 옵션 버튼을 클릭하고 Unified Manager의 *보안* 페이지 또는 System Manager에서 보안 세부 정보를 보도록 선택할 수 있습니다. System Manager에서 세부 정보를 보려면 유효한 자격 증명이 있어야 합니다.


NOTE: 클러스터의 인증서가 만료된 경우 *클러스터 인증서 유효성* 아래의  `expired`을(를) 클릭하고 System Manager(9.10.1 이상)에서 갱신할 수 있습니다. System Manager 인스턴스가 9.10.1 이전 릴리스인 경우  `expired`을(를) 클릭할 수 없습니다.

== 스토리지 VM 페이지에서 모든 클러스터의 보안 세부 정보를 볼 수 있습니다.

*스토리지 VM/보안* 세부 정보 페이지를 사용하면 스토리지 VM 수준에서 보안 규정 준수 상태를 확인할 수 있습니다.

.단계
. 왼쪽 탐색 창에서 *스토리지 > 스토리지 VM*을 클릭합니다.
. *보기 > 보안 > 모든 스토리지 VM*을 선택합니다. 보안 매개변수가 포함된 클러스터 목록이 표시됩니다.


스토리지 VM, 클러스터, 로그인 배너, 감사 로그 및 안전하지 않은 SSH 설정 등 보안 매개변수를 확인하여 스토리지 VM의 보안 규정 준수에 대한 기본 보기를 확인할 수 있습니다.

image:icon_kabob.gif["케밥 아이콘"] 추가 옵션 버튼을 클릭하고 Unified Manager의 *보안* 페이지 또는 System Manager에서 보안 세부 정보를 보도록 선택할 수 있습니다. System Manager에서 세부 정보를 보려면 유효한 자격 증명이 있어야 합니다.

볼륨 및 스토리지 VM에 대한 랜섬웨어 방지 보안 세부 정보는 link:../health-checker/task_view_antiransomware_status_of_all_volumes_storage_vms.html["모든 볼륨 및 스토리지 VM의 랜섬웨어 방지 상태 보기"]을(를) 참조하십시오.
