= Active IQ Unified Manager의 사전 정의된 주석 값 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
*데이터 우선순위*는 미션 크리티컬, 높음, 낮음 값을 가지는 사전 정의된 어노테이션입니다. 이러한 값을 사용하여 스토리지 오브젝트에 포함된 데이터의 우선순위에 따라 어노테이션을 지정할 수 있습니다. 사전 정의된 어노테이션 값은 편집하거나 삭제할 수 없습니다.

* *데이터 우선순위: 미션 크리티컬*
+
이 어노테이션은 미션 크리티컬 데이터가 포함된 스토리지 오브젝트에 적용됩니다. 예를 들어, 운영 애플리케이션이 포함된 오브젝트는 미션 크리티컬로 간주될 수 있습니다.

* *데이터 우선순위: 높음*
+
이 어노테이션은 우선순위가 높은 데이터를 포함하는 스토리지 오브젝트에 적용됩니다. 예를 들어, 비즈니스 애플리케이션을 호스팅하는 오브젝트는 우선순위가 높은 것으로 간주될 수 있습니다.

* *데이터 우선순위: 낮음*
+
이 어노테이션은 우선순위가 낮은 데이터를 포함하는 스토리지 오브젝트에 적용됩니다. 예를 들어 백업 및 미러 대상 등 2차 스토리지에 있는 오브젝트는 우선순위가 낮을 수 있습니다.
