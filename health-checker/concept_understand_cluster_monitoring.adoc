= Active IQ Unified Manager에서 클러스터 모니터링 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 데이터베이스에 클러스터를 추가하여 가용성, 용량 및 CPU 사용량, 인터페이스 통계, 여유 디스크 공간, qtree 사용량, 섀시 환경 등 기타 세부 정보를 모니터링할 수 있습니다.

상태가 비정상적이거나 사전 정의된 임계값을 초과하면 이벤트가 생성됩니다. 구성된 경우 Unified Manager는 이벤트가 경고를 트리거할 때 지정된 수신자에게 알림을 보냅니다.
