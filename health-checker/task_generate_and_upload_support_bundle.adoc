= Active IQ Unified Manager에서 지원 번들 생성 및 업로드
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
진단 정보가 포함된 지원 번들을 생성하여 문제 해결을 위해 기술 지원에 보낼 수 있습니다.

Unified Manager 9.8부터는 Unified Manager 서버가 인터넷에 연결되어 있는 경우 유지 관리 콘솔에서 NetApp에 지원 번들을 업로드할 수도 있습니다.

.시작하기 전에
유지보수 사용자로서 유지보수 콘솔에 접근 권한이 있어야 합니다.

일부 지원 데이터 유형은 클러스터 리소스를 많이 사용하거나 완료하는 데 오랜 시간이 걸릴 수 있으므로, 전체 지원 번들을 선택할 때 포함하거나 제외할 데이터 유형을 지정하여 지원 번들 크기를 줄일 수 있습니다. 또한 성능 데이터, 수집 기록 파일 및 서버 힙 덤프를 제외하고 30일간의 로그 및 구성 데이터베이스 레코드만 포함하는 경량 지원 번들을 생성하는 옵션도 있습니다.

Unified Manager는 가장 최근에 생성된 두 개의 지원 번들만 저장합니다. 오래된 지원 번들은 시스템에서 삭제됩니다.

.단계
. 유지보수 콘솔 *메인 메뉴*에서 *지원/진단*을 선택하십시오.
. 지원 번들에 포함할 세부 정보 수준에 따라 *간단한 지원 번들 생성* 또는 *지원 번들 생성*을 선택하십시오.
. 전체 지원 번들을 선택하는 경우, 지원 번들에 포함하거나 제외할 다음 데이터 유형을 선택하거나 선택 해제하십시오:
+
** *데이터베이스 덤프*
+
MySQL 서버 데이터베이스의 덤프입니다.

** *힙 덤프*
+
Unified Manager 메인 서버 프로세스의 상태 스냅샷입니다. 이 옵션은 기본적으로 비활성화되어 있으며 고객 지원에서 요청할 때만 선택해야 합니다.

** *수집 기록*
+
Unified Manager와 모니터링 대상 클러스터 간의 모든 통신 기록입니다.



+
[NOTE]
====
모든 데이터 유형을 선택 해제하더라도 지원 번들은 다른 Unified Manager 데이터와 함께 생성됩니다.

====
.  `g`을(를) 입력한 다음 Enter를 눌러 지원 번들을 생성하십시오.
+
지원 번들 생성은 메모리 사용량이 많은 작업이므로, 지금 지원 번들을 생성할 것인지 확인하는 메시지가 표시됩니다.

.  `y`을(를) 입력한 후 Enter 키를 눌러 지원 번들을 생성하십시오.
+
지금 지원 번들을 생성하지 않으려면  `n`을(를) 입력한 다음 Enter 키를 누르십시오.

. 전체 지원 번들에 데이터베이스 덤프 파일을 포함시킨 경우, 성능 통계를 포함할 기간을 지정하라는 메시지가 표시됩니다. 성능 통계를 포함하면 상당한 시간과 공간을 차지할 수 있으므로, 성능 통계를 포함하지 않고 데이터베이스를 덤프할 수도 있습니다:
+
.. 시작 날짜를 YYYYMMDD 형식으로 입력하세요.
+
예를 들어, 2021년 1월 1일의 경우  `20210101`을(를) 입력하십시오. 성능 통계를 포함하지 않으려면  `n`을(를) 입력하십시오.

.. 지정된 시작일의 자정부터 포함할 통계 기간(일수)을 입력하십시오.
+
1부터 10까지의 숫자를 입력할 수 있습니다.



+
성능 통계를 포함하는 경우 시스템은 성능 통계가 수집될 기간을 표시합니다.

. 지원 번들이 생성되면 NetApp에 업로드할지 묻는 메시지가 표시됩니다.  `y`을(를) 입력한 다음 Enter 키를 누르십시오.
+
지원 사례 번호를 입력하라는 메시지가 표시됩니다.

. 이미 케이스 번호가 있는 경우, 번호를 입력하고 Enter 키를 누르십시오. 그렇지 않은 경우, Enter 키만 누르십시오.
+
지원 번들이 NetApp에 업로드됩니다.



Unified Manager 서버가 인터넷에 연결되어 있지 않거나 다른 이유로 지원 번들을 업로드할 수 없는 경우, 수동으로 가져와서 전송할 수 있습니다. SFTP 클라이언트 또는 UNIX나 Linux CLI 명령을 사용하여 가져올 수 있습니다. Windows 설치 환경에서는 원격 데스크톱(RDP)을 사용하여 지원 번들을 가져올 수 있습니다.

생성된 지원 번들은 VMware 시스템의 경우 /support 디렉터리에, Linux 시스템의 경우 /opt/netapp/data/support/에, Windows 시스템의 경우 ProgramData\NetApp\OnCommandAppData\ocum\support에 있습니다.
