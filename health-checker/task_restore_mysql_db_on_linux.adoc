= Linux 시스템에서 Active IQ Unified Manager의 MySQL 데이터베이스 백업 복원
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
데이터 손실이나 데이터 손상이 발생한 경우, 데이터 손실을 최소화하면서 Unified Manager를 이전의 안정적인 상태로 복원할 수 있습니다. Unified Manager 유지 관리 콘솔을 사용하여 Unified Manager 데이터베이스를 로컬 또는 원격 Red Hat Enterprise Linux 시스템으로 복원할 수 있습니다.

.시작하기 전에
* Unified Manager가 설치된 Linux 호스트의 루트 사용자 자격 증명이 있어야 합니다.
* Unified Manager 서버의 유지 관리 콘솔에 로그인하도록 승인된 사용자 ID와 암호가 있어야 합니다.
* 복원 작업을 수행할 시스템에 Unified Manager 백업 파일과 데이터베이스 저장소 디렉터리의 내용을 복사해 두어야 합니다.
+
백업 파일을 기본 디렉토리 /`data/ocum`-backup에 복사하는 것이 좋습니다. 데이터베이스 저장소 파일은 /`ocum-backup` 디렉토리 아래의 /`database-dumps-repo` 하위 디렉토리에 복사해야 합니다.

* 백업 파일은  `.7z` 유형이어야 합니다.


복원 기능은 플랫폼 및 버전별로 다릅니다. Unified Manager 백업은 동일한 버전의 Unified Manager에서만 복원할 수 있습니다. Linux 백업 파일 또는 가상 어플라이언스 백업 파일을 Red Hat Enterprise Linux 시스템으로 복원할 수 있습니다.

[TIP]
====
백업 폴더 이름에 공백이 포함된 경우 절대 경로 또는 상대 경로를 큰따옴표로 묶어야 합니다.

====
.단계
. 새 서버에 복원을 수행하는 경우 Unified Manager를 설치한 후 설치가 완료되면 UI를 실행하거나 클러스터, 사용자 또는 인증 설정을 구성하지 마십시오. 백업 파일이 복원 프로세스 중에 이 정보를 채웁니다.
. Secure Shell을 사용하여 Unified Manager 시스템의 IP 주소 또는 정규화된 도메인 이름에 연결합니다.
. 유지보수 사용자(umadmin)의 이름과 비밀번호로 시스템에 로그인하십시오.
. 명령어 `maintenance_console`를 입력하고 Enter 키를 누르십시오.
. 유지 관리 콘솔 *메인 메뉴*에서 *백업 복원* 옵션에 해당하는 번호를 입력하십시오.
. *Restore MySQL Backup*에 대한 번호를 입력하십시오.
. 메시지가 나타나면 백업 파일의 절대 경로를 입력하십시오.
+
[listing]
----
Bundle to restore from: /data/ocum-backup/UM_9.8.N151113.1348_backup_rhel_02-20-2020-04-45.7z
----
+
복원 작업이 완료되면 Unified Manager에 로그인할 수 있습니다.



백업을 복원한 후 OnCommand Workflow Automation 서버가 작동하지 않으면 다음 단계를 수행하십시오.

. Workflow Automation 서버에서 Unified Manager 서버의 IP 주소를 최신 시스템을 가리키도록 변경하십시오.
. Unified Manager 서버에서 1단계에서 데이터 수집이 실패한 경우 데이터베이스 암호를 재설정하십시오.
