= Active IQ Unified Manager에서 주석 규칙이 작동하는 방식 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
어노테이션 규칙은 스토리지 오브젝트(볼륨, 클러스터 또는 스토리지 가상 머신(SVM))에 어노테이션을 추가하기 위해 정의하는 기준입니다. 어노테이션 규칙을 정의할 때는 조건 그룹 또는 조건을 사용할 수 있습니다.

* 주석에는 반드시 주석 규칙을 연결해야 합니다.
* 주석 규칙에 오브젝트 유형을 연결해야 하며, 주석 규칙에는 하나의 오브젝트 유형만 연결할 수 있습니다.
* Unified Manager는 각 모니터링 주기 후 또는 규칙이 생성, 편집, 삭제 또는 재정렬될 때 스토리지 오브젝트에서 주석을 추가하거나 제거합니다.
* 주석 규칙은 하나 이상의 조건 그룹을 가질 수 있으며, 각 조건 그룹은 하나 이상의 조건을 가질 수 있습니다.
* 스토리지 오브젝트는 여러 개의 어노테이션을 가질 수 있습니다. 특정 어노테이션에 대한 어노테이션 규칙은 규칙 조건에서 다른 어노테이션을 사용하여 이미 어노테이션이 지정된 오브젝트에 또 다른 어노테이션을 추가할 수도 있습니다.




[[conditions]]
== 조건

여러 개의 조건 그룹을 생성할 수 있으며, 각 조건 그룹에는 하나 이상의 조건을 지정할 수 있습니다. 정의된 모든 조건 그룹을 어노테이션 규칙에 적용하여 스토리지 오브젝트에 어노테이션을 추가할 수 있습니다.

조건 그룹 내의 조건은 논리 AND를 사용하여 실행됩니다. 조건 그룹의 모든 조건이 충족되어야 합니다. 주석 규칙을 생성하거나 수정할 때, 조건 그룹의 모든 조건을 충족하는 스토리지 오브젝트만 적용, 선택 및 주석 처리하는 조건이 생성됩니다. 주석을 처리할 스토리지 오브젝트의 범위를 좁히고자 할 때 조건 그룹 내에서 여러 조건을 사용할 수 있습니다.

다음 피연산자와 연산자를 사용하고 필요한 값을 지정하여 스토리지 오브젝트로 조건을 생성할 수 있습니다.

스토리지 오브젝트의 피연산자로 주석을 선택하면 "`Is`" 연산자를 사용할 수 있습니다. 다른 모든 피연산자의 경우 "`Is`" 또는 "`Contains`"를 연산자로 선택할 수 있습니다. "`Is`" 연산자를 선택하면 피연산자 값이 선택한 피연산자에 대해 제공된 값과 정확히 일치하는지 조건이 평가됩니다. "`Contains`" 연산자를 선택하면 다음 기준 중 하나를 충족하는지 조건이 평가됩니다:

* 피연산자 값은 선택된 피연산자 값과 정확히 일치합니다.
* 피연산자 값에는 선택된 피연산자에 대해 제공된 값이 포함됩니다.

== 조건을 포함하는 주석 규칙의 예

다음 두 가지 조건을 가진 볼륨에 대해 하나의 조건 그룹이 있는 주석 규칙을 고려해 보겠습니다.

* 이름에 "`vol`" 포함
* SVM 이름은 "`data_svm`"입니다


이 주석 규칙은 이름에 "`vol`"이 포함되어 있고 "`data_svm`"이라는 이름의 SVM에 호스팅된 모든 볼륨에 선택된 주석과 주석 유형을 추가합니다.



[[condition-groups]]
== 조건 그룹

조건 그룹은 논리 OR을 사용하여 실행된 후 스토리지 오브젝트에 적용됩니다. 스토리지 오브젝트에 주석이 추가되려면 조건 그룹 중 하나의 요구 사항을 충족해야 합니다. 모든 조건 그룹의 조건을 충족하는 스토리지 오브젝트에 주석이 추가됩니다. 조건 그룹을 사용하면 주석을 추가할 스토리지 오브젝트의 범위를 확장할 수 있습니다.



[[example-of-an-annotation-rule-with-condition-groups]]
== 조건 그룹을 사용한 주석 규칙의 예

볼륨에 대한 두 개의 조건 그룹으로 구성된 주석 규칙을 생각해 보겠습니다. 각 그룹에는 다음 두 가지 조건이 포함됩니다:

* 조건 그룹 1
+
** 이름에 "`vol`" 포함
** SVM 이름은 "`data_svm`"입니다. 이 조건 그룹은 이름에 "`vol`"이 포함되어 있고 "`data_svm`"이라는 이름의 SVM에서 호스팅되는 모든 볼륨에 주석을 추가합니다.


* 조건 그룹 2
+
** 이름에 "`vol`" 포함
** data-priority의 주석 값은 "`critical`"입니다. 이 조건 그룹은 이름에 "`vol`"이 포함되어 있고 data-priority 주석 값이 "`critical`"로 지정된 모든 볼륨에 주석을 추가합니다.




이 두 조건 그룹을 포함하는 주석 규칙이 스토리지 오브젝트에 적용되면 다음과 같은 스토리지 오브젝트에 주석이 추가됩니다.

* 이름에 "`vol`"이 포함되어 있고 "`data_svm`"이라는 이름의 SVM에 호스팅된 모든 볼륨입니다.
* 이름에 "`vol`"이 포함되어 있고 데이터 우선순위 주석 값이 "`critical`"로 지정된 모든 볼륨.
