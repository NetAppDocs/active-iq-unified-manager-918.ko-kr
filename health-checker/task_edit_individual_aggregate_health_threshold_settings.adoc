= Active IQ Unified Manager에서 개별 애그리게이트 상태 임계값 설정 편집
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
하나 이상의 애그리게이트에 대한 애그리게이트 용량, 증가율 및 Snapshot 복사본의 상태 임계값 설정을 편집할 수 있습니다. 임계값을 초과하면 경고가 생성되어 알림을 받게 됩니다. 이러한 알림을 통해 발생한 이벤트에 따라 예방 조치를 취할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

임계값 변경에 따라 다음 모니터링 주기에서 이벤트가 생성되거나 삭제됩니다.

애그리게이트에 있는 볼륨에서 자동 증가(Autogrow)가 활성화된 경우, 애그리게이트 용량 임계값 초과 여부는 원래 볼륨 크기가 아닌 자동 증가 기능으로 설정된 최대 볼륨 크기를 기준으로 판단됩니다.

.단계
. 왼쪽 탐색 창에서 *스토리지* > *애그리게이트*를 클릭합니다.
. *상태: 모든 애그리게이트* 보기에서 하나 이상의 애그리게이트를 선택한 다음 *임계값 편집*을 클릭합니다.
. *애그리게이트 임계값 편집* 대화 상자에서 해당 확인란을 선택한 다음 설정을 수정하여 용량, 증가 또는 Snapshot 복사본 중 하나의 임계값 설정을 편집하십시오.
. *저장*을 클릭합니다.
