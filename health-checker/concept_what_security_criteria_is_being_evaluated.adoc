= Active IQ Unified Manager 보안 기준을 평가하는 방법을 이해하십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
일반적으로 ONTAP 클러스터, 스토리지 가상 머신(SVM) 및 볼륨에 대한 보안 기준은 _NetApp ONTAP 9용 보안 강화 가이드_에 정의된 권장 사항을 기준으로 평가됩니다.

보안 검사에는 다음과 같은 사항들이 포함됩니다:

* 클러스터가 SAML 등 보안 인증 방법을 사용하는지 여부
* 피어링된 클러스터의 통신이 암호화되는지 여부
* 스토리지 VM에서 감사 로그가 활성화되어 있는지 여부
* 볼륨에 소프트웨어 또는 하드웨어 암호화가 활성화되어 있는지 여부


규정 준수 범주 및 https://www.netapp.com/pdf.html?item=/media/10674-tr4569pdf.pdf["NetApp ONTAP 9 보안 강화 가이드"^]에 대한 자세한 내용은 관련 항목을 참조하십시오.

[NOTE]
====
Active IQ 플랫폼에서 보고되는 업그레이드 이벤트는 보안 이벤트로도 간주됩니다. 이러한 이벤트는 해결을 위해 ONTAP 소프트웨어, 노드 펌웨어 또는 운영 체제 소프트웨어(보안 권고 사항의 경우)를 업그레이드해야 하는 문제를 나타냅니다. 이러한 이벤트는 보안 패널에는 표시되지 않지만 이벤트 관리 인벤토리 페이지에서 확인할 수 있습니다.
