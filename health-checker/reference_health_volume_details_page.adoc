= Active IQ Unified Manager에서 볼륨/상태 세부 정보 페이지를 봅니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
볼륨 / 상태 세부 정보 페이지를 사용하여 용량, 스토리지 효율성, 구성, 보호, 주석 및 생성된 이벤트 등 선택한 볼륨에 대한 자세한 정보를 볼 수 있습니다. 또한 해당 볼륨과 관련된 개체 및 관련 경고에 대한 정보도 확인할 수 있습니다.

애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.



[[command-buttons]]
== 명령 버튼

명령 버튼을 사용하면 선택한 볼륨에 대해 다음과 같은 작업을 수행할 수 있습니다:

* *성능 보기로 전환*
+
볼륨/성능 세부 정보 페이지로 이동할 수 있습니다.

* *작업*
+
** 알림 추가
+
선택한 볼륨에 알림을 추가할 수 있습니다.

** 임계값 편집
+
선택한 볼륨에 대한 임계값 설정을 수정할 수 있습니다.

** 주석 달기
+
선택한 볼륨에 주석을 달 수 있습니다.

** 보호
+
선택한 볼륨에 대해 SnapMirror 또는 SnapVault 관계를 생성할 수 있습니다.

** 관계
+
다음과 같은 보호 관계 작업을 실행할 수 있습니다:

+
*** 편집
+
기존 보호 관계에 대한 기존 SnapMirror 정책, 일정 및 최대 전송 속도를 변경할 수 있는 관계 편집 대화 상자를 실행합니다.

*** 중단
+
선택한 관계에 대해 진행 중인 전송을 중단합니다. 선택적으로 기본 전송 이외의 전송에 대한 재시작 체크포인트를 제거할 수 있습니다. 기본 전송에 대한 체크포인트는 제거할 수 없습니다.

*** 정지
+
선택한 관계에 대한 예약된 업데이트를 일시적으로 비활성화합니다. 이미 진행 중인 전송은 관계가 정지되기 전에 완료되어야 합니다.

*** 중단
+
원본 볼륨과 대상 볼륨 간의 관계를 끊고 대상 볼륨을 읽기/쓰기 볼륨으로 변경합니다.

*** 제거
+
선택한 소스와 대상 간의 관계를 영구적으로 삭제합니다. 볼륨은 파괴되지 않으며 볼륨에 있는 스냅샷 복사본도 제거되지 않습니다. 이 작업은 되돌릴 수 없습니다.

*** 재개
+
정지된 관계에 대해 예약된 전송을 활성화합니다. 다음 예약된 전송 간격에서 재시작 체크포인트가 있는 경우 해당 체크포인트가 사용됩니다.

*** 재동기화
+
이전에 끊어진 관계를 재동기화할 수 있도록 해줍니다.

*** 초기화/업데이트
+
새로운 보호 관계에 대해 최초 기본 전송을 수행하거나, 관계가 이미 초기화된 경우 수동으로 업데이트할 수 있습니다.

*** 역방향 재동기화
+
원본을 원래 대상의 복사본으로 만들어 원본과 대상의 기능을 반전시킴으로써 이전에 끊어진 보호 관계를 다시 설정할 수 있습니다. 원본의 내용은 대상의 내용으로 덮어쓰이며, 공통 스냅샷 복사본의 데이터보다 최신인 데이터는 모두 삭제됩니다.



** 복원
+
한 볼륨에서 다른 볼륨으로 데이터를 복원할 수 있습니다. 자세한 내용은 link:../data-protection/task_restore_data_use_health_volume_details_page.html["볼륨/상태 세부 정보 페이지를 사용하여 데이터 복원"]을 참조하십시오.



+
[NOTE]
====
동기식 보호 관계에 있는 볼륨의 경우 복원 버튼과 관계 작업 버튼을 사용할 수 없습니다.

====
* *볼륨 보기*
+
이 기능을 사용하면 상태: 모든 볼륨 보기로 이동할 수 있습니다.





[[capacity-tab]]
== 용량 탭

용량 탭에는 물리적 용량, 논리적 용량, 임계값 설정, 할당량 용량 및 볼륨 이동 작업에 대한 정보 등 선택한 볼륨에 대한 세부 정보가 표시됩니다:

* *물리적 용량*
+
볼륨의 물리적 용량에 대한 세부 정보:

+
** 스냅샷 오버플로
+
스냅샷 복사본이 사용하는 데이터 공간을 표시합니다.

** 사용됨
+
해당 볼륨에서 데이터가 사용하는 공간을 표시합니다.

** 경고
+
볼륨 내 공간이 거의 가득 찼음을 나타냅니다. 이 임계값을 초과하면 '공간 거의 가득 참' 이벤트가 발생합니다.

** 오류
+
볼륨의 공간이 가득 찼음을 나타냅니다. 이 임계값을 초과하면 Space Full 이벤트가 발생합니다.

** 사용할 수 없는
+
Thin-Provisioned Volume Space At Risk 이벤트가 발생했으며, 애그리게이트 용량 문제로 인해 씬 프로비저닝된 볼륨의 공간이 위험에 처해 있음을 나타냅니다. 사용 불가능한 용량은 씬 프로비저닝된 볼륨에 대해서만 표시됩니다.

** 데이터 그래프
+
볼륨의 총 데이터 용량과 사용된 데이터 용량을 표시합니다.

+
자동 증가가 활성화된 경우 데이터 그래프에는 애그리게이트에서 사용 가능한 공간도 표시됩니다. 데이터 그래프는 볼륨의 데이터가 사용할 수 있는 유효 스토리지 공간을 표시하며, 이는 다음 중 하나일 수 있습니다.

+
*** 다음 조건에서의 볼륨의 실제 데이터 용량:
+
**** 자동 성장 기능이 비활성화되었습니다.
**** 자동 확장 기능이 활성화된 볼륨이 최대 크기에 도달했습니다.
**** 자동 확장 기능이 활성화된 Thick 프로비저닝 볼륨은 더 이상 확장될 수 없습니다.


*** 최대 볼륨 크기를 고려한 후의 볼륨 데이터 용량 (씬 프로비저닝 볼륨 및 애그리게이트에 볼륨이 최대 크기에 도달할 수 있는 공간이 있는 경우의 씩 프로비저닝 볼륨)
*** 다음으로 가능한 자동 증가 크기를 고려한 후의 볼륨 데이터 용량(자동 증가율 임계값이 있는 Thick 프로비저닝된 볼륨의 경우)


** 스냅샷 복사본 그래프
+
이 그래프는 사용된 스냅샷 용량 또는 스냅샷 예약이 0이 아닌 경우에만 표시됩니다.



+
사용된 스냅샷 용량이 스냅샷 예약을 초과하는 경우, 두 그래프 모두 스냅샷 용량이 스냅샷 예약을 초과한 용량을 표시합니다.

* *용량 논리*
+
볼륨의 논리 공간 특성을 표시합니다. 논리 공간은 ONTAP 스토리지 효율성 기술을 사용한 절감 효과를 적용하지 않은 상태에서 디스크에 저장되는 실제 데이터 크기를 나타냅니다.

+
** 논리적 공간 보고
+
해당 볼륨에 논리 공간 보고가 구성되어 있는지 여부를 표시합니다. 값은 활성화됨, 비활성화됨 또는 해당 없음일 수 있습니다. "`해당 없음`"은 이전 버전의 ONTAP이나 논리 공간 보고를 지원하지 않는 볼륨에 표시됩니다.

** 사용됨
+
볼륨 내 데이터가 사용하고 있는 논리 공간의 양과 전체 데이터 용량 대비 사용된 논리 공간의 비율을 표시합니다.

** 논리적 공간 강제
+
씬 프로비저닝된 볼륨에 대해 논리 공간 강제 적용이 구성되었는지 여부를 표시합니다. Enabled로 설정된 경우 볼륨의 논리적 사용 크기는 현재 설정된 물리적 볼륨 크기보다 클 수 없습니다.



* *자동 성장*
+
볼륨이 공간이 부족할 때 자동으로 확장되는지 여부를 표시합니다.

* *공간 보장*
+
볼륨이 어그리게이트에서 사용 가능한 블록을 제거할 때 FlexVol 볼륨 설정 컨트롤을 표시합니다. 그런 다음 이 블록들은 볼륨 내 파일에 대한 쓰기 작업에 사용할 수 있도록 보장됩니다. 공간 보장은 다음 중 하나로 설정할 수 있습니다.

+
** None
+
해당 볼륨에는 공간 보장이 구성되어 있지 않습니다.

** 파일
+
드물게 기록되는 파일(예: LUN)의 전체 크기가 보장됩니다.

** 볼륨
+
볼륨의 전체 크기가 보장됩니다.

** 부분적
+
FlexCache 볼륨은 크기에 따라 공간을 예약합니다. FlexCache 볼륨의 크기가 100MB 이상인 경우 최소 공간 보장은 기본적으로 100MB로 설정됩니다. FlexCache 볼륨의 크기가 100MB 미만인 경우 최소 공간 보장은 FlexCache 볼륨의 크기로 설정됩니다. FlexCache 볼륨의 크기가 나중에 증가하더라도 최소 공간 보장은 증가하지 않습니다.



+
[NOTE]
====
볼륨 유형이 Data-Cache인 경우 공간 보장은 부분적입니다.

====
* *상세 정보 (물리적)*
+
볼륨의 물리적 특성을 표시합니다.

* *총 용량*
+
볼륨의 총 물리적 용량을 표시합니다.

* *데이터 용량*
+
볼륨이 사용한 물리적 공간(사용 용량)과 볼륨에서 사용 가능한 물리적 공간(여유 용량)을 표시합니다. 이 값들은 전체 물리적 용량 대비 백분율로도 표시됩니다.

+
씬 프로비저닝된 볼륨에 대해 '씬 프로비저닝된 볼륨 공간 위험' 이벤트가 발생하면 해당 볼륨에서 사용된 공간(사용 용량)과 볼륨에서 사용 가능하지만 애그리게이트 용량 문제로 인해 사용할 수 없는 공간(사용 불가능 용량)이 표시됩니다.

* *스냅샷 예약*
+
볼륨에서 Snapshot 복사본이 사용하는 공간(사용 용량)과 Snapshot 복사본에 사용할 수 있는 공간(여유 용량)을 표시합니다. 이러한 값은 전체 스냅샷 예약의 백분율로도 표시됩니다.

+
씬 프로비저닝된 볼륨에 대해 씬 프로비저닝된 볼륨 공간 위험 이벤트가 발생하면 스냅샷 복사본에서 사용되는 공간(사용된 용량)과 볼륨에서 사용 가능하지만 애그리게이트 용량 문제로 인해 스냅샷 복사본을 만드는 데 사용할 수 없는 공간(사용 불가능한 용량)이 표시됩니다.

* *Volume Thresholds*
+
다음과 같은 볼륨 용량 임계값을 표시합니다:

+
** 거의 꽉 참 임계값
+
볼륨이 거의 가득 찬 백분율을 지정합니다.

** 전체 임계값
+
볼륨이 채워진 비율을 백분율로 지정합니다.



* *기타 세부 사항*
+
** 자동 성장 최대 크기
+
볼륨이 자동으로 확장될 수 있는 최대 크기를 표시합니다. 기본값은 볼륨 생성 시 크기의 120%입니다. 이 필드는 볼륨에 자동 확장이 활성화된 경우에만 표시됩니다.

** Qtree 할당량 약정 용량
+
할당량에 예약된 공간을 표시합니다.

** Qtree 할당량 초과 커밋된 용량
+
시스템에서 볼륨 Q트리 할당량 초과 이벤트가 발생하기 전에 사용할 수 있는 공간의 양을 표시합니다.

** 부분 예약
+
덮어쓰기 예약의 크기를 제어합니다. 기본적으로 부분 예약은 100으로 설정되며, 이는 필요한 예약 공간의 100%가 예약되어 객체가 덮어쓰기로부터 완벽하게 보호됨을 의미합니다. 부분 예약이 100% 미만인 경우, 해당 볼륨의 모든 공간 예약 파일에 대한 예약 공간이 부분 예약 비율로 줄어듭니다.

** 스냅샷 일일 증가율
+
선택한 볼륨의 스냅샷 복사본에서 24시간마다 발생하는 변화량(백분율 또는 KB, MB, GB 등)을 표시합니다.

** 스냅샷이 가득 찰 때까지 남은 일수
+
볼륨에서 스냅샷 복사본을 위해 예약된 공간이 지정된 임계값에 도달하기까지 남은 예상 일수를 표시합니다.

+
볼륨 내 스냅샷 복사본의 증가율이 0이거나 음수이거나, 증가율을 계산하기에 데이터가 부족한 경우 스냅샷 완료까지 소요 일수 필드에 해당 없음 값이 표시됩니다.

** 스냅샷 자동 삭제
+
애그리게이트의 공간 부족으로 인해 볼륨에 대한 쓰기가 실패할 경우 여유 공간을 확보하기 위해 스냅샷 복사본을 자동으로 삭제할지 여부를 지정합니다.

** 스냅샷 복사본
+
해당 볼륨에 있는 스냅샷 복사본에 대한 정보를 표시합니다.

+
볼륨에 있는 스냅샷 복사본의 수는 링크로 표시됩니다. 이 링크를 클릭하면 스냅샷 복사본에 대한 세부 정보를 표시하는 '볼륨의 스냅샷 복사본' 대화 상자가 열립니다.

+
스냅샷 복사본 수는 약 1시간마다 업데이트되지만, 스냅샷 복사본 목록은 아이콘을 클릭하는 시점에 업데이트됩니다. 따라서 토폴로지에 표시되는 스냅샷 복사본 수와 아이콘을 클릭했을 때 표시되는 스냅샷 복사본 수에 차이가 발생할 수 있습니다.



* *볼륨 이동*
+
볼륨에서 수행된 현재 또는 마지막 볼륨 이동 작업의 상태와 현재 진행 중인 볼륨 이동 작업의 단계, 소스 애그리게이트, 대상 애그리게이트, 시작 시간, 종료 시간 및 예상 종료 시간 등 기타 세부 정보를 표시합니다.

+
선택한 볼륨에 대해 수행된 볼륨 이동 작업 횟수도 표시됩니다. 볼륨 이동 작업에 대한 자세한 정보는 *볼륨 이동 내역* 링크를 클릭하여 확인할 수 있습니다.

== 구성 탭

구성 탭에는 내보내기 정책, RAID 유형, 용량 및 볼륨의 스토리지 효율성 관련 기능 등 선택한 볼륨에 대한 세부 정보가 표시됩니다:

* *개요*
+
** 성명
+
볼륨의 전체 이름을 표시합니다.

** 애그리게이트
+
볼륨이 속한 애그리게이트의 이름 또는 FlexGroup 볼륨이 속한 애그리게이트의 개수를 표시합니다.

** 계층화 정책
+
볼륨에 설정된 티어링 정책을 표시합니다. 볼륨이 FabricPool 활성화된 애그리게이트에 배포된 경우에 적용됩니다. 정책은 없음, 스냅샷 전용, 백업, 자동 또는 전체일 수 있습니다.

** 스토리지 VM
+
해당 볼륨을 포함하는 SVM의 이름을 표시합니다.

** 접합 경로
+
경로의 상태(활성 또는 비활성)를 표시합니다. 볼륨이 마운트된 SVM의 경로도 표시됩니다. *History* 링크를 클릭하면 정션 경로에 대한 최근 5건의 변경 사항을 볼 수 있습니다.

** 엑스포트 정책
+
해당 볼륨에 대해 생성된 내보내기 정책의 이름을 표시합니다. 링크를 클릭하면 SVM에 속한 볼륨에 대해 활성화된 내보내기 정책, 인증 프로토콜 및 액세스에 대한 세부 정보를 볼 수 있습니다.

** 스타일
+
볼륨 스타일을 표시합니다. 볼륨 스타일은 FlexVol 또는 FlexGroup일 수 있습니다.

** 유형
+
선택한 볼륨의 유형을 표시합니다. 볼륨 유형은 읽기-쓰기, 로드 공유, 데이터 보호, 데이터 캐시 또는 임시일 수 있습니다.

** RAID 유형
+
선택한 볼륨의 RAID 유형을 표시합니다. RAID 유형은 RAID0, RAID4, RAID-DP 또는 RAID-TEC일 수 있습니다.

+
[NOTE]
====
FlexGroup 볼륨에 대해 여러 RAID 유형이 표시될 수 있는데, 이는 FlexGroups의 구성 볼륨이 서로 다른 유형의 애그리게이트에 있을 수 있기 때문입니다.

====
** SnapLock 타입
+
볼륨이 포함된 애그리게이트의 SnapLock 유형을 표시합니다.

** SnapLock 만료
+
SnapLock 볼륨의 만료일을 표시합니다.



* *용량*
+
** 씬 프로비저닝
+
해당 볼륨에 대해 씬 프로비저닝이 구성되었는지 여부를 표시합니다.

** 자동 확장
+
애그리게이트 내에서 유연한 볼륨이 자동으로 증가하는지 여부를 표시합니다.

** 스냅샷 자동 삭제
+
애그리게이트의 공간 부족으로 인해 볼륨에 대한 쓰기가 실패할 경우 여유 공간을 확보하기 위해 스냅샷 복사본을 자동으로 삭제할지 여부를 지정합니다.

** 할당량
+
볼륨에 대해 할당량 기능을 사용할지 여부를 지정합니다.



* *효율성*
+
** 압축
+
압축 기능을 활성화할지 비활성화할지 지정합니다.

** 중복제거
+
중복 제거 기능을 활성화할지 비활성화할지 지정합니다.

** 중복 제거 모드
+
볼륨에서 활성화된 중복 제거 작업이 수동, 예약 또는 정책 기반 작업인지 여부를 지정합니다. 모드가 예약으로 설정된 경우 작업 일정이 표시되고, 모드가 정책으로 설정된 경우 정책 이름이 표시됩니다.

** 중복 제거 유형
+
볼륨에서 실행되는 중복 제거 작업 유형을 지정합니다. 볼륨이 SnapVault 관계에 있는 경우 표시되는 유형은 SnapVault입니다. 다른 볼륨의 경우 유형은 Regular로 표시됩니다.

** 스토리지 효율성 정책
+
Unified Manager를 통해 이 볼륨에 할당된 스토리지 효율성 정책의 이름을 지정합니다. 이 정책은 압축 및 중복 제거 설정을 제어할 수 있습니다.



* *보호*
+
** 스냅샷 복사본
+
자동 스냅샷 복사본을 활성화할지 비활성화할지 지정합니다.







[[protection-tab]]
== 보호 탭

보호 탭에는 지연 정보, 관계 유형, 관계 토폴로지 등 선택한 볼륨에 대한 보호 세부 정보가 표시됩니다.

* *요약*
+
선택한 볼륨에 대한 보호 관계(SnapMirror, SnapVault 또는 Storage VM DR) 속성을 표시합니다. 다른 관계 유형의 경우 관계 유형 속성만 표시됩니다. 기본 볼륨이 선택된 경우 관리형 및 로컬 스냅샷 복사 정책만 표시됩니다. SnapMirror 및 SnapVault 관계에 대해 표시되는 속성은 다음과 같습니다.

+
** 소스 볼륨
+
선택한 볼륨이 대상 볼륨인 경우, 해당 볼륨의 소스 이름을 표시합니다.

** 지연 상태
+
보호 관계에 대한 업데이트 또는 전송 지연 상태를 표시합니다. 상태는 오류, 경고 또는 심각일 수 있습니다.

+
지연 상태는 동기 관계에는 적용되지 않습니다.

** 지연 시간
+
미러에 저장된 데이터가 원본 데이터보다 뒤처지는 시간을 표시합니다.

** 최근 성공적인 업데이트
+
가장 최근에 성공한 보호 업데이트의 날짜와 시간을 표시합니다.

+
마지막으로 성공한 업데이트는 동기식 관계에 적용되지 않습니다.

** 스토리지 서비스 멤버
+
볼륨이 스토리지 서비스에 속하고 스토리지 서비스에서 관리되는지 여부를 '예' 또는 '아니요'로 표시합니다.

** 버전 유연 복제
+
예, 백업 옵션 포함 예, 또는 없음 중 하나가 표시됩니다. 예는 소스 및 대상 볼륨에서 실행되는 ONTAP 소프트웨어 버전이 다르더라도 SnapMirror 복제가 가능함을 나타냅니다. 백업 옵션 포함 예는 대상에 여러 버전의 백업 복사본을 보관할 수 있는 SnapMirror 보호 기능이 구현되었음을 나타냅니다. 없음은 버전 유연 복제가 활성화되지 않았음을 나타냅니다.

** 관계 역량
+
보호 관계에 사용 가능한 ONTAP 기능을 나타냅니다.

** 보호 서비스
+
보호 파트너 애플리케이션에서 관계를 관리하는 경우 보호 서비스의 이름을 표시합니다.

** 관계 유형
+
비동기 미러, 비동기 볼트, 비동기 MirrorVault, StrictSync 및 Sync를 포함한 모든 관계 유형을 표시합니다.

** 관계 상태
+
SnapMirror 또는 SnapVault 관계의 상태를 표시합니다. 상태는 초기화되지 않음, SnapMirrored 또는 연결 끊김일 수 있습니다. 소스 볼륨이 선택된 경우 관계 상태는 적용되지 않으므로 표시되지 않습니다.

** 전송 상태
+
보호 관계에 대한 전송 상태를 표시합니다. 전송 상태는 다음 중 하나일 수 있습니다.

+
*** 중단
+
SnapMirror 전송이 활성화되어 있지만, 체크포인트 제거를 포함할 수 있는 전송 중단 작업이 진행 중입니다.

*** 확인 중
+
대상 볼륨에 대한 진단 검사가 진행 중이며 전송이 진행되지 않고 있습니다.

*** 마무리 작업
+
SnapMirror 전송이 활성화되었습니다. 현재 볼륨은 증분 SnapVault 전송의 전송 후 단계에 있습니다.

*** 유휴
+
전송이 활성화되어 있으며 진행 중인 전송이 없습니다.

*** 동기화됨
+
동기 관계에 있는 두 볼륨의 데이터는 동기화됩니다.

*** 동기화되지 않음
+
대상 볼륨의 데이터가 소스 볼륨과 동기화되지 않았습니다.

*** 준비 중
+
SnapMirror 전송이 활성화되었습니다. 현재 볼륨은 증분 SnapVault 전송을 위한 사전 전송 단계에 있습니다.

*** 대기 중
+
SnapMirror 전송이 활성화되었습니다. 현재 진행 중인 전송은 없습니다.

*** 정지
+
SnapMirror 전송이 비활성화되었습니다. 진행 중인 전송이 없습니다.

*** 정지
+
SnapMirror 전송이 진행 중입니다. 추가 전송은 비활성화되었습니다.

*** 전송 중
+
SnapMirror 전송이 활성화되었으며 전송이 진행 중입니다.

*** 전환
+
소스 볼륨에서 대상 볼륨으로의 비동기 데이터 전송이 완료되었으며, 동기 작업으로의 전환이 시작되었습니다.

*** 대기 중
+
SnapMirror 전송이 시작되었지만 일부 관련 작업이 대기열에 추가되기를 기다리고 있습니다.



** 최대 전송 속도
+
관계의 최대 전송 속도를 표시합니다. 최대 전송 속도는 킬로바이트/초(Kbps), 메가바이트/초(Mbps), 기가바이트/초(Gbps) 또는 테라바이트/초(Tbps) 단위의 숫자 값일 수 있습니다. 제한 없음이 표시되면 관계 간 기본 전송은 무제한입니다.

** SnapMirror 정책
+
볼륨에 대한 보호 정책을 표시합니다. DPDefault는 기본 비동기 미러 보호 정책을, XDPDefault는 기본 비동기 볼트 정책을, DPSyncDefault는 기본 비동기 MirrorVault 정책을 나타냅니다. StrictSync는 기본 동기식 엄격 보호 정책을, Sync는 기본 동기식 정책을 나타냅니다. 정책 이름을 클릭하면 해당 정책과 관련된 세부 정보를 볼 수 있으며, 여기에는 다음 정보가 포함됩니다.

+
*** 전송 우선순위
*** 액세스 시간 설정을 무시합니다
*** 시도 횟수 제한
*** 댓글
*** SnapMirror 라벨
*** 보존 설정
*** 실제 스냅샷 사본
*** 스냅샷 사본 보존
*** 보존 경고 임계값
*** 보존 설정이 없는 스냅샷 복사본의 경우, 소스가 데이터 보호(DP) 볼륨인 계단식 SnapVault 관계에서는 "`sm_created`" 규칙만 적용됩니다.


** 업데이트 일정
+
관계에 할당된 SnapMirror 일정을 표시합니다. 정보 아이콘 위에 마우스 커서를 올리면 일정 세부 정보가 표시됩니다.

** 로컬 스냅샷 정책
+
볼륨에 대한 스냅샷 복사 정책을 표시합니다. 정책은 기본값, 없음 또는 사용자 지정 정책에 지정된 이름입니다.

** 보호 수단
+
선택한 볼륨에 사용된 보호 유형을 표시합니다. 예를 들어 볼륨이 일관성 그룹 및 SnapMirror 볼륨 관계로 보호되는 경우 이 필드에는 SnapMirror와 일관성 그룹이 모두 표시됩니다. 또한 이 필드에는 통합 관계 상태를 볼 수 있는 관계 페이지로 이동하는 링크가 제공됩니다. 이 링크는 구성 요소 관계에만 적용됩니다.

** 일관성 그룹
+
SnapMirror 활성 동기화 관계로 보호되는 볼륨의 경우 이 열에는 볼륨의 일관성 그룹이 표시됩니다.



* *뷰*
+
선택한 볼륨의 보호 토폴로지를 표시합니다. 토폴로지에는 선택한 볼륨과 관련된 모든 볼륨의 그래픽 표현이 포함됩니다. 선택한 볼륨은 짙은 회색 테두리로 표시되며, 토폴로지에서 볼륨 사이의 선은 보호 관계 유형을 나타냅니다. 토폴로지에서 관계의 방향은 왼쪽에서 오른쪽으로 표시되며, 각 관계의 소스는 왼쪽에, 대상은 오른쪽에 있습니다.

+
굵은 두 줄은 비동기 미러 관계를, 굵은 한 줄은 비동기 볼트 관계를, 이중 실선은 비동기 MirrorVault 관계를, 굵은 한 줄과 굵지 않은 한 줄은 동기 관계를 나타냅니다. 아래 표는 동기 관계가 StrictSync인지 Sync인지를 보여줍니다.

+
볼륨을 마우스 오른쪽 버튼으로 클릭하면 볼륨을 보호하거나 데이터를 복원할 수 있는 메뉴가 표시됩니다. 관계를 마우스 오른쪽 버튼으로 클릭하면 관계를 편집, 중단, 일시 중지, 끊기, 제거 또는 재개할 수 있는 메뉴가 표시됩니다.

+
다음과 같은 경우에는 메뉴가 표시되지 않습니다:

+
** RBAC 설정에서 이 작업을 허용하지 않는 경우(예: 운영자 권한만 있는 경우)
** 볼륨이 동기 보호 관계에 있는 경우
** 볼륨 ID를 알 수 없는 경우(예: 클러스터 간 관계가 있고 타겟 클러스터가 아직 검색되지 않은 경우) 토폴로지에서 다른 볼륨을 클릭하면 해당 볼륨이 선택되어 정보가 표시됩니다. 볼륨 왼쪽 상단에 물음표(image:../media/hastate_unknown.gif["HA 상태 아이콘 – 알 수 없음"] )가 있으면 해당 볼륨이 없거나 아직 검색되지 않았음을 나타냅니다. 용량 정보가 누락되었음을 나타낼 수도 있습니다. 물음표 위에 마우스 커서를 올리면 해결 방법을 포함한 추가 정보가 표시됩니다.


+
토폴로지가 일반적인 토폴로지 템플릿 중 하나를 따르는 경우, 볼륨 용량, 지연 시간, 스냅샷 복사본 및 마지막 성공적인 데이터 전송에 대한 정보가 표시됩니다. 토폴로지가 이러한 템플릿 중 하나를 따르지 않는 경우, 볼륨 지연 시간 및 마지막 성공적인 데이터 전송에 대한 정보는 토폴로지 아래의 관계 테이블에 표시됩니다. 이 경우 테이블에서 강조 표시된 행은 선택된 볼륨을 나타내며, 토폴로지 보기에서 파란색 점이 있는 굵은 선은 선택된 볼륨과 해당 소스 볼륨 간의 관계를 나타냅니다.



토폴로지 뷰에는 다음 정보가 포함됩니다:

* 용량
+
볼륨에서 사용된 총 용량을 표시합니다. 토폴로지에서 볼륨 위에 커서를 올리면 현재 임계값 설정 대화 상자에 해당 볼륨의 현재 경고 및 위험 임계값 설정이 표시됩니다. 현재 임계값 설정 대화 상자에서 *임계값 편집* 링크를 클릭하여 임계값 설정을 편집할 수도 있습니다. *용량* 확인란의 선택을 해제하면 토폴로지의 모든 볼륨에 대한 모든 용량 정보가 숨겨집니다.

* 지연
+
수신되는 보호 관계의 지연 시간 및 지연 상태를 표시합니다. *지연* 확인란의 선택을 해제하면 토폴로지의 모든 볼륨에 대한 모든 지연 정보가 숨겨집니다. *지연* 확인란이 흐리게 표시된 경우, 선택한 볼륨의 지연 정보와 관련된 모든 볼륨의 지연 정보가 토폴로지 아래의 관계 테이블에 표시됩니다.

* 스냅샷
+
볼륨에 사용 가능한 스냅샷 복사본 수를 표시합니다. *스냅샷* 확인란을 선택 취소하면 토폴로지의 모든 볼륨에 대한 모든 스냅샷 복사본 정보가 숨겨집니다. 스냅샷 복사본 아이콘( image:../media/icon_snapshot_list.gif["볼륨과 연결된 스냅샷 사본 목록 아이콘"] )을 클릭하면 볼륨의 스냅샷 복사본 목록이 표시됩니다. 아이콘 옆에 표시되는 스냅샷 복사본 수는 약 1시간마다 업데이트되지만, 스냅샷 복사본 목록은 아이콘을 클릭하는 시점에 업데이트됩니다. 이로 인해 토폴로지에 표시되는 스냅샷 복사본 수와 아이콘을 클릭할 때 나열되는 스냅샷 복사본 수에 차이가 발생할 수 있습니다.

* 마지막 성공적인 전송
+
마지막으로 성공한 데이터 전송의 양, 기간, 시간 및 날짜를 표시합니다. *Last Successful Transfer* 확인란이 흐리게 표시되면 선택한 볼륨의 마지막 성공 전송 정보가 토폴로지 아래의 관계 테이블에 표시되며, 관련된 모든 볼륨의 마지막 성공 전송 정보도 함께 표시됩니다.

+
** *이력*
+
선택한 볼륨에 대한 수신 SnapMirror 및 SnapVault 보호 관계의 기록을 그래프로 표시합니다. 수신 관계 지연 시간, 수신 관계 전송 시간, 수신 관계 전송 크기의 세 가지 기록 그래프를 사용할 수 있습니다. 기록 정보는 대상 볼륨을 선택한 경우에만 표시됩니다. 기본 볼륨을 선택하면 그래프가 비어 있고 데이터를 찾을 수 없음 메시지가 표시됩니다. 볼륨이 일관성 그룹 및 SnapMirror 동기 관계로 보호되는 경우 관계 전송 시간 및 관계 전송 크기에 대한 정보는 표시되지 않습니다.



+
기록 창 상단의 드롭다운 목록에서 그래프 유형을 선택할 수 있습니다. 1주, 1개월 또는 1년을 선택하여 특정 기간의 세부 정보를 볼 수도 있습니다. 기록 그래프는 추세를 파악하는 데 도움이 됩니다. 예를 들어, 하루 또는 매주 같은 시간에 대량의 데이터가 전송되거나 지연 경고 또는 지연 오류 임계값이 지속적으로 초과되는 경우 적절한 조치를 취할 수 있습니다. 또한 *내보내기* 버튼을 클릭하여 현재 보고 있는 차트에 대한 CSV 형식 보고서를 생성할 수 있습니다.



보호 이력 그래프에는 다음 정보가 표시됩니다:

* *관계 지연 기간*
+
선택한 기간에 따라 세로(y) 축에는 초, 분 또는 시간을, 가로(x) 축에는 일, 월 또는 년을 표시합니다. y축의 최대값은 x축에 표시된 기간 동안 발생한 최대 지연 시간을 나타냅니다. 그래프의 가로 주황색 선은 지연 오류 임계값을, 가로 노란색 선은 지연 경고 임계값을 나타냅니다. 마우스 커서를 이 선 위에 올리면 임계값 설정이 표시됩니다. 가로 파란색 선은 지연 시간을 나타냅니다. 관심 있는 영역에 마우스 커서를 올리면 해당 지점의 세부 정보를 볼 수 있습니다.

* *관계 전송 기간*
+
선택한 기간에 따라 세로(y)축에는 초, 분 또는 시간을 표시하고, 가로(x)축에는 일, 월 또는 연도를 표시합니다. y축의 상단 값은 x축에 표시된 기간 동안 도달한 최대 전송 시간을 나타냅니다. 관심 있는 영역 위에 커서를 올려놓으면 그래프의 특정 지점에 대한 세부 정보를 볼 수 있습니다.

+
[NOTE]
====
이 차트는 동기식 보호 관계가 설정된 볼륨에는 사용할 수 없습니다.

====
* *관계 전송 크기*
+
세로축(y축)에는 전송 크기에 따라 바이트, 킬로바이트, 메가바이트 등이 표시되고, 가로축(x축)에는 선택한 기간에 따라 일, 월 또는 년이 표시됩니다. y축의 상단 값은 x축에 표시된 기간 동안 도달한 최대 전송 크기를 나타냅니다. 그래프에서 관심 있는 영역에 커서를 올려놓으면 특정 지점에 대한 자세한 정보를 볼 수 있습니다.

+
[NOTE]
====
이 차트는 동기식 보호 관계가 설정된 볼륨에는 사용할 수 없습니다.

====




[[history-area]]
== 기록 영역

기록 영역에는 선택한 볼륨의 용량 및 공간 예약 정보를 제공하는 그래프가 표시됩니다. 또한 *내보내기* 버튼을 클릭하여 현재 보고 있는 차트를 CSV 형식의 보고서로 생성할 수 있습니다.

데이터 또는 볼륨의 상태가 일정 기간 동안 변경되지 않으면 그래프가 비어 있고 데이터를 찾을 수 없음 메시지가 표시될 수 있습니다.

기록 창 상단의 드롭다운 목록에서 그래프 유형을 선택할 수 있습니다. 1주, 1개월 또는 1년을 선택하여 특정 기간의 세부 정보를 볼 수도 있습니다. 기록 그래프는 추세를 파악하는 데 도움이 됩니다. 예를 들어, 볼륨 사용량이 지속적으로 '거의 가득 참' 임계값을 초과하는 경우 적절한 조치를 취할 수 있습니다.

이력 그래프는 다음과 같은 정보를 표시합니다:

* *사용된 볼륨 용량*
+
세로(y) 축에 바이트, 킬로바이트, 메가바이트 등의 단위로 볼륨의 사용 용량과 사용 이력을 기반으로 한 볼륨 용량 사용 추세를 선 그래프로 표시합니다. 가로(x) 축에는 기간이 표시됩니다. 일주일, 한 달 또는 1년의 기간을 선택할 수 있습니다. 특정 영역에 커서를 올려 그래프의 특정 지점에 대한 세부 정보를 볼 수 있습니다. 해당 범례를 클릭하여 선 그래프를 숨기거나 표시할 수 있습니다. 예를 들어, 볼륨 사용 용량 범례를 클릭하면 볼륨 사용 용량 그래프 선이 숨겨집니다.

* *볼륨 사용 용량 대비 총 용량*
+
사용 이력을 기반으로 볼륨 용량이 사용되는 추세와 사용된 용량, 총 용량, 중복 제거 및 압축을 통한 공간 절약 세부 정보를 세로(y) 축에 바이트, 킬로바이트, 메가바이트 등의 단위로 선 그래프로 표시합니다. 가로(x) 축에는 기간이 표시됩니다. 일주일, 한 달 또는 1년의 기간을 선택할 수 있습니다. 특정 영역에 커서를 올려 그래프의 특정 지점에 대한 세부 정보를 볼 수 있습니다. 해당 범례를 클릭하여 선 그래프를 숨기거나 표시할 수 있습니다. 예를 들어, Trend Capacity Used 범례를 클릭하면 Trend Capacity Used 그래프 선이 숨겨집니다.

* *사용된 볼륨 용량(%)*
+
사용 이력을 기반으로 볼륨의 사용된 용량과 볼륨 용량 사용 추세를 세로(y) 축에 백분율로 선 그래프로 표시합니다. 기간은 가로(x) 축에 표시됩니다. 1주, 1개월 또는 1년의 기간을 선택할 수 있습니다. 특정 영역에 커서를 올려 그래프의 특정 지점에 대한 세부 정보를 볼 수 있습니다. 해당 범례를 클릭하여 선 그래프를 숨기거나 표시할 수 있습니다. 예를 들어, 볼륨 사용 용량 범례를 클릭하면 볼륨 사용 용량 그래프 선이 숨겨집니다.

* *스냅샷 용량 사용률(%)*
+
세로(y) 축의 백분율로, 스냅샷 예약 및 스냅샷 경고 임계값을 꺾은선 그래프로 표시하고 Snapshot 복사본에서 사용하는 용량을 영역 그래프로 표시합니다. 스냅샷 오버플로는 서로 다른 색상으로 표시됩니다. 시간 기간은 가로(x) 축에 표시됩니다. 주, 월 또는 연도의 기간을 선택할 수 있습니다. 커서를 특정 영역 위에 놓으면 그래프의 특정 지점에 대한 세부 정보를 볼 수 있습니다. 해당 범례를 클릭하여 꺾은선 그래프를 숨기거나 표시할 수 있습니다. 예를 들어, Snapshot Reserve 범례를 클릭하면 Snapshot Reserve 그래프 선이 숨겨집니다.

[[related-devices-pane]]
== 관련 장치 창

관련 장치 창을 사용하면 볼륨과 관련된 SVM, 애그리게이트, qtree, LUN 및 스냅샷 복사본을 보고 탐색할 수 있습니다:

* *스토리지 가상 머신*
+
선택한 볼륨을 포함하는 SVM의 용량과 상태를 표시합니다.

* *애그리게이트*
+
선택한 볼륨을 포함하는 애그리게이트의 용량 및 상태를 표시합니다. FlexGroup 볼륨의 경우 FlexGroup을 구성하는 애그리게이트 수가 나열됩니다.

* *애그리게이트의 볼륨*
+
선택한 볼륨의 상위 애그리게이트에 속한 모든 볼륨의 개수와 용량을 표시합니다. 볼륨의 상태도 가장 높은 심각도 수준을 기준으로 표시됩니다. 예를 들어, 애그리게이트에 10개의 볼륨이 있고 그중 5개가 경고 상태이고 나머지 5개가 심각 상태인 경우, 심각 상태가 표시됩니다. 이 구성 요소는 FlexGroup 볼륨에는 나타나지 않습니다.

* * Qtree *
+
선택한 볼륨에 포함된 qtree의 개수와 할당량이 있는 qtree의 용량을 표시합니다. 할당량이 있는 qtree의 용량은 볼륨 데이터 용량 대비로 표시됩니다. qtree의 상태 또한 가장 높은 심각도 수준을 기준으로 표시됩니다. 예를 들어, 볼륨에 10개의 qtree가 있고 그중 5개가 경고(Warning) 상태이고 나머지 5개가 심각(Critical) 상태인 경우, 심각(Critical) 상태가 표시됩니다.

* *NFS 공유*
+
해당 볼륨과 연결된 NFS 공유의 수와 상태를 표시합니다.

* *SMB 공유*
+
SMB/CIFS 공유의 개수와 상태를 표시합니다.

* * LUN *
+
선택한 볼륨에 있는 모든 LUN의 개수와 총 크기를 표시합니다. 또한 가장 높은 심각도 수준을 기준으로 LUN의 상태도 표시됩니다.

* *사용자 및 그룹 할당량*
+
볼륨 및 해당 qtree와 연결된 사용자 및 사용자 그룹 할당량의 수와 상태를 표시합니다.

* *FlexClone 볼륨*
+
선택한 볼륨의 모든 복제된 볼륨의 수와 용량을 표시합니다. 선택한 볼륨에 복제된 볼륨이 포함되어 있는 경우에만 수와 용량이 표시됩니다.

* *상위 볼륨*
+
선택한 FlexClone 볼륨의 상위 볼륨 이름과 용량을 표시합니다. 상위 볼륨은 선택한 볼륨이 FlexClone 볼륨인 경우에만 표시됩니다.

== 관련 그룹 창

관련 그룹 창을 사용하면 선택한 볼륨과 연결된 그룹 목록을 볼 수 있습니다.



[[related-alerts-pane]]
== 관련 알림 창

관련 알림 창에서는 선택한 볼륨에 대해 생성된 알림 목록을 볼 수 있습니다. 알림 추가 링크를 클릭하여 알림을 추가하거나 알림 이름을 클릭하여 기존 알림을 편집할 수도 있습니다.
