= Active IQ Unified Manager에서 FabricPool 용량 정보 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
클러스터, 애그리게이트 및 볼륨에 대한 FabricPool 용량 정보는 해당 개체의 용량 및 성능 인벤토리 및 세부 정보 페이지에서 확인할 수 있습니다. 미러 계층이 구성된 경우 이러한 페이지에는 FabricPool 미러 정보도 표시됩니다.

이 페이지에는 로컬 성능 계층과 클라우드 계층에서 사용 가능한 용량, 두 계층에서 사용 중인 용량, 클라우드 계층에 연결된 애그리게이트, 특정 정보를 클라우드 계층으로 이동하여 FabricPool 기능을 구현하는 볼륨 등의 정보가 표시됩니다.

클라우드 계층이 다른 클라우드 공급자("`미러 계층`")로 미러링되면 애그리게이트 / 상태 세부 정보 페이지에 두 클라우드 계층이 모두 표시됩니다.

.단계
. 다음 중 하나를 수행하십시오:
+
[cols="2*"]
|===
| 용량 정보를 보려면... | 이렇게 하세요... 


 a| 
클러스터
 a| 
.. 용량: 모든 클러스터 보기에서 클러스터를 클릭합니다.
.. 클러스터/상태 세부 정보 페이지에서 *구성* 탭을 클릭합니다.
+
화면에는 이 클러스터가 연결된 클라우드 계층의 이름이 표시됩니다.





 a| 
애그리게이트
 a| 
.. 용량: 모든 애그리게이트 보기에서 유형 필드에 "`SSD (FabricPool)`" 또는 "`HDD (FabricPool)`"가 표시된 애그리게이트를 클릭합니다.
.. 애그리게이트/상태 상세 페이지에서 *용량* 탭을 클릭합니다.
+
디스플레이에는 클라우드 계층에서 사용된 총 용량이 표시됩니다.

.. *디스크 정보* 탭을 클릭하십시오.
+
화면에는 클라우드 티어 이름과 사용 중인 용량이 표시됩니다.

.. *구성* 탭을 클릭합니다.
+
화면에는 클라우드 티어의 이름과 해당 클라우드 티어에 대한 기타 자세한 정보가 표시됩니다.





 a| 
볼륨
 a| 
.. 용량: 모든 볼륨 보기에서 "`계층화 정책`" 필드에 정책 이름이 표시되는 볼륨을 클릭합니다.
.. 볼륨/상태 세부 정보 페이지에서 *구성* 탭을 클릭합니다.
+
화면에는 볼륨에 할당된 FabricPool 티어링 정책의 이름이 표시됩니다.



|===
. *워크로드 분석* 페이지의 *용량 추세* 영역에서 "`클라우드 계층 보기`"를 선택하면 지난 한 달 동안 로컬 성능 계층과 클라우드 계층에서 사용된 용량을 확인할 수 있습니다.


FabricPool 애그리게이트에 대한 자세한 내용은 다음을 참조하십시오 https://docs.netapp.com/us-en/ontap/disks-aggregates/index.html["디스크 및 애그리게이트 개요"].
