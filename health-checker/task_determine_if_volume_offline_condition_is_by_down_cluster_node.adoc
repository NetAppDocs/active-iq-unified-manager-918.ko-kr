= Active IQ Unified Manager에서 호스트 노드가 다운되어 볼륨이 오프라인 상태인지 확인합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 웹 UI를 사용하여 볼륨이 오프라인 상태가 된 이유가 호스트 노드가 다운되었고 스토리지 페일오버가 HA 페어 파트너로 실패했기 때문인지 여부를 확인하거나 배제할 수 있습니다.

.시작하기 전에
운영자, 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

볼륨 오프라인 상태가 호스팅 노드 장애 및 그에 따른 스토리지 페일오버 실패로 인한 것인지 확인하려면 다음 작업을 수행하십시오:

.단계
. 오프라인 볼륨의 *볼륨 / 상태* 세부 정보 페이지의 *관련 장치* 창에서 SVM 아래에 표시된 하이퍼텍스트 링크를 찾아 클릭합니다.
+
스토리지 VM / 상태 세부 정보 페이지에는 오프라인 볼륨을 호스팅하는 스토리지 가상 머신(SVM)에 대한 정보가 표시됩니다.

. *스토리지 VM / 상태* 세부 정보 페이지의 *관련 장치* 창에서 볼륨 아래에 표시된 하이퍼텍스트 링크를 찾아 클릭합니다.
+
상태: 모든 볼륨 보기에는 SVM에서 호스팅하는 모든 볼륨에 대한 정보가 표 형식으로 표시됩니다.

. *상태: 모든 볼륨* 보기의 상태 열 헤더에서 필터 기호 image:../media/filtericon_um60.png["컬럼 필터 아이콘"]를 클릭한 다음 *오프라인* 옵션을 선택합니다.
+
오프라인 상태인 SVM 볼륨만 목록에 표시됩니다.

. 상태: 모든 볼륨 보기에서 격자 기호 image:../media/gridviewicon.gif["그리드 보기용 아이콘"]를 클릭한 다음 *Cluster Nodes* 옵션을 선택합니다.
+
그리드 선택 상자에서 *클러스터 노드* 옵션을 찾으려면 스크롤해야 할 수도 있습니다.

+
볼륨 인벤토리에 클러스터 노드 열이 추가되어 각 오프라인 볼륨을 호스팅하는 노드의 이름을 표시합니다.

. *상태: 모든 볼륨* 보기에서 오프라인 볼륨의 목록을 찾은 다음, 클러스터 노드 열에서 해당 호스팅 노드의 이름을 클릭합니다.
+
클러스터/상태 세부 정보 페이지의 노드 탭에는 호스팅 노드가 속한 HA 노드 쌍의 상태가 표시됩니다. 호스팅 노드의 상태와 클러스터 장애 조치 작업의 성공 여부가 표시됩니다.



볼륨이 오프라인 상태가 된 이유가 호스트 노드가 다운되었고 HA 페어 파트너로의 스토리지 페일오버가 실패했기 때문임을 확인한 후에는 해당 관리자 또는 운영자에게 문의하여 다운된 노드를 수동으로 재시작하고 스토리지 페일오버 문제를 해결하십시오.
