= Active IQ Unified Manager에서 Linux의 백업 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager가 Linux 시스템에 설치된 경우 NetApp 스냅샷을 사용하여 백업 및 복원을 구성할 수 있습니다.

스냅샷 복사본을 생성하는 데는 보통 몇 분 정도로 시간이 매우 짧게 소요되며, Unified Manager 데이터베이스가 잠기는 시간도 매우 짧아 설치에 미치는 중단이 거의 없습니다. 이미지는 마지막 스냅샷 복사본 생성 이후 파일 변경 사항만 기록하므로 최소한의 스토리지 공간을 소비하며 성능 오버헤드도 무시할 수 있는 수준입니다. 스냅샷은 ONTAP 클러스터에서 생성되므로, 필요한 경우 SnapMirror 등 다른 NetApp 기능을 활용하여 보조 보호를 생성할 수 있습니다.

Unified Manager는 백업 작업을 시작하기 전에 대상 시스템을 사용할 수 있는지 확인하기 위해 무결성 검사를 수행합니다.

[NOTE]
====
* 동일한 버전의 Active IQ Unified Manager에서만 Snapshot 복사본을 복원할 수 있습니다.
+
예를 들어 Unified Manager 9.18에서 백업을 생성한 경우 해당 백업은 Unified Manager 9.18 시스템에서만 복원할 수 있습니다.

* 스냅샷 구성에 변경 사항이 있는 경우 스냅샷이 무효화될 수 있습니다.


====


[[configure-snapshot-copy-location-in-active-iq-unified-manager]]
== Active IQ Unified Manager에서 스냅샷 복사본 위치 구성

ONTAP 시스템 관리자 또는 ONTAP CLI를 사용하여 ONTAP 클러스터 중 하나에서 Snapshot 복사본이 저장될 볼륨을 구성할 수 있습니다.

.시작하기 전에
클러스터, 스토리지 VM 및 볼륨은 다음 요구 사항을 충족해야 합니다:

* 클러스터 요구 사항:
+
** ONTAP 9.3 이상 버전이 설치되어 있어야 합니다
** 해당 위치는 Unified Manager 서버와 지리적으로 가까워야 합니다.
** Unified Manager를 통해 모니터링할 수 있지만 필수 사항은 아닙니다


* 스토리지 VM 요구 사항:
+
** 이름 전환 및 이름 매핑은 "`files`"를 사용하도록 설정해야 합니다.
** 클라이언트 측 사용자와 대응하도록 생성된 로컬 사용자
** 모든 읽기/쓰기 액세스가 선택되어 있는지 확인하십시오
** 내보내기 정책에서 슈퍼유저 액세스가 "`any`"로 설정되어 있는지 확인하십시오.
** Linux용 NetApp 스냅샷용 NFS
** NFS 서버에서 NFSv4를 활성화해야 하며 클라이언트 및 스토리지 VM에 NFSv4 ID 도메인을 지정해야 합니다.
** 볼륨은 Unified Manager/opt/netapp/data 디렉터리 크기의 최소 두 배 이상이어야 합니다.
+
현재 크기를 확인하려면 du -sh /opt/netapp/data/ 명령어를 사용하십시오.



* 볼륨 요구 사항:
+
** 볼륨은 Unified Manager /opt/netapp/data 디렉터리 크기의 최소 두 배 이상이어야 합니다.
** 보안 스타일은 UNIX로 설정해야 합니다.
** 로컬 스냅샷 정책을 비활성화해야 합니다
** 볼륨 자동 크기 조정 기능을 활성화해야 합니다
** 성능 서비스 수준은 "`Extreme`" 등 높은 IOPS와 낮은 지연 시간을 제공하는 정책으로 설정해야 합니다.




NFS 볼륨 생성에 대한 자세한 단계는  https://kb.netapp.com/Advice_and_Troubleshooting/Data_Storage_Software/ONTAP_OS/How_to_configure_NFSv4_in_Cluster-Mode["ONTAP 9에서 NFSv4를 구성하는 방법"] 및  http://docs.netapp.com/ontap-9/topic/com.netapp.doc.exp-nfsv3-cg/home.html["ONTAP 9 NFS 구성 간편 가이드"]를 참조하십시오.



[[specify-the-destination-location-for-snapshot-copies-in-active-iq-unified-manager]]
== Active IQ Unified Manager에서 스냅샷 복사본의 대상 위치를 지정합니다

Active IQ Unified Manager 스냅샷 복사본의 대상 위치는 ONTAP 클러스터 중 하나에 이미 구성한 볼륨으로 구성해야 합니다. 위치를 정의하려면 유지 관리 콘솔을 사용해야 합니다.

* Active IQ Unified Manager가 설치된 Linux 호스트의 루트 사용자 자격 증명이 있어야 합니다.
* Unified Manager 서버의 유지 관리 콘솔에 로그인하도록 승인된 사용자 ID와 암호가 있어야 합니다.
* 클러스터 관리 IP 주소, 스토리지 VM 이름, 볼륨 이름, 스토리지 시스템 사용자 이름 및 암호가 있어야 합니다.
* 볼륨을 Active IQ Unified Manager 호스트에 마운트해야 하며, 마운트 경로를 알고 있어야 합니다.


.단계
. Secure Shell을 사용하여 Active IQ Unified Manager 시스템의 IP 주소 또는 FQDN에 연결하십시오.
. 유지보수 사용자(umadmin)의 이름과 비밀번호로 시스템에 로그인하십시오.
. 명령어 `maintenance_console`를 입력하고 Enter 키를 누르십시오.
. 유지 관리 콘솔 *메인 메뉴*에서 *백업 복원* 옵션에 해당하는 번호를 입력하십시오.
. *NetApp 스냅샷 백업 구성*에 대한 번호를 입력하십시오.
. NFS를 구성하려면 숫자를 입력하십시오.
. 제공해야 할 정보를 검토한 후 *백업 구성 세부 정보 입력*에 번호를 입력하십시오.
. 스냅샷이 기록될 볼륨을 식별하려면 클러스터 관리 인터페이스의 IP 주소, 스토리지 VM 이름, 볼륨 이름, LUN 이름, 스토리지 시스템 사용자 이름 및 암호, 마운트 경로를 입력하십시오.
. 이 정보를 확인하고 입력하십시오 `y`.
+
시스템은 다음과 같은 작업을 수행합니다:

+
** 클러스터와의 연결을 설정합니다
** 모든 서비스를 중지합니다
** 볼륨에 새 디렉터리를 생성하고 Active IQ Unified Manager 데이터베이스 구성 파일을 복사합니다
** Active IQ Unified Manager에서 파일을 삭제하고 새 데이터베이스 디렉터리에 대한 심볼릭 링크를 생성합니다.
** 모든 서비스를 재시작합니다


. 아직 이 작업을 수행하지 않은 경우, 유지 관리 콘솔을 종료하고 Active IQ Unified Manager 인터페이스를 실행하여 스냅샷 복사본에 대한 일정을 생성하십시오.
