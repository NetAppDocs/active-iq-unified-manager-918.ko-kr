= Active IQ Unified Manager에서 주석 규칙 재정렬
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager에서 스토리지 오브젝트에 주석 규칙을 적용하는 순서를 변경할 수 있습니다. 주석 규칙은 순위에 따라 순차적으로 스토리지 오브젝트에 적용됩니다. 주석 규칙을 구성할 때 순위는 가장 낮습니다. 하지만 필요에 따라 주석 규칙의 순위를 변경할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

한 행 또는 여러 행을 선택하고 드래그 앤 드롭 작업을 통해 주석 규칙의 순위를 변경할 수 있습니다. 단, 변경 사항을 저장해야 주석 규칙 탭에 우선순위 재지정이 표시됩니다.

.단계
. 왼쪽 탐색 창에서 *스토리지 관리* > *주석*을 클릭합니다.
. *주석 규칙* 탭에서 *순서 변경*을 클릭합니다.
. *주석 규칙 재정렬* 대화 상자에서 단일 또는 여러 행을 드래그 앤 드롭하여 주석 규칙의 순서를 재정렬합니다.
. *저장*을 클릭합니다.
+
재정렬이 표시되려면 변경 사항을 저장해야 합니다.
