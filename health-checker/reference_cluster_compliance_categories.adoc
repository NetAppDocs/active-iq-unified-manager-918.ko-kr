= Active IQ Unified Manager의 클러스터 규정 준수 범주 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이 표는 Unified Manager가 평가하는 클러스터 보안 규정 준수 매개변수, NetApp 권장 사항, 그리고 해당 매개변수가 클러스터의 규정 준수 여부 최종 결정에 영향을 미치는지 여부를 설명합니다.

클러스터에 규정을 준수하지 않는 SVM이 있는 경우 클러스터의 규정 준수 값에 영향을 미칩니다. 따라서 경우에 따라 클러스터 보안이 규정을 준수하는 것으로 간주되기 전에 SVM의 보안 문제를 해결해야 할 수 있습니다.

아래 나열된 모든 매개변수가 모든 설치 환경에서 표시되는 것은 아닙니다. 예를 들어, 피어링된 클러스터가 없거나 클러스터에서 AutoSupport를 비활성화한 경우 UI 페이지에 클러스터 피어링 또는 AutoSupport HTTPS 전송 항목이 표시되지 않습니다.

[cols="4*"]
|===
| 매개변수 | 설명 | 권장 사항 | 클러스터 규정 준수에 영향을 미칩니다 


 a| 
글로벌 FIPS
 a| 
글로벌 FIPS(연방 정보 처리 표준) 140-2 준수 모드 활성화 여부를 나타냅니다. FIPS가 활성화되면 TLSv1 및 SSLv3이 비활성화되고 TLSv1.1 및 TLSv1.2만 허용됩니다.
 a| 
활성화됨
 a| 
예



 a| 
Telnet
 a| 
시스템에 대한 Telnet 액세스가 활성화되었는지 비활성화되었는지 여부를 나타냅니다. NetApp은 안전한 원격 액세스를 위해 SSH(Secure Shell) 사용을 권장합니다.
 a| 
비활성화됨
 a| 
예



 a| 
안전하지 않은 SSH 설정
 a| 
SSH가 안전하지 않은 암호화 방식(예: *cbc로 시작하는 암호화 방식)을 사용하는지 여부를 나타냅니다.
 a| 
아니요
 a| 
예



 a| 
로그인 배너
 a| 
시스템에 접속하는 사용자에 대해 로그인 배너가 활성화 또는 비활성화되어 있는지 나타냅니다.
 a| 
활성화됨
 a| 
예



 a| 
클러스터 피어링
 a| 
피어링된 클러스터 간 통신이 암호화되는지 또는 암호화되지 않는지를 나타냅니다. 이 매개변수가 규정을 준수하는 것으로 간주되려면 소스 클러스터와 대상 클러스터 모두에 암호화가 구성되어 있어야 합니다.
 a| 
암호화됨
 a| 
예



 a| 
네트워크 시간 프로토콜
 a| 
클러스터에 하나 이상의 NTP 서버가 구성되어 있는지 여부를 나타냅니다. 이중화 및 최상의 서비스를 위해 NetApp은 클러스터에 최소 3개의 NTP 서버를 연결할 것을 권장합니다.
 a| 
구성됨
 a| 
예



 a| 
OCSP
 a| 
9.14.1부터 Active IQ Unified Manager는 스토리지 가상 머신(SVM, 이전 명칭: Vserver) 수준에서 온라인 인증서 상태 프로토콜(OCSP) 상태 정보를 제공합니다. 즉, SVM에 대한 모든 SSL/TLS 연결에 OCSP 유효성 검사가 적용되어 이러한 연결에 사용되는 인증서의 무결성과 유효성이 보장됩니다.

활성화됨
 a| 
아니요

 a| 
암호화됨
 a| 
예

 a|
