= Active IQ Unified Manager의 유지보수 콘솔에서 Snapshot 백업 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스냅샷 복사본을 사용하여 Active IQ Unified Manager 백업을 수행하려면 유지 관리 콘솔에서 몇 가지 구성 단계를 수행해야 합니다.

.시작하기 전에
시스템에 대한 다음 정보를 가지고 있어야 합니다:

* 클러스터 IP 주소
* 스토리지 VM 이름
* 볼륨 이름
* LUN 이름
* 마운트 경로
* 스토리지 시스템 자격 증명


.단계
. Unified Manager의 유지 관리 콘솔에 액세스합니다.
. 4를 입력하여 *백업 복원*을 선택하세요.
. 2를 입력하여 *NetApp 스냅샷을 사용한 백업 및 복원*을 선택하십시오.
+
[NOTE]
====
백업 구성을 변경하려면 3을 입력하여 *NetApp 스냅샷 백업 구성 업데이트*를 선택하십시오. 암호만 업데이트할 수 있습니다.

====
. 메뉴에서 1을 입력하여 *NetApp 스냅샷 백업 구성*을 선택하십시오.
. 필수 정보를 제공하려면 1을 입력하십시오.
. 유지 관리 콘솔의 사용자 이름과 암호를 입력한 다음, LUN이 호스트에 마운트되었는지 확인하십시오.
+
그런 다음 프로세스는 사용자가 제공한 데이터 디렉터리, LUN 경로, 스토리지 VM, 볼륨, 공간 가용성, 드라이브 등이 올바른지 확인합니다. 백그라운드에서 진행되는 작업은 다음과 같습니다.

+
** 서비스가 중단되었습니다
** 데이터베이스 디렉터리가 마운트된 스토리지로 이동되었습니다
** 데이터베이스 디렉터리가 삭제되고 심볼릭 링크가 생성됩니다
** Active IQ Unified Manager 인터페이스에서 구성이 완료된 후 서비스가 다시 시작되고, 백업 유형이 NetApp 스냅샷으로 수정되며 사용자 인터페이스에 데이터베이스 백업(스냅샷 기반)으로 반영됩니다.




스냅샷 구성 변경으로 인해 스냅샷이 무효화될 수 있으므로 백업 작업을 시작하기 전에 스냅샷 구성에 변경 사항이 있는지 확인해야 합니다. G 드라이브에 백업을 구성하고 스냅샷을 생성했다고 가정해 보겠습니다. 나중에 백업을 E 드라이브로 재구성하면 새 구성에 따라 데이터가 E 드라이브에 저장됩니다. G 드라이브에 있을 때 생성된 스냅샷을 복원하려고 하면 G 드라이브가 존재하지 않는다는 오류와 함께 실패합니다.
