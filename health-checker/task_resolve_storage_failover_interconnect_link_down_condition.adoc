= Active IQ Unified Manager에서 스토리지 페일오버 인터커넥트 링크 다운 상태를 검색하고 해결합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이 워크플로는 다운된 스토리지 페일오버 상호 연결 링크 상태를 검색, 평가 및 해결하는 방법에 대한 예를 제공합니다. 이 시나리오에서 귀하는 관리자로서 Unified Manager를 사용하여 노드에서 ONTAP 버전 업그레이드를 시작하기 전에 스토리지 페일오버 위험을 검색합니다.

.시작하기 전에
운영자, 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

무중단 업그레이드 시도 중에 HA 쌍 노드 간의 스토리지 페일오버 상호 연결에 문제가 발생하면 업그레이드가 실패합니다. 따라서 관리자가 업그레이드를 시작하기 전에 업그레이드 대상 클러스터 노드의 스토리지 페일오버 안정성을 모니터링하고 확인하는 것이 일반적입니다.

.단계
. 왼쪽 탐색 창에서 *이벤트 관리*를 클릭합니다.
. *이벤트 관리* 인벤토리 페이지에서 *활성 가용성 이벤트*를 선택합니다.
. *이벤트 관리* 인벤토리 페이지 *이름* 열 상단에서 image:../media/filtericon_um60.png["컬럼 필터 아이콘"]을(를) 클릭하고 텍스트 상자에  `*failover`을(를) 입력하여 표시되는 이벤트를 스토리지 페일오버 관련 이벤트로 제한하십시오.
+
과거 스토리지 장애 조치 조건과 관련된 모든 이벤트가 표시됩니다.

+
이 시나리오에서 Unified Manager는 가용성 인시던트 섹션에 "`Storage Failover Interconnect One or More Links Down`" 이벤트를 표시합니다.

. 스토리지 장애 조치와 관련된 이벤트가 *이벤트 관리* 인벤토리 페이지에 하나 이상 표시되는 경우 다음 단계를 수행하십시오.
+
.. 이벤트 제목 링크를 클릭하면 해당 이벤트의 세부 정보를 볼 수 있습니다.
+
이 예시에서는 "`Storage Failover Interconnect One or More Links Down`" 이벤트 제목을 클릭합니다.

+
해당 이벤트의 상세 정보 페이지가 표시됩니다.

.. 이벤트 상세 정보 페이지에서 다음 작업 중 하나 이상을 수행할 수 있습니다:
+
*** 원인 필드에 있는 오류 메시지를 검토하고 문제를 평가하십시오.
*** 이벤트를 관리자에게 할당하십시오.
*** 이벤트를 확인하십시오.
