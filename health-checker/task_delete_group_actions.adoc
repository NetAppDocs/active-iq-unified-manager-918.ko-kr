= Active IQ Unified Manager에서 그룹 작업 삭제
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager에서 더 이상 필요하지 않은 그룹 작업을 삭제할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

볼륨 상태 임계값에 대한 그룹 작업을 삭제하면 해당 그룹의 스토리지 오브젝트에 전역 임계값이 적용됩니다. 스토리지 오브젝트에 설정된 모든 오브젝트 수준 상태 임계값은 영향을 받지 않습니다.

.단계
. 왼쪽 탐색 창에서 *스토리지 관리* > *그룹*을 클릭합니다.
. *그룹 작업* 탭에서 삭제하려는 그룹 작업을 선택한 다음 *삭제*를 클릭합니다.
. *경고* 대화 상자에서 *예*를 클릭하여 삭제를 확인합니다.
