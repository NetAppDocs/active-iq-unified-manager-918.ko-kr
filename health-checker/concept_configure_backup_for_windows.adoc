= Active IQ Unified Manager에서 Windows 백업 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager는 iSCSI 프로토콜을 사용하는 LUN을 통해 Windows 운영 체제에서 NetApp 스냅샷을 이용한 백업 및 복원을 지원합니다.

스냅샷 기반 백업은 모든 Unified Manager 서비스가 실행 중인 상태에서 수행할 수 있습니다. 백업 시 전체 데이터베이스에 전역 읽기 잠금이 설정되어 동시 쓰기 작업을 방지하므로, 스냅샷의 일부로 일관된 데이터베이스 상태가 캡처됩니다. Windows OS에 설치된 Unified Manager 시스템에서 NetApp 스냅샷을 사용하여 백업 및 복원을 수행하려면 먼저 유지 관리 콘솔을 사용하여 Unified Manager 백업을 스냅샷 기반으로 구성해야 합니다.

Unified Manager를 사용하여 스냅샷 복사본을 생성하도록 구성하기 전에 다음 구성 작업을 수행해야 합니다.

* ONTAP 클러스터 구성
* Windows 호스트 머신 구성




[[configure-a-backup-location-for-active-iq-unified-manager-on-windows]]
== Windows에서 Active IQ Unified Manager의 백업 위치 구성

Windows에서 Unified Manager를 백업한 후에는 스냅샷 복사본을 저장할 볼륨을 구성해야 합니다.

.시작하기 전에
클러스터, 스토리지 VM 및 볼륨은 다음 요구 사항을 충족해야 합니다:

* 클러스터 요구 사항:
+
** ONTAP 9.3 이상 버전이 설치되어 있어야 합니다
** 해당 위치는 Unified Manager 서버와 지리적으로 가까워야 합니다.
** Unified Manager가 모니터링합니다


* 스토리지 VM 요구 사항:
+
** ONTAP 클러스터의 iSCSI 연결
** 구성된 장비에 iSCSI 프로토콜이 활성화되어 있어야 합니다.
** 백업 구성을 위한 전용 볼륨 및 LUN이 있어야 합니다. 선택한 볼륨에는 LUN이 하나만 포함되어야 하며, 다른 내용은 없어야 합니다.
** LUN의 크기는 9.9 Active IQ Unified Manager에서 처리될 것으로 예상되는 데이터 크기의 최소 두 배여야 합니다.
+
이는 볼륨에 대해서도 동일한 크기 요건을 설정합니다.

** 모든 읽기/쓰기 액세스가 선택되어 있는지 확인하십시오
** 내보내기 정책에서 슈퍼유저 액세스가 "`any`"로 설정되어 있는지 확인하십시오.


* 볼륨 및 LUN 요구 사항:
+
** 볼륨은 Unified Manager MySQL 데이터 디렉터리 크기의 최소 두 배 이상이어야 합니다.
** 보안 스타일은 Windows로 설정해야 합니다.
** 로컬 스냅샷 정책을 비활성화해야 합니다
** 볼륨 자동 크기 조정 기능을 활성화해야 합니다
** 성능 서비스 수준은 "`Extreme`" 등 높은 IOPS와 낮은 지연 시간을 제공하는 정책으로 설정해야 합니다.






[[configure-an-ontap-cluster-for-backup-and-restore-in-active-iq-unified-manager]]
== Active IQ Unified Manager에서 백업 및 복원을 위한 ONTAP 클러스터 구성

Windows 시스템에서 스냅샷 복사를 사용하여 Active IQ Unified Manager를 백업 및 복원하려면 먼저 ONTAP 클러스터에서 몇 가지 사전 구성 단계를 수행해야 합니다.

명령 프롬프트 또는 System Manager 사용자 인터페이스를 사용하여 ONTAP 클러스터를 구성할 수 있습니다. ONTAP 클러스터 구성에는 스토리지 VM에 iSCSI LIF로 할당할 수 있도록 데이터 LIF를 구성하는 작업이 포함됩니다. 다음 단계는 System Manager 사용자 인터페이스를 사용하여 iSCSI 지원 스토리지 VM을 구성하는 것입니다. LIF가 아웃바운드 트래픽을 위해 네트워크를 사용하는 방식을 제어하려면 이 스토리지 VM에 대한 정적 네트워크 경로를 구성해야 합니다.

[NOTE]
====
백업 구성을 위한 전용 볼륨과 LUN이 있어야 합니다. 선택한 볼륨에는 LUN이 하나만 포함되어야 합니다. LUN의 크기는 Active IQ Unified Manager에서 처리할 것으로 예상되는 데이터 크기의 두 배 이상이어야 합니다.

====
다음 구성을 수행해야 합니다:

.단계
. iSCSI가 활성화된 스토리지 VM을 구성하거나 동일한 구성을 가진 기존 스토리지 VM을 사용하십시오.
. 구성된 스토리지 VM에 대한 네트워크 경로를 구성합니다.
. 적절한 용량의 볼륨과 그 안에 하나의 LUN을 구성하고, 해당 볼륨이 이 LUN 전용으로 사용되도록 하십시오.
+

NOTE: System Manager에서 LUN을 생성하는 시나리오에서 LUN 매핑을 해제하면 igroup이 삭제되어 복원이 실패할 수 있습니다. 이러한 상황을 방지하려면 LUN을 생성할 때 명시적으로 생성하고 LUN 매핑 해제 시 삭제되지 않도록 해야 합니다.

. 스토리지 VM에서 이니시에이터 그룹을 구성합니다.
. 포트셋을 구성합니다.
. igroup을 포트셋과 통합합니다.
. LUN을 igroup에 매핑합니다.




[[configure-a-windows-host-machine-in-active-iq-unified-manager]]
== Active IQ Unified Manager에서 Windows 호스트 머신 구성

NetApp Snapshot을 사용하여 Active IQ Unified Manager를 백업 및 복원하려면 먼저 Windows 호스트 머신을 구성해야 합니다. Windows 호스트 머신에서 Microsoft iSCSI 이니시에이터를 시작하려면 검색 창에 "`iscsi`"를 입력하고 *iSCSI 이니시에이터*를 클릭하십시오.

.시작하기 전에
호스트 시스템의 이전 구성을 모두 정리해야 합니다.

새로 설치한 Windows에서 iSCSI 이니시에이터를 시작하려고 하면 확인 메시지가 표시되고, 확인을 누르면 iSCSI 속성 대화 상자가 나타납니다. 기존 Windows 설치 환경이라면 iSCSI 속성 대화 상자에는 비활성화되었거나 연결을 시도 중인 대상이 표시됩니다. 따라서 Windows 호스트의 이전 구성이 모두 제거되었는지 확인해야 합니다.

.단계
. 호스트 시스템의 이전 구성을 모두 정리합니다.
. 대상 포털을 검색하십시오.
. 대상 포털에 연결하십시오.
. 다중 경로를 사용하여 대상 포털에 연결합니다.
. 두 LIF를 모두 검색하십시오.
. Windows 컴퓨터에 장치로 구성된 LUN을 검색합니다.
. 검색된 LUN을 Windows에서 새 볼륨 드라이브로 구성합니다.




[[specify-the-destination-location-for-snapshot-copies-on-windows-in-active-iq-unified-manager]]
== Active IQ Unified Manager에서 Windows의 스냅샷 복사본 대상 위치를 지정합니다

Active IQ Unified Manager 스냅샷 복사본의 대상 위치는 ONTAP 클러스터 중 하나에 이미 구성한 볼륨으로 구성해야 합니다. 위치를 정의하려면 유지 관리 콘솔을 사용해야 합니다.

* Active IQ Unified Manager가 설치된 Windows 호스트에 대한 관리자 권한이 있어야 합니다.
* Unified Manager 서버의 유지 관리 콘솔에 로그인하도록 승인된 사용자 ID와 암호가 있어야 합니다.
* 클러스터 관리 IP 주소, 스토리지 VM 이름, 볼륨 이름, LUN 이름, 스토리지 시스템 사용자 이름 및 암호가 있어야 합니다.
* 볼륨을 Active IQ Unified Manager 호스트에 네트워크 드라이브로 마운트해야 하며, 마운트 드라이브가 있어야 합니다.


.단계
. Power Shell을 사용하여 Active IQ Unified Manager 시스템의 IP 주소 또는 정규화된 도메인 이름에 연결합니다.
. 유지보수 사용자(umadmin)의 이름과 비밀번호로 시스템에 로그인하십시오.
. 명령어 `maintenance_console`를 입력하고 Enter 키를 누르십시오.
. 유지 관리 콘솔 *메인 메뉴*에서 *백업 복원* 옵션에 해당하는 번호를 입력하십시오.
. *NetApp 스냅샷 백업 구성*에 대한 번호를 입력하십시오.
. iSCSI를 구성하려면 숫자를 입력하십시오.
. 제공해야 할 정보를 검토한 후 *백업 구성 세부 정보 입력*에 번호를 입력하십시오.
. 스냅샷이 기록될 볼륨을 식별하려면 클러스터 관리 인터페이스의 IP 주소, 스토리지 VM 이름, 볼륨 이름, LUN 이름, 스토리지 시스템 사용자 이름 및 암호, 마운트 드라이브를 입력하십시오.
. 이 정보를 확인하고 입력하십시오 `y`.
+
시스템은 다음과 같은 작업을 수행합니다:

+
** 스토리지 VM이 검증되었습니다
** 볼륨이 검증되었습니다
** 마운트 드라이브 및 상태가 검증되었습니다.
** LUN 존재 여부 및 상태
** 네트워크 드라이브 존재 여부
** 마운트한 볼륨에 권장 공간(mysql 데이터 디렉토리의 2배 이상)이 존재하는지 확인됩니다.
** 볼륨 내 전용 LUN에 해당하는 LUN 경로
** i그룹 이름
** 네트워크 드라이브가 마운트된 볼륨의 GUID
** ONTAP과 통신하는 데 사용되는 iSCSI 이니시에이터


. 유지 관리 콘솔을 종료하고 Active IQ Unified Manager 인터페이스를 실행하여 스냅샷 복사본 일정을 생성하십시오.
