= Active IQ Unified Manager 상태 점검 워크플로 및 작업을 이해합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager와 관련된 일반적인 관리 워크플로 및 작업에는 모니터링할 스토리지 클러스터 선택, 데이터 가용성, 용량 및 보호에 악영향을 미치는 조건 진단, 손실된 데이터 복구, 볼륨 구성 및 관리, (필요한 경우) 진단 데이터를 묶어 기술 지원에 전송하는 작업이 포함됩니다.

Unified Manager를 사용하면 스토리지 관리자가 대시보드를 보고, 관리되는 스토리지 클러스터의 전체 용량, 가용성 및 보호 상태를 평가한 다음, 발생할 수 있는 특정 문제를 신속하게 식별, 위치 파악, 진단 및 해결을 위해 할당할 수 있습니다.

관리형 스토리지 객체의 스토리지 용량이나 데이터 가용성에 영향을 미치는 클러스터, 스토리지 가상 머신(SVM), 볼륨 또는 FlexGroup 볼륨과 관련된 가장 중요한 문제는 대시보드 페이지의 시스템 상태 그래프 및 이벤트에 표시됩니다. 심각한 문제가 발견되면 이 페이지에서 적절한 문제 해결 워크플로를 지원하는 링크를 제공합니다.

Unified Manager는 스토리지 리소스의 직접 구성을 지원하기 위해 OnCommand Workflow Automation(WFA) 등 관련 관리 툴을 포함하는 워크플로우에도 포함될 수 있습니다.

이 문서에서는 다음과 같은 관리 작업과 관련된 일반적인 워크플로를 설명합니다:

* 가용성 문제 진단 및 관리
+
하드웨어 장애 또는 스토리지 리소스 구성 문제로 인해 대시보드 페이지에 데이터 가용성 이벤트가 표시되는 경우, 스토리지 관리자는 내장된 링크를 따라 영향을 받는 스토리지 리소스에 대한 연결 정보를 확인하고, 문제 해결 지침을 살펴보고, 다른 관리자에게 문제 해결을 할당할 수 있습니다.

* 성능 인시던트 구성 및 모니터링
+
관리자는 모니터링되는 스토리지 시스템 리소스의 성능을 모니터링하고 관리할 수 있습니다. 자세한 내용은 link:../performance-checker/concept_introduction_to_unified_manager_performance_monitoring.html["Active IQ Unified Manager 성능 모니터링 소개"]을(를) 참조하십시오.

* 볼륨 용량 문제 진단 및 관리
+
대시보드 페이지에 볼륨 스토리지 용량 문제가 표시되면 스토리지 관리자는 내장된 링크를 따라 해당 볼륨의 스토리지 용량과 관련된 현재 및 과거 추세를 확인하고, 문제 해결 지침을 보고, 다른 관리자에게 문제 해결을 할당할 수 있습니다.

* 보호 관계 문제 구성, 모니터링 및 진단
+
보호 관계를 생성 및 구성한 후 스토리지 관리자는 보호 관계와 관련된 잠재적 문제, 보호 관계의 현재 상태, 영향을 받는 관계에 대한 현재 및 과거 보호 작업 성공 정보, 문제 해결 권장 사항을 확인할 수 있습니다. 자세한 내용은 link:../data-protection/concept_manage_and_monitor_protection_relationships.html["보호 관계 관리 및 모니터링에 대해 알아보기"]을 참조하십시오.

* 백업 파일 생성 및 백업 파일에서 데이터 복원.
* 스토리지 객체와 주석 연결
+
스토리지 관리자는 스토리지 객체에 주석을 연결함으로써 해당 스토리지 객체와 관련된 이벤트를 필터링하고 볼 수 있으므로, 이벤트와 관련된 문제를 우선순위를 정하고 해결할 수 있습니다.

* Unified Manager에서 수집한 상태, 용량 및 성능 정보를 확인하여 클러스터를 관리하는 데 도움이 되는 REST API를 사용할 수 있습니다. 자세한 내용은 link:../api-automation/concept_get_started_with_um_apis.html["Active IQ Unified Manager REST API 시작하기"]을(를) 참조하십시오.
* 기술 지원에 지원 번들 전송
+
스토리지 관리자는 유지보수 콘솔을 사용하여 지원 번들을 검색하고 기술 지원에 보낼 수 있습니다. 문제에 AutoSupport 메시지에서 제공하는 것보다 더 자세한 진단 및 문제 해결이 필요한 경우 지원 번들을 기술 지원에 보내야 합니다.
