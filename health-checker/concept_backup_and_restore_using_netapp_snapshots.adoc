= Active IQ Unified Manager에서 NetApp 스냅샷을 사용하여 백업 및 복원
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp 스냅샷 복사본은 시스템 장애 또는 데이터 손실 발생 시 복원할 수 있도록 Unified Manager 데이터베이스 및 구성 파일의 시점 이미지를 생성합니다. 스냅샷 복사본이 ONTAP 클러스터 중 하나의 볼륨에 주기적으로 기록되도록 예약하여 항상 최신 복사본을 유지할 수 있습니다.

[NOTE]
====
이 기능은 가상 어플라이언스에 설치된 Active IQ Unified Manager에서는 사용할 수 없습니다.

====
