= Active IQ Unified Manager에서 스크립트 추가
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager에 스크립트를 추가하고 해당 스크립트를 경고와 연결할 수 있습니다. 이러한 스크립트는 경고가 생성될 때 자동으로 실행되며, 이벤트가 발생한 스토리지 오브젝트에 대한 정보를 얻을 수 있도록 해줍니다.

.시작하기 전에
* Unified Manager 서버에 추가하려는 스크립트를 생성하고 저장해야 합니다.
* 스크립트에서 지원하는 파일 형식은 Perl, Shell, PowerShell, Python 및 `.bat` 파일입니다.
+
[cols="2*"]
|===
| Unified Manager가 설치된 플랫폼 | 지원되는 언어 


 a| 
VMware
 a| 
Perl 및 Shell 스크립트



 a| 
Linux
 a| 
Perl, Python 및 Shell 스크립트



 a| 
Windows
 a| 
PowerShell, Perl, Python 및 .bat 스크립트

|===
+
** Perl 스크립트를 사용하려면 Unified Manager 서버에 Perl이 설치되어 있어야 합니다. VMware 환경에서는 Perl 5가 기본적으로 설치되며, 스크립트는 Perl 5에서 지원하는 기능만 지원합니다. Unified Manager 설치 후에 Perl을 설치한 경우 Unified Manager 서버를 재시작해야 합니다.
** PowerShell 스크립트의 경우, 스크립트를 실행할 수 있도록 Windows 서버에 적절한 PowerShell 실행 정책이 설정되어 있어야 합니다.


+
[NOTE]
====
스크립트가 경고 스크립트 진행 상황을 추적하기 위해 로그 파일을 생성하는 경우, 해당 로그 파일이 Unified Manager 설치 폴더 내에 생성되지 않도록 해야 합니다.

====
* 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.


사용자 지정 스크립트를 업로드하고 알림에 대한 이벤트 세부 정보를 수집할 수 있습니다.

[NOTE]
====
사용자 인터페이스에서 이 기능을 볼 수 없는 경우 관리자가 해당 기능을 비활성화했기 때문입니다. 필요한 경우 *스토리지 관리* > *기능 설정*에서 이 기능을 활성화할 수 있습니다.

====
.단계
. 왼쪽 탐색 창에서 *스토리지 관리* > *스크립트*를 클릭합니다.
. *스크립트* 페이지에서 *추가*를 클릭합니다.
. *스크립트 추가* 대화 상자에서 *찾아보기*를 클릭하여 스크립트 파일을 선택합니다.
. 선택한 스크립트에 대한 설명을 입력하십시오.
. *추가*를 클릭합니다.
