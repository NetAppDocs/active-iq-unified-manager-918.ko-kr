= Active IQ Unified Manager의 데이터베이스 복원에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
MySQL 데이터베이스 복원은 기존 Unified Manager 백업 파일을 동일하거나 다른 Unified Manager 서버로 복원하는 프로세스입니다. Unified Manager 유지 관리 콘솔에서 복원 작업을 수행합니다.

동일한(로컬) 시스템에서 복원 작업을 수행하고 백업 파일이 모두 로컬에 저장된 경우 기본 위치를 사용하여 복원 옵션을 실행할 수 있습니다. 다른 Unified Manager 시스템(원격 시스템)에서 복원 작업을 수행하는 경우, 복원 옵션을 실행하기 전에 2차 스토리지에서 로컬 디스크로 백업 파일(또는 파일들)을 복사해야 합니다.

복원 과정 중에는 Unified Manager에서 로그아웃됩니다. 복원 과정이 완료된 후 시스템에 로그인할 수 있습니다.

새 서버에 백업 이미지를 복원하는 경우, 복원 작업이 완료된 후 새 HTTPS 보안 인증서를 생성하고 Unified Manager 서버를 다시 시작해야 합니다. 또한 새 서버에 백업 이미지를 복원할 때 필요한 경우 SAML 인증 설정을 다시 구성해야 합니다.

[NOTE]
====
Unified Manager를 최신 버전의 소프트웨어로 업그레이드한 후에는 이전 백업 파일을 사용하여 이미지를 복원할 수 없습니다. 공간을 절약하기 위해 Unified Manager를 업그레이드할 때 최신 파일을 제외한 모든 이전 백업 파일이 자동으로 삭제됩니다.

====
