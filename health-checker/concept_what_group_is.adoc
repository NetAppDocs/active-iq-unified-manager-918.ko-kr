= Active IQ Unified Manager의 그룹에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
그룹은 이기종 스토리지 오브젝트(클러스터, SVM 또는 볼륨)의 동적 모음입니다. Unified Manager에서 그룹을 생성하여 스토리지 오브젝트 집합을 쉽게 관리할 수 있습니다. 그룹의 구성원은 특정 시점에 Unified Manager에서 모니터링하는 스토리지 오브젝트에 따라 변경될 수 있습니다.

* 각 그룹은 고유한 이름을 가지고 있습니다.
* 각 그룹에 대해 최소 하나 이상의 그룹 규칙을 구성해야 합니다.
* 하나의 그룹에 여러 그룹 규칙을 연결할 수 있습니다.
* 각 그룹에는 클러스터, SVM, 볼륨 등 여러 유형의 스토리지 오브젝트가 포함될 수 있습니다.
* 스토리지 오브젝트는 그룹 규칙이 생성될 때 또는 Unified Manager가 모니터링 주기를 완료할 때 동적으로 그룹에 추가됩니다.
* 그룹 내의 모든 스토리지 오브젝트에 볼륨 임계값 설정 등의 작업을 동시에 적용할 수 있습니다.
