= Active IQ Unified Manager에서 Windows 클라이언트를 사용하여 지원 번들 검색
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Windows 사용자인 경우, Unified Manager 서버에서 지원 번들을 가져오는 툴을 다운로드하여 설치할 수 있습니다. 문제에 대한 더 자세한 진단을 위해 지원 번들을 기술 지원에 보낼 수 있습니다. 사용할 수 있는 툴의 예로는 Filezilla 또는 WinSCP가 있습니다.

.시작하기 전에
이 작업을 수행하려면 유지 관리 사용자여야 합니다.

SCP 또는 SFTP를 지원하는 툴을 사용해야 합니다.

.단계
. 지원 번들을 가져오려면 툴을 다운로드하여 설치하십시오.
. 툴을 여십시오.
. SFTP를 통해 Unified Manager 관리 서버에 연결하세요.
+
툴은 /support 디렉터리의 내용을 표시하며, 기존의 모든 지원 번들을 볼 수 있습니다.

. 복사할 지원 번들의 대상 디렉토리를 선택합니다.
. 복사할 지원 번들을 선택하고 툴을 사용하여 Unified Manager 서버에서 로컬 시스템으로 파일을 복사하십시오.
