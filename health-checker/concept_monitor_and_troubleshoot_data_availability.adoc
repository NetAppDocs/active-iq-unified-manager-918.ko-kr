= Active IQ Unified Manager에서 데이터 가용성 모니터링 및 문제 해결
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager는 승인된 사용자가 저장된 데이터에 액세스할 수 있는 안정성을 모니터링하고, 액세스를 차단하거나 방해하는 상황에 대해 경고하며, 이러한 상황을 진단하고 해결 방법을 지정 및 추적할 수 있도록 지원합니다.

이 섹션의 가용성 워크플로 항목에서는 스토리지 관리자가 Unified Manager 웹 UI를 사용하여 데이터 가용성에 부정적인 영향을 미치는 하드웨어 및 소프트웨어 상태를 탐색, 진단하고 해결을 위해 할당하는 방법에 대한 예를 설명합니다.
