= Active IQ Unified Manager에서 주석 규칙 생성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager가 볼륨, 클러스터 또는 스토리지 가상 머신(SVM) 등 스토리지 오브젝트에 동적으로 주석을 추가하는 데 사용하는 주석 규칙을 생성할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

현재 모니터링 중인 스토리지 오브젝트는 어노테이션 규칙이 생성되는 즉시 어노테이션이 추가됩니다. 새로운 오브젝트는 모니터링 주기가 완료된 후에만 어노테이션이 추가됩니다.

.단계
. 왼쪽 탐색 창에서 *스토리지 관리* > *주석*을 클릭합니다.
. *주석 규칙* 탭에서 *추가*를 클릭합니다.
. *주석 규칙 추가* 대화 상자에서 주석 규칙의 이름을 지정합니다.
. *대상 오브젝트 유형* 필드에서 주석을 달 스토리지 오브젝트 유형을 선택합니다.
. *주석 적용* 필드에서 사용할 주석과 주석 값을 선택합니다.
. 조건 섹션에서 적절한 작업을 수행하여 조건, 조건 그룹 또는 둘 다를 생성합니다:
+
[cols="2*"]
|===
| 만들기 위해... | 이렇게 하세요... 


 a| 
조건
 a| 
.. 피연산자 목록에서 피연산자를 선택하십시오.
.. 연산자로 *포함* 또는 *이다* 중 하나를 선택하세요.
.. 값을 입력하거나 사용 가능한 목록에서 값을 선택하십시오.




 a| 
조건 그룹
 a| 
.. *조건 그룹 추가*를 클릭합니다.
.. 피연산자 목록에서 피연산자를 선택하십시오.
.. 연산자로 *포함* 또는 *이다* 중 하나를 선택하세요.
.. 값을 입력하거나 사용 가능한 목록에서 값을 선택하십시오.
.. 필요한 경우 *조건 추가*를 클릭하여 조건을 더 만들고, 각 조건에 대해 단계 a부터 d까지를 반복하십시오.


|===
. *추가*를 클릭합니다.

== 주석 규칙 생성 예시

주석 규칙 추가 대화 상자에서 다음 단계를 수행하여 조건 구성 및 조건 그룹 추가를 포함한 주석 규칙을 생성합니다:

.단계
. 주석 규칙의 이름을 지정하십시오.
. 대상 오브젝트 유형을 스토리지 가상 머신(SVM)으로 선택합니다.
. 주석 목록에서 주석을 선택하고 값을 지정하십시오.
. 조건 섹션에서 피연산자로 *오브젝트 이름*을 선택합니다.
. 연산자로 *포함*을 선택하세요.
. 값을  `svm_data`(으)로 입력하십시오.
. *조건 그룹 추가*를 클릭합니다.
. *오브젝트 이름*을 피연산자로 선택하십시오.
. 연산자로 *포함*을 선택하세요.
. 값을 다음과 같이 입력하십시오 `vol`.
. *조건 추가*를 클릭하세요.
. 8단계에서 피연산자로 *data-priority*를, 9단계에서 연산자로 *Is*를, 10단계에서 값으로 *mission-critical*을 선택하여 8단계부터 10단계까지를 반복합니다.
. *추가*를 클릭합니다.
