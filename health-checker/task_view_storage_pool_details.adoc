= Active IQ Unified Manager에서 스토리지 풀 세부 정보 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 풀의 세부 정보를 확인하여 스토리지 풀 상태, 전체 및 사용 가능한 캐시, 사용된 할당 및 사용 가능한 할당을 모니터링할 수 있습니다.

.시작하기 전에
운영자, 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

.단계
. 왼쪽 탐색 창에서 *스토리지* > *애그리게이트*를 클릭합니다.
. 애그리게이트 이름을 클릭하십시오.
+
선택한 애그리게이트의 세부 정보가 표시됩니다.

. *디스크 정보* 탭을 클릭하십시오.
+
디스크에 대한 자세한 정보가 표시됩니다.

+
[NOTE]
====
캐시 테이블은 선택한 애그리게이트가 스토리지 풀을 사용 중일 때만 표시됩니다.

====
. 캐시 테이블에서 필요한 스토리지 풀의 이름 위로 포인터를 이동합니다.
+
스토리지 풀의 세부 정보가 표시됩니다.
