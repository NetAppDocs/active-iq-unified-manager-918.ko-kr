= Windows에서 Active IQ Unified Manager 다시 시작
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
구성 변경 후 Unified Manager를 다시 시작해야 할 수도 있습니다.

.시작하기 전에
Windows 관리자 권한이 있어야 합니다.

.단계
. 기본 로컬 관리자 계정을 사용하여 Windows에 로그인하십시오.
. Unified Manager 서비스를 중지하십시오:
+
[cols="2*"]
|===
| 에서... | 다음 순서대로 서비스를 중지하십시오... 


 a| 
명령줄
 a| 
.. `sc stop ocie-au`
.. `sc stop Oncommandsvc`




 a| 
Microsoft Service Manager
 a| 
.. NetApp Active IQ 수집 서비스(Ocie-au)
.. NetApp Active IQ 관리 서버 서비스(Oncommandsvc)


|===
. Unified Manager 서비스를 시작하십시오:
+
[cols="2*"]
|===
| 에서... | 다음 순서대로 서비스를 시작하십시오... 


 a| 
명령줄
 a| 
.. `sc start Oncommandsvc`
.. `sc start ocie-au`




 a| 
Microsoft Service Manager
 a| 
.. NetApp Active IQ 관리 서버 서비스(Oncommandsvc)
.. NetApp Active IQ 수집 서비스(Ocie-au)


|===
