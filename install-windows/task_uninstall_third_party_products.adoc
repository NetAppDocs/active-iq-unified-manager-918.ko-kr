= Active IQ Unified Manager에서 타사 제품 제거
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager를 업그레이드한 후에는 Python이나 Microsoft Visual C++ 2013 등 타사 제품을 제거할 수 있습니다. 이는 선택 사항입니다.



[[uninstall-python]]
== Python 제거

.단계
. *제어판*에서 *프로그램* > *프로그램 및 기능*을 선택합니다.
. 프로그램 목록에서 Python을 선택하세요.
. *이 프로그램 제거*를 선택하십시오. Python 3.13.3 버전을 제외한 모든 버전을 제거하십시오. Python 3.13.3 버전은 그대로 유지하십시오.




[[uninstall-microsoft-visual-c-2013]]
== Microsoft Visual C++ 2013 제거

.단계
. *제어판*에서 *프로그램* > *프로그램 및 기능*을 선택합니다.
. 프로그램 목록에서 *Microsoft Visual C++ 2013*을 선택하십시오.
. *이 프로그램 제거*를 선택하십시오.
