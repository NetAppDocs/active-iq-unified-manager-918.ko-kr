= Windows의 Active IQ Unified Manager에서 JBoss 암호 변경
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
설치 중에 설정된 인스턴스별 JBoss 암호를 재설정할 수 있습니다. 사이트에서 Unified Manager 설치 설정을 재정의하기 위해 이 보안 기능이 필요한 경우 암호를 재설정할 수 있습니다(선택 사항). 이 작업은 JBoss가 MySQL에 액세스하는 데 사용하는 암호도 변경합니다.

.시작하기 전에
* Unified Manager가 설치된 시스템에 대한 Windows 관리자 권한이 있어야 합니다.
* MySQL 루트 사용자의 암호가 있어야 합니다.
* 디렉터리에서 NetApp에서 제공하는 `password.bat` 스크립트에 액세스할 수 있어야 합니다.
+
`C:\Program Files\NetApp\essentials\bin`.



.단계
. Unified Manager 호스트 컴퓨터에서 관리자 사용자로 로그인하십시오.
. Windows 서비스 콘솔을 사용하여 다음 Unified Manager 서비스를 중지하십시오:
+
** NetApp Active IQ 수집 서비스(Ocie-au)
** NetApp Active IQ 관리 서버 서비스(Oncommandsvc)


. 암호 변경 프로세스를 시작하려면  `password.bat` 스크립트를 실행하십시오:
+
`C:\Program Files\NetApp\essentials\bin> password.bat resetJBossPassword`

. 메시지가 나타나면 MySQL 루트 사용자 암호를 입력하십시오.
. 메시지가 나타나면 새 JBoss 사용자 암호를 입력하고, 확인을 위해 다시 한 번 입력하십시오.
+
참고로 비밀번호는 8자에서 16자 사이여야 하며, 숫자 하나, 대문자 하나, 소문자 하나, 그리고 다음 특수 문자 중 하나 이상을 포함해야 합니다:

+
`+!@%^*-_+=[]:<>.?/~+`

. 스크립트 실행이 완료되면 Windows 서비스 콘솔을 사용하여 Unified Manager 서비스를 시작합니다:
+
** NetApp Active IQ 관리 서버 서비스(Oncommandsvc)
** NetApp Active IQ 수집 서비스(Ocie-au)


. 모든 서비스가 시작되면 Unified Manager UI에 로그인할 수 있습니다.
