= Windows에서 Active IQ Unified Manager 업그레이드
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 9.14 또는 9.16을 9.18으로 업그레이드하려면 Windows 플랫폼에서 설치 파일을 다운로드하여 실행하면 됩니다.

.시작하기 전에
* Unified Manager를 업그레이드할 시스템은 시스템 및 소프트웨어 요구 사항을 충족해야 합니다.
+
link:concept_virtual_infrastructure_or_hardware_system_requirements.html["하드웨어 시스템 요구 사항"]를 참조하십시오.

+
link:reference_windows_software_and_installation_requirements.html["Windows 소프트웨어 및 설치 요구 사항"]를 참조하십시오.

+
[NOTE]
====
Unified Manager 9.5부터는 설치 패키지에 OpenJDK가 포함되어 자동으로 설치됩니다. Unified Manager 9.5부터는 Oracle Java가 지원되지 않습니다.

====
+
[NOTE]
====
업그레이드를 시작하기 전에 시스템에 Microsoft .NET 4.5.2 이상이 설치되어 있는지 확인하십시오.

====
* MySQL Community Edition은 Unified Manager 업그레이드 중에 자동으로 업그레이드됩니다. 시스템에 설치된 MySQL 버전이 8.4.10 이전 버전인 경우 Unified Manager 업그레이드 프로세스에서 MySQL을 자동으로 8.4.10으로 업그레이드합니다. 이전 버전의 MySQL을 8.4.10으로 업그레이드하는 독립 실행형 업그레이드 프로세스를 실행해서는 안 됩니다.
* ASA r2 시스템을 제외한 모든 클러스터가 지원됩니다.
* Windows 관리자 권한이 있어야 합니다. 사용자 이름이 느낌표("`!`". Installation of Unified Manager might fail if the user name of user running the installation begins with "`!`")로 시작하지 않는지 확인하십시오.
* NetApp 지원 사이트에 로그인하려면 유효한 자격 증명이 있어야 합니다.
* 데이터 손실을 방지하려면 업그레이드 중에 문제가 발생할 경우를 대비하여 Unified Manager 시스템의 백업을 생성해 두어야 합니다.
* 업그레이드를 수행하려면 충분한 디스크 공간이 확보되어 있어야 합니다.
+
설치 드라이브의 사용 가능한 공간은 데이터 디렉터리 크기보다 2.5GB 더 커야 합니다. 사용 가능한 공간이 부족하면 업그레이드가 중단되고 추가해야 할 공간의 크기를 나타내는 오류 메시지가 표시됩니다.

* 업그레이드 과정에서 성능 데이터 보존 기간을 13개월로 유지할지, 아니면 6개월로 변경할지 확인하는 메시지가 나타날 수 있습니다. 확인을 누르면 6개월 이후의 과거 성능 데이터가 삭제됩니다.
* 업그레이드하기 전에 _<InstallDir>\JDK_ 및 _MySQL 데이터 디렉터리_에 열려 있는 파일이나 폴더를 모두 닫아야 합니다.
* Windows 시스템에 활성화된 바이러스 백신 소프트웨어가 설치되어 있는 경우 Unified Manager 업그레이드가 실패할 수 있습니다. Unified Manager를 업그레이드하기 전에 시스템의 모든 바이러스 검사 소프트웨어를 비활성화해야 합니다.


업그레이드 과정 중에는 Unified Manager를 사용할 수 없습니다. Unified Manager를 업그레이드하기 전에 실행 중인 모든 작업을 완료하십시오.

Unified Manager가 OnCommand Workflow Automation 인스턴스와 페어링되어 있고 두 제품 모두에 새 버전의 소프트웨어가 있는 경우, 두 제품의 연결을 해제한 다음 업그레이드를 수행한 후 Workflow Automation 연결을 새로 설정해야 합니다. 두 제품 중 하나만 업그레이드하는 경우에는 업그레이드 후 Workflow Automation에 로그인하여 Unified Manager에서 데이터를 계속 가져오는지 확인해야 합니다.

.단계
. NetApp 지원 사이트에 로그인하고 Unified Manager 다운로드 페이지로 이동하십시오:
+
https://mysupport.netapp.com/site/products/all/details/activeiq-unified-manager/downloads-tab["NetApp 지원 사이트"^].

. 필요한 Unified Manager 버전을 선택하고 최종 사용자 라이선스 계약(EULA)에 동의하십시오.
. Unified Manager Windows 설치 파일 또는 zip 파일을 Windows 시스템의 대상 디렉터리에 다운로드합니다. 필요한 경우 zip 파일의 압축을 풀고 설치 파일이 있는 디렉터리로 이동합니다. Unified Manager 설치 프로그램 실행 파일(.exe)을 마우스 오른쪽 버튼으로 클릭하고 관리자 권한으로 실행합니다.
+
Unified Manager에서 다음과 같은 메시지가 표시됩니다.

+
[listing]
----
This setup will perform an upgrade of Unified Manager. Do you want to continue?
----
. *예*를 클릭한 다음 *다음*을 클릭하십시오.
. 설치 중에 설정한 MySQL84 루트 암호를 입력한 다음 *다음*을 클릭하십시오.
. 지원되는 웹 브라우저에서 새 창으로 웹 UI를 실행하고 로그인하여 업그레이드된 버전의 Unified Manager를 사용하십시오.
. Windows 시스템에 활성 바이러스 백신 소프트웨어가 설치되어 있는 경우, 업그레이드가 완료된 후 다음 경로를 바이러스 검사에서 수동으로 제외하십시오:
+
** Unified Manager 데이터 디렉터리
** Unified Manager 설치 디렉터리
** MySQL 데이터 디렉터리




[NOTE]
====
Unified Manager를 사일런트 업그레이드하려면 다음 명령을 실행하십시오:
`ActiveIQUnifiedManager-<version\>.exe /s /v"MYSQL_PASSWORD=<password> /qn /l*v <system_drive>:\install.log"`

====
