= Active IQ Unified Manager의 사용자 지정 umadmin 사용자 및 유지 관리 그룹 제거
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager를 설치하기 전에 사용자 지정 홈 디렉토리를 생성하여 자체 umadmin 사용자 및 유지 관리 계정을 정의한 경우, Unified Manager를 제거한 후 이러한 항목을 제거해야 합니다.

Unified Manager를 표준 방식으로 제거하면 사용자 정의 umadmin 사용자 및 유지 관리 계정이 삭제되지 않습니다. 이러한 항목은 수동으로 삭제해야 합니다.

.단계
. 루트 사용자로 Red Hat Enterprise Linux 서버에 로그인하십시오.
. umadmin 사용자를 삭제합니다:
+
`userdel umadmin`

. 유지 관리 그룹을 삭제합니다:
+
`groupdel maintenance`
