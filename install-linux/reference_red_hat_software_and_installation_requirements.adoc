= Active IQ Unified Manager의 Linux 소프트웨어 및 설치 요구 사항에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager를 설치할 Linux 시스템에는 특정 버전의 운영 체제 및 지원 소프트웨어가 필요합니다. Linux 설치의 경우 Unified Manager는 Red Hat Enterprise Linux 운영 체제에만 설치할 수 있습니다. 다른 운영 체제에는 설치할 수 없습니다.



[[operating-system-software]]
== 운영 체제 소프트웨어

Linux 시스템에는 다음 버전의 운영 체제 및 지원 소프트웨어가 설치되어 있어야 합니다:

* x86_64 아키텍처 기반의 Red Hat Enterprise Linux 버전 8.x 및 9.6


지원되는 Red Hat Enterprise Linux 버전의 전체 및 최신 목록은 상호 운용성 매트릭스를 참조하십시오.

https://mysupport.netapp.com/matrix["NetApp 상호 운용성 매트릭스"^]

서버는 Unified Manager 실행 전용이어야 합니다. 서버에 다른 애플리케이션을 설치해서는 안 됩니다. 일부 환경에서는 회사 정책으로 인해 Qualys 등 취약점 스캐너가 Linux 시스템에 설치되어 있는 경우가 있습니다. 설치 실패를 방지하려면 Unified Manager를 설치하기 전에 취약점 스캐너를 비활성화해야 합니다.


NOTE: Qualys 등 취약점 스캐너는 내부적으로(Unified Manager와 취약점 스캐너가 동일한 VM에 설치된 경우) 또는 외부적으로(Unified Manager와 취약점 스캐너가 서로 다른 두 서버에 설치되어 있고 취약점 스캐너가 Unified Manager가 설치된 VM을 스캔하는 경우) 가상 머신(VM)을 스캔할 때 높은 CPU 사용량을 유발할 수 있습니다. 이 문제는 종종 VM이 응답하지 않는 결과를 초래하며 Unified Manager 서비스에 영향을 미칩니다. 따라서 NetApp은 Unified Manager가 설치된 VM에서 취약점 스캐너를 비활성화할 것을 권장합니다. 스캐너를 비활성화할 수 없는 경우, 업무 시간 외에 VM을 스캔하고 스캔이 완료되면 서비스를 다시 시작하십시오.



[[third-party-software]]
== 타사 소프트웨어

Unified Manager는 WildFly 웹 서버에 배포됩니다. WildFly 27.0.1.Final은 Unified Manager와 함께 번들로 제공되며 구성됩니다.

다음 타사 패키지가 필요하지만 Unified Manager에는 포함되어 있지 않습니다. 다음 섹션에 언급된 대로 리포지토리를 구성한 경우, 설치 중에  `yum`설치 프로그램이 이 패키지를 자동으로 설치합니다.

* MySQL Community Edition 버전 8.4.10 (MySQL 저장소에서 다운로드)
* OpenJDK 버전 17.0.14+6 (Red Hat Extra Enterprise Linux Server 저장소에서 가져옴)
* Python 3.13.3 (Red Hat Extra Enterprise Linux Server 저장소에서 가져옴)
* 7zip 버전 7z2301-linux-x64. 자세한 내용은 link:task_configure_7zip_package.html["7-zip 소프트웨어 패키지를 구성합니다"]을(를) 참조하십시오.


[NOTE]
====
타사 소프트웨어를 업그레이드하기 전에 실행 중인 Unified Manager 인스턴스를 종료해야 합니다. 타사 소프트웨어 설치가 완료되면 Unified Manager를 다시 시작할 수 있습니다.

====


[[user-authorization-requirements]]
== 사용자 권한 요구 사항

Linux 시스템에 Unified Manager를 설치하는 작업은 루트 사용자 또는  `sudo` 명령어를 사용하는 비루트 사용자가 수행할 수 있습니다.

또한 기본 Unified Manager 설치에는 umadmin 사용자(기본 유지 관리 사용자)와 jboss 사용자가 sudoers 파일 (`ocum_sudoers` 및 `ocie_sudoers`)에 포함되어 있으며, 이는 `/etc/sudoers.d/` 디렉토리에 있습니다. 보안 정책이나 보안 모니터링 툴로 인해 환경에서 이 콘텐츠를 제거한 경우 다시 추가해야 합니다. 일부 Unified Manager 작업에는 이러한 sudo 권한이 필요하므로 sudoers 구성을 유지해야 합니다.



[[installation-requirements]]
== 설치 요구 사항

시스템에 Red Hat Enterprise Linux 및 관련 저장소를 설치하기 위한 모범 사례는 다음과 같습니다. 설치 또는 구성 방식이 다르거나 온프레미스 외부(클라우드)에 배포된 시스템의 경우 추가 단계가 필요할 수 있으며, 이러한 배포 환경에서는 Unified Manager가 제대로 작동하지 않을 수 있습니다.

* Red Hat 모범 사례에 따라 Red Hat Enterprise Linux를 설치해야 하며, "`Server with GUI`" 기본 환경 선택이 필요한 다음 기본 옵션을 선택해야 합니다.
* Red Hat Enterprise Linux에 Unified Manager를 설치하는 동안 시스템은 설치 프로그램이 필요한 모든 소프트웨어 종속성에 액세스하여 설치할 수 있도록 적절한 저장소에 액세스할 수 있어야 합니다.
*  `yum`설치 프로그램이 Red Hat Enterprise Linux 저장소에서 종속 소프트웨어를 찾으려면 Red Hat Enterprise Linux 설치 중에 또는 설치 후에 유효한 Red Hat 구독을 사용하여 시스템을 등록해야 합니다.
+
Red Hat Subscription Manager에 대한 자세한 내용은 Red Hat 설명서를 참조하십시오.

* 시스템에 필요한 타사 유틸리티를 성공적으로 설치하려면 Enterprise Linux용 추가 패키지(EPEL) 저장소를 활성화해야 합니다.
+
시스템에 EPEL 저장소가 구성되어 있지 않은 경우, 저장소를 수동으로 다운로드하고 구성해야 합니다.

+
link:task_manually_configure_epel_repository.html["EPEL 저장소 수동 구성"]를 참조하십시오.

* 올바른 버전의 MySQL이 설치되어 있지 않은 경우, 시스템에 MySQL 소프트웨어를 성공적으로 설치하려면 MySQL 저장소를 활성화해야 합니다.
+
시스템에 MySQL 저장소가 구성되어 있지 않은 경우, 저장소를 수동으로 다운로드하고 구성해야 합니다.

+
link:task_manually_configure_mysql_repository.html["MySQL 저장소를 수동으로 구성하기"]를 참조하십시오.

* Unified Manager 호스트에는 Java 버전을 하나만 설치해야 합니다. 그렇지 않으면 시스템에서 사용할 버전을 결정하지 못할 수 있습니다.  https://kb.netapp.com/data-mgmt/AIQUM/AIQUM_Kbs/After_updating_Java_on_the_Active_IQ_Unified_Manager_host_services_will_not_start["Active IQ Unified Manager 호스트에서 Java를 업데이트한 후 서비스가 시작되지 않습니다."]을(를) 참조하십시오.


시스템에 인터넷 연결이 없고, 인터넷에 연결된 시스템에서 연결되지 않은 시스템으로 저장소가 미러링되지 않은 경우, 설치 지침에 따라 시스템의 외부 소프트웨어 종속성을 확인해야 합니다. 그런 다음 필요한 소프트웨어를 인터넷에 연결된 시스템으로 다운로드하고,  `.rpm` 파일을 Unified Manager를 설치할 시스템으로 복사할 수 있습니다. 아티팩트 및 패키지를 다운로드하려면  `yum install` 명령어를 사용해야 합니다. 두 시스템의 운영 체제 버전이 동일하고 구독 라이선스가 적절한 Red Hat Enterprise Linux용인지 확인해야 합니다.

[NOTE]
====
여기에 나열된 리포지토리 이외의 리포지토리에서 필수 타사 소프트웨어를 설치해서는 안 됩니다. Red Hat 리포지토리에서 설치된 소프트웨어는 Red Hat Enterprise Linux를 위해 명시적으로 설계되었으며, Red Hat 모범 사례(디렉토리 레이아웃, 권한 등)를 준수합니다. 다른 위치의 소프트웨어는 이러한 지침을 따르지 않을 수 있으며, 이로 인해 Unified Manager 설치가 실패하거나 향후 업그레이드 시 문제가 발생할 수 있습니다.

====


[[port-443-requirement]]
== 포트 443 요구 사항

일반 Red Hat Enterprise Linux 이미지에서는 포트 443에 대한 외부 액세스가 차단될 수 있습니다. 이러한 제한으로 인해 Unified Manager를 설치한 후 관리자 웹 UI에 연결할 수 없을 수 있습니다. 다음 명령을 실행하면 일반 Red Hat Enterprise Linux에서 모든 외부 사용자 및 애플리케이션이 포트 443에 액세스할 수 있게 됩니다.

`# firewall-cmd --zone=public --add-port=443/tcp --permanent; firewall-cmd --reload`

Red Hat Enterprise Linux를 "`Server with GUI`" 기본 환경으로 설치해야 합니다. 이 환경은 Unified Manager 설치 지침에서 사용되는 명령을 제공합니다. 다른 기본 환경에서는 설치를 검증하거나 완료하기 위해 추가 명령을 설치해야 할 수도 있습니다. 시스템에서  `firewall-cmd`을(를) 사용할 수 없는 경우 다음 명령을 실행하여 설치해야 합니다:

`# sudo yum install firewalld`

명령어를 실행하기 전에 IT 부서에 문의하여 보안 정책에 따라 다른 절차가 필요한지 확인하십시오.

[NOTE]
====
Red Hat 시스템에서는 THP(Transparent Huge Pages)를 비활성화해야 합니다. 활성화할 경우, 특정 프로세스가 과도한 메모리를 소비하여 종료될 때 Unified Manager가 종료되는 문제가 발생할 수 있습니다.
