= Linux에서 Active IQ Unified Manager 시작하기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
설치 패키지를 다운로드하여 물리적 또는 가상 Red Hat Enterprise Linux 플랫폼에 Unified Manager를 설치할 수 있습니다.



[[system-requirements]]
== 시스템 요구 사항

* 운영 체제: Red Hat Enterprise Linux 버전 8.x 및 9.4(x86_64 아키텍처 기반, OS 설치 프로그램의 *소프트웨어 선택* 옵션에서 “GUI가 포함된 서버” 기본 환경을 사용하여 설치됨)
* RAM: 12 GB, CPU: 총 9572 MHz
* 여유 디스크 공간:  `/opt/netapp/data` 디렉터리에 100GB의 디스크 공간, 루트 파티션에 50GB. 별도로 마운트된  `/opt` 및  `/var/log` 디렉터리의 경우,  `/opt`에 15GB,  `/var/log`에 16GB,  `/tmp`에 10GB의 여유 공간이 있는지 확인하십시오.


자세한 시스템 요구 사항 및 보안 사이트에 제품을 설치하는 방법에 대한 정보는 link:../install-linux/concept_requirements_for_install_unified_manager.html["Unified Manager 설치를 위한 요구 사항"] 및 link:http://mysupport.netapp.com/matrix["상호 운용성 매트릭스"]을(를) 참조하십시오.



[[install-active-iq-unified-manager]]
== Active IQ Unified Manager 설치



[[download-the-installer]]
=== 설치 프로그램을 다운로드하십시오

.  `ActiveIQUnifiedManager-<version>.zip` 설치 패키지를 코드 서명 인증서 (`.pem`) 및 디지털 서명 (`.sig`)과 함께 다운로드하십시오.
. 설치 파일을 다운로드한 디렉토리에서 다음을 실행하십시오:
+
`# unzip ActiveIQUnifiedManager-<version>.zip`





[[verify-integrity]]
=== 무결성 검증

설치 패키지의 무결성을 확인하려면 다음 명령을 실행하십시오:

* 코드 서명 인증서의 공개 키가 포함된 파일을 생성하려면  `openssl x509 -pubkey -noout -in AIQUM-RHEL-CLIENT-INTER-ROOT.pem > <public_key_file_name>`을(를) 실행하십시오.
* 설치 패키지의 서명을 확인하려면  `openssl dgst -sha256 -verify <public_key_file_name> -signature <signature_file_name> ActiveIQUnifiedManager-<version>.zip`을(를) 실행하십시오.




[[verify-repository-configuration]]
=== 저장소 구성 확인

Red Hat Enterprise Linux 저장소 구성 절차는 사이트별로 다릅니다. 설치 패키지에 포함된  `pre_install_check.sh` 스크립트를 사용하여 운영 체제 구성을 확인할 수 있습니다. 시스템이 인터넷에 연결되어 있는 경우 Red Hat Enterprise Linux 저장소 설정에 대한 지침을 자동으로 받게 됩니다.

`# sudo ./pre_install_check.sh`



[[install-unified-manager]]
=== Unified Manager 설치

Unified Manager는  `yum` 유틸리티를 사용하여 소프트웨어 및 종속 소프트웨어를 설치합니다. Red Hat Enterprise Linux의 이미지가 다양하기 때문에 설치되는 패키지는 이미지에 있는 소프트웨어에 따라 달라집니다.  `yum` 유틸리티는 설치할 종속 소프트웨어 패키지를 결정합니다. 종속 소프트웨어 패키지에 대한 자세한 내용은 link:../install-linux/reference_red_hat_software_and_installation_requirements.html["Linux 소프트웨어 및 설치 요구 사항"]을(를) 참조하십시오.

Unified Manager를 설치하려면 설치 파일의 압축을 푼 디렉터리에서 루트 사용자로 또는  `sudo`을(를) 사용하여 다음 명령을 실행하십시오:

`# yum install netapp-um<version>.x86_64.rpm`

또는

`% sudo yum install netapp-um<version>.x86_64.rpm`

설치가 완료되면 Unified Manager 웹 UI에 연결하기 위한 정보가 표시됩니다. 웹 UI에 연결할 수 없는 경우 포트 443 제한에 대한 자세한 내용은 소프트웨어에 포함된  `README` 파일을 참조하십시오.
