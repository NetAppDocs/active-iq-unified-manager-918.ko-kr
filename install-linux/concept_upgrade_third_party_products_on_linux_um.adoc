= Active IQ Unified Manager 설치 후 타사 제품 업그레이드
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Linux 시스템에 Unified Manager가 이미 설치되어 있는 경우 JRE 등 타사 제품을 업그레이드할 수 있습니다.

이러한 타사 제품을 개발하는 회사들은 정기적으로 보안 취약점을 보고합니다. 사용자는 원하는 시기에 이 소프트웨어의 최신 버전으로 업그레이드할 수 있습니다.
