= Active IQ Unified Manager 설치 중에 생성된 사용자에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Red Hat Enterprise Linux에 Unified Manager를 설치하면 Unified Manager와 타사 유틸리티가 umadmin, jboss 및 mysql 사용자를 생성합니다.

* *umadmin*
+
Unified Manager에 처음 로그인할 때 사용됩니다. 이 사용자에게는 "`Application Administrator`" 사용자 역할이 할당되어 있으며 "`Maintenance User`" 유형으로 구성됩니다. 이 사용자는 Unified Manager에서 생성됩니다.

* *jboss*
+
JBoss 유틸리티와 관련된 Unified Manager 서비스를 실행하는 데 사용됩니다. 이 사용자는 Unified Manager에서 생성합니다.

* *mysql*
+
Unified Manager의 MySQL 데이터베이스 쿼리를 실행하는 데 사용됩니다. 이 사용자는 MySQL 타사 유틸리티가 생성합니다.



Unified Manager는 이러한 사용자 외에도 maintenance, jboss 및 mysql과 같은 해당 그룹을 생성합니다. maintenance 및 jboss 그룹은 Unified Manager에서 생성하고, mysql 그룹은 타사 유틸리티에서 생성합니다.

[NOTE]
====
Unified Manager를 설치하기 전에 사용자 지정 홈 디렉토리를 만들고 자체 umadmin 사용자 암호를 정의한 경우, 설치 프로그램은 유지 관리 그룹이나 umadmin 사용자를 다시 생성하지 않습니다.

====
