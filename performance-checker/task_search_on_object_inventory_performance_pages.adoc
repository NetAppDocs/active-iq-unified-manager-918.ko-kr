= Active IQ Unified Manager의 오브젝트 인벤토리 성능 페이지에서 검색
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
오브젝트 인벤토리 성능 페이지에서 문자열을 검색할 수 있습니다. 페이지 오른쪽 상단에 있는 *검색* 필드를 사용하여 오브젝트 이름 또는 정책 이름을 기준으로 데이터를 빠르게 찾을 수 있습니다. 이를 통해 특정 오브젝트와 관련 데이터를 신속하게 찾거나, 정책을 빠르게 찾고 관련 정책 오브젝트 데이터를 확인할 수 있습니다.

.단계
. 검색 요구 사항에 따라 다음 옵션 중 하나를 수행하십시오:
+
|===
| 이것을 찾으려면... | 이것을 입력하세요... 


 a| 
특정 오브젝트
 a| 
*검색* 필드에 오브젝트 이름을 입력하고 *검색*을 클릭합니다. 검색한 오브젝트와 관련 데이터가 표시됩니다.



 a| 
사용자 정의 성능 임계값 정책
 a| 
정책 이름의 전체 또는 일부를 *검색* 필드에 입력하고 *검색*을 클릭합니다. 검색한 정책에 할당된 오브젝트가 표시됩니다.

|===
