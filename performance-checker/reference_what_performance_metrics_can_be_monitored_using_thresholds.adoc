= Active IQ Unified Manager에서 임계값을 사용하여 추적되는 성능 카운터 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
IOPS 및 MB/s 등 일부 일반적인 성능 카운터는 모든 스토리지 오브젝트에 대해 임계값을 설정할 수 있습니다. 특정 스토리지 오브젝트에 대해서만 임계값을 설정할 수 있는 다른 카운터도 있습니다.



[[available-performance-counters]]
== 사용 가능한 성능 카운터

|===
| 스토리지 객체 | 성능 카운터 | 설명 


 a| 
클러스터
 a| 
IOPS
 a| 
클러스터가 초당 처리하는 평균 입출력 작업 수.



 a| 
MB/s
 a| 
이 클러스터에서 초당 송수신되는 데이터의 평균 메가바이트 수입니다.



 a| 
노드
 a| 
IOPS
 a| 
노드가 초당 처리하는 평균 입출력 작업 수.



 a| 
MB/s
 a| 
이 노드에서 초당 송수신되는 데이터의 평균 메가바이트 수입니다.



 a| 
지연 시간
 a| 
노드가 애플리케이션 요청에 응답하는 데 걸리는 평균 시간(밀리초).



 a| 
사용률
 a| 
노드의 CPU 및 RAM 사용률 평균값입니다.



 a| 
사용된 성능 용량
 a| 
노드가 사용하고 있는 성능 용량의 평균 백분율입니다.



 a| 
성능 용량 사용 - 인수
 a| 
해당 노드가 사용하고 있는 성능 용량의 평균 백분율에 파트너 노드의 성능 용량을 더한 값입니다.



 a| 
애그리게이트
 a| 
IOPS
 a| 
애그리게이트가 초당 처리하는 평균 입출력 작업 수.



 a| 
MB/s
 a| 
이 애그리게이트와 송수신되는 데이터의 초당 평균 메가바이트 수.



 a| 
지연 시간
 a| 
애그리게이트가 애플리케이션 요청에 응답하는 데 걸리는 평균 시간(밀리초)입니다.



 a| 
사용률
 a| 
애그리게이트의 디스크 중 사용 중인 디스크의 평균 백분율입니다.



 a| 
사용된 성능 용량
 a| 
애그리게이트에서 소비되는 성능 용량의 평균 백분율입니다.



 a| 
스토리지 VM
 a| 
IOPS
 a| 
SVM이 초당 처리하는 평균 입력/출력 작업 수.



 a| 
MB/s
 a| 
이 SVM에서 초당 전송된 데이터의 평균 메가바이트 수입니다.



 a| 
지연 시간
 a| 
SVM이 애플리케이션 요청에 응답하는 데 걸리는 평균 시간(밀리초).



 a| 
볼륨
 a| 
IOPS
 a| 
해당 볼륨이 초당 처리하는 입출력 작업의 평균 횟수입니다.



 a| 
MB/s
 a| 
이 볼륨으로 전송되거나 이 볼륨에서 전송되는 데이터의 초당 평균 메가바이트 수입니다.



 a| 
지연 시간
 a| 
볼륨이 애플리케이션 요청에 응답하는 데 걸리는 평균 시간(밀리초).



 a| 
캐시 미스 비율
 a| 
클라이언트 애플리케이션의 읽기 요청 중 캐시가 아닌 볼륨에서 반환되는 평균 비율입니다.



 a| 
LUN
 a| 
IOPS
 a| 
LUN이 초당 처리하는 평균 입출력 작업 수.



 a| 
MB/s
 a| 
이 LUN으로 전송되거나 이 LUN에서 전송되는 데이터의 초당 평균 메가바이트 수입니다.



 a| 
지연 시간
 a| 
LUN이 애플리케이션 요청에 응답하는 데 걸리는 평균 시간(밀리초).



 a| 
네임스페이스
 a| 
IOPS
 a| 
네임스페이스가 초당 처리하는 입출력 작업의 평균 횟수입니다.



 a| 
MB/s
 a| 
초당 이 네임스페이스로 전송되거나 이 네임스페이스로부터 전송된 데이터의 평균 메가바이트 수입니다.



 a| 
지연 시간
 a| 
네임스페이스가 애플리케이션 요청에 응답하는 데 걸리는 평균 시간(밀리초).



 a| 
포트
 a| 
대역폭 활용
 a| 
포트의 사용 가능한 대역폭 중 사용 중인 평균 백분율입니다.



 a| 
MB/s
 a| 
이 포트를 통해 초당 송수신되는 데이터의 평균 메가바이트 수입니다.



 a| 
네트워크 인터페이스(LIF)
 a| 
MB/s
 a| 
이 LIF를 통해 초당 송수신되는 데이터의 평균 메가바이트 수입니다.

|===
