= 클라우드로 데이터를 계층화하기 위한 Active IQ Unified Manager 권장 사항 검토
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능: 모든 볼륨 보기에는 비활성(콜드) 상태인 볼륨에 저장된 사용자 데이터의 크기와 관련된 정보가 표시됩니다. 경우에 따라 Unified Manager는 비활성 데이터를 FabricPool 활성화된 애그리게이트의 클라우드 계층(클라우드 공급자 또는 StorageGRID)으로 계층화하면 이점이 있는 특정 볼륨을 식별합니다.

[NOTE]
====
FabricPool은 ONTAP 9.2에서 도입되었으므로, ONTAP 9.2 이전 버전의 ONTAP 소프트웨어를 사용 중인 경우 Unified Manager에서 권장하는 데이터 계층화 기능을 사용하려면 ONTAP 소프트웨어를 업그레이드해야 합니다. 또한,  `*auto*` 계층화 정책은 ONTAP 9.4에서,  `*all*` 계층화 정책은 ONTAP 9.6에서 도입되었으므로 자동 계층화 정책 사용을 권장하는 경우 ONTAP 9.4 이상 버전으로 업그레이드해야 합니다.

====
성능: 모든 볼륨 보기의 다음 세 필드는 비활성 데이터를 클라우드 계층으로 이동하여 스토리지 시스템의 디스크 사용률을 개선하고 성능 계층의 공간을 절약할 수 있는지 여부에 대한 정보를 제공합니다.

* *계층화 정책*
+
계층화 정책은 볼륨의 데이터가 성능 계층에 유지될지, 아니면 데이터의 일부가 성능 계층에서 클라우드 계층으로 이동될지를 결정합니다.

+
이 필드의 값은 볼륨이 현재 FabricPool 애그리게이트에 있지 않더라도 볼륨에 설정된 티어링 정책을 나타냅니다. 티어링 정책은 볼륨이 FabricPool 애그리게이트에 있을 때만 적용됩니다.

* *콜드 데이터*
+
콜드 데이터는 비활성(콜드) 상태인 볼륨에 저장된 사용자 데이터의 크기를 표시합니다.

+
여기에 값이 표시되는 경우는 ONTAP 9.4 이상 소프트웨어를 사용하는 경우뿐입니다. 이는 볼륨이 배포된 애그리게이트의  `*inactive data reporting parameter*`이(가)  `*enabled*`(으)로 설정되어 있어야 하고, 최소 냉각 일수 임계값을 충족해야 하기 때문입니다( `*snapshot-only*` 또는  `*auto*` 티어링 정책을 사용하는 볼륨의 경우). 그렇지 않으면 값은 "`N/A`"로 표시됩니다.

* *클라우드 추천*
+
볼륨의 데이터 활동에 대한 충분한 정보가 수집되면 Unified Manager는 조치가 필요하지 않거나 비활성 데이터를 클라우드 계층으로 계층화하여 성능 계층의 공간을 절약할 수 있다고 판단할 수 있습니다.



[NOTE]
====
콜드 데이터 필드는 15분마다 업데이트되지만, 클라우드 권장 사항 필드는 볼륨에 대한 콜드 데이터 분석이 수행될 때 7일마다 업데이트됩니다. 따라서 두 필드에 표시되는 콜드 데이터의 정확한 양은 다를 수 있습니다. 클라우드 권장 사항 필드에는 분석이 실행된 날짜가 표시됩니다.

====
비활성 데이터 보고 기능이 활성화되면 콜드 데이터 필드에 비활성 데이터의 정확한 양이 표시됩니다. 비활성 데이터 보고 기능이 없으면 Unified Manager는 성능 통계를 사용하여 볼륨에서 데이터가 비활성 상태인지 확인합니다. 이 경우 콜드 데이터 필드에는 비활성 데이터 양이 표시되지 않지만, 클라우드 권장 사항을 보기 위해 *Tier*라는 단어 위에 커서를 올리면 표시됩니다.

표시되는 클라우드 권장 사항은 다음과 같습니다:

* *학습*. 권장 사항을 제시하기에는 수집된 데이터가 충분하지 않습니다.
* *티어*. 분석 결과 해당 볼륨에 비활성(콜드) 데이터가 포함되어 있으므로 클라우드 티어로 이동하도록 볼륨을 구성해야 합니다. 경우에 따라 볼륨을 FabricPool 활성화된 애그리게이트로 먼저 이동해야 할 수 있습니다. 볼륨이 이미 FabricPool 애그리게이트에 있는 경우에는 티어링 정책만 변경하면 됩니다.
* *조치 없음*. 볼륨에 비활성 데이터가 거의 없거나, 볼륨이 FabricPool 애그리게이트에서 "`auto`" 계층화 정책으로 이미 설정되어 있거나, 볼륨이 데이터 보호 볼륨인 경우입니다. 이 값은 볼륨이 오프라인 상태이거나 MetroCluster 구성에서 사용 중일 때도 표시됩니다.


볼륨을 이동하거나 볼륨 계층화 정책 또는 애그리게이트 비활성 데이터 보고 설정을 변경하려면 ONTAP System Manager, ONTAP CLI 명령 또는 이러한 툴의 조합을 사용하십시오.

애플리케이션 관리자 또는 스토리지 관리자 역할로 Unified Manager에 로그인한 경우, 클라우드 권장 사항에서 *Tier*라는 단어 위에 마우스 커서를 올리면 *Configure Volume* 링크가 나타납니다. 이 버튼을 클릭하면 System Manager의 볼륨 페이지가 열리고 권장 변경 사항을 적용할 수 있습니다.
