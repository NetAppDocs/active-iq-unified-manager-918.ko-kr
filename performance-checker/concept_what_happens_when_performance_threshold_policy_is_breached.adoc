= Active IQ Unified Manager에서 위반된 성능 임계값 정책에 대응합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
카운터 값이 지정된 시간 동안 정의된 성능 임계값을 초과하면 임계값 위반으로 간주되어 이벤트가 보고됩니다.

이 이벤트로 인해 다음과 같은 작업이 시작됩니다:

* 해당 이벤트는 대시보드, 성능 클러스터 요약 페이지, 이벤트 페이지 및 오브젝트별 성능 인벤토리 페이지에 표시됩니다.
* (선택 사항) 이벤트에 대한 이메일 알림을 하나 이상의 이메일 수신자에게 보낼 수 있으며, SNMP 트랩을 트랩 수신자에게 보낼 수 있습니다.
* (선택 사항) 스크립트를 실행하여 스토리지 오브젝트를 자동으로 수정하거나 업데이트할 수 있습니다.


첫 번째 조치는 항상 실행됩니다. 선택적 조치 수행 여부는 알림 설정 페이지에서 구성할 수 있습니다. 경고 또는 심각 임계값 정책 위반 여부에 따라 고유한 조치를 정의할 수 있습니다.

스토리지 오브젝트에서 성능 임계값 정책 위반이 발생한 후에는 카운터 값이 임계값 아래로 떨어질 때까지 해당 정책에 대해 더 이상 이벤트가 생성되지 않으며, 임계값 아래로 떨어지는 시점에 해당 제한에 대한 지속 시간이 재설정됩니다. 임계값이 계속 초과되는 동안에는 이벤트 종료 시간이 지속적으로 업데이트되어 이벤트가 진행 중임을 반영합니다.

임계값 이벤트는 심각도 및 정책 정의와 관련된 정보를 캡처하거나 고정하여 향후 임계값 정책이 수정되더라도 해당 이벤트와 함께 고유한 임계값 정보가 표시되도록 합니다.
