= Active IQ Unified Manager에서 성능 이벤트 및 알림 분석
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 이벤트는 클러스터 구성 요소의 경합으로 인해 워크로드에서 발생하는 I/O 성능 문제를 알려줍니다. Unified Manager는 이벤트를 분석하여 관련된 모든 워크로드, 경합이 발생한 구성 요소, 그리고 해당 이벤트가 여전히 해결해야 할 문제인지 여부를 파악합니다.

Unified Manager는 클러스터의 볼륨에 대한 I/O 지연 시간(응답 시간)과 IOPS(작업)를 모니터링합니다. 예를 들어, 다른 워크로드가 클러스터 구성 요소를 과도하게 사용하는 경우 해당 구성 요소는 경합 상태에 빠져 워크로드 요구 사항을 충족할 만큼 최적의 성능을 발휘하지 못할 수 있습니다. 동일한 구성 요소를 사용하는 다른 워크로드의 성능에 영향을 미쳐 지연 시간이 증가할 수 있습니다. 지연 시간이 동적 성능 임계값을 초과하면 Unified Manager는 성능 이벤트를 발생시켜 사용자에게 알립니다.



[[event-analysis]]
== 이벤트 분석

Unified Manager는 지난 15일간의 성능 통계를 사용하여 다음과 같은 분석을 수행하여 이벤트에 관련된 피해 워크로드, 가해 워크로드 및 클러스터 구성 요소를 식별합니다:

* 지연 시간이 동적 성능 임계값(지연 시간 예측의 상한선)을 초과한 피해 워크로드를 식별합니다:
+
** HDD 또는 Flash Pool 하이브리드 애그리게이트(로컬 계층)의 볼륨의 경우, 지연 시간이 5밀리초(ms)보다 길고 IOPS가 초당 10회 작업(ops/sec)보다 많을 때만 이벤트가 트리거됩니다.
** all-SSD 애그리게이트 또는 FabricPool 애그리게이트(클라우드 계층)의 볼륨에 대해서는 지연 시간이 1ms보다 크고 IOPS가 100 ops/sec보다 클 때만 이벤트가 트리거됩니다.


* 경합이 발생한 클러스터 구성 요소를 식별합니다.
+
[NOTE]
====
클러스터 인터커넥트에서 피해 워크로드의 지연 시간이 1ms보다 크면 Unified Manager는 이를 중요한 것으로 간주하고 클러스터 인터커넥트에 대한 이벤트를 트리거합니다.

====
* 클러스터 구성 요소를 과도하게 사용하고 경합을 유발하는 악성 워크로드를 식별합니다.
* 클러스터 구성 요소의 활용도 또는 활동도의 편차를 기준으로 관련된 워크로드의 순위를 매겨, 어떤 가해자가 클러스터 구성 요소 사용량에 가장 큰 변화를 보였는지, 그리고 어떤 피해자가 가장 큰 영향을 받았는지 파악합니다.


이벤트는 아주 짧은 순간 발생했다가 사용 중인 구성 요소의 경합이 끝나면 자동으로 해결될 수 있습니다. 연속 이벤트는 동일한 클러스터 구성 요소에 대해 5분 간격 내에 다시 발생하고 활성 상태를 유지하는 이벤트입니다. 연속 이벤트의 경우, Unified Manager는 두 번의 연속적인 분석 간격 동안 동일한 이벤트가 감지되면 경고를 발생시킵니다.

이벤트가 해결되면 해당 이벤트는 Unified Manager에서 볼륨의 과거 성능 문제 기록의 일부로 유지됩니다. 각 이벤트에는 이벤트 유형과 관련된 볼륨, 클러스터 및 클러스터 구성 요소를 식별하는 고유 ID가 있습니다.

[NOTE]
====
하나의 볼륨이 동시에 여러 이벤트에 관여할 수 있습니다.

====


[[event-state]]
== 이벤트 상태

이벤트는 다음 상태 중 하나일 수 있습니다:

* *활성*
+
현재 성능 이벤트가 활성화된 상태(새로 발생했거나 확인됨)임을 나타냅니다. 이벤트의 원인이 되는 문제가 자체적으로 수정되지 않았거나 해결되지 않았습니다. 스토리지 오브젝트의 성능 카운터가 성능 임계값보다 높은 상태로 유지되고 있습니다.

* *폐기됨*
+
이벤트가 더 이상 활성화되어 있지 않음을 나타냅니다. 이벤트를 발생시킨 문제가 자체적으로 수정되었거나 해결되었습니다. 스토리지 오브젝트의 성능 카운터가 더 이상 성능 임계값을 초과하지 않습니다.





[[event-notification]]
== 이벤트 알림

이벤트는 대시보드 페이지와 사용자 인터페이스의 다른 여러 페이지에 표시되며, 해당 이벤트에 대한 알림은 지정된 이메일 주소로 전송됩니다. 이벤트 상세 정보 페이지와 워크로드 분석 페이지에서 이벤트에 대한 자세한 분석 정보를 확인하고 해결 방법을 제안받을 수 있습니다.



[[event-interaction]]
== 이벤트 상호작용

이벤트 세부 정보 페이지와 워크로드 분석 페이지에서 다음과 같은 방법으로 이벤트와 상호 작용할 수 있습니다.

* 이벤트 위에 마우스를 올리면 해당 이벤트가 감지된 날짜와 시간을 보여주는 메시지가 표시됩니다.
+
동일한 기간에 여러 이벤트가 발생한 경우 메시지에 이벤트 수가 표시됩니다.

* 단일 이벤트를 클릭하면 관련 클러스터 구성 요소를 포함하여 해당 이벤트에 대한 자세한 정보를 보여주는 대화 상자가 표시됩니다.
+
문제가 발생한 구성 요소는 빨간색 원으로 표시되고 강조 표시됩니다. *전체 분석 보기*를 클릭하면 이벤트 세부 정보 페이지에서 전체 분석을 볼 수 있습니다. 동일한 기간에 여러 이벤트가 발생한 경우 대화 상자에는 가장 최근 이벤트 3개에 대한 세부 정보가 표시됩니다. 이벤트를 클릭하면 이벤트 세부 정보 페이지에서 해당 이벤트 분석을 볼 수 있습니다.
