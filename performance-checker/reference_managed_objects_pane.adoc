= Active IQ Unified Manager에서 관리 오브젝트 창 검토
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 요약 탭의 관리 오브젝트 창은 클러스터의 스토리지 오브젝트 유형 및 개수에 대한 개괄적인 정보를 제공합니다. 이 창을 통해 각 클러스터의 오브젝트 상태를 추적할 수 있습니다.

관리되는 오브젝트 수는 마지막 수집 기간 기준의 특정 시점 데이터입니다. 새로운 오브젝트는 15분 간격으로 검색됩니다.

각 오브젝트 유형에 연결된 번호를 클릭하면 해당 오브젝트 유형의 오브젝트 성능 인벤토리 페이지가 표시됩니다. 오브젝트 인벤토리 페이지는 이 클러스터에 있는 오브젝트만 표시하도록 필터링됩니다.

관리 대상 오브젝트는 다음과 같습니다.

* *노드*
+
클러스터 내의 물리적 시스템.

* *애그리게이트*
+
보호 및 프로비저닝을 위해 단일 단위로 관리할 수 있는 여러 개의 독립 디스크로 구성된 중복 배열(RAID) 그룹 세트입니다.

* *포트*
+
노드에 있는 물리적 연결 지점으로, 네트워크상의 다른 장치와 연결하는 데 사용됩니다.

* *스토리지 VM*
+
고유한 네트워크 주소를 통해 네트워크 액세스를 제공하는 가상 머신입니다. SVM은 별도의 네임스페이스에서 데이터를 제공할 수 있으며, 클러스터의 나머지 부분과 별도로 관리할 수 있습니다.

* *볼륨*
+
지원되는 액세스 프로토콜 중 하나 이상을 통해 접근 가능한 사용자 데이터를 보유하는 논리적 엔티티입니다. 이 개수에는 FlexVol 볼륨과 FlexGroup 볼륨이 모두 포함되지만 FlexGroup 구성 요소는 포함되지 않습니다.

* * LUN *
+
파이버 채널(FC) 논리 장치 또는 iSCSI 논리 장치의 식별자입니다. 논리 장치는 일반적으로 스토리지 볼륨에 해당하며 컴퓨터 운영 체제에서 장치로 표시됩니다.

* *네트워크 인터페이스*
+
노드에 대한 네트워크 액세스 포인트를 나타내는 논리적 네트워크 인터페이스입니다. 이 수치에는 모든 인터페이스 유형이 포함됩니다.
