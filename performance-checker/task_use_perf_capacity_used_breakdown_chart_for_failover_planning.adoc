= Active IQ Unified Manager에서 페일오버 계획에 사용된 성능 용량 분석 차트 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
상세 성능 용량 사용량 분석 차트는 기본 노드와 파트너 노드에서 사용된 성능 용량을 보여줍니다. 또한 예상 인계 노드의 사용 가능한 성능 용량도 표시합니다. 이 정보를 통해 파트너 노드에 장애가 발생할 경우 성능 문제가 발생할 수 있는지 판단할 수 있습니다.

노드에 사용된 총 성능 용량을 보여주는 것 외에도, 분석 차트는 각 노드의 값을 사용자 프로토콜과 백그라운드 프로세스로 구분하여 보여줍니다.

* 사용자 프로토콜은 사용자 애플리케이션과 클러스터 간의 입출력 작업입니다.
* 백그라운드 프로세스는 스토리지 효율성, 데이터 복제 및 시스템 상태와 관련된 내부 시스템 프로세스입니다.


이러한 추가적인 세부 정보를 통해 성능 문제가 사용자 애플리케이션 활동으로 인한 것인지, 아니면 중복 제거, RAID 재구성, 디스크 스크러빙, SnapMirror 복사 등 백그라운드 시스템 프로세스로 인한 것인지 판단할 수 있습니다.

.단계
. 예상 테이크오버 노드 역할을 할 노드의 *성능/노드 장애 조치 계획* 페이지로 이동하십시오.
. *시간 범위* 선택기에서 카운터 그리드 및 카운터 차트에 과거 통계가 표시되는 기간을 선택하십시오.
+
기본 노드, 파트너 노드 및 예상 테이크오버 노드에 대한 통계가 포함된 카운터 차트가 표시됩니다.

. *차트 선택* 목록에서 *사용된 성능  용량*을 선택하십시오.
. *사용된 성능  용량* 차트에서 *세부 분석*을 선택하고 *확대 보기*를 클릭합니다.
+
성능 용량 사용량에 대한 자세한 차트가 표시됩니다.

+
image::../media/headroom_advanced_zoom_chart.gif[성능에 대한 자세한 차트를 보여주는 UI 스크린샷입니다. 용량 사용량.]

. 상세 차트 위로 마우스 커서를 가져가면 팝업 창에서 사용된 성능 용량 정보를 확인할 수 있습니다.
+
성능  용량 여유율은 예상 인수 노드에서 사용 가능한 성능 용량입니다. 이는 장애 조치 후 인수 노드에 남아 있는 성능 용량을 나타냅니다. 이 값이 0%인 경우, 장애 조치로 인해 인수 노드의 지연 시간이 허용할 수 없는 수준으로 증가합니다.

. 성능 용량 여유 비율이 낮아지는 것을 방지하기 위해 시정 조치를 고려하십시오.
+
노드 유지 관리를 위해 페일오버를 시작할 계획이라면, 성능 용량 여유 비율이 0이 아닌 시점을 선택하여 파트너 노드를 페일오버하십시오.
