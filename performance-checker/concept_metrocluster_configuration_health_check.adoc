= Active IQ Unified Manager에서 MetroCluster 구성 상태 확인
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager를 사용하여 IP 또는 FC를 통한 MetroCluster 구성의 클러스터 상태를 검토할 수 있습니다. 상태 및 이벤트를 통해 워크로드의 성능에 영향을 미칠 수 있는 하드웨어 또는 소프트웨어 문제가 있는지 확인할 수 있습니다.

Unified Manager에서 이메일 알림을 보내도록 구성하면 로컬 또는 원격 클러스터의 상태 문제로 인해 성능 이벤트가 발생했는지 이메일을 통해 확인할 수 있습니다. Unified Manager GUI에서 *이벤트 관리*를 선택하면 현재 이벤트 목록을 볼 수 있으며, 필터를 사용하여 MetroCluster 구성 이벤트만 표시할 수 있습니다.

자세한 내용은 link:../health-checker/task_check_health_of_clusters_in_metrocluster_configuration.html["MetroCluster 구성에서 클러스터의 상태 확인"]
