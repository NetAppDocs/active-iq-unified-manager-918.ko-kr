= Active IQ Unified Manager에서 최고 성능 페이지 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
최고 성능 항목 페이지에는 선택한 성능 카운터를 기준으로 가장 높은 성능 또는 가장 낮은 성능을 보이는 스토리지 오브젝트가 표시됩니다. 예를 들어 스토리지 VM 범주에서는 IOPS가 가장 높거나, 지연 시간이 가장 길거나, MB/s가 가장 낮은 SVM을 표시할 수 있습니다. 또한 이 페이지에는 최고 성능 항목 중 활성 성능 이벤트(새로 발생했거나 승인됨)가 있는 항목이 있는지 여부도 표시됩니다.

최고 성과 항목 페이지에는 각 오브젝트가 최대 10개까지 표시됩니다. 볼륨 오브젝트에는 FlexVol 볼륨과 FlexGroup 볼륨이 모두 포함된다는 점에 유의하십시오.

* *시간 범위*
+
최고 성과를 보이는 항목을 볼 기간 범위를 선택할 수 있습니다. 선택한 기간 범위는 모든 스토리지 오브젝트에 적용됩니다. 사용 가능한 기간 범위:

+
** 지난 1시간
** 지난 24시간
** 최근 72시간 (기본값)
** 지난 7일


* *메트릭*
+
*메트릭* 메뉴를 클릭하여 다른 카운터를 선택하십시오. 카운터 옵션은 오브젝트 유형별로 다릅니다. 예를 들어, *볼륨* 오브젝트에 사용 가능한 카운터는 *지연 시간*, *IOPS* 및 *MB/s*입니다. 카운터를 변경하면 선택한 카운터를 기준으로 최고 성능을 보여주는 항목으로 패널 데이터가 다시 로드됩니다.

+
사용 가능한 카운터:

+
** 지연 시간
** IOPS
** MB/s
** 성능 용량 사용량 (노드 및 애그리게이트 기준)
** 사용률(노드 및 애그리게이트용)


* *정렬*
+
선택한 오브젝트와 카운터에 대해 오름차순 또는 내림차순 정렬을 선택하려면 *정렬* 메뉴를 클릭하십시오. 옵션은 *높은 값에서 낮은 값 순*과 *낮은 값에서 높은 값 순*입니다. 이 옵션을 사용하면 성능이 가장 높은 오브젝트 또는 가장 낮은 오브젝트를 볼 수 있습니다.

* *카운터 바*
+
그래프의 카운터 막대는 각 오브젝트에 대한 성능 통계를 해당 항목의 막대로 표시합니다. 막대 그래프는 색상으로 구분됩니다. 카운터가 성능 임계값을 초과하지 않으면 카운터 막대는 파란색으로 표시됩니다. 임계값 초과가 활성 상태인 경우(새로운 이벤트 또는 확인된 이벤트) 막대는 해당 이벤트의 색상으로 표시됩니다. 경고 이벤트는 노란색(image:../media/treemapstatus_warning_png.gif["TreeMap 아이콘 – 경고 상태"])으로, 심각한 이벤트는 빨간색(image:../media/treemapred_png.gif["TreeMap 아이콘 – 빨간색"])으로 표시됩니다. 임계값 초과는 경고 및 심각한 이벤트에 대한 심각도 이벤트 표시 아이콘으로 추가로 표시됩니다.

+
image::../media/top_10_example.gif[그래프에서 카운터 막대로 표시된 각 오브젝트의 성능 통계를 보여주는 UI 스크린샷입니다.]

+
각 그래프에서 X축은 선택한 오브젝트 유형에 대한 상위 성능 항목을 표시합니다. Y축은 선택한 카운터에 적용 가능한 단위를 표시합니다. 각 세로 막대 그래프 요소 아래에 있는 오브젝트 이름 링크를 클릭하면 선택한 오브젝트의 Performance Landing 페이지로 이동합니다.

* *심각도 이벤트 표시기*
+
*심각도 이벤트* 표시기 아이콘은 최고 성과자 그래프에서 활성 심각(image:../media/sev_critical_um60.png["이벤트 심각도 아이콘 – 심각"]) 또는 경고(image:../media/sev_warning_um60.png["이벤트 심각도 아이콘 – 경고"]) 이벤트의 오브젝트 이름 왼쪽에 표시됩니다. *심각도 이벤트* 표시기 아이콘을 클릭하여 다음을 확인합니다.

+
** *하나의 이벤트*
+
해당 이벤트의 상세 정보 페이지로 이동합니다.

** *두 개 이상의 이벤트*
+
선택한 오브젝트의 모든 이벤트를 표시하도록 필터링된 이벤트 인벤토리 페이지로 이동합니다.



* *내보내기 버튼*
+
카운터 막대에 표시되는 데이터가 포함된  `.csv` 파일을 생성합니다. 현재 보고 있는 단일 클러스터에 대한 파일 또는 데이터 센터의 모든 클러스터에 대한 파일을 생성할 수 있습니다.
