= Active IQ Unified Manager에서 성능 이벤트에 대한 정보를 표시합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이벤트 관리 인벤토리 페이지를 사용하면 Unified Manager에서 모니터링하는 클러스터의 모든 성능 이벤트 목록을 볼 수 있습니다. 이 정보를 통해 가장 중요한 이벤트를 파악하고, 자세한 정보를 확인하여 이벤트의 원인을 분석할 수 있습니다.

.시작하기 전에
* 운영자, 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.


이벤트 목록은 감지 시간 순으로 정렬되며, 가장 최근 이벤트가 먼저 표시됩니다. 열 헤더를 클릭하면 해당 열을 기준으로 이벤트를 정렬할 수 있습니다. 예를 들어, 상태 열을 기준으로 정렬하면 심각도별로 이벤트를 볼 수 있습니다. 특정 이벤트 또는 특정 유형의 이벤트를 찾고 있다면 필터 및 검색 기능을 사용하여 목록에 표시되는 이벤트를 세분화할 수 있습니다.

이 페이지에는 모든 출처의 이벤트가 표시됩니다:

* 사용자 정의 성능 임계값 정책
* 시스템 정의 성능 임계값 정책
* 동적 성능 임계값


이벤트 유형 열에는 이벤트의 출처가 표시됩니다. 이벤트를 선택하면 이벤트 세부 정보 페이지에서 해당 이벤트에 대한 자세한 내용을 볼 수 있습니다.

.단계
. 왼쪽 탐색 창에서 *이벤트 관리*를 클릭합니다.
. 보기 메뉴에서 *활성 성능 이벤트*를 선택합니다.
+
이 페이지에는 지난 7일 동안 생성된 모든 신규 및 승인된 성능 이벤트가 표시됩니다.

. 분석하려는 이벤트를 찾아서 이벤트 이름을 클릭합니다.
+
이벤트 상세 정보 페이지가 표시됩니다.

+
[NOTE]
====
또한 성능 탐색기 페이지와 알림 이메일에서 이벤트 이름 링크를 클릭하여 이벤트 세부 정보 페이지를 표시할 수 있습니다.

====
