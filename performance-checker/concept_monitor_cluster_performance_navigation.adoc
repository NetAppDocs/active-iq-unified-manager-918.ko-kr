= Active IQ Unified Manager에서 클러스터 성능 탐색 모니터링
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager에서 관리하는 모든 클러스터의 성능을 모니터링할 수 있습니다. 클러스터 모니터링을 통해 클러스터 및 오브젝트 성능에 대한 개요를 확인할 수 있으며, 성능 이벤트 모니터링도 포함됩니다. 성능 및 이벤트를 개략적으로 살펴보거나, 클러스터 및 오브젝트 성능과 성능 이벤트에 대한 자세한 내용을 추가로 조사할 수 있습니다.

이는 가능한 여러 클러스터 성능 탐색 경로 중 하나의 예입니다:

. 왼쪽 탐색 창에서 *스토리지* > *애그리게이트*를 클릭합니다.
. 해당 애그리게이트의 성능에 대한 정보를 보려면 Performance: All Aggregates 보기를 선택하십시오.
. 조사하려는 애그리게이트를 확인하고 해당 애그리게이트 이름을 클릭하여 애그리게이트 / 성능 탐색기 페이지로 이동합니다.
. 선택적으로, 보기 및 비교 메뉴에서 이 애그리게이트와 비교할 다른 오브젝트를 선택한 다음, 해당 오브젝트 중 하나를 비교 창에 추가합니다.
+
두 오브젝트에 대한 통계는 비교를 위해 카운터 차트에 표시됩니다.

. 탐색기 페이지 오른쪽의 비교 창에서 카운터 차트 중 하나의 *확대 보기*를 클릭하여 해당 애그리게이트의 성능 기록에 대한 세부 정보를 확인합니다.
