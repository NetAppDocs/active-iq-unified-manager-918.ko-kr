= Active IQ Unified Manager에서 사용된 성능 용량 카운터 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 용량 사용량 카운터는 노드 또는 애그리게이트의 성능이 워크로드 증가 시 성능 저하가 발생할 수 있는 지점에 도달했는지 여부를 파악하는 데 도움이 됩니다. 또한 특정 기간 동안 노드 또는 애그리게이트가 현재 과도하게 사용되고 있는지 여부도 확인할 수 있습니다. 성능 용량 사용량은 활용률과 유사하지만, 특정 워크로드에 대해 물리적 리소스에서 사용 가능한 성능 기능에 대해 더 많은 통찰력을 제공합니다.

최적 사용 성능 용량은 노드 또는 애그리게이트의 활용률과 지연 시간(응답 시간)이 최적이면서 효율적으로 사용되는 지점입니다. 다음 그림은 애그리게이트의 지연 시간 대 활용률 곡선 예시를 보여줍니다.

image::../media/headroom_chart.gif[애그리게이트에 대한 지연 시간 대 사용률 곡선 샘플을 보여주는 UI 스크린샷입니다.]

이 예시에서 _운영 지점_은 현재 애그리게이트가 50% 사용률과 1.0ms/op의 지연 시간으로 작동 중임을 나타냅니다. Unified Manager는 애그리게이트에서 수집된 통계를 기반으로 이 애그리게이트에 추가적인 성능 용량이 확보되어 있다고 판단합니다. 이 예시에서 _최적 지점_은 애그리게이트 사용률이 80%이고 지연 시간이 2.0ms/op인 시점으로 정의됩니다. 따라서 이 애그리게이트에 볼륨과 LUN을 추가하여 시스템을 더욱 효율적으로 사용할 수 있습니다.

성능 용량 사용량 카운터는 지연 시간에 미치는 영향을 반영하기 때문에 "`활용률`" 카운터보다 더 큰 값을 나타낼 것으로 예상됩니다. 예를 들어, 노드 또는 애그리게이트의 사용률이 70%인 경우, 지연 시간 값에 따라 성능 용량 값은 80%에서 100% 사이가 될 수 있습니다.

하지만 경우에 따라 대시보드 페이지의 사용률 카운터가 더 높게 표시될 수 있습니다. 이는 대시보드가 각 데이터 수집 주기마다 현재 카운터 값을 새로 고치기 때문에 정상적인 현상입니다. 대시보드는 Unified Manager 사용자 인터페이스의 다른 페이지처럼 일정 기간 동안의 평균을 표시하지 않습니다. 성능 용량 사용량 카운터는 일정 기간 동안의 평균 성능을 나타내는 지표로 가장 적합하며, 사용률 카운터는 리소스의 순간 사용량을 파악하는 데 가장 적합합니다.
