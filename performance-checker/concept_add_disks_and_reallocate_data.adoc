= Active IQ Unified Manager에서 디스크 추가가 데이터 재할당에 미치는 영향 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
애그리게이트에 디스크를 추가하여 스토리지 용량과 성능을 향상시킬 수 있습니다. 디스크를 추가한 후에는 추가된 디스크에 데이터가 재할당된 후에만 읽기 성능이 향상됩니다.

Unified Manager가 동적 임계값 또는 시스템 정의 성능 임계값으로 인해 트리거된 애그리게이트 이벤트를 수신한 경우 다음 지침을 사용할 수 있습니다.

* 동적 임계값 이벤트가 수신되면 이벤트 세부 정보 페이지에서 경합 중인 애그리게이트를 나타내는 클러스터 구성 요소 아이콘이 빨간색으로 강조 표시됩니다.
+
아이콘 아래 괄호 안에는 디스크를 추가할 수 있는 애그리게이트의 이름이 표시됩니다.

* 시스템에서 정의한 임계값 이벤트를 수신하면 이벤트 세부 정보 페이지의 이벤트 설명 텍스트에 문제가 발생한 애그리게이트의 이름이 표시됩니다.
+
이 애그리게이트에 디스크를 추가하고 데이터를 재할당할 수 있습니다.



애그리게이트에 추가하는 디스크는 클러스터에 이미 존재해야 합니다. 클러스터에 사용 가능한 추가 디스크가 없는 경우 관리자에게 문의하거나 디스크를 추가로 구매해야 할 수 있습니다. ONTAP System Manager 또는 ONTAP 명령을 사용하여 애그리게이트에 디스크를 추가할 수 있습니다.

[NOTE]
====
HDD 및 Flash Pool 애그리게이트를 사용할 때만 데이터를 재할당해야 합니다. SSD 또는 FabricPool 애그리게이트에서는 데이터를 재할당하지 마십시오.
