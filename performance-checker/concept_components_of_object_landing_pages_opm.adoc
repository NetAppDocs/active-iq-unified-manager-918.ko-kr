= Active IQ Unified Manager의 오브젝트 랜딩 페이지 구성 요소 검토
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
오브젝트 랜딩 페이지는 모든 중요 이벤트, 경고 이벤트 및 정보 이벤트에 대한 세부 정보를 제공합니다. 이러한 페이지는 모든 클러스터 오브젝트의 성능을 자세히 보여주므로 다양한 기간에 걸쳐 개별 오브젝트를 선택하고 비교할 수 있습니다.

오브젝트 랜딩 페이지를 사용하면 모든 오브젝트의 전반적인 성능을 검토하고 오브젝트 성능 데이터를 나란히 비교할 수 있습니다. 이는 성능 평가 및 이벤트 문제 해결 시 유용합니다.

[NOTE]
====
카운터 요약 패널과 카운터 차트에 표시되는 데이터는 5분 샘플링 간격을 기반으로 합니다. 페이지 왼쪽의 오브젝트 인벤토리 그리드에 표시되는 데이터는 1시간 샘플링 간격을 기반으로 합니다.

====
다음 이미지는 탐색기 정보를 표시하는 오브젝트 랜딩 페이지의 예를 보여줍니다:

image::../media/perf_manager_page_1.gif[탐색기 정보를 표시하는 오브젝트 랜딩 페이지의 예를 보여주는 UI 스크린샷입니다.]

보고 있는 스토리지 오브젝트에 따라 오브젝트 랜딩 페이지에는 오브젝트에 대한 성능 데이터를 제공하는 다음과 같은 탭이 있을 수 있습니다:

* 요약
+
지난 72시간 동안의 오브젝트별 이벤트 및 성능을 포함하는 3~4개의 카운터 차트를 표시하며, 해당 기간 동안의 최고값과 최저값을 나타내는 추세선도 함께 보여줍니다.

* 탐색기
+
현재 오브젝트와 관련된 스토리지 오브젝트의 그리드를 표시하여 현재 오브젝트의 성능 값을 관련 오브젝트의 성능 값과 비교할 수 있도록 합니다. 이 탭에는 최대 11개의 카운터 차트와 시간 범위 선택기가 포함되어 있어 다양한 비교를 수행할 수 있습니다.

* 정보
+
설치된 ONTAP 소프트웨어 버전, HA 파트너 이름, 포트 및 LIF 수 등 스토리지 오브젝트에 대한 비성능 구성 속성 값을 표시합니다.

* 상위 성능
+
클러스터의 경우: 선택한 성능 카운터를 기준으로 성능이 가장 높거나 가장 낮은 스토리지 오브젝트를 표시합니다.

* 장애 조치 계획
+
노드의 경우: 해당 노드의 HA 파트너에 장애가 발생할 경우 노드에 미치는 성능 영향에 대한 예상치를 표시합니다.

* 세부 정보
+
볼륨의 경우: 선택한 볼륨 워크로드에 대한 모든 I/O 활동 및 작업에 대한 자세한 성능 통계를 표시합니다. 이 탭은 FlexVol 볼륨, FlexGroup 볼륨 및 FlexGroups의 구성 요소에 사용할 수 있습니다.
