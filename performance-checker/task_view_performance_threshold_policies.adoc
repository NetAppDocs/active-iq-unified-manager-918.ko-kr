= Active IQ Unified Manager에서 성능 임계값 정책 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
현재 정의된 모든 성능 임계값 정책은 성능 임계값 페이지에서 확인할 수 있습니다.

임계값 정책 목록은 정책 이름의 알파벳순으로 정렬되어 있으며, 모든 유형의 스토리지 오브젝트에 대한 정책을 포함합니다. 열 헤더를 클릭하면 해당 열을 기준으로 정책을 정렬할 수 있습니다. 특정 정책을 찾으려면 필터 및 검색 기능을 사용하여 인벤토리 목록에 표시되는 임계값 정책 목록을 세분화하십시오.

마우스 커서를 정책 이름과 조건 이름 위에 올리면 해당 정책의 구성 세부 정보를 볼 수 있습니다. 또한 제공된 버튼을 사용하여 사용자 정의 임계값 정책을 생성, 복제, 편집 및 삭제할 수 있습니다.

.단계
. 왼쪽 탐색 창에서 *이벤트 임계값* > *성능*을 선택합니다.
+
성능 임계값 페이지가 표시됩니다.
