= Active IQ Unified Manager에서 비교 그래프를 위한 상관 오브젝트 정의
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
카운터 차트 창에서 데이터 및 성능 비교를 위해 상관 관계가 있는 오브젝트 목록을 정의할 수 있습니다. 예를 들어 스토리지 가상 머신(SVM)에서 성능 문제가 발생하는 경우 SVM의 모든 볼륨을 비교하여 어떤 볼륨이 문제의 원인인지 파악할 수 있습니다.

상관관계가 있는 오브젝트 그리드의 모든 오브젝트를 비교 및 카운터 차트 창에 추가할 수 있습니다. 이를 통해 여러 오브젝트의 데이터를 확인하고 루트 오브젝트와 비교할 수 있습니다. 상관관계가 있는 오브젝트 그리드에서 오브젝트를 추가하거나 제거할 수 있지만, 비교 창의 루트 오브젝트는 제거할 수 없습니다.

[NOTE]
====
비교 창에 많은 오브젝트를 추가하면 성능에 부정적인 영향을 미칠 수 있습니다. 성능을 유지하려면 데이터 비교에 사용할 차트 수를 제한적으로 선택해야 합니다.

====
.단계
. 오브젝트 그리드에서 추가하려는 오브젝트를 찾고 *추가* 버튼을 클릭합니다.
+
*추가* 버튼이 회색으로 바뀌고 오브젝트가 비교 창의 추가 오브젝트 목록에 추가됩니다. 오브젝트의 데이터가 카운터 차트 창의 그래프에 추가됩니다. 오브젝트의 눈 아이콘(image:../media/eye_icon.gif[""]) 색상은 그래프에서 오브젝트의 데이터 추세선 색상과 일치합니다.

. *선택 사항:* 선택한 오브젝트의 데이터를 숨기거나 표시합니다:
+
|===
| 이렇게 하려면... | 다음 조치를 취하십시오... 


 a| 
선택한 오브젝트 숨기기
 a| 
비교 창에서 선택한 오브젝트의 눈 아이콘(image:../media/eye_icon.gif[""])을 클릭합니다. 오브젝트의 데이터가 숨겨지고 해당 오브젝트의 눈 아이콘이 회색으로 바뀝니다.



 a| 
숨겨진 오브젝트 표시
 a| 
비교 창에서 선택한 오브젝트의 회색 눈 아이콘을 클릭합니다.

눈 아이콘은 원래 색상으로 돌아가고, 오브젝트 데이터는 카운터 차트 창의 그래프에 다시 추가됩니다.

|===
. *선택 사항:* *비교* 창에서 선택한 오브젝트를 제거합니다.
+
|===
| 이렇게 하려면... | 다음 조치를 취하십시오... 


 a| 
선택한 오브젝트 제거
 a| 
비교 창에서 선택한 오브젝트의 이름 위에 마우스를 올려 오브젝트 제거 버튼(*X*)을 표시한 다음 해당 버튼을 클릭합니다. 오브젝트가 비교 창에서 제거되고 카운터 차트에서 해당 데이터가 지워집니다.



 a| 
선택한 모든 오브젝트를 제거합니다
 a| 
비교 창 상단의 모든 오브젝트 제거 버튼(*X*)을 클릭합니다. 선택한 모든 오브젝트와 해당 데이터가 제거되고 루트 오브젝트만 남습니다.

|===
