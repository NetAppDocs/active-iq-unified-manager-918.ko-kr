= Active IQ Unified Manager의 시스템 정의 성능 임계값 정책 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager는 클러스터 성능을 모니터링하고 이벤트를 자동으로 생성하는 몇 가지 표준 임계값 정책을 제공합니다. 이러한 정책은 기본적으로 활성화되어 있으며, 모니터링되는 성능 임계값을 초과하면 경고 또는 정보 이벤트를 생성합니다.

[NOTE]
====
Cloud Volumes ONTAP, ONTAP Edge 또는 ONTAP Select 시스템에서는 시스템 정의 성능 임계값 정책이 활성화되어 있지 않습니다.

====
시스템에서 정의한 성능 임계값 정책으로 인해 불필요한 이벤트가 수신되는 경우, 이벤트 설정 페이지에서 개별 정책에 대한 이벤트를 비활성화할 수 있습니다.



[[cluster-threshold-policies]]
== 클러스터 임계값 정책

Unified Manager에서 모니터링하는 모든 클러스터에는 기본적으로 시스템에서 정의한 클러스터 성능 임계값 정책이 할당됩니다:

* *클러스터 부하 불균형*
+
클러스터의 다른 노드보다 한 노드가 훨씬 더 높은 부하로 작동하여 워크로드 지연 시간에 잠재적으로 영향을 미칠 수 있는 상황을 식별합니다.

+
이는 클러스터 내 모든 노드의 사용된 성능 용량 값을 비교하여 24시간 이상 30% 임계값을 초과한 노드가 있는지 확인함으로써 수행됩니다. 이는 경고 이벤트입니다.

* *클러스터 용량 불균형*
+
클러스터 내에서 특정 애그리게이트의 사용 용량이 다른 애그리게이트보다 훨씬 높은 경우를 식별하여 운영에 필요한 공간에 잠재적인 영향을 미치는 상황을 파악합니다.

+
이는 클러스터 내 모든 애그리게이트의 사용 용량 값을 비교하여 애그리게이트 간에 70%의 차이가 있는지 확인하는 방식으로 이루어집니다. 이는 경고 이벤트입니다.





[[node-threshold-policies]]
== 노드 임계값 정책

Unified Manager에서 모니터링하는 클러스터의 모든 노드에는 기본적으로 시스템에서 정의한 노드 성능 임계값 정책이 할당됩니다:

* *성능 용량 사용량 임계값 초과*
+
단일 노드가 운영 효율성의 한계를 초과하여 작동함으로써 워크로드 지연 시간에 잠재적으로 영향을 미치는 상황을 식별합니다.

+
이는 12시간 이상 성능 용량의 100% 이상을 사용하는 노드를 찾아냄으로써 이루어집니다. 이는 경고 이벤트입니다.

* *노드 HA 쌍이 과다 사용 중입니다*
+
HA 쌍의 노드가 HA 쌍 운영 효율성의 한계를 초과하여 작동하는 상황을 식별합니다.

+
이는 HA 쌍의 두 노드에 대한 성능 용량 사용량 값을 확인하여 이를 수행합니다. 두 노드의 성능 용량 사용량 합계가 12시간 이상 200%를 초과하면 컨트롤러 페일오버가 워크로드 지연 시간에 영향을 미칩니다. 이는 정보 이벤트입니다.

* *노드 디스크 조각화*
+
애그리게이트 내 하나 이상의 디스크가 조각화되어 주요 시스템 서비스 속도가 저하되고 노드의 워크로드 지연 시간에 영향을 미칠 수 있는 상황을 식별합니다.

+
이는 노드의 모든 애그리게이트에 걸쳐 특정 읽기 및 쓰기 작업 비율을 확인하여 이를 수행합니다. 이 정책은 SyncMirror 재동기화 중이나 디스크 스크럽 작업 중 오류가 발견될 때에도 트리거될 수 있습니다. 이는 경고 이벤트입니다.

+
[NOTE]
====
"`노드 디스크 조각화`" 정책은 HDD 전용 애그리게이트를 분석합니다. Flash Pool, SSD 및 FabricPool 애그리게이트는 분석되지 않습니다.

====




[[aggregate-threshold-policies]]
== 애그리게이트 임계값 정책

Unified Manager에서 모니터링하는 클러스터의 모든 애그리게이트에는 기본적으로 시스템 정의 애그리게이트 성능 임계값 정책이 할당됩니다:

* *애그리게이트 디스크 초과 사용*
+
애그리게이트가 운영 효율성의 한계를 초과하여 작동하여 워크로드 지연 시간에 잠재적으로 영향을 미칠 수 있는 상황을 식별합니다. 애그리게이트 내 디스크 사용률이 30분 이상 95%를 초과하는 애그리게이트를 찾아 이러한 상황을 식별합니다. 그런 다음 이 다중 조건 정책은 다음 분석을 수행하여 문제의 원인을 파악하는 데 도움을 줍니다.

+
** 애그리게이트에 속한 디스크 중 현재 백그라운드 유지 관리 작업이 진행 중인 디스크가 있습니까?
+
디스크에서 수행될 수 있는 백그라운드 유지 관리 작업에는 디스크 재구성, 디스크 스크럽, SyncMirror 재동기화 및 패리티 복구가 포함됩니다.

** 디스크 쉘프 파이버 채널 인터커넥트에 통신 병목 현상이 있습니까?
** 애그리게이트에 여유 공간이 너무 부족합니까? 이 정책에 대한 경고 이벤트는 하위 정책 3개 중 하나 이상이 위반된 것으로 간주되는 경우에만 발생합니다. 애그리게이트 내 디스크 사용률만 95%를 초과하는 경우에는 성능 이벤트가 트리거되지 않습니다.




[NOTE]
====
"`Aggregate disks over-utilized`" 정책은 HDD 전용 애그리게이트와 Flash Pool(하이브리드) 애그리게이트를 분석하며, SSD 및 FabricPool 애그리게이트는 분석하지 않습니다.

====


[[workload-latency-threshold-policies]]
== 워크로드 지연 시간 임계값 정책

시스템에서 정의한 워크로드 지연 시간 임계값 정책은 "`예상 지연 시간`" 값이 정의된 성능 서비스 수준 정책이 구성된 모든 워크로드에 할당됩니다:

* *성능 서비스 수준에서 정의한 워크로드 볼륨/LUN 지연 시간 임계값 초과*
+
"`예상 지연 시간`" 제한을 초과하여 워크로드 성능에 영향을 미치는 볼륨(파일 공유) 및 LUN을 식별합니다. 이는 경고 이벤트입니다.

+
이 기능은 지난 1시간 중 30%의 시간 동안 예상 지연 시간 값을 초과한 워크로드를 찾아냄으로써 이를 수행합니다.





[[qos-threshold-policies]]
== QoS 임계값 정책

시스템에서 정의한 QoS 성능 임계값 정책은 ONTAP QoS 최대 처리량 정책(IOPS, IOPS/TB 또는 MB/s)이 구성된 모든 워크로드에 할당됩니다. Unified Manager는 워크로드 처리량 값이 구성된 QoS 값보다 15% 낮을 때 이벤트를 발생시킵니다:

* *QoS 최대 IOPS 또는 MB/s 임계값*
+
QoS 최대 IOPS 또는 MB/s 처리량 제한을 초과하여 워크로드 지연에 영향을 미치는 볼륨 및 LUN을 식별합니다. 이는 경고 이벤트입니다.

+
단일 워크로드가 정책 그룹에 할당될 때, 이는 이전 한 시간 동안의 각 수집 기간 동안 할당된 QoS 정책 그룹에 정의된 최대 처리량 임계값을 초과한 워크로드를 찾아냅니다.

+
여러 워크로드가 단일 QoS 정책을 공유하는 경우, 정책에 포함된 모든 워크로드의 IOPS 또는 MB/s를 합산하여 해당 합계를 임계값과 비교합니다.

* *QoS 최고 IOPS/TB 또는 블록 크기 임계값을 적용한 IOPS/TB*
+
적응형 QoS 최대 IOPS/TB 처리량 제한(또는 블록 크기 제한을 포함한 IOPS/TB)을 초과하여 워크로드 지연에 영향을 미치는 볼륨을 식별합니다. 이는 경고 이벤트입니다.

+
이 기능은 적응형 QoS 정책에 정의된 최대 IOPS/TB 임계값을 각 볼륨 크기에 기반한 QoS 최대 IOPS 값으로 변환한 다음, 이전 시간 동안의 각 성능 수집 기간 동안 QoS 최대 IOPS를 초과한 볼륨을 찾습니다.

+
[NOTE]
====
이 정책은 클러스터에 ONTAP 9.3 이상 소프트웨어가 설치된 경우에만 볼륨에 적용됩니다.

====
+
적응형 QoS 정책에서 "`block size`" 요소가 정의된 경우, 임계값은 각 볼륨의 크기를 기반으로 QoS 최대 MB/s 값으로 변환됩니다. 그런 다음 이전 시간 동안의 각 성능 수집 기간 동안 QoS 최대 MB/s를 초과한 볼륨을 찾습니다.

+
[NOTE]
====
이 정책은 클러스터에 ONTAP 9.5 이상 소프트웨어가 설치된 경우에만 볼륨에 적용됩니다.

====
