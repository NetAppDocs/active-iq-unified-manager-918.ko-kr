[NOTE]
====
볼륨 조합 정책을 FlexGroup 볼륨에 적용할 경우(FlexVol 볼륨 대신), 보조 카운터로 "`Volume IOPS`" 및 "`Volume MB/s`" 속성만 선택할 수 있습니다. 임계값 정책에 노드 또는 애그리게이트 속성 중 하나가 포함된 경우, 해당 정책은 FlexGroup 볼륨에 적용되지 않으며, 이 경우를 설명하는 오류 메시지가 표시됩니다. 이는 FlexGroup 볼륨이 둘 이상의 노드 또는 애그리게이트에 존재할 수 있기 때문입니다.
