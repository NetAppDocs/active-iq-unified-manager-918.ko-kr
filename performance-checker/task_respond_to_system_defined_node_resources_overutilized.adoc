= Active IQ Unified Manager에서 노드 리소스 과다 사용 이벤트에 응답합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager는 단일 노드가 운영 효율성의 한계를 초과하여 작동하여 워크로드 지연 시간에 영향을 미칠 가능성이 있을 때 노드 리소스 과다 사용 경고 이벤트를 생성합니다. 이러한 시스템 정의 이벤트는 여러 워크로드가 지연 시간의 영향을 받기 전에 잠재적인 성능 문제를 해결할 수 있는 기회를 제공합니다.

.시작하기 전에
* 운영자, 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.
* 새로운 또는 더 이상 사용되지 않는 성능 이벤트가 있어야 합니다.


Unified Manager는 30분 이상 성능 용량의 100% 이상을 사용하는 노드를 검색하여 노드 리소스 과다 사용 정책 위반에 대한 경고 이벤트를 생성합니다.

System Manager 또는 ONTAP 명령을 사용하여 다음과 같은 작업을 포함하여 이러한 유형의 성능 문제를 해결할 수 있습니다.

* 시스템 리소스를 과도하게 사용하는 볼륨 또는 LUN에 QoS 정책 생성 및 적용
* 워크로드가 적용된 정책 그룹의 QoS 최대 처리량 제한 줄이기
* 워크로드를 다른 애그리게이트 또는 노드로 이동
* 노드에 디스크를 추가하거나 더 빠른 CPU와 더 많은 RAM을 갖춘 노드로 업그레이드하여 용량 증가


.단계
. 이벤트에 대한 정보를 보려면 *이벤트 상세 정보* 페이지를 표시하십시오.
. 이벤트 발생 원인이 된 임계값 위반에 대한 설명이 포함된 *설명*을 검토하십시오.
+
예를 들어, "`Perf. Capacity Used value of 139% on simplicity-02 has triggered a WARNING event to identify potential performance problems in the data processing unit.`"라는 메시지는 노드 simplicity-02의 성능 용량이 과도하게 사용되어 노드 성능에 영향을 미치고 있음을 나타냅니다.

. *시스템 진단* 섹션에서 다음 세 가지 차트를 검토하십시오. 하나는 노드에서 사용되는 성능 용량, 다른 하나는 상위 워크로드에서 사용되는 평균 스토리지 IOPS, 그리고 마지막 하나는 상위 워크로드의 지연 시간입니다. 이렇게 정리하면 어떤 워크로드가 노드의 지연을 유발하는지 확인할 수 있습니다.
+
IOPS 차트에 마우스 커서를 올리면 어떤 워크로드에 QoS 정책이 적용되었는지, 어떤 워크로드에는 적용되지 않았는지 확인할 수 있습니다.

. *Suggested Actions* 섹션에서 제안 사항을 검토하고 워크로드의 지연 시간 증가를 방지하기 위해 수행해야 하는 작업을 결정합니다.
+
필요한 경우, *도움말* 버튼을 클릭하여 성능 이벤트를 해결하기 위해 시도해 볼 수 있는 권장 조치에 대한 자세한 내용을 확인하십시오.
