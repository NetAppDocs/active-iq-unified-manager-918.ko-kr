= Active IQ Unified Manager에서 사용된 성능 용량 임계값 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
사용자 정의 성능 임계값 정책을 생성하여 노드 또는 애그리게이트의 성능 용량 사용량 값이 정의된 성능 용량 사용량 임계값 설정을 초과할 때 이벤트가 트리거되도록 할 수 있습니다.

또한 노드는 "`성능 용량 사용량 기준 인계`" 임계값 정책으로 구성할 수 있습니다. 이 임계값 정책은 HA 쌍을 이루는 두 노드의 성능 용량 사용량 통계를 합산하여 한 노드에 장애가 발생할 경우 다른 노드에 용량이 부족해지는지 여부를 판단합니다. 장애 조치 시 워크로드는 두 파트너 노드의 워크로드를 합산한 것이므로 동일한 성능 용량 사용량 기준 인계 정책을 두 노드 모두에 적용할 수 있습니다.

[NOTE]
====
일반적으로 노드 간 성능 용량 사용량의 동등성은 성립합니다. 그러나 장애 조치 파트너를 통해 특정 노드로 향하는 노드 간 트래픽이 다른 노드에 비해 훨씬 많은 경우, 모든 워크로드를 한 파트너 노드에서 실행할 때와 다른 파트너 노드에서 실행할 때의 총 성능 용량 사용량은 어느 노드에 장애가 발생했는지에 따라 약간 다를 수 있습니다.

====
성능 용량 사용 조건은 LUN 및 볼륨에 대한 임계값을 정의할 때 조합 임계값 정책을 생성하기 위한 보조 성능 임계값 설정으로도 사용할 수 있습니다. 성능 용량 사용 조건은 볼륨 또는 LUN이 있는 애그리게이트 또는 노드에 적용됩니다. 예를 들어 다음 기준을 사용하여 조합 임계값 정책을 생성할 수 있습니다.
