= Active IQ Unified Manager에서 성능 이벤트 조사
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 이벤트 상세 정보 페이지는 모든 성능 이벤트에 대한 심층적인 분석을 제공합니다. 이는 성능 이벤트 조사, 문제 해결 및 시스템 성능 미세 조정 시 유용합니다.

성능 이벤트 유형에 따라 두 가지 유형의 이벤트 상세 페이지 중 하나가 표시될 수 있습니다:

* 사용자 정의 및 시스템 정의 임계값 정책 이벤트에 대한 이벤트 세부 정보 페이지
* 동적 임계값 정책 이벤트에 대한 이벤트 세부 정보 페이지


이는 이벤트 조사 탐색의 한 예입니다.

. 왼쪽 탐색 창에서 *이벤트 관리*를 클릭합니다.
. 보기 메뉴에서 *활성 성능 이벤트*를 클릭합니다.
. 조사하려는 이벤트 이름을 클릭하면 이벤트 세부 정보 페이지가 표시됩니다.
. 이벤트 설명을 보고 (가능한 경우) 권장 조치를 검토하여 문제 해결에 도움이 될 수 있는 이벤트에 대한 자세한 정보를 확인하십시오. *워크로드 분석* 버튼을 클릭하면 자세한 성능 차트를 표시하여 문제를 더욱 심층적으로 분석할 수 있습니다.
