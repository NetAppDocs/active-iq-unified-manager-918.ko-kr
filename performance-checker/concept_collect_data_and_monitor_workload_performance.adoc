= Active IQ Unified Manager에서 데이터 수집 및 워크로드 성능 모니터링
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager는 5분마다 워크로드 활동을 수집 및 분석하여 성능 이벤트를 식별하고, 15분마다 구성 변경 사항을 감지합니다. 최대 30일 동안 5분 단위의 과거 성능 및 이벤트 데이터를 보관하며, 이 데이터를 사용하여 모니터링되는 모든 워크로드의 예상 지연 시간 범위를 예측합니다.

Unified Manager는 워크로드 분석을 시작하고 I/O 응답 시간 지연 예측을 워크로드 분석 페이지와 이벤트 세부 정보 페이지에 표시하기 전에 최소 3일 동안의 워크로드 활동 데이터를 수집해야 합니다. 활동 데이터 수집 중에는 워크로드 활동으로 인한 모든 변경 사항이 지연 예측에 반영되지 않습니다. 3일 동안의 활동 데이터 수집 후, Unified Manager는 워크로드 활동 변경 사항을 반영하고 보다 정확한 동적 성능 임계값을 설정하기 위해 매 24시간 자정(오전 12시)에 지연 예측을 조정합니다.

Unified Manager가 워크로드를 모니터링하는 첫 4일 동안, 마지막 데이터 수집 이후 24시간 이상 경과한 경우 지연 시간 차트에 해당 워크로드의 지연 시간 예측이 표시되지 않습니다. 마지막 수집 이전에 감지된 이벤트는 계속 사용할 수 있습니다.

[NOTE]
====
일광 절약 시간제(DST)가 시행되면 시스템 시간이 변경되어 모니터링 대상 워크로드의 성능 통계에 대한 지연 시간 예측이 수정됩니다. Unified Manager는 즉시 지연 시간 예측을 수정하기 시작하며, 이 작업은 약 15일이 소요됩니다. 이 기간 동안 Unified Manager를 계속 사용할 수 있지만, Unified Manager는 지연 시간 예측을 사용하여 동적 이벤트를 감지하므로 일부 이벤트가 정확하지 않을 수 있습니다. 시간 변경 이전에 감지된 이벤트는 영향을 받지 않습니다.
