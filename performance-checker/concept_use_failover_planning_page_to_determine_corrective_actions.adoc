= Active IQ Unified Manager의 Performance/Node Failover Planning 페이지에서 수정 조치 결정
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능/노드 장애 조치 계획 페이지에 표시된 정보를 기반으로, 장애 조치로 인해 HA 쌍의 성능이 허용 가능한 수준 이하로 떨어지지 않도록 조치를 취할 수 있습니다.

예를 들어, 장애 조치로 인해 예상되는 성능 영향을 줄이기 위해 HA 쌍의 노드에서 일부 볼륨이나 LUN을 클러스터의 다른 노드로 이동할 수 있습니다. 이렇게 하면 장애 조치 후에도 기본 노드가 허용 가능한 성능을 계속 제공할 수 있습니다.
