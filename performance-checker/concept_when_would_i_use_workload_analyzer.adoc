= Active IQ Unified Manager에서 워크로드 분석기를 사용해야 하는 경우 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
일반적으로 워크로드 분석기는 사용자가 보고한 지연 문제를 해결하거나, 보고된 이벤트 또는 경고를 보다 자세히 분석하거나, 비정상적으로 작동하는 것으로 보이는 워크로드를 조사하는 데 사용합니다.

사용자가 사용 중인 애플리케이션이 매우 느리게 실행된다고 문의하는 경우, 애플리케이션이 실행되는 워크로드에 대한 지연 시간, 처리량 및 사용률 차트를 확인하여 스토리지 문제가 성능 저하의 원인인지 파악할 수 있습니다. 용량 차트를 사용하여 용량 부족 여부도 확인할 수 있습니다. ONTAP 시스템에서 용량 사용률이 85%를 초과하면 성능 문제가 발생할 수 있기 때문입니다. 이러한 차트를 통해 문제가 스토리지 때문인지, 네트워크 문제 또는 기타 관련 문제 때문인지 판단할 수 있습니다.

Unified Manager에서 성능 이벤트가 발생했고 문제의 원인을 보다 자세히 검토하려는 경우, 이벤트 세부 정보 페이지에서 *워크로드 분석* 버튼을 클릭하여 워크로드 분석기를 실행하고 해당 워크로드의 지연 시간, 처리량 및 용량 추세를 조사할 수 있습니다.

워크로드 인벤토리 페이지(볼륨, LUN, 워크로드, NFS 공유 또는 SMB/CIFS 공유)를 볼 때 워크로드가 비정상적으로 작동하는 것처럼 보이는 경우, 더보기 아이콘 image:../media/more_icon.gif[""] 을 클릭한 다음 *워크로드 분석*을 클릭하여 워크로드 분석 페이지를 열고 워크로드를 자세히 검사할 수 있습니다.
