= 클라이언트 또는 네트워크 문제가 Active IQ Unified Manager의 성능에 미치는 영향 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
클러스터의 볼륨에 연결된 클라이언트의 I/O 요청이 증가하면 클러스터는 수요를 충족하기 위해 더 많은 작업을 수행해야 합니다. 클러스터에 대한 수요 증가로 인해 구성 요소에 경합이 발생하고, 해당 구성 요소를 사용하는 워크로드의 지연 시간이 증가하며, Unified Manager에서 이벤트가 발생할 수 있습니다.

이벤트 세부 정보 페이지의 시스템 진단 섹션에는 경합 중인 구성 요소를 사용하는 상위 볼륨 워크로드가 표시됩니다. 특정 볼륨에 액세스하는 클라이언트를 알고 있는 경우, 해당 클라이언트로 이동하여 클라이언트 하드웨어 또는 애플리케이션이 예상대로 작동하지 않거나 평소보다 더 많은 작업을 수행하고 있는지 확인할 수 있습니다. 지원을 받으려면 클라이언트 관리자 또는 애플리케이션 공급업체에 문의해야 할 수 있습니다.

클러스터와 연결된 클라이언트 간의 I/O 요청이 예상보다 느리게 수행되는 원인이 될 수 있는 하드웨어 문제, 병목 현상 또는 경쟁 워크로드가 있는지 확인하기 위해 네트워크 인프라를 점검할 수 있습니다. 도움을 받으려면 네트워크 관리자에게 문의해야 할 수 있습니다.
