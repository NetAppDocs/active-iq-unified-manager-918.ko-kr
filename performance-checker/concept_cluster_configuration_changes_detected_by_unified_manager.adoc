= Active IQ Unified Manager에서 감지된 구성 변경 사항 모니터링
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager는 클러스터의 구성 변경 사항을 모니터링하여 변경 사항이 성능 문제의 원인이 되었는지 또는 성능 문제에 영향을 미쳤는지 판단하는 데 도움을 줍니다. 성능 탐색기 페이지에는 변경 이벤트 아이콘(image:../media/opm_change_icon.gif["이벤트 아이콘 변경"])이 표시되어 변경 사항이 감지된 날짜와 시간을 나타냅니다.

성능 탐색기 페이지와 워크로드 분석 페이지에서 성능 차트를 검토하여 변경 이벤트가 선택한 클러스터 오브젝트의 성능에 영향을 미쳤는지 확인할 수 있습니다. 변경 사항이 성능 이벤트와 거의 동시에 감지된 경우, 해당 변경 사항이 이벤트 경고를 발생시킨 문제의 원인이 되었을 수 있습니다.

Unified Manager는 다음과 같은 변경 이벤트를 감지할 수 있으며, 이러한 이벤트는 정보 이벤트로 분류됩니다:

* 볼륨이 애그리게이트 간에 이동합니다.
+
Unified Manager는 이동이 진행 중인지, 완료되었는지, 또는 실패했는지를 감지할 수 있습니다. 볼륨 이동 중에 Unified Manager가 다운되더라도, 다시 가동되면 볼륨 이동을 감지하고 해당 변경 이벤트를 표시합니다.

* 하나 이상의 모니터링 대상 워크로드를 포함하는 QoS 정책 그룹의 처리량(MB/s 또는 IOPS) 제한이 변경됩니다.
+
정책 그룹 제한을 변경하면 지연 시간(응답 시간)이 간헐적으로 급증할 수 있으며, 이로 인해 정책 그룹에 대한 이벤트가 발생할 수도 있습니다. 지연 시간은 점차 정상으로 돌아오고, 급증으로 인해 발생한 이벤트는 더 이상 필요하지 않게 됩니다.

* HA 쌍의 노드는 파트너 노드의 스토리지를 인계받거나 반환합니다.
+
Unified Manager는 인수, 부분 인수 또는 반환 작업이 완료되었는지 여부를 감지할 수 있습니다. 인수 작업이 패닉 상태에 빠진 노드로 인해 발생한 경우 Unified Manager는 해당 이벤트를 감지하지 못합니다.

* ONTAP 업그레이드 또는 되돌리기 작업이 성공적으로 완료되었습니다.
+
이전 버전과 새 버전이 표시됩니다.
