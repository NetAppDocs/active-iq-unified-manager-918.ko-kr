= Active IQ Unified Manager의 워크로드 성능 측정값 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager는 과거 및 예상 통계 값을 기반으로 클러스터의 워크로드 성능을 측정하고, 이를 통해 워크로드의 지연 시간 예측값을 생성합니다. 실제 워크로드 통계 값을 지연 시간 예측값과 비교하여 워크로드 성능이 너무 높거나 낮은 시점을 판단합니다. 예상대로 작동하지 않는 워크로드는 동적 성능 이벤트를 발생시켜 사용자에게 알립니다.

다음 그림에서 빨간색으로 표시된 실제 값은 해당 기간 동안의 실제 성능 통계를 나타냅니다. 실제 값이 성능 임계값(지연 시간 예측의 상한)을 넘어섰습니다. 최고점은 해당 기간 동안의 가장 높은 실제 값입니다. 편차는 예상 값(예측값)과 실제 값 사이의 변화를 측정하며, 최고 편차는 예상 값과 실제 값 사이의 가장 큰 변화를 나타냅니다.

image::../media/opm_wrkld_perf_measurement_png.gif[Unified Manager 워크로드 성능 측정]

다음 표는 작업 부하 성능 측정값을 나타냅니다.

|===
| 측정 | 설명 


 a| 
활동
 a| 
정책 그룹 내 워크로드가 사용하는 QoS 제한의 백분율입니다.

[NOTE]
====
Unified Manager가 볼륨 추가 또는 제거, QoS 제한 변경 등 정책 그룹에 대한 변경 사항을 감지하면 실제 값과 예상 값이 설정된 제한의 100%를 초과할 수 있습니다. 값이 설정된 제한의 100%를 초과하면 >100%로 표시됩니다. 값이 설정된 제한의 1% 미만이면 <1%로 표시됩니다.

====


 a| 
실제
 a| 
주어진 워크로드에 대해 특정 시점에 측정된 성능 값.



 a| 
편차
 a| 
예상값과 실제값의 차이. 실제값에서 예상값을 뺀 값을 예상 범위의 상한값에서 예상값을 뺀 값으로 나눈 비율입니다.

[NOTE]
====
음의 편차 값은 워크로드 성능이 예상보다 낮음을 나타내고, 양의 편차 값은 워크로드 성능이 예상보다 높음을 나타냅니다.

====


 a| 
예상
 a| 
예상 값은 지정된 워크로드의 과거 성능 데이터 분석을 기반으로 합니다. Unified Manager는 이러한 통계 값을 분석하여 예상 범위(지연 시간 예측) 값을 결정합니다.



 a| 
지연 시간 예측(예상 범위)
 a| 
지연 시간 예측은 특정 시점에 예상되는 성능 값의 상한과 하한을 예측한 것입니다. 워크로드 지연 시간의 경우, 상한값이 성능 임계값을 형성합니다. 실제 값이 성능 임계값을 초과하면 Unified Manager는 동적 성능 이벤트를 발생시킵니다.



 a| 
정점
 a| 
일정 기간 동안 측정된 최댓값.



 a| 
최대 편차
 a| 
일정 기간 동안 측정된 최대 편차 값.



 a| 
큐 깊이
 a| 
상호 연결 구성 요소에서 대기 중인 보류 중인 I/O 요청 수입니다.



 a| 
사용률
 a| 
네트워크 처리, 데이터 처리 및 애그리게이트 구성 요소의 경우, 일정 기간 동안 워크로드 작업을 완료하는 데 소요되는 사용 시간의 비율입니다. 예를 들어, 네트워크 처리 또는 데이터 처리 구성 요소가 I/O 요청을 처리하는 데 걸리는 시간 비율이나 애그리게이트가 읽기 또는 쓰기 요청을 처리하는 데 걸리는 시간 비율입니다.



 a| 
쓰기 처리량
 a| 
MetroCluster 구성에서 로컬 클러스터의 워크로드에서 파트너 클러스터로의 쓰기 처리량(초당 메가바이트(MB/s) 단위)

|===
