= Active IQ Unified Manager에서 카운터 차트 확대/축소 보기 표시
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
카운터 차트 확대 보기 기능을 사용하면 선택한 카운터 차트와 관련 타임라인을 더욱 세밀하게 볼 수 있습니다. 이를 통해 카운터 차트 데이터를 확대하여 성능 이벤트와 그 근본 원인을 더욱 명확하게 파악할 수 있습니다.

모든 카운터 차트에 대해 카운터 차트 확대 보기를 표시할 수 있습니다.

.단계
. 선택한 차트를 새 브라우저 창에서 열려면 *확대 보기*를 클릭하십시오.
. 세부 분석 차트를 보고 있는 상태에서 *확대 보기*를 클릭하면 세부 분석 차트가 확대 보기로 표시됩니다. 보기 옵션을 변경하려는 경우 확대 보기 상태에서 *총계*를 선택할 수 있습니다.
