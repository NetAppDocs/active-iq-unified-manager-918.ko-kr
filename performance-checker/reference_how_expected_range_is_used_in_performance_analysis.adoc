= Active IQ Unified Manager에서 성능 분석을 위한 지연 시간 예측 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager는 지연 시간 예측을 사용하여 모니터링되는 워크로드의 일반적인 I/O 지연 시간(응답 시간) 활동을 나타냅니다. 워크로드의 실제 지연 시간이 지연 시간 예측의 상한값을 초과하면 경고가 발생하고 동적 성능 이벤트가 트리거되어 성능 문제를 분석하고 해결하기 위한 시정 조치를 취할 수 있습니다.

지연 시간 예측은 워크로드의 성능 기준선을 설정합니다. Unified Manager는 시간이 지남에 따라 과거 성능 측정값을 학습하여 워크로드에 대한 예상 성능 및 활동 수준을 예측합니다. 예상 범위의 상한은 동적 성능 임계값을 설정합니다. Unified Manager는 기준선을 사용하여 실제 지연 시간이 임계값보다 높거나 낮을 때, 또는 예상 범위를 벗어날 때를 판단합니다. 실제 값과 예상 값의 비교를 통해 워크로드에 대한 성능 프로파일이 생성됩니다.

클러스터 구성 요소에 대한 경합으로 인해 워크로드의 실제 지연 시간이 동적 성능 임계값을 초과하면 지연 시간이 길어지고 워크로드 성능이 예상보다 저하됩니다. 동일한 클러스터 구성 요소를 공유하는 다른 워크로드의 성능 또한 예상보다 느려질 수 있습니다.

Unified Manager는 임계값 초과 이벤트를 분석하여 해당 활동이 성능 이벤트인지 판단합니다. 수 시간 등 장기간 동안 높은 작업 부하 활동이 지속적으로 유지되는 경우 Unified Manager는 해당 활동을 정상적인 것으로 간주하고 지연 시간 예측을 동적으로 조정하여 새로운 동적 성능 임계값을 형성합니다.

일부 워크로드는 활동량이 지속적으로 낮아 시간에 따른 지연 시간 예측값의 변화율이 높지 않을 수 있습니다. 성능 이벤트 분석 중 이벤트 수를 최소화하기 위해 Unified Manager는 작업 및 지연 시간이 예상보다 훨씬 높은 활동량이 적은 볼륨에 대해서만 이벤트를 발생시킵니다.

image::../media/opm_expected_range_jpg.png[Unified Manager에서 예상되는 지연 시간 범위]

이 예시에서 볼륨의 지연 시간 예측치는 회색으로 표시되며, 최저 3.5밀리초/작업(ms/op)에서 최고 5.5ms/op입니다. 네트워크 트래픽의 간헐적인 급증이나 클러스터 구성 요소의 경합으로 인해 실제 지연 시간(파란색)이 갑자기 10ms/op로 증가한다면, 이는 지연 시간 예측치를 초과하여 동적 성능 임계값을 넘어선 것입니다.

네트워크 트래픽이 감소하거나 클러스터 구성 요소가 더 이상 경합하지 않으면 지연 시간은 지연 시간 예측 범위 내로 돌아옵니다. 지연 시간이 장기간 10ms/op 이상으로 유지되는 경우 이벤트를 해결하기 위해 시정 조치를 취해야 할 수 있습니다.
