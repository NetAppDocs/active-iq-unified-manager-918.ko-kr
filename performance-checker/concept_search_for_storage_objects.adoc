= Active IQ Unified Manager에서 스토리지 오브젝트 검색
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
특정 오브젝트에 빠르게 액세스하려면 메뉴 표시줄 상단의 *Search all Storage Objects* 필드를 사용할 수 있습니다. 모든 오브젝트에 걸친 이 글로벌 검색 방법을 사용하면 유형별로 특정 오브젝트를 빠르게 찾을 수 있습니다. 검색 결과는 스토리지 오브젝트 유형별로 정렬되며 드롭다운 메뉴를 사용하여 필터링할 수 있습니다. 유효한 검색은 최소 세 개의 문자를 포함해야 합니다.

전체 검색은 결과의 총 개수를 표시하지만 상위 25개 검색 결과에만 액세스할 수 있습니다. 이 때문에 전체 검색 기능은 빠르게 찾고자 하는 항목을 알고 있는 경우 특정 항목을 찾기 위한 단축 툴로 생각할 수 있습니다. 전체 검색 결과를 보려면 오브젝트 인벤토리 페이지의 검색 및 관련 필터링 기능을 사용할 수 있습니다.

드롭다운 상자를 클릭하고 *모두*를 선택하여 모든 오브젝트와 이벤트를 동시에 검색할 수 있습니다. 또는 드롭다운 상자를 클릭하여 오브젝트 유형을 지정할 수도 있습니다. *모든 스토리지 오브젝트 검색* 필드에 오브젝트 또는 이벤트 이름을 최소 세 글자 이상 입력한 다음 *Enter* 키를 누르면 다음과 같은 검색 결과가 표시됩니다.

* 클러스터: 클러스터 이름
* 노드: 노드 이름
* 애그리게이트: 애그리게이트 이름
* SVM: SVM 이름
* 볼륨: 볼륨 이름
* LUN: LUN 경로


image::../media/opm_search_field_jpg.gif[Unified Manager의 검색 필드]

[NOTE]
====
LIF와 포트는 글로벌 검색창에서 검색할 수 없습니다.

====
이 예시에서는 드롭다운 상자에서 볼륨 오브젝트 유형이 선택되어 있습니다. *모든 스토리지 오브젝트 검색* 필드에 "`vol`"을 입력하면 이름에 이 문자가 포함된 모든 볼륨 목록이 표시됩니다. 오브젝트 검색의 경우 검색 결과에서 항목을 클릭하면 해당 오브젝트의 성능 탐색기 페이지로 이동합니다. 이벤트 검색의 경우 검색 결과에서 항목을 클릭하면 이벤트 세부 정보 페이지로 이동합니다.
