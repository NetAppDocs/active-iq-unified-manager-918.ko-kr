= Active IQ Unified Manager에서 성능 인벤토리 페이지 콘텐츠 구체화
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 오브젝트의 인벤토리 페이지에는 오브젝트 인벤토리 데이터 콘텐츠를 세분화하는 데 도움이 되는 툴이 포함되어 있어 특정 데이터를 빠르고 쉽게 찾을 수 있습니다.

성능 오브젝트 인벤토리 페이지에 포함된 정보는 방대하며, 여러 페이지에 걸쳐 표시되는 경우가 많습니다. 이처럼 포괄적인 데이터는 성능 모니터링, 추적 및 개선에 매우 유용하지만, 특정 데이터를 찾으려면 원하는 데이터를 신속하게 찾을 수 있도록 해주는 툴이 필요합니다. 따라서 성능 오브젝트 인벤토리 페이지에는 검색, 정렬 및 필터링 기능이 포함되어 있습니다. 또한 검색과 필터링 기능을 함께 사용하면 검색 결과를 더욱 좁힐 수 있습니다.
