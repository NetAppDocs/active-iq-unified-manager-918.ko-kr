= Active IQ Unified Manager의 성능 탐색기 페이지를 사용하여 성능 모니터링
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 탐색기 페이지는 클러스터 내 각 오브젝트의 성능에 대한 자세한 정보를 표시합니다. 이 페이지는 모든 클러스터 오브젝트의 성능을 자세히 보여주므로 특정 오브젝트의 성능 데이터를 선택하여 다양한 기간에 걸쳐 비교할 수 있습니다.

또한 모든 오브젝트의 전반적인 성능을 평가하고 오브젝트 성능 데이터를 나란히 비교할 수 있습니다.
