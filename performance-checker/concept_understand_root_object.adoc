= Active IQ Unified Manager에서 성능 모니터링을 위해 루트 오브젝트 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
루트 오브젝트는 다른 오브젝트를 비교하는 기준점이 됩니다. 이를 통해 다른 오브젝트의 데이터를 루트 오브젝트와 비교 및 조회할 수 있으며, 오브젝트 성능 문제를 해결하고 개선하는 데 도움이 되는 성능 데이터 분석을 제공합니다.

비교 창 맨 위에는 루트 오브젝트 이름이 표시됩니다. 추가 오브젝트는 루트 오브젝트 아래에 표시됩니다. 비교 창에 추가할 수 있는 추가 오브젝트의 수에는 제한이 없지만, 루트 오브젝트는 하나만 허용됩니다. 루트 오브젝트의 데이터는 카운터 차트 창의 그래프에 자동으로 표시됩니다.

루트 오브젝트는 변경할 수 없습니다. 항상 현재 보고 있는 오브젝트 페이지로 설정됩니다. 예를 들어, Volume1의 볼륨 성능 탐색기 페이지를 열면 Volume1이 루트 오브젝트가 되며 변경할 수 없습니다. 다른 루트 오브젝트와 비교하려면 오브젝트의 링크를 클릭하여 해당 랜딩 페이지를 열어야 합니다.

[NOTE]
====
이벤트 및 임계값은 루트 오브젝트에 대해서만 표시됩니다.
