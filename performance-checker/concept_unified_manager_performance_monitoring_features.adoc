= Active IQ Unified Manager 성능 모니터링 기능 살펴보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager는 ONTAP 소프트웨어가 실행되는 시스템의 성능 통계를 수집하고 분석합니다. 동적 성능 임계값과 사용자 정의 성능 임계값을 사용하여 여러 클러스터 구성 요소에 걸쳐 다양한 성능 카운터를 모니터링합니다.

응답 시간(지연 시간)이 길다는 것은 볼륨 등 스토리지 오브젝트의 성능이 평소보다 느리다는 것을 의미합니다. 또한 이 문제는 해당 볼륨을 사용하는 클라이언트 애플리케이션의 성능 저하를 나타냅니다. Unified Manager는 성능 문제가 발생하는 스토리지 구성 요소를 식별하고 성능 문제를 해결하기 위해 취할 수 있는 권장 조치 목록을 제공합니다.

Unified Manager에는 다음과 같은 기능이 포함되어 있습니다:

* ONTAP 소프트웨어가 실행되는 시스템의 워크로드 성능 통계를 모니터링하고 분석합니다.
* 클러스터, 노드, 애그리게이트, 포트, SVM, 볼륨, LUN, NVMe 네임스페이스 및 네트워크 인터페이스(LIF)에 대한 성능 카운터를 추적합니다.
* IOPS(작업 수), MB/s(처리량), 지연 시간(응답 시간), 활용률, 성능 용량 및 캐시 비율을 포함하여 시간에 따른 작업 부하 활동을 자세히 보여주는 그래프를 표시합니다.
* 이 기능을 사용하면 사용자가 정의한 성능 임계값 정책을 생성하여 임계값이 초과될 때 이벤트를 트리거하고 이메일 알림을 보낼 수 있습니다.
* 시스템에서 정의한 임계값과 워크로드 활동을 학습하는 동적 성능 임계값을 사용하여 성능 문제를 식별하고 알려줍니다.
* 볼륨 및 LUN에 적용되는 서비스 품질(QoS) 정책과 성능 서비스 수준(PSL) 정책을 식별합니다.
* 경합이 발생하는 클러스터 구성 요소를 명확하게 식별합니다.
* 클러스터 구성 요소를 과도하게 사용하는 워크로드와 활동 증가로 인해 성능에 영향을 받는 워크로드를 식별합니다.
