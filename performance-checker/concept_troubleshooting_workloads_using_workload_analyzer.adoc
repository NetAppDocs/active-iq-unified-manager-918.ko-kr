= Active IQ Unified Manager의 워크로드 분석기를 사용하여 워크로드 문제를 해결합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
워크로드 분석기는 문제 해결을 지원하기 위해 단일 워크로드의 주요 상태 및 성능 기준을 한 페이지에서 확인할 수 있는 방법을 제공합니다. 워크로드의 현재 및 과거 이벤트를 모두 확인하면 해당 워크로드에 현재 성능 또는 용량 문제가 발생하는 원인을 더 잘 파악할 수 있습니다.

이 툴을 사용하면 애플리케이션 성능 문제의 원인이 스토리지인지, 아니면 네트워킹이나 기타 관련 문제인지 판단하는 데에도 도움이 될 수 있습니다.

사용자 인터페이스의 다양한 위치에서 이 기능을 시작할 수 있습니다:

* 왼쪽 탐색 메뉴의 작업 부하 분석 선택 항목에서
* 이벤트 상세 페이지에서 *워크로드 분석* 버튼을 클릭하여
* 워크로드 인벤토리 페이지(볼륨, LUN, 워크로드, NFS 공유 또는 SMB/CIFS 공유)에서 더 보기 아이콘 image:../media/more_icon.gif[""]을 클릭한 다음 *워크로드 분석*을 선택합니다.
* 가상 머신 페이지에서 데이터스토어 오브젝트의 *Analyze Workload* 버튼을 클릭하여


왼쪽 탐색 메뉴에서 툴을 실행하면 분석하려는 워크로드의 이름을 입력하고 문제 해결을 위한 시간 범위를 선택할 수 있습니다. 워크로드 또는 가상 머신 인벤토리 페이지에서 툴을 실행하면 워크로드 이름이 자동으로 입력되고, 워크로드 데이터는 기본값인 2시간 범위로 표시됩니다. 이벤트 세부 정보 페이지에서 툴을 실행하면 워크로드 이름이 자동으로 입력되고 10일간의 데이터가 표시됩니다.
