= Active IQ Unified Manager의 카운터 차트 확대/축소 보기에서 성능 임계값 선택
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
카운터 차트 확대 보기에서 임계값을 적용하면 성능 임계값 이벤트 발생 현황을 자세히 확인할 수 있습니다. 이를 통해 임계값을 적용하거나 제거하고 결과를 즉시 확인할 수 있으므로, 문제 해결이 다음 단계가 되어야 할지 결정하는 데 도움이 될 수 있습니다.

카운터 차트 확대 보기에서 임계값을 선택하면 성능 임계값 이벤트에 대한 정확한 데이터를 볼 수 있습니다. 카운터 차트 확대 보기의 *정책* 영역에 나타나는 모든 임계값을 적용할 수 있습니다.

카운터 차트 확대 보기의 오브젝트에는 한 번에 하나의 정책만 적용할 수 있습니다.

.단계
. 정책과 관련된 image:../media/eye_icon.gif["눈 아이콘"] 항목을 선택하거나 선택 해제하십시오.
+
선택한 임계값은 카운터 차트 확대 보기(Counter Charts Zoom View)에 적용됩니다. 중요 임계값은 빨간색 선으로, 경고 임계값은 노란색 선으로 표시됩니다.
