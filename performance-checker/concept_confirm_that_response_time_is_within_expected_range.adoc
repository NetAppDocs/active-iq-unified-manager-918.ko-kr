= Active IQ Unified Manager에서 지연 시간이 예상 범위 내에 있는지 확인합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
클러스터 구성 요소에 경합이 발생하면 해당 구성 요소를 사용하는 볼륨 워크로드의 응답 시간(지연 시간)이 감소할 수 있습니다. 경합 중인 구성 요소에서 각 피해 워크로드의 지연 시간을 검토하여 실제 지연 시간이 예상 범위 내에 있는지 확인할 수 있습니다. 볼륨 이름을 클릭하여 해당 볼륨의 기간별 데이터를 볼 수도 있습니다.

성능 이벤트가 더 이상 사용되지 않는 상태라면, 해당 이벤트에 관련된 각 대상의 지연 시간이 예상 범위 내로 돌아왔을 수 있습니다.
