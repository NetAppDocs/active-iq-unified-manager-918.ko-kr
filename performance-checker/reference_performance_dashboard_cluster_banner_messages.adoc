= Active IQ Unified Manager에서 성능 배너 메시지 해석
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager는 특정 클러스터의 상태 문제를 알려주기 위해 알림 페이지(알림 벨)에 배너 메시지를 표시할 수 있습니다.

|===
| 배너 메시지 | 설명 | 해결 


 a| 
`No performance data is being collected from cluster _cluster_name_. Restart Unified Manager to correct this issue.`
 a| 
Unified Manager 수집 서비스가 중지되어 어떤 클러스터에서도 성능 데이터가 수집되지 않고 있습니다.
 a| 
Unified Manager를 다시 시작하여 이 문제를 해결하십시오. 그래도 문제가 해결되지 않으면 기술 지원에 문의하십시오.



 a| 
`More than x hour(s) of historical data is being collected from cluster _cluster_name_. Current data collections will start after all historical data is collected.`
 a| 
현재 실시간 클러스터 성능 수집 주기 외부에서 성능 데이터를 수집하기 위해 데이터 연속성 수집 주기가 실행 중입니다.
 a| 
별도의 조치는 필요하지 않습니다. 데이터 연속성 수집 주기가 완료된 후 현재 성능 데이터가 수집될 예정입니다.

데이터 연속성 수집 주기는 새 클러스터가 추가될 때 또는 Unified Manager가 어떤 이유로든 현재 성능 데이터를 수집할 수 없을 때 실행됩니다.

|===
