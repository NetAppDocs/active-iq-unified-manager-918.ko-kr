= Active IQ Unified Manager에서 노드 및 애그리게이트에 사용 가능한 IOPS 값 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
클러스터 내의 모든 노드 또는 모든 애그리게이트에 대한 사용 가능한 IOPS 값을 모니터링하거나 단일 노드 또는 애그리게이트에 대한 세부 정보를 볼 수 있습니다.

사용 가능한 IOPS 값은 성능 인벤토리 페이지와 노드 및 애그리게이트의 성능 탐색기 페이지 차트에 표시됩니다. 예를 들어, 노드/성능 탐색기 페이지에서 노드를 볼 때 목록에서 "`사용 가능한 IOPS`" 카운터 차트를 선택하여 해당 노드와 그 노드에 있는 여러 애그리게이트의 사용 가능한 IOPS 값을 비교할 수 있습니다.

image::../media/available_iops_zoom.gif[노드/성능 탐색기 페이지에서 노드를 보고 목록에서 “사용 가능한 IOPS”를 선택하는 방법을 보여주는 UI 스크린샷입니다.]

사용 가능한 IOPS 카운터를 모니터링하면 다음을 파악할 수 있습니다:

* 향후 워크로드를 배포할 위치를 결정하는 데 도움이 되도록 사용 가능한 IOPS 값이 가장 높은 노드 또는 애그리게이트입니다.
* 향후 잠재적인 성능 문제에 대해 모니터링해야 할 리소스를 파악하기 위해 사용 가능한 IOPS 값이 가장 작은 노드 또는 애그리게이트입니다.
* IOPS 가용값이 낮은 애그리게이트에서 가장 사용량이 많은 볼륨과 LUN입니다.
