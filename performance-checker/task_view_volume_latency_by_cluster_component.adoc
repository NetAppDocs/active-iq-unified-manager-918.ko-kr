= Active IQ Unified Manager에서 클러스터 구성 요소별 볼륨 지연 시간 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
볼륨 성능 탐색기 페이지를 사용하면 볼륨의 자세한 지연 시간 정보를 볼 수 있습니다. 지연 시간 - 총계 카운터 차트는 볼륨의 총 지연 시간을 보여주고, 지연 시간 - 세부 분석 카운터 차트는 읽기 및 쓰기 지연 시간이 볼륨에 미치는 영향을 파악하는 데 유용합니다.

또한, 지연 시간 - 클러스터 구성 요소 차트는 각 클러스터 구성 요소의 지연 시간을 자세히 비교하여 각 구성 요소가 볼륨의 전체 지연 시간에 어떻게 영향을 미치는지 파악하는 데 도움을 줍니다. 다음 클러스터 구성 요소가 표시됩니다.

* 네트워크
* QoS 최대 제한
* QoS 최소 제한
* 네트워크 처리
* 클러스터 상호 연결
* Data Processing
* 애그리게이트 작업
* 볼륨 활성화
* MetroCluster 리소스
* 클라우드 지연 시간
* 동기화 SnapMirror


.단계
. 선택한 볼륨의 *볼륨 성능 탐색기* 페이지에서 지연 시간 차트의 드롭다운 메뉴에서 *클러스터 구성 요소*를 선택합니다.
+
지연 시간 - 클러스터 구성 요소 차트가 표시됩니다.

. 차트를 더 크게 보려면 *확대 보기*를 선택하세요.
+
클러스터 구성 요소 비교 차트가 표시됩니다. 각 클러스터 구성 요소와 연결된 image:../media/eye_icon.gif["눈 아이콘"]을(를) 선택 해제하거나 선택하여 비교를 제한할 수 있습니다.

. 구체적인 값을 보려면 커서를 차트 영역으로 이동하여 팝업 창을 확인하십시오.
