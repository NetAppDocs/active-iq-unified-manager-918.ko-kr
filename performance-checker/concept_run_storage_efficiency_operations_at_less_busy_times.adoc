= Active IQ Unified Manager에서 사용량이 적은 시간에 스토리지 효율성 작업을 예약합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 효율성 작업을 처리하는 정책이나 일정을 수정하여 해당 볼륨의 워크로드 사용량이 적을 때 실행되도록 할 수 있습니다.

스토리지 효율성 작업은 클러스터 CPU 리소스를 많이 사용하므로 작업이 실행되는 볼륨에 과부하를 줄 수 있습니다. 스토리지 효율성 작업이 실행되는 동안 해당 볼륨의 활동량이 많으면 지연 시간이 증가하여 이벤트가 발생할 수 있습니다.

이벤트 세부 정보 페이지의 시스템 진단 섹션에서는 QoS 정책 그룹 내 워크로드를 활동의 최대 편차별로 표시하여 과도한 워크로드를 식별할 수 있습니다. 표 상단 근처에 "`스토리지 효율성`"이 표시되면 이러한 작업이 다른 워크로드에 과도한 부담을 주고 있는 것입니다. 효율성 정책 또는 실행 일정을 수정하여 해당 워크로드의 사용량이 적은 시간에 실행되도록 하면 스토리지 효율성 작업으로 인해 클러스터에 경합이 발생하는 것을 방지할 수 있습니다.

ONTAP System Manager를 사용하여 효율성 정책을 관리할 수 있습니다. ONTAP 명령을 사용하여 효율성 정책 및 일정을 관리할 수 있습니다.
