= Active IQ Unified Manager에서 성능 요약 페이지를 검토합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
요약 페이지에는 지난 72시간 동안의 오브젝트별 이벤트 및 성능에 대한 세부 정보를 포함하는 카운터 차트가 표시됩니다. 이 데이터는 자동으로 새로 고쳐지지 않으며, 마지막 페이지 로드 시점을 기준으로 최신 정보입니다. 요약 페이지의 차트는 _추가 조사가 필요한가?_라는 질문에 대한 답을 제공합니다.



[[charts-and-counter-statistics]]
== 차트 및 카운터 통계

요약 차트는 지난 72시간 동안의 상황을 빠르고 간략하게 보여주며, 추가 조사가 필요한 잠재적인 문제를 파악하는 데 도움이 됩니다.

요약 페이지의 카운터 통계는 그래프로 표시됩니다.

그래프의 추세선 위에 커서를 올려놓으면 특정 시점의 카운터 값을 볼 수 있습니다. 요약 차트에는 다음 카운터에 대해 지난 72시간 동안 발생한 활성 중요 및 경고 이벤트의 총 개수도 표시됩니다:

* *지연 시간*
+
모든 I/O 요청에 대한 평균 응답 시간(작업당 밀리초 단위).

+
모든 오브젝트 유형에 대해 표시됩니다.

* *IOPS*
+
평균 작동 속도; 초당 입력/출력 작업 수로 표시됩니다.

+
모든 오브젝트 유형에 대해 표시됩니다.

* *MB/s*
+
평균 처리량; 초당 메가바이트로 표시됩니다.

+
모든 오브젝트 유형에 대해 표시됩니다.

* *사용된 성능 용량*
+
노드 또는 애그리게이트가 사용하고 있는 성능 용량의 백분율입니다.

+
노드 및 애그리게이트에 대해서만 표시됩니다.

* *사용률*
+
노드 및 애그리게이트에 대한 오브젝트 활용률 또는 포트에 대한 대역폭 활용률(%)

+
노드, 애그리게이트 및 포트에 대해서만 표시됩니다.



활성 이벤트의 이벤트 수 위에 커서를 올리면 이벤트 유형과 수를 확인할 수 있습니다. 중요 이벤트는 빨간색(image:../media/treemapred_png.gif["TreeMap 아이콘 – 빨간색"])으로 표시되고, 경고 이벤트는 노란색(image:../media/treemapstatus_warning_png.gif["TreeMap 아이콘 – 경고 상태"])으로 표시됩니다.

차트 오른쪽 상단의 회색 막대에 표시된 숫자는 지난 72시간 동안의 평균값입니다. 추세선 그래프의 상단과 하단에 표시된 숫자는 지난 72시간 동안의 최소값과 최대값입니다. 차트 아래의 회색 막대에는 지난 72시간 동안의 활성(신규 및 승인된) 이벤트와 폐기된 이벤트의 수가 표시됩니다.

image::../media/iops_graph.gif[IOPS 그래프를 보여주는 UI 스크린샷입니다.]

* *지연 시간 카운터 차트*
+
지연 시간 카운터 차트는 지난 72시간 동안의 오브젝트 지연 시간에 대한 개략적인 정보를 제공합니다. 지연 시간은 모든 I/O 요청에 대한 평균 응답 시간을 나타내며, 작업당 밀리초 단위로 표시됩니다. 이는 해당 클러스터 스토리지 구성 요소에서 데이터 패킷 또는 블록에 발생하는 서비스 시간, 대기 시간 또는 둘 다를 의미합니다.

+
*상단(카운터 값):* 헤더의 숫자는 직전 72시간 동안의 평균값을 나타냅니다.

+
*중간(성능 그래프):* 그래프 하단의 숫자는 가장 낮은 지연 시간을, 그래프 상단의 숫자는 지난 72시간 동안의 가장 높은 지연 시간을 나타냅니다. 그래프 추세선 위에 마우스 커서를 올려놓으면 특정 시점의 지연 시간 값을 볼 수 있습니다.

+
*하단(이벤트):* 마우스를 올리면 팝업 창에 이벤트 세부 정보가 표시됩니다. 그래프 아래의 *활성 이벤트* 링크를 클릭하면 이벤트 인벤토리 페이지로 이동하여 전체 이벤트 세부 정보를 볼 수 있습니다.

* *IOPS 카운터 차트*
+
IOPS 카운터 차트는 지난 72시간 동안의 오브젝트 IOPS 상태에 대한 개괄적인 정보를 제공합니다. IOPS는 초당 입출력 작업 수로 나타낸 스토리지 시스템의 속도를 의미합니다.

+
*상단(카운터 값):* 헤더의 숫자는 직전 72시간 동안의 평균값을 나타냅니다.

+
*중간(성능 그래프):* 그래프 하단의 숫자는 직전 72시간 동안의 최저 IOPS를, 그래프 상단의 숫자는 최고 IOPS를 나타냅니다. 그래프 추세선 위에 마우스 커서를 올려놓으면 특정 시점의 IOPS 값을 볼 수 있습니다.

+
*하단(이벤트):* 마우스를 올리면 팝업 창에 이벤트 세부 정보가 표시됩니다. 그래프 아래의 *활성 이벤트* 링크를 클릭하면 이벤트 인벤토리 페이지로 이동하여 전체 이벤트 세부 정보를 볼 수 있습니다.

* *MB/s 카운터 차트*
+
MB/s 카운터 차트는 오브젝트 MB/s 성능을 표시하며, 초당 메가바이트 단위로 오브젝트와 주고받은 데이터 양을 나타냅니다. MB/s 카운터 차트는 지난 72시간 동안 오브젝트의 MB/s 상태를 개괄적으로 보여줍니다.

+
*상단(카운터 값):* 헤더의 숫자는 이전 72시간 동안의 평균 MB/s 값을 나타냅니다.

+
*중간(성능 그래프):* 그래프 하단의 값은 이전 72시간 동안의 최저 MB/s 값을, 그래프 상단의 값은 최고 MB/s 값을 나타냅니다. 그래프 추세선 위에 마우스 커서를 올려놓으면 특정 시점의 MB/s 값을 볼 수 있습니다.

+
*하단(이벤트):* 마우스를 올리면 팝업 창에 이벤트 세부 정보가 표시됩니다. 그래프 아래의 *활성 이벤트* 링크를 클릭하면 이벤트 인벤토리 페이지로 이동하여 전체 이벤트 세부 정보를 볼 수 있습니다.

* *성능 용량 사용량 카운터 차트*
+
성능 용량 사용량 카운터 차트는 오브젝트가 소비하고 있는 성능 용량의 백분율을 표시합니다.

+
*상단(카운터 값):* 헤더의 숫자는 직전 72시간 동안 사용된 평균 성능 용량을 나타냅니다.

+
*중간(성능 그래프):* 그래프 하단의 값은 지난 72시간 동안 사용된 성능 용량의 최저 백분율을 나타내고, 그래프 상단의 값은 사용된 성능 용량의 최고 백분율을 나타냅니다. 그래프 추세선 위에 마우스 커서를 올려놓으면 특정 시점의 사용된 성능 용량 값을 볼 수 있습니다.

+
*하단(이벤트):* 마우스를 올리면 팝업 창에 이벤트 세부 정보가 표시됩니다. 그래프 아래의 *활성 이벤트* 링크를 클릭하면 이벤트 인벤토리 페이지로 이동하여 전체 이벤트 세부 정보를 볼 수 있습니다.

* *활용도 카운터 차트*
+
사용률 카운터 차트는 오브젝트 사용률을 백분율로 표시합니다. 사용률 카운터 차트는 지난 72시간 동안의 오브젝트 또는 대역폭 사용률의 백분율에 대한 개괄적인 정보를 제공합니다.

+
*상단(카운터 값):* 헤더의 숫자는 직전 72시간 동안의 평균 사용률을 나타냅니다.

+
*중간(성능 그래프):* 그래프 하단의 값은 직전 72시간 동안의 최저 사용률을, 그래프 상단의 값은 최고 사용률을 나타냅니다. 그래프 추세선 위에 마우스 커서를 올려놓으면 특정 시점의 사용률 값을 확인할 수 있습니다.

+
*하단(이벤트):* 마우스를 올리면 팝업 창에 이벤트 세부 정보가 표시됩니다. 그래프 아래의 *활성 이벤트* 링크를 클릭하면 이벤트 인벤토리 페이지로 이동하여 전체 이벤트 세부 정보를 볼 수 있습니다.

== 이벤트

해당되는 경우 이벤트 기록 테이블에는 해당 오브젝트에서 발생한 가장 최근 이벤트가 나열됩니다. 이벤트 이름을 클릭하면 이벤트 세부 정보 페이지에 이벤트의 세부 정보가 표시됩니다.
