= Active IQ Unified Manager에서 프로토콜별 SVM IOPS 트래픽 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능/SVM 탐색기 페이지를 사용하면 SVM의 자세한 IOPS 정보를 확인할 수 있습니다. IOPS - 총계 카운터 차트는 SVM의 총 IOPS 사용량을 보여주고, IOPS - 세부 카운터 차트는 읽기, 쓰기 및 기타 IOPS가 SVM에 미치는 영향을 파악하는 데 유용합니다.

또한, IOPS - 프로토콜 차트는 SVM에서 사용되는 각 프로토콜의 IOPS 트래픽을 자세히 비교하여 보여줍니다. 사용 가능한 프로토콜은 다음과 같습니다.

* CIFS
* NFS
* FCP
* iSCSI
* NVMe-FC


.단계
. 선택한 SVM의 *성능/SVM 탐색기* 페이지에서 IOPS 차트의 드롭다운 메뉴에서 *프로토콜*을 선택합니다.
+
IOPS - 프로토콜 차트가 표시됩니다.

. 차트를 더 크게 보려면 *확대 보기*를 선택하세요.
+
IOPS 고급 프로토콜 비교 차트가 표시됩니다. 프로토콜과 연결된 image:../media/eye_icon.gif["눈 아이콘"]을(를) 선택 해제하거나 선택하여 비교를 제한할 수 있습니다.

. 구체적인 값을 확인하려면 두 차트 중 하나의 차트 영역으로 커서를 이동하여 팝업 창을 확인하십시오.
