= Active IQ Unified Manager를 사용하여 처리량 차트에서 QoS 정책 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 탐색기 및 워크로드 분석의 IOPS, IOPS/TB, MB/s 차트에서 볼륨 또는 LUN에 적용된 ONTAP 정의 QoS(서비스 품질) 정책 설정을 확인할 수 있습니다. 차트에 표시되는 정보는 워크로드에 적용된 QoS 정책 유형에 따라 다릅니다.

최대 처리량(또는 "`peak`") 설정은 워크로드가 소비할 수 있는 최대 처리량을 정의하여 시스템 리소스를 두고 경쟁하는 워크로드에 미치는 영향을 제한합니다. 최소 처리량(또는 "`expected`") 설정은 중요한 워크로드가 경쟁 워크로드의 수요와 관계없이 최소 처리량 목표를 충족할 수 있도록 워크로드에 제공되어야 하는 최소 처리량을 정의합니다.

IOPS 및 MB/s에 대한 공유 및 비공유 QoS 정책은 "`minimum`" 및 "`maximum`"이라는 용어를 사용하여 하한값과 상한값을 정의합니다. ONTAP 9.3에서 도입된 IOPS/TB에 대한 적응형 QoS 정책은 "`expected`" 및 "`peak`"라는 용어를 사용하여 하한값과 상한값을 정의합니다.

ONTAP에서 이 두 가지 유형의 QoS 정책을 생성할 수 있지만, 워크로드에 적용되는 방식에 따라 성능 차트에 QoS 정책이 표시되는 방식은 세 가지가 있습니다.

|===
| 정책 유형 | 기능 | Unified Manager 인터페이스의 표시기 


 a| 
단일 워크로드에 할당된 QoS 공유 정책 또는 단일 워크로드 또는 여러 워크로드에 할당된 QoS 비공유 정책
 a| 
각 워크로드는 지정된 처리량 설정을 사용할 수 있습니다
 a| 
"`(QoS)`"를 표시합니다.



 a| 
여러 워크로드에 할당된 QoS 공유 정책
 a| 
모든 워크로드는 지정된 처리량 설정을 공유합니다
 a| 
"`(QoS Shared)`"를 표시합니다.



 a| 
단일 워크로드 또는 여러 워크로드에 할당되는 적응형 QoS 정책
 a| 
각 워크로드는 지정된 처리량 설정을 사용할 수 있습니다
 a| 
"`(QoS Adaptive)`"를 표시합니다.

|===
다음 그림은 세 가지 옵션이 카운터 차트에 표시되는 방식을 보여주는 예시입니다.

image::../media/3_qos_policy_charts.gif[카운터 차트에 세 가지 옵션이 표시되는 방식의 예를 보여주는 UI 스크린샷입니다.]

워크로드에 대한 IOPS/TB 차트에 IOPS 단위로 정의된 일반 QoS 정책이 나타나면 ONTAP은 IOPS 값을 IOPS/TB 값으로 변환하고 Unified Manager는 해당 정책을 "`IOPS 단위로 정의된 QoS`"라는 텍스트와 함께 IOPS/TB 차트에 표시합니다.

워크로드의 IOPS 차트에 IOPS/TB 단위로 정의된 적응형 QoS 정책이 나타나면 ONTAP은 IOPS/TB 값을 IOPS 값으로 변환하고 Unified Manager는 피크 IOPS 할당 설정 구성 방식에 따라 "`QoS Adaptive - Used, defined in IOPS/TB`" 또는 "`QoS Adaptive - Allocated, defined in IOPS/TB`"라는 텍스트와 함께 해당 정책을 IOPS 차트에 표시합니다. 할당 설정이 "`allocated-space`"로 설정된 경우 피크 IOPS는 볼륨 크기를 기준으로 계산됩니다. 할당 설정이 "`used-space`"로 설정된 경우 피크 IOPS는 스토리지 효율성을 고려하여 볼륨에 저장된 데이터 양을 기준으로 계산됩니다.

[NOTE]
====
IOPS/TB 차트는 볼륨에서 사용되는 논리 용량이 128GB 이상일 때만 성능 데이터를 표시합니다. 선택한 기간 동안 사용 용량이 128GB 미만으로 떨어지면 차트에 공백이 표시됩니다.
