= Active IQ Unified Manager의 카운터 차트에서 확대/축소 보기에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
카운터 차트는 확대/축소 기능을 제공하여 지정된 기간 동안의 성능 세부 정보를 자세히 살펴볼 수 있습니다. 이를 통해 성능 세부 정보와 이벤트를 훨씬 더 세밀하게 확인할 수 있으므로 성능 문제 해결에 도움이 됩니다.

확대 보기로 표시될 때 일부 분석 차트는 확대 보기가 아닐 때 표시되는 정보보다 추가 정보를 제공합니다. 예를 들어 IOPS, IOPS/TB 및 MBps 분석 차트의 확대 보기 페이지에는 ONTAP에서 설정된 경우 볼륨 및 LUN에 대한 QoS 정책 값이 표시됩니다.

[NOTE]
====
시스템 정의 성능 임계값 정책의 경우, *정책* 목록에서는 "`노드 리소스 과다 사용`" 및 "`QoS 처리량 제한 초과`" 정책만 사용할 수 있습니다. 다른 시스템 정의 임계값 정책은 현재 사용할 수 없습니다.

====
