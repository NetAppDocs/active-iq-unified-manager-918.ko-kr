= Active IQ Unified Manager가 이벤트의 성능 영향을 판단하는 방법 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager는 워크로드의 활동, 활용률, 쓰기 처리량, 클러스터 구성 요소 사용량 또는 I/O 지연 시간(응답 시간)의 편차를 사용하여 워크로드 성능에 미치는 영향 수준을 판단합니다. 이 정보는 이벤트에서 각 워크로드의 역할과 이벤트 세부 정보 페이지에서의 순위를 결정하는 데 사용됩니다.

Unified Manager는 워크로드에 대해 마지막으로 분석된 값을 예상 범위(지연 시간 예측)와 비교합니다. 마지막으로 분석된 값과 예상 범위 간의 차이를 통해 해당 이벤트로 인해 성능에 가장 큰 영향을 받은 워크로드를 식별할 수 있습니다.

예를 들어, 클러스터에 워크로드 A와 워크로드 B라는 두 개의 워크로드가 있다고 가정해 보겠습니다. 워크로드 A의 지연 시간 예측치는 작업당 5~10밀리초(ms/op)이고 실제 지연 시간은 보통 약 7ms/op입니다. 워크로드 B의 지연 시간 예측치는 10~20ms/op이고 실제 지연 시간은 보통 약 15ms/op입니다. 두 워크로드 모두 지연 시간 예측 범위 내에 있습니다. 클러스터의 경합으로 인해 두 워크로드의 지연 시간이 모두 40ms/op로 증가하여 동적 성능 임계값(지연 시간 예측치의 상한값)을 초과하고 이벤트를 트리거합니다. 예상 값에서 성능 임계값을 초과하는 값까지의 지연 시간 편차는 워크로드 A의 경우 약 33ms/op이고, 워크로드 B의 경우 약 25ms/op입니다. 두 워크로드 모두 지연 시간이 40ms/op로 급증했지만, 워크로드 A는 지연 시간 편차가 33ms/op로 더 컸기 때문에 더 큰 성능 영향을 미쳤습니다.

이벤트 세부 정보 페이지의 시스템 진단 섹션에서 클러스터 구성 요소의 활동, 사용률 또는 처리량 편차를 기준으로 워크로드를 정렬할 수 있습니다. 또한 지연 시간을 기준으로 워크로드를 정렬할 수도 있습니다. 정렬 옵션을 선택하면 Unified Manager는 이벤트가 감지된 이후 활동, 사용률, 처리량 또는 지연 시간의 편차를 예상 값과 비교하여 워크로드 정렬 순서를 결정합니다. 지연 시간의 경우 빨간색 점(image:../media/opm_incident_icon_png.gif["Performance Manager 경고 아이콘"])은 피해 워크로드의 성능 임계값 초과 및 그에 따른 지연 시간 영향을 나타냅니다. 각 빨간색 점은 더 높은 수준의 지연 시간 편차를 나타내며, 이를 통해 이벤트로 인해 지연 시간에 가장 큰 영향을 받은 피해 워크로드를 식별할 수 있습니다.
