= Active IQ Unified Manager의 Performance Explorer 페이지를 검토합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 탐색기 페이지를 사용하면 클러스터 내에서 유사한 오브젝트(예: 클러스터의 모든 볼륨)의 성능을 비교할 수 있습니다. 이는 성능 이벤트를 해결하고 오브젝트 성능을 미세 조정할 때 유용합니다. 또한 오브젝트를 다른 오브젝트 비교의 기준이 되는 루트 오브젝트와 비교할 수도 있습니다.

*상태 보기로 전환* 버튼을 클릭하여 이 오브젝트의 상태 세부 정보 페이지를 표시할 수 있습니다. 경우에 따라 문제 해결 시 도움이 될 수 있는 이 오브젝트의 스토리지 구성 설정에 대한 중요한 정보를 확인할 수 있습니다.

성능 탐색기 페이지에는 클러스터 오브젝트 목록과 해당 성능 데이터가 표시됩니다. 이 페이지는 동일한 유형의 모든 클러스터 오브젝트(예: 볼륨 및 해당 오브젝트별 성능 통계)를 표 형식으로 표시합니다. 이 보기는 클러스터 오브젝트 성능에 대한 효율적인 개요를 제공합니다.

[NOTE]
====
표의 어떤 셀에든 "`N/A`"가 표시되면, 현재 해당 오브젝트에 I/O가 없기 때문에 해당 카운터의 값을 사용할 수 없다는 의미입니다.

====
성능 탐색기 페이지에는 다음과 같은 구성 요소가 포함되어 있습니다:

* *시간 범위*
+
오브젝트 데이터에 대한 시간 범위를 선택할 수 있습니다.

+
미리 정의된 범위를 선택하거나 사용자 지정 시간 범위를 지정할 수 있습니다.

* *보기 및 비교*
+
그리드에 표시할 상관 오브젝트의 유형을 선택할 수 있습니다.

+
사용 가능한 옵션은 루트 오브젝트 유형과 사용 가능한 데이터에 따라 다릅니다. 보기 및 비교 드롭다운 목록을 클릭하여 오브젝트 유형을 선택할 수 있습니다. 선택한 오브젝트 유형이 목록에 표시됩니다.

* *필터링*
+
사용자의 선호도에 따라 수신하는 데이터 양을 줄일 수 있습니다.

+
오브젝트 데이터에 적용되는 필터(예: IOPS가 4보다 큰 경우)를 생성할 수 있습니다. 최대 4개의 필터를 동시에 추가할 수 있습니다.

* *비교하기*
+
루트 오브젝트와 비교하기 위해 선택한 오브젝트 목록을 표시합니다.

+
비교 창에 있는 오브젝트의 데이터가 카운터 차트에 표시됩니다.

* *통계 보기*
+
볼륨 및 LUN의 경우, 통계를 각 수집 주기(기본값 5분) 후에 표시할지 또는 시간별 평균으로 표시할지 선택할 수 있습니다. 이 기능을 통해 NetApp "성능 보장" 프로그램을 지원하는 지연 시간 차트를 확인할 수 있습니다.

* *카운터 차트*
+
각 오브젝트 성능 범주에 대한 그래프 데이터를 표시합니다.

+
일반적으로 3~4개의 차트만 기본으로 표시됩니다. 차트 선택 구성 요소를 사용하면 추가 차트를 표시하거나 특정 차트를 숨길 수 있습니다. 이벤트 타임라인을 표시하거나 숨길 수도 있습니다.

* *이벤트 타임라인*
+
시간 범위 구성 요소에서 선택한 기간 동안 발생하는 성능 및 상태 이벤트를 표시합니다.
