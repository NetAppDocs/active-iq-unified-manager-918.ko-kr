= Active IQ Unified Manager가 예상 성능 범위를 계산하는 방법 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
지연 시간 예측은 특정 시점에 예상되는 성능 값의 상한과 하한을 예측한 것입니다. 워크로드 지연 시간의 경우, 상한값이 성능 임계값을 형성합니다. 실제 값이 성능 임계값을 초과하면 Unified Manager는 동적 성능 이벤트를 발생시킵니다.

예를 들어, 일반적인 업무 시간인 오전 9시부터 오후 5시 사이에 대부분의 직원은 오전 9시에서 10시 30분 사이에 이메일을 확인할 수 있습니다. 이메일 서버에 대한 수요 증가로 인해 이 시간대에 백엔드 스토리지의 작업 부하가 증가합니다. 직원들은 이메일 클라이언트의 응답 속도가 느려지는 것을 경험할 수 있습니다.

점심시간인 정오 12시부터 오후 1시 사이, 그리고 일과가 끝나는 오후 5시 이후에는 대부분의 직원이 컴퓨터를 사용하지 않을 가능성이 높습니다. 일반적으로 이메일 서버에 대한 수요가 감소하며, 이에 따라 백엔드 스토리지에 대한 수요도 감소합니다. 또는 오후 5시 이후에 시작되어 백엔드 스토리지의 활동을 증가시키는 스토리지 백업이나 바이러스 검사 등 예약된 워크로드 작업이 있을 수도 있습니다.

며칠에 걸쳐 작업 부하 활동의 증감 추이를 통해 예상 활동 범위(지연 시간 예측)가 결정되며, 작업 부하에 대한 상한선과 하한선이 설정됩니다. 오브젝트의 실제 작업 부하 활동이 상한선 또는 하한선을 벗어나고 일정 기간 동안 그 범위를 벗어난 상태로 유지될 경우, 이는 해당 오브젝트가 과도하게 사용되거나 사용량이 부족함을 나타낼 수 있습니다.

== 지연 시간 예측이 생성되는 방법

Unified Manager는 분석을 시작하고 I/O 응답 시간에 대한 지연 예측을 GUI에 표시하기 전에 최소 3일간의 워크로드 활동을 수집해야 합니다. 최소 필수 데이터 수집은 워크로드 활동에서 발생하는 모든 변화를 반영하지는 않습니다. 처음 3일간의 활동을 수집한 후, Unified Manager는 워크로드 활동 변화를 반영하고 보다 정확한 동적 성능 임계값을 설정하기 위해 24시간마다 오전 12시에 지연 예측을 조정합니다.

[NOTE]
====
일광 절약 시간제(DST)가 시행되면 시스템 시간이 변경되어 모니터링 대상 워크로드의 성능 통계에 대한 지연 시간 예측이 수정됩니다. Unified Manager는 즉시 지연 시간 예측을 수정하기 시작하며, 이 작업은 약 15일이 소요됩니다. 이 기간 동안 Unified Manager를 계속 사용할 수 있지만, Unified Manager는 지연 시간 예측을 사용하여 동적 이벤트를 감지하므로 일부 이벤트가 정확하지 않을 수 있습니다. 시간 변경 이전에 감지된 이벤트는 영향을 받지 않습니다.
