= Active IQ Unified Manager의 스토리지 오브젝트에서 성능 임계값 정책 제거
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager에서 더 이상 성능 카운터 값을 모니터링하지 않으려면 스토리지 오브젝트에서 사용자 정의 성능 임계값 정책을 제거할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 역할이 있어야 합니다.

선택한 오브젝트에서 한 번에 하나의 정책만 제거할 수 있습니다.

목록에서 둘 이상의 오브젝트를 선택하여 여러 스토리지 오브젝트에서 임계값 정책을 제거할 수 있습니다.

.단계
. 모든 스토리지 오브젝트의 *인벤토리* 페이지에서 성능 임계값 정책이 하나 이상 적용된 오브젝트를 하나 이상 선택합니다.
+
|===
| 임계값을 제거하려면... | 이렇게 하세요... 


 a| 
단일 오브젝트
 a| 
해당 오브젝트의 왼쪽에 있는 확인란을 선택합니다.



 a| 
여러 오브젝트
 a| 
각 오브젝트 왼쪽의 확인란을 선택합니다.



 a| 
페이지의 모든 오브젝트
 a| 
열 머리글에서 image:../media/select_dropdown_65_png.gif["드롭다운 아이콘을 선택하세요"]을(를) 클릭합니다.

|===
. *성능 임계값 정책 지우기*를 클릭합니다.
+
임계값 정책 지우기 페이지가 표시되며, 현재 스토리지 오브젝트에 할당된 임계값 정책 목록이 나타납니다.

. 오브젝트에서 제거할 임계값 정책을 선택하고 *정책 지우기*를 클릭합니다.
+
임계값 정책을 선택하면 정책 세부 정보가 표시되므로 적절한 정책을 선택했는지 확인할 수 있습니다.
