= Active IQ Unified Manager에서 워크로드 분석기 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
사용자 인터페이스에서 워크로드 분석기를 시작하는 방법에는 여러 가지가 있습니다. 여기서는 왼쪽 탐색 창에서 툴을 실행하는 방법을 설명합니다.

.단계
. 왼쪽 탐색 창에서 *워크로드 분석*을 클릭합니다.
+
워크로드 분석 페이지가 표시됩니다.

. 워크로드 이름을 알고 있다면 이름을 입력하십시오. 전체 이름을 확실히 모르는 경우 최소 3자 이상을 입력하면 시스템에서 해당 문자열과 일치하는 워크로드 목록을 표시합니다.
. 기본값인 2시간보다 더 긴 기간 동안 통계를 보려면 시간 범위를 선택하고 *적용*을 클릭하십시오.
. 요약 영역에서 해당 기간 동안 발생한 이벤트를 확인하십시오.
. 성능 및 용량 차트를 확인하여 어떤 지표가 비정상적일 때를 파악하고, 비정상 항목과 관련된 이벤트가 있는지 확인하십시오.
