= Active IQ Unified Manager에서 성능 향상을 위해 LIF 이동
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
논리 인터페이스(LIF)를 사용량이 적은 포트로 이동하면 로드 밸런싱을 개선하고 유지 관리 작업 및 성능 튜닝을 지원하며 간접 액세스를 줄일 수 있습니다.

간접 액세스는 시스템 효율성을 저하시킬 수 있습니다. 이는 볼륨 워크로드가 네트워크 처리와 데이터 처리에 서로 다른 노드를 사용할 때 발생합니다. 간접 액세스를 줄이려면 LIF를 재배치할 수 있습니다. 즉, 네트워크 처리와 데이터 처리에 동일한 노드를 사용하도록 LIF를 이동하는 것입니다. ONTAP이 사용량이 많은 LIF를 다른 포트로 자동으로 이동하도록 로드 밸런싱을 구성하거나 LIF를 수동으로 이동할 수 있습니다.

[cols="2*"]
|===
| *이점* | *고려사항* 


 a| 
* 로드 밸런싱을 개선합니다.
* 간접 액세스를 줄이십시오.

 a| 
[NOTE]
====
CIFS 공유에 연결된 LIF를 이동할 때 CIFS 공유에 액세스하는 클라이언트의 연결이 끊어집니다. CIFS 공유에 대한 모든 읽기 또는 쓰기 요청이 중단됩니다.

====
|===
ONTAP 명령을 사용하여 로드 밸런싱을 구성합니다. 자세한 내용은 ONTAP 네트워킹 설명서를 참조하십시오.

ONTAP System Manager와 ONTAP CLI 명령을 사용하여 LIF를 수동으로 이동합니다.
