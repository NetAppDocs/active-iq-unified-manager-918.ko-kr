= Active IQ Unified Manager에서 노드 및 애그리게이트 성능 용량 사용 값 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
클러스터의 모든 노드 또는 모든 애그리게이트에 대한 성능 용량 사용량 값을 모니터링하거나 단일 노드 또는 애그리게이트에 대한 세부 정보를 볼 수 있습니다.

성능 용량 사용량 값은 대시보드, 성능 인벤토리 페이지, 최고 성능 페이지, 임계값 정책 생성 페이지, 성능 탐색기 페이지 및 상세 차트에 표시됩니다. 예를 들어, 성능: 모든 애그리게이트 페이지에는 모든 애그리게이트에 대한 성능 용량 사용량 값을 볼 수 있는 성능 용량 사용량 열이 제공됩니다.

image::../media/node_inventory_used_headroom.gif[성능: 모든 애그리게이트 페이지의 UI 스크린샷]

성능 용량 사용량 카운터를 모니터링하면 다음 사항을 파악할 수 있습니다:

* 클러스터의 노드 또는 애그리게이트 중 성능 용량 사용 값이 높은 것이 있는지 여부
* 클러스터의 노드 또는 애그리게이트에 활성 성능 용량 사용 이벤트가 있는지 여부
* 클러스터에서 성능 용량 사용 값이 가장 높고 낮은 노드 및 애그리게이트
* 성능 용량 사용 값이 높은 노드 또는 애그리게이트와 연계된 지연 시간 및 활용률 카운터 값
* 노드 중 하나에 장애가 발생할 경우 HA 쌍에 있는 노드의 성능 용량 사용 값이 어떻게 영향을 받는지
* 성능 용량 사용 값이 높은 애그리게이트에서 가장 사용량이 많은 볼륨 및 LUN
