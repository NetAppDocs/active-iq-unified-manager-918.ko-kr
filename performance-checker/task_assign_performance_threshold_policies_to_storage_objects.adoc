= Active IQ Unified Manager의 스토리지 오브젝트에 성능 임계값 정책 할당
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 카운터 값이 정책 설정을 초과할 경우 Unified Manager가 이벤트를 보고하도록 스토리지 오브젝트에 사용자 정의 성능 임계값 정책을 할당합니다.

.시작하기 전에
애플리케이션 관리자 역할이 있어야 합니다.

오브젝트에 적용하려는 성능 임계값 정책이 존재해야 합니다.

오브젝트 또는 오브젝트 그룹에 한 번에 하나의 성능 정책만 적용할 수 있습니다.

각 스토리지 오브젝트에 최대 3개의 임계값 정책을 할당할 수 있습니다. 여러 오브젝트에 정책을 할당할 때, 이미 할당된 정책 수가 최대치에 도달한 오브젝트가 하나라도 있는 경우 Unified Manager는 다음 작업을 수행합니다.

* 최대치에 도달하지 않은 선택된 모든 오브젝트에 정책을 적용합니다
* 정책 최대 개수에 도달한 오브젝트는 무시합니다
* 정책이 모든 오브젝트에 할당되지 않았다는 메시지를 표시합니다.


.단계
. 모든 스토리지 오브젝트의 성능 인벤토리 페이지에서 임계값 정책을 할당할 오브젝트를 선택합니다:
+
|===
| 임계값을 지정하려면... | 클릭... 


 a| 
단일 오브젝트
 a| 
해당 오브젝트의 왼쪽에 있는 확인란.



 a| 
여러 오브젝트
 a| 
각 오브젝트의 왼쪽에 있는 확인란.



 a| 
페이지의 모든 오브젝트
 a| 
image:../media/select_dropdown_65_png.gif["드롭다운 아이콘을 선택하세요"] 드롭다운 상자에서 *이 페이지의 모든 오브젝트 선택*을 선택합니다.



 a| 
같은 유형의 모든 오브젝트
 a| 
image:../media/select_dropdown_65_png.gif["드롭다운 아이콘을 선택하세요"] 드롭다운 상자에서 *모든 오브젝트 선택*을 선택합니다.

|===
+
인벤토리 페이지에서 정렬 및 필터링 기능을 사용하여 오브젝트 목록을 세분화하면 여러 오브젝트에 임계값 정책을 더 쉽게 적용할 수 있습니다.

. 원하는 옵션을 선택한 다음 *성능 임계값 정책 할당*을 클릭하십시오.
+
성능 임계값 정책 할당 페이지가 표시되며, 해당 특정 스토리지 오브젝트 유형에 대해 존재하는 임계값 정책 목록이 나타납니다.

. 각 정책을 클릭하여 성능 임계값 설정의 세부 정보를 표시하고 올바른 임계값 정책을 선택했는지 확인하십시오.
. 적절한 임계값 정책을 선택한 후 *정책 할당*을 클릭하십시오.
+
페이지 상단의 성공 메시지는 임계값 정책이 하나 이상의 오브젝트에 할당되었음을 확인해 주며, 이 오브젝트 및 정책에 대한 알림 설정을 구성할 수 있도록 알림 페이지에 대한 링크를 제공합니다.



특정 성능 이벤트가 발생했음을 이메일이나 SNMP 트랩으로 알림 받도록 설정하려면 알림 설정 페이지에서 알림 설정을 구성해야 합니다.
