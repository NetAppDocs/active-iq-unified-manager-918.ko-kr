= Active IQ Unified Manager의 그래픽 인터페이스 및 탐색 경로 살펴보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager는 뛰어난 유연성을 제공하여 다양한 방식으로 여러 작업을 수행할 수 있도록 지원합니다. Unified Manager에서 작업하다 보면 다양한 탐색 경로를 탐색하게 될 것입니다. 가능한 모든 탐색 조합을 표시할 수는 없지만, 몇 가지 일반적인 시나리오는 숙지해 두는 것이 좋습니다.
