= Active IQ Unified Manager의 성능 카운터 차트 유형 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
선택한 스토리지 오브젝트에 대한 카운터 값을 표시하는 표준 성능 차트가 있습니다. 각 분석 카운터 차트는 읽기, 쓰기 및 기타 범주로 구분된 총값을 표시합니다. 또한 일부 분석 카운터 차트는 확대 보기로 표시할 때 추가적인 세부 정보를 보여줍니다.

다음 표는 사용 가능한 성능 카운터 차트를 보여줍니다.

|===
| 이용 가능한 차트 | 차트 설명 


 a| 
이벤트
 a| 
루트 오브젝트에 대한 통계 차트와 연관하여 중요, 오류, 경고 및 정보 이벤트를 표시합니다. 성능 이벤트 외에도 상태 이벤트를 표시하여 성능에 영향을 미칠 수 있는 원인을 종합적으로 파악할 수 있도록 합니다.



 a| 
지연 시간 - 총합
 a| 
애플리케이션 요청에 응답하는 데 필요한 밀리초 수입니다. 평균 지연 시간 값은 I/O 가중치를 반영한다는 점에 유의하십시오.



 a| 
지연 시간 - 분석
 a| 
Latency Total에 표시된 정보와 동일하지만, 성능 데이터가 읽기, 쓰기 및 기타 지연 시간으로 구분됩니다. 이 차트 옵션은 선택한 오브젝트가 SVM, 노드, 애그리게이트, 볼륨, LUN 또는 네임스페이스일 때만 적용됩니다.



 a| 
지연 시간 - 클러스터 구성 요소
 a| 
Latency Total에 표시된 정보와 동일하지만, 성능 데이터가 클러스터 구성 요소별 지연 시간으로 구분되어 표시됩니다. 이 차트 옵션은 선택한 오브젝트가 볼륨인 경우에만 적용됩니다.



 a| 
IOPS - 총계
 a| 
초당 처리되는 입출력 작업 수입니다. 노드에 대해 표시할 때 "`Total`"을 선택하면 로컬 노드 또는 원격 노드에 있을 수 있는 해당 노드를 통과하는 데이터의 IOPS가 표시되고, "`Total (Local)`"을 선택하면 현재 노드에만 있는 데이터의 IOPS가 표시됩니다.



 a| 
IOPS - 분석
 a| 
IOPS 총계와 동일한 정보가 표시되지만, 성능 데이터가 읽기, 쓰기 및 기타 IOPS로 구분됩니다. 이 차트 옵션은 선택한 오브젝트가 SVM, 노드, 애그리게이트, 볼륨, LUN 또는 네임스페이스인 경우에만 적용됩니다.

확대 보기로 표시될 때 볼륨 차트는 ONTAP에서 구성된 경우 QoS 최소 및 최대 처리량 값을 표시합니다.

노드에 대해 표시될 때 "`분석`"을 선택하면 로컬 노드 또는 원격 노드에 있을 수 있는 해당 노드를 통과하는 데이터의 IOPS 분석이 표시되고, "`분석 (로컬)`"을 선택하면 현재 노드에만 있는 데이터의 IOPS 분석이 표시됩니다.



 a| 
IOPS - 프로토콜
 a| 
IOPS 총계에 표시된 정보와 동일하지만, 성능 데이터가 CIFS, NFS, FCP, NVMe 및 iSCSI 프로토콜 트래픽별로 개별 차트로 구분되어 표시됩니다. 이 차트 옵션은 선택한 오브젝트가 SVM인 경우에만 적용됩니다.



 a| 
IOPS/TB - 총계
 a| 
워크로드가 사용하는 총 공간(테라바이트)을 기준으로 초당 처리되는 입출력 작업 수입니다. I/O 밀도라고도 하는 이 카운터는 주어진 스토리지 용량에서 얼마나 많은 성능을 제공할 수 있는지 측정합니다. 확대 보기로 표시할 때 ONTAP에 구성된 경우 볼륨 차트에 QoS 예상 및 최대 처리량 값이 표시됩니다.

이 차트 옵션은 선택한 오브젝트가 볼륨인 경우에만 적용됩니다.



 a| 
MB/s - 총합
 a| 
초당 오브젝트로 전송되거나 오브젝트에서 전송되는 데이터의 메가바이트 수.



 a| 
MB/s - 분석
 a| 
MB/s 차트에 표시된 것과 동일한 정보이지만, 처리량 데이터가 디스크 읽기, Flash Cache 읽기, 쓰기 및 기타로 구분되어 표시됩니다. 확대 보기로 표시할 때 ONTAP에 구성되어 있으면 볼륨 차트에 QoS 최대 처리량 값이 표시됩니다.

이 차트 옵션은 선택한 오브젝트가 SVM, 노드, 애그리게이트, 볼륨, LUN 또는 네임스페이스인 경우에만 적용됩니다.

[NOTE]
====
Flash Cache 데이터는 노드에 대해서만 표시되며, 해당 노드에 Flash Cache 모듈이 설치된 경우에만 표시됩니다.

====


 a| 
성능 용량 사용량 - 총계
 a| 
노드 또는 애그리게이트가 사용하고 있는 성능 용량의 백분율입니다.



 a| 
성능 용량 사용량 - 분석
 a| 
성능 용량 사용량 데이터는 사용자 프로토콜과 시스템 백그라운드 프로세스로 구분됩니다. 또한, 사용 가능한 성능 용량도 표시됩니다.



 a| 
사용 가능한 IOPS - 총계
 a| 
현재 이 오브젝트에서 사용 가능한(여유) 초당 입출력 작업 수입니다. 이 수치는 Unified Manager가 해당 오브젝트가 수행할 수 있다고 계산한 총 IOPS에서 현재 사용 중인 IOPS를 뺀 값입니다. 이 차트 옵션은 선택한 오브젝트가 노드 또는 애그리게이트인 경우에만 적용됩니다.



 a| 
활용률 - 총계
 a| 
사용 중인 오브젝트의 가용 리소스 백분율입니다. 사용률은 노드의 경우 노드 사용률, 애그리게이트의 경우 디스크 사용률, 포트의 경우 대역폭 사용률을 나타냅니다. 이 차트 옵션은 선택한 오브젝트가 노드, 애그리게이트 또는 포트인 경우에만 적용됩니다.



 a| 
캐시 미스 비율 - 총계
 a| 
클라이언트 애플리케이션의 읽기 요청 중 캐시가 아닌 디스크에서 반환되는 비율입니다. 이 차트 옵션은 선택한 오브젝트가 볼륨인 경우에만 적용됩니다.

|===
