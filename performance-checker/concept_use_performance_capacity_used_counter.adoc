= Active IQ Unified Manager에서 사용된 성능 용량 카운터 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
일반적으로 조직에서는 리소스를 효율적으로 사용하면서 피크 기간의 수요를 지원하기 위한 추가 성능 용량을 확보할 수 있도록 성능 용량 사용률을 100 미만으로 유지하여 운영하고자 합니다. 임계값 정책을 사용하여 높은 성능 용량 사용 값에 대해 알림이 전송되는 시점을 사용자 지정할 수 있습니다.

성능 요구 사항에 따라 구체적인 목표를 설정할 수 있습니다. 예를 들어, 금융 서비스 회사는 거래의 적시 실행을 보장하기 위해 더 많은 성능 용량을 확보해 둘 수 있습니다. 이러한 회사들은 성능 용량 사용률 임계값을 70-80% 범위로 설정할 수 있습니다. 마진이 적은 제조 회사는 IT 비용을 효율적으로 관리하기 위해 성능 저하 위험을 감수하더라도 더 적은 성능 용량을 확보해 둘 수 있습니다. 이러한 회사들은 성능 용량 사용률 임계값을 85-95% 범위로 설정할 수 있습니다.

성능 용량 사용률이 사용자 정의 임계값 정책에 설정된 백분율을 초과하면 Unified Manager는 경고 이메일을 보내고 이벤트 인벤토리 페이지에 이벤트를 추가합니다. 이를 통해 성능에 영향을 미치기 전에 잠재적인 문제를 관리할 수 있습니다. 또한 이러한 이벤트는 노드 및 애그리게이트 내에서 워크로드 이동 및 변경이 필요한 시점을 나타내는 지표로 사용할 수 있습니다.
