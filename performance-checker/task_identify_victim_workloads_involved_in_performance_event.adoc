= Active IQ Unified Manager의 동적 성능 이벤트에서 피해자 워크로드 식별
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager에서는 스토리지 구성 요소 경합으로 인해 응답 시간(지연 시간) 편차가 가장 큰 볼륨 워크로드를 식별할 수 있습니다. 이러한 워크로드를 식별하면 해당 워크로드에 액세스하는 클라이언트 애플리케이션의 성능이 평소보다 저하되는 이유를 파악하는 데 도움이 됩니다.

.시작하기 전에
* 운영자, 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.
* 새로운, 확인된 또는 더 이상 사용되지 않는 동적 성능 이벤트가 있어야 합니다.


이벤트 세부 정보 페이지에는 사용자 정의 및 시스템 정의 워크로드 목록이 표시되며, 해당 구성 요소 또는 이벤트의 영향을 가장 많이 받은 구성 요소의 활동 또는 사용량 편차가 가장 큰 순서대로 정렬됩니다. 이 값은 Unified Manager가 이벤트를 감지하고 마지막으로 분석했을 때 식별된 최고치를 기준으로 합니다.

.단계
. 이벤트에 대한 정보를 보려면 *이벤트 상세 정보* 페이지를 표시하십시오.
. 워크로드 지연 시간 및 워크로드 활동 차트에서 *피해자 워크로드*를 선택합니다.
. 차트 위에 마우스 커서를 올리면 해당 구성 요소에 영향을 미치는 상위 사용자 정의 워크로드와 피해 워크로드의 이름을 볼 수 있습니다.
