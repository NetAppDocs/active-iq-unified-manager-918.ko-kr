= Active IQ Unified Manager의 모든 스토리지 오브젝트에 대한 성능 인벤토리 페이지 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 인벤토리 페이지를 사용하여 클러스터, 애그리게이트, 볼륨 등 사용 가능한 각 스토리지 오브젝트에 대한 성능 정보 요약을 볼 수 있습니다. 성능 오브젝트 세부 정보 페이지에 연결하여 특정 오브젝트에 대한 자세한 정보를 볼 수 있습니다.

기본적으로 보기 페이지의 오브젝트는 이벤트 중요도에 따라 정렬됩니다. 중요 이벤트가 있는 오브젝트가 먼저 표시되고 경고 이벤트가 있는 오브젝트가 두 번째로 표시됩니다. 이를 통해 해결해야 할 문제를 시각적으로 즉시 파악할 수 있습니다.

*보고서* 버튼을 사용하여 이 페이지의 데이터를 쉼표로 구분된 값 (`.csv`) 파일, Microsoft Excel 파일 (`.xlsx`) 또는 (`.pdf`) 문서로 내보낸 다음, 내보낸 데이터를 사용하여 보고서를 작성할 수 있습니다. 또한 *예약 보고서* 버튼을 사용하여 페이지를 사용자 지정하고 정기적으로 보고서를 생성하여 이메일로 전송하도록 예약할 수 있습니다.

이 페이지의 모든 필드는 사용자 지정 보기 및 보고서에서 사용할 수 있습니다. 일부 필드는 관련 페이지에 연결되어 있어 더 자세한 정보를 확인할 수 있습니다.

== 성능: 모든 클러스터 보기

성능: 모든 클러스터 보기에서는 Unified Manager 인스턴스에서 모니터링하는 각 클러스터의 성능 이벤트, 데이터 및 구성 정보에 대한 개요를 표시합니다. 이 페이지를 통해 클러스터 성능을 모니터링하고 성능 문제 및 임계값 이벤트를 해결할 수 있습니다.

오브젝트 인벤토리 페이지에서 *성능 임계값 정책 할당* 및 *성능 임계값 정책 해제* 버튼을 사용하여 모든 오브젝트에 성능 임계값 정책을 할당하거나 해제할 수 있습니다.

다음은 성능: 모든 클러스터 보기에서 중요한 몇 가지 필드입니다.

* 클러스터 FQDN: 클러스터의 정규화된 도메인 이름(FQDN)입니다.
* IOPS: 클러스터의 초당 입출력 작업 수.
* MB/s: 클러스터의 처리량으로, 초당 MiB 단위로 측정됩니다.
* 용량 필드: 사용 가능한 용량 및 총 용량(GiB).
* 호스트 이름 또는 IP 주소: 클러스터 관리 LIF의 호스트 이름 또는 IP 주소(IPv4 또는 IPv6)입니다.
* OS 버전: 클러스터에 설치된 ONTAP 소프트웨어 버전입니다.
+

NOTE: 클러스터의 노드에 서로 다른 버전의 ONTAP 소프트웨어가 설치된 경우 가장 낮은 버전 번호가 표시됩니다. 각 노드에 설치된 ONTAP 버전은 성능: 모든 노드 보기에서 확인할 수 있습니다.

* 임계값 정책: 이 스토리지 오브젝트에서 활성화된 사용자 정의 성능 임계값 정책입니다. 줄임표(...)가 포함된 정책 이름 위에 커서를 놓으면 전체 정책 이름 또는 할당된 정책 이름 목록을 볼 수 있습니다. 맨 왼쪽에 있는 확인란을 클릭하여 하나 이상의 오브젝트를 선택할 때까지 성능 임계값 정책 할당 및 성능 임계값 정책 지우기 버튼은 비활성화 상태로 유지됩니다.

== 성능: 전체 볼륨 보기

성능: 모든 볼륨 보기에서는 Unified Manager 인스턴스에서 모니터링하는 각 FlexVol 볼륨 및 FlexGroup 볼륨에 대한 성능 이벤트, 카운터 데이터 및 구성 정보 개요를 표시합니다. 이를 통해 볼륨 성능을 신속하게 모니터링하고 성능 문제 및 임계값 이벤트를 해결할 수 있습니다.

특정 오브젝트의 대기 시간 및 처리량을 분석하려면 추가 옵션 버튼 image:icon_kabob.gif[""]을 클릭한 다음 *Analyze Workload*를 클릭하십시오. 그러면 워크로드 분석 페이지에서 성능 및 용량 차트를 볼 수 있습니다. System Manager에 대한 유효한 자격 증명이 있는 경우 System Manager에서 자세한 내용을 확인할 수 있습니다.


NOTE: 데이터 보호(DP) 볼륨의 경우 사용자 생성 트래픽에 대한 카운터 값만 표시됩니다. 루트 볼륨은 이 페이지에 표시되지 않습니다.

다음은 성능: 전체 볼륨 보기에서 중요한 몇 가지 필드입니다.

* 스타일: FlexVol 또는 FlexGroup.
* 지연 시간: FlexVol 볼륨의 경우, 이는 모든 I/O 요청에 대한 볼륨의 평균 응답 시간으로, 작업당 밀리초 단위로 표시됩니다. FlexGroup 볼륨의 경우, 이는 모든 구성 볼륨의 평균 지연 시간입니다.
* IOPS/TB: 워크로드가 사용하는 총 공간(테라바이트)을 기준으로 초당 처리되는 입출력 작업 수입니다. 이 카운터는 주어진 스토리지 용량에서 얼마나 많은 성능을 제공할 수 있는지 측정합니다.
* IOPS: FlexVol 볼륨의 경우, 이는 해당 볼륨의 초당 입출력 작업 수를 나타냅니다. FlexGroup 볼륨의 경우, 이는 모든 구성 볼륨의 IOPS 합계입니다.
* MB/s: FlexVol 볼륨의 경우, 이는 볼륨의 처리량으로 초당 메가바이트 단위로 측정됩니다. FlexGroup 볼륨의 경우, 이는 모든 구성 볼륨의 MB/s 합계입니다.
* 용량 필드: 사용 가능한 용량 및 총 용량(GiB).

== 성능: 모든 애그리게이트 보기

성능: 모든 애그리게이트 보기에서는 Unified Manager 인스턴스에서 모니터링하는 각 애그리게이트에 대한 성능 이벤트, 데이터 및 구성 정보의 개요를 표시합니다. 이 페이지를 통해 애그리게이트의 성능을 모니터링하고 성능 문제 및 임계값 이벤트를 해결할 수 있습니다.

다음은 성능: 전체 애그리게이트 보기에서 중요한 몇 가지 필드입니다.

* 유형: 애그리게이트 유형:
+
** HDD
** 하이브리드. HDD와 SSD를 결합하지만 Flash Pool은 활성화되지 않았습니다.
** 하이브리드(Flash Pool). HDD와 SSD를 결합하며, Flash Pool이 활성화되었습니다.
** SSD
** SSD(FabricPool). SSD와 클라우드 계층을 결합합니다
** HDD(FabricPool). HDD와 클라우드 계층을 결합합니다
** VMDisk (SDS). 가상 머신 내의 가상 디스크
** VMDisk(FabricPool). 가상 디스크와 클라우드 계층을 결합합니다
** LUN


* 비활성 데이터 보고: 이 애그리게이트에서 비활성 데이터 보고 기능이 활성화되었는지 또는 비활성화되었는지 여부입니다. 활성화된 경우, 이 애그리게이트의 볼륨은 성능: 모든 볼륨 보기에서 콜드 데이터 양을 표시합니다. ONTAP 버전이 비활성 데이터 보고를 지원하지 않는 경우 이 필드의 값은 "N/A"입니다.
* 임계값 정책: 이 스토리지 오브젝트에서 활성화된 사용자 정의 성능 임계값 정책입니다. 줄임표(...)가 포함된 정책 이름 위에 마우스 커서를 올려놓으면 전체 정책 이름 또는 할당된 정책 이름 목록을 볼 수 있습니다. 맨 왼쪽에 있는 확인란을 클릭하여 하나 이상의 오브젝트를 선택할 때까지 성능 임계값 정책 할당 및 성능 임계값 정책 지우기 버튼은 비활성화된 상태로 유지됩니다. 자세한 내용은 다음 링크를 참조하십시오.
* link:../performance-checker/task_assign_performance_threshold_policies_to_storage_objects.html["스토리지 오브젝트에 성능 임계값 정책 할당"]
* link:../performance-checker/task_remove_performance_threshold_policies_from_storage_objects.html["스토리지 오브젝트에서 성능 임계값 정책 제거"]

== 성능: 모든 노드 보기

성능: 모든 노드 보기에서는 Unified Manager 인스턴스에서 모니터링하는 각 노드의 성능 이벤트, 데이터 및 구성 정보에 대한 개요를 표시합니다. 이를 통해 노드 성능을 신속하게 모니터링하고 성능 문제 및 임계값 이벤트를 해결할 수 있습니다.


NOTE: Flash Cache Reads는 노드에서 수행되는 읽기 작업 중 디스크에서 반환되는 대신 캐시에서 처리된 비율을 반환합니다. Flash Cache 데이터는 노드에 대해서만, 그리고 노드에 Flash Cache 모듈이 설치된 경우에만 표시됩니다.

*보고서* 메뉴에서 *하드웨어 인벤토리 보고서* 옵션은 Unified Manager와 Unified Manager가 관리하는 클러스터가 외부 네트워크 연결이 없는 사이트에 설치된 경우에 제공됩니다. 이 버튼은 하드웨어 모델 번호 및 일련 번호, 디스크 유형 및 개수, 설치된 라이선스 등 클러스터 및 노드 정보의 전체 목록이 포함된 .csv 파일을 생성합니다. 이 보고 기능은 NetApp Active IQ 플랫폼에 연결되지 않은 보안 사이트 내에서의 계약 갱신에 유용합니다. *성능 임계값 정책 할당* 및 *성능 임계값 정책 해제* 버튼을 사용하여 오브젝트 인벤토리 페이지의 모든 오브젝트에 성능 임계값 정책을 할당하거나 해제할 수 있습니다.

== 성능: 모든 스토리지 VM 보기

성능: 모든 스토리지 VM 보기에서는 Unified Manager 인스턴스에서 모니터링하는 각 스토리지 가상 머신(SVM)의 성능 이벤트, 데이터 및 구성 정보에 대한 개요를 표시합니다. 이를 통해 SVM 성능을 신속하게 모니터링하고 성능 문제 및 임계값 이벤트를 해결할 수 있습니다. 이 페이지의 지연 시간 필드는 모든 I/O 요청에 대한 평균 응답 시간을 작업당 밀리초 단위로 표시합니다.


NOTE: 이 페이지에 나열된 SVM은 데이터 SVM과 클러스터 SVM만 포함합니다. Unified Manager는 관리자 SVM이나 노드 SVM을 사용하거나 표시하지 않습니다.

== 성능: 모든 NVMe 네임스페이스 보기

성능: 모든 NVMe 네임스페이스 보기에서는 Unified Manager 인스턴스에서 모니터링하는 각 NVMe 네임스페이스의 성능 이벤트, 데이터 및 구성 정보에 대한 개요를 표시합니다. 이를 통해 네임스페이스의 성능 및 상태를 신속하게 모니터링하고 문제 및 임계값 이벤트를 해결할 수 있습니다.

다음은 보고되는 정보 중 일부입니다. 네임스페이스의 현재 상태. * 오프라인 - 네임스페이스에 대한 읽기 또는 쓰기 액세스가 허용되지 않습니다. * 온라인 - 네임스페이스에 대한 읽기 및 쓰기 액세스가 허용됩니다. * NVFail - NVRAM 오류로 인해 네임스페이스가 자동으로 오프라인 상태가 되었습니다. * 공간 오류 - 네임스페이스의 공간이 부족합니다.

== 성능: 모든 네트워크 인터페이스 보기

성능: 모든 네트워크 인터페이스 보기에는 이 Unified Manager 인스턴스에서 모니터링하는 각 네트워크 인터페이스(LIF)의 성능 이벤트, 데이터 및 구성 정보에 대한 개요가 표시됩니다. 이 페이지를 통해 인터페이스 성능을 신속하게 모니터링하고 성능 문제 및 임계값 이벤트를 해결할 수 있습니다. 성능: 모든 네트워크 인터페이스 보기의 주요 필드는 다음과 같습니다.

* IOPS: 초당 입출력 작업 수. IOPS는 NFS LIF 및 CIFS LIF에는 적용되지 않으며, 이러한 유형의 경우 N/A로 표시됩니다.
* 지연 시간: 모든 I/O 요청에 대한 평균 응답 시간으로, 작업당 밀리초 단위로 표시됩니다. 지연 시간은 NFS LIF 및 CIFS LIF에는 적용되지 않으며, 이러한 유형의 경우 N/A로 표시됩니다.
* 홈 위치: 인터페이스의 홈 위치이며, 노드 이름과 포트 이름이 콜론(:)으로 구분되어 표시됩니다. 위치가 줄임표(...)로 표시되는 경우, 마우스 커서를 위치 이름 위에 올려놓으면 전체 위치를 볼 수 있습니다.
* 현재 위치: 인터페이스의 현재 위치이며, 노드 이름과 포트 이름이 콜론(:)으로 구분되어 표시됩니다. 위치가 줄임표(...)로 표시되는 경우, 마우스 커서를 위치 이름 위에 올려놓으면 전체 위치 정보를 볼 수 있습니다.
* 역할: 인터페이스 역할: 데이터, 클러스터, 노드 관리 또는 클러스터 간.



NOTE: 이 페이지에 나열된 인터페이스에는 데이터 LIF, 클러스터 LIF, 노드 관리 LIF 및 클러스터 간 LIF가 포함됩니다. Unified Manager는 시스템 LIF를 사용하거나 표시하지 않습니다.

== 성능: 모든 포트 보기

성능: 모든 포트 보기에서는 Unified Manager 인스턴스에서 모니터링하는 각 포트의 성능 이벤트, 데이터 및 구성 정보에 대한 개요를 표시합니다. 이를 통해 포트 성능을 신속하게 모니터링하고 성능 문제 및 임계값 이벤트를 해결할 수 있습니다. 포트 역할의 경우, 네트워크 포트 기능(데이터 또는 클러스터)이 표시됩니다. FCP 포트는 역할을 가질 수 없으며, 역할은 N/A로 표시됩니다.


NOTE: 성능 카운터 값은 물리적 포트에 대해서만 표시됩니다. VLAN 또는 인터페이스 그룹에 대한 카운터 값은 표시되지 않습니다.

== 성능: QoS 정책 그룹 보기

QoS 정책 그룹 보기에는 Unified Manager가 모니터링하는 클러스터에서 사용 가능한 QoS 정책 그룹이 표시됩니다. 여기에는 기존 QoS 정책, 적응형 QoS 정책 및 성능 서비스 수준을 사용하여 할당된 QoS 정책이 포함됩니다.

다음은 성능: QoS 정책 그룹 보기에서 중요한 몇 가지 필드입니다.

* QoS 정책 그룹: QoS 정책 그룹의 이름입니다. Unified Manager 9.7 이상으로 가져온 NetApp Service Level Manager(NSLM) 1.3 정책의 경우, 여기에 표시되는 이름에는 SVM 이름 및 NSLM에서 성능 서비스 수준을 정의할 때 이름에 포함되지 않은 기타 정보가 포함됩니다. 예를 들어, "NSLM_vs6_Performance_2_0"이라는 이름은 SVM "vs6"에서 생성되고 예상 지연 시간이 "2 ms/op"인 NSLM 시스템 정의 "Performance" PSL 정책을 의미합니다.
* SVM: QoS 정책 그룹이 속한 스토리지 VM(SVM)입니다. 스토리지 VM 이름을 클릭하면 해당 스토리지 VM의 세부 정보 페이지로 이동할 수 있습니다. 이 스토리지 VM 유형은 클러스터를 나타내므로, QoS 정책이 관리자 스토리지 VM에 생성된 경우 이 필드는 비어 있습니다.
* 최소 처리량: 정책 그룹이 보장하는 최소 처리량(IOPS)입니다. 적응형 정책의 경우 이는 스토리지 오브젝트 할당 크기를 기준으로 볼륨 또는 LUN에 할당된 TB당 예상되는 최소 IOPS입니다.
* 최대 처리량: 정책 그룹이 초과해서는 안 되는 처리량(IOPS 및/또는 MB/s)입니다. 이 필드가 비어 있으면 ONTAP에 정의된 최대 처리량이 무한대임을 의미합니다. 적응형 정책의 경우, 이는 스토리지 오브젝트 할당 크기 또는 스토리지 오브젝트 사용 크기를 기준으로 볼륨 또는 LUN에 할당된 TB당 가능한 최대(피크) IOPS입니다.
* 절대 최소 IOPS: 적응형 정책의 경우, 예상 IOPS가 이 값보다 낮을 때 재정의 기준으로 사용되는 절대 최소 IOPS 값입니다.
* 블록 크기: QoS 적응형 정책에 지정된 블록 크기입니다.
* 최소 할당량: 최대 처리량(피크) IOPS를 결정할 때 "할당된 공간" 또는 "사용된 공간" 중 어느 것을 사용할지 여부.
* 예상 지연 시간: 스토리지 입출력 작업에 대한 예상 평균 지연 시간입니다.
* 공유 여부: 기존 QoS 정책의 경우, 정책 그룹에 정의된 처리량 값이 여러 오브젝트 간에 공유되는지 여부입니다.
* 연결된 오브젝트: QoS 정책 그룹에 할당된 워크로드 수입니다. QoS 정책 그룹 이름 옆에 있는 확장 버튼(image:../media/chevron_down.gif[""])을 클릭하면 정책 그룹에 대한 자세한 내용을 볼 수 있습니다.
* 할당된 용량: QoS 정책 그룹에 속한 오브젝트가 현재 사용하고 있는 공간의 양입니다.
* 연결된 오브젝트: QoS 정책 그룹에 할당된 워크로드 수를 볼륨 및 LUN으로 구분하여 표시합니다. 숫자를 클릭하면 선택한 볼륨 또는 LUN에 대한 자세한 정보를 제공하는 페이지로 이동할 수 있습니다.
