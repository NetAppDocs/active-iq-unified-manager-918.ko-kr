= Active IQ Unified Manager UI에 로그인합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
지원되는 웹 브라우저를 사용하여 Unified Manager UI에 로그인할 수 있습니다.

.시작하기 전에
* 웹 브라우저는 최소 요구 사항을 충족해야 합니다.
+
지원되는 브라우저 버전의 전체 목록은  http://mysupport.netapp.com/matrix["mysupport.netapp.com/matrix"]에서 상호 운용성 매트릭스를 참조하십시오.

* Unified Manager 서버의 IP 주소 또는 URL이 있어야 합니다.


1시간 동안 활동이 없으면 자동으로 세션에서 로그아웃됩니다. 이 시간 설정은 *일반* > *기능 설정*에서 구성할 수 있습니다.

.단계
. 웹 브라우저에 URL을 입력하십시오. 여기서 URL은 Unified Manager 서버의 IP 주소 또는 정규화된 도메인 이름(FQDN)입니다:
+
** IPv4의 경우: `+https://URL/+`
** IPv6의 경우: `https://[URL]/`




서버에서 자체 서명된 디지털 인증서를 사용하는 경우 브라우저에 인증서가 신뢰할 수 없다는 경고가 표시될 수 있습니다. 위험을 감수하고 접속을 계속하거나, 인증 기관(CA)에서 서명한 디지털 인증서를 설치하여 서버 인증을 진행할 수 있습니다. . 로그인 화면에서 사용자 이름과 비밀번호를 입력하십시오.

Unified Manager 사용자 인터페이스에 대한 로그인이 SAML 인증으로 보호되는 경우 Unified Manager 로그인 페이지 대신 ID 공급자(IdP) 로그인 페이지에 자격 증명을 입력합니다.

대시보드 페이지가 표시됩니다.

[NOTE]
====
Unified Manager 서버가 초기화되지 않은 경우, 새 브라우저 창에 초기 설정 마법사가 표시됩니다. 이메일 알림을 받을 초기 이메일 수신자, 이메일 통신을 처리할 SMTP 서버, 그리고 Unified Manager 설치 정보를 기술 지원에 보내도록 AutoSupport가 활성화되어 있는지 여부를 입력해야 합니다. 이 정보를 모두 입력하면 Unified Manager 사용자 인터페이스가 나타납니다.
