= Active IQ Unified Manager를 사용하여 MetroCluster 성능 모니터링
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager를 사용하면 MetroCluster 구성에서 클러스터 간의 쓰기 처리량을 모니터링하여 쓰기 처리량이 많은 워크로드를 식별할 수 있습니다.

이러한 고성능 워크로드로 인해 로컬 클러스터의 다른 볼륨에서 I/O 응답 시간이 높아지는 경우 Unified Manager는 성능 이벤트를 발생시켜 사용자에게 알립니다.


NOTE: Unified Manager는 MetroCluster 구성의 클러스터를 개별 클러스터로 취급합니다. 파트너인 클러스터를 구분하거나 각 클러스터의 쓰기 처리량을 상호 연관시키지 않습니다.

MetroCluster 구성의 로컬 클러스터가 파트너 클러스터로 데이터를 미러링할 때, 데이터는 NVRAM에 기록된 다음 스위치 간 링크(ISL)를 통해 원격 애그리게이트로 전송됩니다. Unified Manager는 NVRAM을 분석하여 높은 쓰기 처리량으로 인해 NVRAM을 과도하게 사용하여 NVRAM에 경합을 일으키는 워크로드를 식별합니다.

응답 시간 편차가 성능 임계값을 초과한 워크로드를 _피해자_라고 하고, NVRAM에 대한 쓰기 처리량 편차가 평소보다 높아 경합을 일으키는 워크로드를 _가해자_라고 합니다. 쓰기 요청만 파트너 클러스터에 미러링되므로 Unified Manager는 읽기 처리량을 분석하지 않습니다.

다음 화면에서 해당 LUN 및 볼륨의 워크로드를 분석하여 MetroCluster 구성에 있는 클러스터의 처리량을 확인할 수 있습니다. 클러스터별로 결과를 필터링할 수 있습니다. 왼쪽 탐색 창에서:

* *스토리지 > 클러스터 > 성능: 모든 클러스터* 보기. 참조하십시오
* *스토리지 > 볼륨 > 성능: 모든 볼륨* 보기.
* *스토리지 > LUN > 성능: 모든 LUN* 보기.
* *워크로드 분석 > 모든 워크로드*
