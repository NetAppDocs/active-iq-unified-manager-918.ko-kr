= Active IQ Unified Manager의 데이터 연속성 수집 주기 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
데이터 연속성 수집 주기는 기본적으로 5분마다 실행되는 실시간 클러스터 성능 수집 주기와는 별도로 성능 데이터를 수집합니다. 데이터 연속성 수집을 통해 Unified Manager는 실시간 데이터를 수집할 수 없었던 시점에 발생하는 통계 데이터 공백을 메울 수 있습니다.

Unified Manager는 다음과 같은 이벤트가 발생할 때 기간별 성능 데이터에 대한 데이터 연속성 수집 폴링을 수행합니다:

* 클러스터가 Unified Manager에 처음 추가됩니다.
+
Unified Manager는 지난 15일간의 기간별 성능 데이터를 수집합니다. 이를 통해 클러스터를 추가한 후 몇 시간 만에 해당 클러스터의 2주간의 기간별 성능 정보를 확인할 수 있습니다.

+
또한, 이전 기간에 시스템에서 정의한 임계값 이벤트가 있는 경우 해당 이벤트가 보고됩니다.

* 현재 성능 데이터 수집 주기가 제때 완료되지 않습니다.
+
실시간 성능 폴링이 5분 수집 기간을 초과하면 누락된 정보를 수집하기 위해 데이터 연속성 수집 주기가 시작됩니다. 데이터 연속성 수집이 이루어지지 않으면 다음 수집 기간은 건너뛰게 됩니다.

* Unified Manager에 일정 시간 동안 접근할 수 없었다가 다음과 같은 상황에서 다시 온라인 상태로 돌아옵니다:
+
** 재시작되었습니다.
** 소프트웨어 업그레이드 중이나 백업 파일 생성 중에 종료되었습니다.
** 네트워크 장애가 복구되었습니다.


* 클러스터가 일정 기간 동안 접근할 수 없었다가 다음과 같은 상황에서 다시 온라인 상태가 됩니다:
+
** 네트워크 장애가 복구되었습니다.
** 느린 광역 네트워크 연결로 인해 성능 데이터의 정상적인 수집이 지연되었습니다.




데이터 연속성 수집 주기는 최대 24시간의 기간별 데이터를 수집할 수 있습니다. Unified Manager가 24시간 이상 다운되면 UI 페이지에 성능 데이터 공백이 나타납니다.

데이터 연속성 수집 주기와 실시간 데이터 수집 주기는 동시에 실행될 수 없습니다. 실시간 성능 데이터 수집이 시작되기 전에 데이터 연속성 수집 주기가 완료되어야 합니다. 데이터 연속성 수집에서 1시간 이상의 기간별 데이터를 수집해야 하는 경우, 알림 창 상단에 해당 클러스터에 대한 배너 메시지가 표시됩니다.
