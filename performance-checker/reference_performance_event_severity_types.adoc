= Active IQ Unified Manager에서 심각도별로 성능 이벤트 우선 순위 지정
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
각 성능 이벤트는 즉각적인 시정 조치가 필요한 이벤트의 우선순위를 정하는 데 도움이 되도록 심각도 유형과 연결되어 있습니다.

* *치명적*
+
성능 이벤트가 발생했으며, 즉시 시정 조치를 취하지 않으면 서비스 중단으로 이어질 수 있습니다.

+
중요 이벤트는 사용자 정의 임계값에서만 전송됩니다.

* *경고*
+
클러스터 오브젝트의 성능 카운터가 정상 범위를 벗어났으므로 위험 심각도에 도달하지 않도록 모니터링해야 합니다. 이 수준의 심각도를 가진 이벤트는 서비스 중단을 유발하지 않으며 즉각적인 시정 조치가 필요하지 않을 수 있습니다.

+
경고 이벤트는 사용자 정의, 시스템 정의 또는 동적 임계값에 따라 전송됩니다.

* *정보*
+
이 이벤트는 새 오브젝트가 발견되거나 사용자 작업이 수행될 때 발생합니다. 예를 들어, 스토리지 오브젝트가 삭제되거나 구성이 변경될 때 심각도 유형이 정보인 이벤트가 생성됩니다.

+
ONTAP에서 구성 변경을 감지하면 정보 이벤트가 직접 전송됩니다.
