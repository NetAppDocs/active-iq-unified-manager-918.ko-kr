= Active IQ Unified Manager의 성능 인벤토리 페이지를 사용하여 오브젝트 성능 모니터링
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
오브젝트 인벤토리 성능 페이지는 오브젝트 유형 범주 내의 모든 오브젝트에 대한 성능 정보, 성능 이벤트 및 오브젝트 상태를 표시합니다. 이를 통해 모든 노드 또는 모든 볼륨 등 클러스터 내 각 오브젝트의 성능 상태를 한눈에 파악할 수 있습니다.

오브젝트 인벤토리 성능 페이지는 오브젝트 상태에 대한 개괄적인 정보를 제공하여 모든 오브젝트의 전반적인 성능을 평가하고 오브젝트 성능 데이터를 비교할 수 있도록 합니다. 검색, 정렬 및 필터링을 통해 오브젝트 인벤토리 페이지의 내용을 세분화할 수 있습니다. 이는 오브젝트 성능을 모니터링하고 관리할 때 유용하며, 성능 문제가 있는 오브젝트를 신속하게 찾아 문제 해결 프로세스를 시작할 수 있도록 해줍니다.

image::../media/perf_node_inventory.gif[성능/모든 노드 인벤토리 페이지에서 오브젝트의 세부 정보를 보여주는 UI 스크린샷입니다.]

기본적으로 성능 인벤토리 페이지의 오브젝트는 오브젝트 성능 중요도에 따라 정렬됩니다. 새로운 중요 성능 이벤트가 발생한 오브젝트가 먼저 표시되고, 경고 이벤트가 발생한 오브젝트가 두 번째로 표시됩니다. 이를 통해 해결해야 할 문제를 시각적으로 즉시 파악할 수 있습니다. 모든 성능 데이터는 72시간 평균값을 기준으로 합니다.

오브젝트 인벤토리 성능 페이지에서 오브젝트 이름 열의 오브젝트 이름을 클릭하여 오브젝트 세부 정보 페이지로 쉽게 이동할 수 있습니다. 예를 들어, 성능/모든 노드 인벤토리 페이지에서 *Nodes* 열의 노드 오브젝트를 클릭합니다. 오브젝트 세부 정보 페이지는 활성 이벤트의 나란히 비교를 포함하여 선택한 오브젝트에 대한 심층적인 정보와 세부 정보를 제공합니다.
