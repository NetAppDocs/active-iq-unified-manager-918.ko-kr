= Active IQ Unified Manager에서 사용된 성능 용량 값 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 용량 사용량 값은 현재 과도하게 사용되거나 사용률이 낮은 노드 및 애그리게이트를 식별하는 데 도움이 됩니다. 이를 통해 워크로드를 재분배하여 스토리지 리소스를 더욱 효율적으로 활용할 수 있습니다.

다음 그림은 리소스의 지연 시간 대 사용률 곡선을 보여주고, 색깔 있는 점으로 현재 운영 지점이 위치할 수 있는 세 영역을 나타냅니다.

image::../media/headroom_chart_over_under.gif[리소스의 지연 시간 대 사용률 곡선을 보여주는 UI 스크린샷입니다.]

* 성능 용량 활용률이 100%일 때가 최적의 지점입니다.
+
현재 자원이 효율적으로 사용되고 있습니다.

* 성능 용량 사용률이 100%를 초과하면 노드 또는 애그리게이트가 과도하게 사용되고 있으며 워크로드가 최적의 성능을 얻지 못하고 있음을 나타냅니다.
+
해당 리소스에 새로운 워크로드를 추가해서는 안 되며, 기존 워크로드를 재분배해야 할 수도 있습니다.

* 성능 용량 사용률이 100 미만이면 노드 또는 애그리게이트의 활용도가 낮고 리소스가 효율적으로 사용되지 않고 있음을 나타냅니다.
+
리소스에 더 많은 워크로드를 추가할 수 있습니다.



[NOTE]
====
활용률과는 달리, 성능 용량 사용률은 100%를 초과할 수 있습니다. 최대 사용률은 정해져 있지 않지만, 일반적으로 리소스가 과다 사용 중일 때는 110%에서 140% 범위에 머무릅니다. 이보다 높은 사용률은 리소스에 심각한 문제가 있음을 나타냅니다.

====
