= Active IQ Unified Manager에서 사용자 정의 성능 임계값 정책 생성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 오브젝트에 대한 성능 임계값 정책을 생성하여 성능 카운터가 특정 값을 초과할 때 알림이 전송되도록 합니다. 이벤트 알림은 클러스터에 성능 문제가 발생했음을 알려줍니다.

.시작하기 전에
애플리케이션 관리자 역할이 있어야 합니다.

성능 임계값 정책 생성 페이지에서 임계값을 입력하여 성능 임계값 정책을 생성합니다. 이 페이지에서 모든 정책 값을 정의하여 새 정책을 생성하거나, 기존 정책을 복사하고 복사본의 값을 변경(이를 _클로닝_이라고 함)할 수 있습니다.

유효한 임계값은 숫자의 경우 0.001~10,000,000, 백분율의 경우 0.001~100, 성능 용량 사용률의 경우 0.001~200입니다.

[NOTE]
====
현재 릴리스에서는 카운터 값이 설정된 임계값을 초과할 때 이벤트를 전송하는 임계값 기능을 제공합니다. 카운터 값이 설정된 임계값 미만으로 떨어질 때 이벤트를 전송하는 임계값은 설정할 수 없습니다.

====
.단계
. 왼쪽 탐색 창에서 *이벤트 임계값* > *성능*을 선택합니다.
+
성능 임계값 페이지가 표시됩니다.

. 새 정책을 만들 것인지, 아니면 유사한 정책을 복제하여 복제본을 수정할 것인지에 따라 적절한 버튼을 클릭하십시오.
+
|===
| ~하려면... | 클릭... 


 a| 
새 정책 생성
 a| 
*만들기*



 a| 
기존 정책을 복제합니다
 a| 
기존 정책을 선택하고 *복제*를 클릭하십시오

|===
+
성능 임계값 정책 생성 페이지 또는 성능 임계값 정책 복제 페이지가 표시됩니다.

. 특정 스토리지 오브젝트에 대해 설정할 성능 카운터 임계값을 지정하여 임계값 정책을 정의합니다:
+
.. 스토리지 오브젝트 유형을 선택하고 정책의 이름과 설명을 지정합니다.
.. 추적할 성능 카운터를 선택하고 경고 및 심각 이벤트를 정의하는 제한 값을 지정하십시오.
+
경고 한계 또는 임계 한계 중 하나 이상을 반드시 정의해야 합니다. 두 가지 유형의 한계를 모두 정의할 필요는 없습니다.

.. 필요한 경우 보조 성능 카운터를 선택하고 경고 및 심각 이벤트에 대한 제한 값을 지정합니다.
+
보조 카운터를 포함하려면 임계값이 초과되어 이벤트가 보고되기 전에 두 카운터 모두 제한 값을 초과해야 합니다. 특정 오브젝트와 카운터만 조합 정책을 사용하여 구성할 수 있습니다.

.. 이벤트가 전송되기 위해 제한값이 초과되어야 하는 시간을 선택하십시오.


+
기존 정책을 복제할 때는 정책에 새 이름을 입력해야 합니다.

. 정책을 저장하려면 *저장*을 클릭하십시오.
+
성능 임계값 페이지로 돌아갑니다. 페이지 상단에 임계값 정책이 생성되었음을 알리는 성공 메시지가 표시되며, 해당 오브젝트 유형의 인벤토리 페이지 링크가 제공되어 새 정책을 스토리지 오브젝트에 즉시 적용할 수 있습니다.



지금 스토리지 오브젝트에 새 임계값 정책을 적용하려면 *지금 오브젝트 유형으로 이동* 링크를 클릭하여 인벤토리 페이지로 이동할 수 있습니다.
