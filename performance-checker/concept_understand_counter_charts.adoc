= Active IQ Unified Manager에서 카운터 차트 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
카운터 차트 창의 차트를 사용하면 루트 오브젝트와 상관 오브젝트 그리드에서 추가한 오브젝트의 성능 데이터를 보고 비교할 수 있습니다. 이를 통해 성능 추세를 파악하고 성능 문제를 찾아 해결할 수 있습니다.

기본적으로 표시되는 카운터 차트는 이벤트, 지연 시간, IOPS 및 MBps입니다. 선택적으로 표시할 수 있는 차트로는 사용률, 성능 용량 사용량, 사용 가능한 IOPS, IOPS/TB 및 캐시 미스 비율이 있습니다. 또한 지연 시간, IOPS, MBps 및 성능 용량 사용량 차트에 대해 총계 값 또는 세부 분석 값을 선택하여 볼 수 있습니다.

성능 탐색기는 스토리지 오브젝트가 이를 모두 지원하는지 여부와 관계없이 기본적으로 특정 카운터 차트를 표시합니다. 카운터가 지원되지 않는 경우 카운터 차트는 비어 있고 메시지 `Not applicable for <object>`가 표시됩니다.

차트는 루트 오브젝트와 비교 창에서 선택한 모든 오브젝트의 성능 추세를 보여줍니다. 각 차트의 데이터는 다음과 같이 배열됩니다.

* *X축*
+
지정된 기간을 표시합니다. 기간 범위를 지정하지 않으면 기본값은 이전 72시간입니다.

* *Y축*
+
선택한 오브젝트 또는 오브젝트들에 고유한 카운터 단위를 표시합니다.



추세선 색상은 비교 창에 표시된 오브젝트 이름의 색상과 일치합니다. 추세선의 특정 지점 위에 커서를 올려놓으면 해당 지점의 시간 및 값에 대한 세부 정보를 볼 수 있습니다.

차트에서 특정 기간을 조사하려면 다음 방법 중 하나를 사용할 수 있습니다.

* *<* 버튼을 사용하여 카운터 차트 창을 페이지 너비 전체에 걸쳐 확장하십시오.
* 커서(돋보기로 바뀔 때)를 사용하여 차트의 기간 중 일부를 선택하여 해당 영역에 초점을 맞추고 확대하십시오. Reset Chart Zoom을 클릭하여 차트를 기본 기간으로 되돌릴 수 있습니다.
* *확대 보기* 버튼을 사용하여 확장된 세부 정보와 임계값 표시기가 포함된 큰 단일 카운터 차트를 표시하십시오.


[NOTE]
====
때때로 추세선에 공백이 표시됩니다. 공백은 Unified Manager가 스토리지 시스템에서 성능 데이터를 수집하지 못했거나 Unified Manager가 다운되었을 수 있음을 의미합니다.
