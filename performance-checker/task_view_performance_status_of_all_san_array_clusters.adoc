= Active IQ Unified Manager에서 All SAN Array 클러스터의 성능 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능: 모든 클러스터 보기를 사용하여 All SAN Array 클러스터의 성능 상태를 표시할 수 있습니다.

.시작하기 전에
운영자, 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

성능: 모든 클러스터 보기에서 All SAN Array 클러스터에 대한 개요 정보를 볼 수 있으며, 클러스터 / 성능 탐색기 페이지에서 세부 정보를 확인할 수 있습니다.

.단계
. 왼쪽 탐색 창에서 *스토리지* > *클러스터*를 클릭합니다.
. *상태: 모든 클러스터* 보기에서 "`Personality`" 열이 표시되는지 확인하거나 *표시 / 숨기기* 컨트롤을 사용하여 추가하십시오.
+
이 열에는 All SAN Array 클러스터에 대한 "`All SAN Array`"가 표시됩니다.

. 해당 클러스터의 성능 정보를 보려면 *성능: 모든 클러스터* 보기를 선택하십시오.
+
All SAN Array 클러스터의 성능 정보를 확인하십시오.

. 해당 클러스터의 성능에 대한 자세한 정보를 보려면 All SAN Array 클러스터 이름을 클릭하십시오.
. *탐색기* 탭을 클릭하십시오.
. *클러스터 / 성능 탐색기* 페이지의 *보기 및 비교* 메뉴에서 *이 클러스터의 노드*를 선택합니다.
+
이 클러스터의 두 노드 성능 통계를 비교하여 두 노드의 부하가 거의 동일한지 확인할 수 있습니다. 두 노드 간에 큰 차이가 있는 경우 두 번째 노드를 차트에 추가하고 더 긴 기간 동안 값을 비교하여 구성 문제를 파악할 수 있습니다.
