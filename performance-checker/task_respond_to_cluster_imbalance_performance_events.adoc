= Active IQ Unified Manager에서 클러스터 불균형 성능 이벤트에 응답합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager는 클러스터 내 한 노드가 다른 노드보다 훨씬 높은 부하로 작동하여 워크로드 지연에 영향을 미칠 가능성이 있을 때 클러스터 불균형 경고 이벤트를 생성합니다. 이러한 시스템 정의 이벤트는 많은 워크로드가 지연의 영향을 받기 전에 잠재적인 성능 문제를 해결할 수 있는 기회를 제공합니다.

.시작하기 전에
운영자, 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

Unified Manager는 클러스터의 모든 노드에 대한 성능 용량 사용량 값을 비교하여 노드 간 부하 차이가 30% 이상인지 확인함으로써 클러스터 불균형 임계값 정책 위반에 대한 경고 이벤트를 생성합니다.

다음 단계를 따르면 성능이 높은 워크로드를 사용률이 낮은 노드로 이동할 수 있도록 다음 리소스를 식별할 수 있습니다:

* 동일 클러스터 내에서 활용도가 낮은 노드
* 새 노드에서 활용도가 가장 낮은 애그리게이트
* 현재 노드에서 가장 성능이 뛰어난 볼륨


.단계
. *이벤트* 상세 정보 페이지를 표시하여 이벤트에 대한 정보를 확인하십시오.
. 이벤트 발생 원인이 된 임계값 위반에 대한 설명이 포함된 *설명*을 검토하십시오.
+
예를 들어, "\`성능 용량 사용량 카운터는 클러스터 Dallas-1-8의 노드 간 부하 차이가 62%임을 나타내며 시스템 임계값 30%를 기준으로 WARNING 이벤트를 트리거했습니다\`"라는 메시지는 노드 중 하나의 성능 용량이 과도하게 사용되어 노드 성능에 영향을 미치고 있음을 나타냅니다.

. *권장 조치*의 텍스트를 검토하여 성능 용량 사용량이 높은 노드에서 성능 용량 사용량이 가장 낮은 노드로 고성능 볼륨을 이동하십시오.
. 성능 용량 사용량 값이 가장 높은 노드와 가장 낮은 노드를 식별하십시오:
+
.. *이벤트 정보* 섹션에서 소스 클러스터의 이름을 클릭합니다.
.. *클러스터/성능 요약* 페이지에서 *관리되는 오브젝트* 영역의 *노드*를 클릭합니다.
.. *노드* 인벤토리 페이지에서 *사용된 성능 용량* 열을 기준으로 노드를 정렬합니다.
.. 성능 용량 사용량이 가장 높고 가장 낮은 노드를 식별하고 해당 노드의 이름을 기록하십시오.


. 성능 용량 사용 값이 가장 높은 노드에서 가장 많은 IOPS를 사용하는 볼륨을 식별하십시오:
+
.. 성능 용량 사용량 값이 가장 높은 노드를 클릭하십시오.
.. *노드 / 성능 탐색기* 페이지의 *보기 및 비교* 메뉴에서 *이 노드의 애그리게이트*를 선택합니다.
.. 사용된 성능 용량 값이 가장 높은 애그리게이트를 클릭합니다.
.. *애그리게이트 / 성능 탐색기* 페이지의 *보기 및 비교* 메뉴에서 *이 애그리게이트의 볼륨*을 선택합니다.
.. 볼륨을 *IOPS* 열을 기준으로 정렬하고, 가장 높은 IOPS를 사용하는 볼륨의 이름과 해당 볼륨이 속한 애그리게이트의 이름을 기록하십시오.


. 성능 용량 사용 값이 가장 낮은 노드에서 사용률이 가장 낮은 애그리게이트를 식별하십시오:
+
.. *스토리지* > *애그리게이트*를 클릭하여 *애그리게이트* 인벤토리 페이지를 표시합니다.
.. *성능: 모든 애그리게이트* 보기를 선택하십시오.
.. *필터* 버튼을 클릭하고 4단계에서 기록해 둔 성능 용량 사용량 값이 가장 낮은 노드의 이름과 "`Node`"가 일치하는 필터를 추가합니다.
.. 성능 용량 사용 값이 가장 낮은 애그리게이트의 이름을 적으십시오.


. 과부하가 걸린 노드에서 사용률이 낮은 것으로 확인된 새 노드의 애그리게이트로 볼륨을 이동합니다.
+
ONTAP System Manager, OnCommand Workflow Automation, ONTAP 명령 또는 이러한 툴의 조합을 사용하여 이동 작업을 수행할 수 있습니다.



며칠 후, 해당 클러스터에서 동일한 클러스터 불균형 이벤트가 발생하는지 확인하십시오.
