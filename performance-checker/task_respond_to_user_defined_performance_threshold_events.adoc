= Active IQ Unified Manager에서 사용자 정의 성능 임계값 이벤트에 응답합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager를 사용하면 성능 카운터가 사용자 정의 경고 또는 심각 임계값을 초과하여 발생한 성능 이벤트를 조사할 수 있습니다. 또한 Unified Manager를 사용하여 클러스터 구성 요소의 상태를 확인하고 해당 구성 요소에서 감지된 최근 상태 이벤트가 성능 이벤트에 영향을 미쳤는지 확인할 수 있습니다.

.시작하기 전에
* 운영자, 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.
* 새로운 또는 더 이상 사용되지 않는 성능 이벤트가 있어야 합니다.


.단계
. 이벤트에 대한 정보를 보려면 *이벤트 상세 정보* 페이지를 표시하십시오.
. 이벤트 발생 원인이 된 임계값 위반에 대한 설명이 포함된 *설명*을 검토하십시오.
+
예를 들어, "`Latency value of 456 ms/op has triggered a WARNING event based on threshold setting of 400 ms/op`"라는 메시지는 해당 오브젝트에 지연 시간 경고 이벤트가 발생했음을 나타냅니다.

. 마우스 커서를 정책 이름 위에 올리면 해당 이벤트를 발생시킨 임계값 정책에 대한 세부 정보가 표시됩니다.
+
여기에는 정책 이름, 평가 대상 성능 카운터, 심각 또는 경고 이벤트로 간주되기 위해 초과해야 하는 카운터 값, 그리고 카운터가 해당 값을 초과해야 하는 기간이 포함됩니다.

. *이벤트 발생 시간*을 기록해 두면 이 이벤트에 영향을 미쳤을 수 있는 다른 이벤트가 같은 시간에 발생했는지 조사할 수 있습니다.
. 아래 옵션 중 하나를 선택하여 해당 이벤트를 자세히 조사하고 성능 문제를 해결하기 위해 필요한 조치가 있는지 확인하십시오:
+
|===
| 옵션 | 가능한 조사 조치 


 a| 
소스 오브젝트 이름을 클릭하여 해당 오브젝트의 Explorer 페이지를 표시합니다.
 a| 
이 페이지에서는 오브젝트 세부 정보를 확인하고 이 오브젝트를 다른 유사한 스토리지 오브젝트와 비교하여 다른 스토리지 오브젝트에서도 비슷한 시점에 성능 문제가 발생하는지 확인할 수 있습니다. 예를 들어, 동일한 애그리게이트에 있는 다른 볼륨에서도 성능 문제가 발생하는지 확인할 수 있습니다.



 a| 
클러스터 이름을 클릭하면 클러스터 요약 페이지가 표시됩니다.
 a| 
이 페이지에서는 해당 오브젝트가 있는 클러스터의 세부 정보를 확인하여 비슷한 시기에 다른 성능 문제가 발생했는지 여부를 확인할 수 있습니다.

|===
