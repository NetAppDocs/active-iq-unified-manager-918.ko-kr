= Active IQ Unified Manager에서 성능 용량 카운터 차트 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 탐색기 페이지에서 노드 및 애그리게이트에 대한 성능 용량 사용량 차트를 볼 수 있습니다. 이를 통해 특정 기간 동안 선택한 노드 및 애그리게이트에 대한 자세한 성능 용량 데이터를 확인할 수 있습니다.

표준 카운터 차트는 선택된 노드 또는 애그리게이트에 사용된 성능 용량 값을 표시합니다. 분석 카운터 차트는 루트 오브젝트에 대한 총 성능 용량 값을 사용자 프로토콜 기반 사용량과 백그라운드 시스템 프로세스 기반 사용량으로 구분하여 표시합니다. 또한, 사용 가능한 성능 용량도 함께 표시됩니다.

[NOTE]
====
시스템 및 데이터 관리와 관련된 일부 백그라운드 활동이 사용자 워크로드로 식별되어 사용자 프로토콜로 분류되기 때문에, 이러한 프로세스가 실행될 때 사용자 프로토콜 비율이 실제보다 높게 나타날 수 있습니다. 이러한 프로세스는 일반적으로 클러스터 사용량이 낮은 자정 무렵에 실행됩니다. 자정 무렵에 사용자 프로토콜 활동이 급증하는 경우, 클러스터 백업 작업이나 다른 백그라운드 활동이 해당 시간에 실행되도록 구성되어 있는지 확인하십시오.

====
.단계
. 노드 또는 애그리게이트 *랜딩* 페이지에서 *탐색기* 탭을 선택합니다.
. *카운터 차트* 창에서 *차트 선택*을 클릭한 다음 *성능  사용된 용량* 차트를 선택합니다.
. 차트를 볼 수 있을 때까지 아래로 스크롤합니다.
+
표준 차트의 색상은 오브젝트가 최적 범위에 있을 때(노란색), 오브젝트가 과소 활용될 때(녹색), 그리고 오브젝트가 과다 활용될 때(빨간색)를 나타냅니다. 분석 차트는 루트 오브젝트에 대한 상세한 성능 용량 세부 정보만 표시합니다.

+
image::../media/headroom_counter_charts.gif[루트 오브젝트에 대해서만 상세한 성능 용량을 포함한 분석 차트를 보여주는 UI 스크린샷입니다.]

. 차트를 전체 크기로 보려면 *확대 보기*를 클릭하십시오.
+
이러한 방식으로 여러 카운터 차트를 별도의 창에서 열어 동일한 기간 동안 성능 용량 사용량 값을 IOPS 또는 MBps 값과 비교할 수 있습니다.
