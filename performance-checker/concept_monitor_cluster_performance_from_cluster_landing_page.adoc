= Active IQ Unified Manager의 Performance Cluster Landing 페이지에서 클러스터 성능 모니터링

:icons: font
:imagesdir: ../media/


[role="lead"]
성능 클러스터 랜딩 페이지는 Unified Manager 인스턴스에서 모니터링 중인 선택된 클러스터의 개략적인 성능 상태를 표시합니다. 이 페이지를 통해 특정 클러스터의 전반적인 성능을 평가하고, 식별된 클러스터 관련 이벤트를 신속하게 기록, 검색 또는 해결 담당자에게 할당할 수 있습니다.
