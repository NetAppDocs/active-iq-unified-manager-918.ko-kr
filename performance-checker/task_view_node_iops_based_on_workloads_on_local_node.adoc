= Active IQ Unified Manager에서 로컬 워크로드를 기반으로 노드 IOPS 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
노드 IOPS 카운터 차트는 네트워크 LIF를 사용하여 원격 노드의 볼륨에 대한 읽기/쓰기 작업을 수행할 때 로컬 노드를 통해서만 작업이 이루어지는 부분을 강조 표시할 수 있습니다. IOPS - "`Total (Local)`" 및 "`Breakdown (Local)`" 차트는 현재 노드의 로컬 볼륨에만 있는 데이터에 대한 IOPS를 표시합니다.

이러한 카운터 차트의 "`Local`" 버전은 로컬 볼륨에 있는 데이터에 대한 통계만 표시하므로 성능 용량 및 활용률에 대한 노드 차트와 유사합니다.

이러한 카운터 차트의 "`Local`" 버전을 일반 Total 버전과 비교하면 로컬 노드를 통해 원격 노드의 볼륨에 액세스하는 트래픽이 많은지 확인할 수 있습니다. 로컬 노드를 통해 원격 노드의 볼륨에 도달하는 작업이 너무 많으면 노드 사용률이 높아져 성능 문제가 발생할 수 있습니다. 이러한 경우 볼륨을 로컬 노드로 이동하거나, 해당 볼륨에 액세스하는 호스트의 트래픽이 연결될 수 있는 LIF를 원격 노드에 생성하는 것이 좋습니다.

.단계
. 선택한 노드의 *성능/노드 탐색기* 페이지에서 IOPS 차트의 드롭다운 메뉴에서 *총계*를 선택합니다.
+
IOPS - 총계 차트가 표시됩니다.

. 차트를 확대하여 새 브라우저 탭에서 보려면 *확대 보기*를 클릭하십시오.
. *성능/노드 탐색기* 페이지로 돌아가서 IOPS 차트의 드롭다운 메뉴에서 *총계(로컬)*를 선택합니다.
+
IOPS - 총(로컬) 차트가 표시됩니다.

. 차트를 확대하여 새 브라우저 탭에서 보려면 *확대 보기*를 클릭하십시오.
. 두 차트를 나란히 놓고 IOPS 값이 상당히 다르게 나타나는 영역을 확인하십시오.
. 마우스 커서를 해당 영역 위로 이동하면 특정 시점의 로컬 IOPS와 전체 IOPS를 비교할 수 있습니다.
