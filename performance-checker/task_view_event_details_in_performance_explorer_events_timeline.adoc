= Active IQ Unified Manager 이벤트 타임라인에서 이벤트 세부 정보 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 탐색기의 이벤트 타임라인 창에서 모든 이벤트와 관련 세부 정보를 볼 수 있습니다. 이는 지정된 기간 동안 루트 오브젝트에서 발생한 모든 상태 및 성능 이벤트를 빠르고 효율적으로 확인할 수 있는 방법으로, 성능 문제 해결에 도움이 될 수 있습니다.

이벤트 타임라인 창에는 선택한 시간 범위 동안 루트 오브젝트에서 발생한 심각, 오류, 경고 및 정보 이벤트가 표시됩니다. 각 이벤트 심각도에는 고유한 타임라인이 있습니다. 단일 이벤트 및 여러 이벤트는 타임라인의 이벤트 점으로 표시됩니다. 이벤트 점 위에 커서를 올려놓으면 이벤트 세부 정보를 볼 수 있습니다. 여러 이벤트의 시각적 세분성을 높이려면 시간 범위를 줄일 수 있습니다. 이렇게 하면 여러 이벤트가 단일 이벤트로 분산되어 각 이벤트를 개별적으로 보고 조사할 수 있습니다.

이벤트 타임라인의 각 성능 이벤트 점은 타임라인 아래에 표시되는 카운터 차트 추세선의 해당 급증 지점과 수직으로 정렬됩니다. 이를 통해 이벤트와 전반적인 성능 간의 직접적인 시각적 상관관계를 확인할 수 있습니다. 상태 관련 이벤트도 타임라인에 표시되지만, 이러한 이벤트는 성능 차트의 급증 지점과 반드시 일치하지는 않습니다.

.단계
. *이벤트 타임라인* 창에서 타임라인의 이벤트 점 위에 커서를 놓으면 해당 이벤트 시점의 이벤트 요약을 볼 수 있습니다.
+
팝업 대화 상자에는 이벤트 유형, 이벤트 발생 날짜 및 시간, 상태, 이벤트 지속 시간에 대한 정보가 표시됩니다.
