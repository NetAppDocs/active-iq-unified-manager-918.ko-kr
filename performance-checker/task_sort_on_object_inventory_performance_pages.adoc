= Active IQ Unified Manager의 오브젝트 인벤토리 성능 페이지에서 데이터 정렬
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
오브젝트 인벤토리 성능 페이지에서는 모든 데이터를 원하는 열을 기준으로 오름차순 또는 내림차순으로 정렬할 수 있습니다. 이를 통해 오브젝트 인벤토리 데이터를 빠르게 찾을 수 있으며, 성능을 분석하거나 문제 해결을 시작할 때 유용합니다.

정렬할 열은 강조 표시된 열 제목과 그 오른쪽에 있는 정렬 방향을 나타내는 화살표 아이콘으로 표시됩니다. 위쪽 화살표는 오름차순을, 아래쪽 화살표는 내림차순을 나타냅니다. 기본 정렬 순서는 *상태*(이벤트 중요도)를 기준으로 내림차순이며, 가장 중요한 성능 이벤트가 먼저 표시됩니다.

.단계
. 열 이름을 클릭하면 해당 열의 정렬 순서를 오름차순 또는 내림차순으로 전환할 수 있습니다.
+
오브젝트 인벤토리 성능 페이지의 내용은 선택한 열을 기준으로 오름차순 또는 내림차순으로 정렬됩니다.
