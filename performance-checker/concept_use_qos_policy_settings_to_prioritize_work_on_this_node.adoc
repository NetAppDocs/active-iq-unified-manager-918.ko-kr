= Active IQ Unified Manager에서 QoS 정책 설정을 사용하여 노드 워크로드의 우선 순위를 지정합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
QoS 정책 그룹에 제한을 설정하여 해당 그룹에 속한 워크로드의 초당 I/O(IOPS) 또는 MBps 처리량 제한을 제어할 수 있습니다. 워크로드가 기본 정책 그룹 등 제한이 설정되지 않은 정책 그룹에 있거나 설정된 제한이 요구 사항을 충족하지 못하는 경우, 설정된 제한을 늘리거나 워크로드를 원하는 제한이 있는 새 정책 그룹 또는 기존 정책 그룹으로 이동할 수 있습니다.

노드의 성능 이벤트가 노드 리소스를 과도하게 사용하는 워크로드로 인해 발생한 경우, 이벤트 세부 정보 페이지의 이벤트 설명에 관련된 볼륨 목록에 대한 링크가 표시됩니다. 성능/볼륨 페이지에서 영향을 받는 볼륨을 IOPS 및 MBps 기준으로 정렬하여 이벤트에 영향을 미쳤을 수 있는 사용량이 가장 높은 워크로드를 확인할 수 있습니다.

노드 리소스를 과도하게 사용하는 볼륨에 더 엄격한 정책 그룹 설정을 할당하면 정책 그룹이 워크로드를 제한하여 해당 노드의 리소스 사용량을 줄일 수 있습니다.

ONTAP System Manager 또는 ONTAP 명령어를 사용하여 정책 그룹을 관리할 수 있으며, 여기에는 다음과 같은 작업이 포함됩니다.

* 정책 그룹 만들기
* 정책 그룹에 워크로드 추가 또는 제거
* 정책 그룹 간 워크로드 이동
* 정책 그룹의 처리량 제한 변경
