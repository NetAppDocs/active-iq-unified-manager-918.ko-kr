= Active IQ Unified Manager에서 클러스터 구성 요소 및 경합 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
클러스터 구성 요소에 경합이 발생하면 클러스터 성능 문제를 파악할 수 있습니다. 해당 구성 요소를 사용하는 워크로드의 성능이 저하되고 클라이언트 요청에 대한 응답 시간(지연 시간)이 증가하여 Unified Manager에 이벤트가 발생합니다.

경합 상태에 있는 구성 요소는 최적의 수준으로 성능을 발휘할 수 없습니다. 해당 구성 요소의 성능이 저하되고, _victims_라고 하는 다른 클러스터 구성 요소 및 워크로드의 지연 시간이 증가할 수 있습니다. 구성 요소를 경합 상태에서 벗어나게 하려면 성능이 정상 수준으로 돌아갈 수 있도록 워크로드를 줄이거나 더 많은 작업을 처리할 수 있는 능력을 늘려야 합니다. Unified Manager는 5분 간격으로 워크로드 성능을 수집 및 분석하므로 클러스터 구성 요소가 지속적으로 과도하게 사용되는 경우에만 감지합니다. 5분 간격 내에서 짧은 시간 동안만 지속되는 일시적인 과사용 급증은 감지되지 않습니다.

예를 들어, 스토리지 애그리게이트에서 하나 이상의 워크로드가 I/O 요청을 처리하기 위해 경쟁하기 때문에 경합이 발생할 수 있습니다. 애그리게이트의 다른 워크로드에 영향을 미쳐 성능이 저하될 수 있습니다. 애그리게이트의 활동량을 줄이기 위해, 현재 애그리게이트의 전체 워크로드 수요를 줄이도록 하나 이상의 워크로드를 사용량이 적은 애그리게이트나 노드로 이동하는 등 다양한 조치를 취할 수 있습니다. QoS 정책 그룹의 경우, 처리량 제한을 조정하거나 워크로드를 다른 정책 그룹으로 이동하여 워크로드가 더 이상 스로틀링되지 않도록 할 수 있습니다.

Unified Manager는 다음 클러스터 구성 요소를 모니터링하여 경합이 발생할 경우 사용자에게 알림을 보냅니다:

* *네트워크*
+
클러스터에서 외부 네트워킹 프로토콜의 I/O 요청 대기 시간을 나타냅니다. 대기 시간은 클러스터가 I/O 요청에 응답하기 전에 "`transfer ready`" 트랜잭션이 완료될 때까지 기다리는 시간입니다. 네트워크 구성 요소에 경합이 발생하면 프로토콜 계층의 높은 대기 시간이 하나 이상의 워크로드 지연 시간에 영향을 미치고 있음을 의미합니다.

* *네트워크 처리*
+
이 항목은 프로토콜 계층과 클러스터 간의 I/O 처리에 관여하는 클러스터 내 소프트웨어 구성 요소를 나타냅니다. 네트워크 처리를 담당하는 노드는 이벤트가 감지된 이후 변경되었을 수 있습니다. 네트워크 처리 구성 요소에 경합이 발생했다는 것은 해당 네트워크 처리 노드의 높은 사용률이 하나 이상의 워크로드의 지연 시간에 영향을 미치고 있음을 의미합니다.

+
액티브-액티브 구성에서 All SAN Array 클러스터를 사용할 때 두 노드 모두에 대해 네트워크 처리 지연 시간 값이 표시되므로 노드가 부하를 균등하게 분담하고 있는지 확인할 수 있습니다.

* *QoS 최대 제한*
+
워크로드에 할당된 스토리지 QoS(서비스 품질) 정책 그룹의 최대 처리량(피크) 설정을 나타냅니다. 정책 그룹 구성 요소가 경합 상태인 경우, 해당 정책 그룹의 모든 워크로드가 설정된 처리량 제한으로 인해 스로틀링되고 있으며, 이로 인해 하나 이상의 워크로드 지연 시간에 영향을 미치고 있음을 의미합니다.

* *QoS 최소 제한*
+
이는 다른 워크로드에 할당된 QoS 최소 처리량(예상) 설정으로 인해 발생하는 워크로드의 지연 시간을 나타냅니다. 특정 워크로드에 설정된 QoS 최소값이 약속된 처리량을 보장하기 위해 대역폭의 대부분을 사용하는 경우, 다른 워크로드는 처리량이 제한되어 지연 시간이 증가합니다.

* *클러스터 인터커넥트*
+
클러스터링된 노드가 물리적으로 연결되는 케이블과 어댑터를 나타냅니다. 클러스터 인터커넥트 구성 요소에 경합이 발생하면, 클러스터 인터커넥트에서 I/O 요청에 대한 대기 시간이 길어져 하나 이상의 워크로드 지연 시간에 영향을 미치고 있음을 의미합니다.

* *Data Processing*
+
클러스터와 워크로드를 포함하는 스토리지 애그리게이트 간의 I/O 처리에 관련된 클러스터 내 소프트웨어 구성 요소를 나타냅니다. 이벤트가 감지된 이후 Data Processing을 담당하는 노드가 변경되었을 수 있습니다. Data Processing 구성 요소에 경합이 발생하면 Data Processing 노드의 높은 사용률이 하나 이상의 워크로드의 지연 시간에 영향을 미치고 있음을 의미합니다.

* *볼륨 활성화*
+
모든 활성 볼륨의 사용량을 추적하는 프로세스를 나타냅니다. 1000개 이상의 볼륨이 활성 상태인 대규모 환경에서는 이 프로세스를 통해 노드를 통해 동시에 리소스에 액세스해야 하는 중요 볼륨의 수를 추적합니다. 동시 활성 볼륨 수가 권장 최대 임계값을 초과하면 일부 중요하지 않은 볼륨에서 여기에서 식별된 것과 같은 지연이 발생합니다.

* *MetroCluster 리소스*
+
MetroCluster 구성에서 클러스터 간에 데이터를 미러링하는 데 사용되는 NVRAM 및 ISL(스위치 간 링크) 등 MetroCluster 리소스를 나타냅니다. MetroCluster 구성 요소에 경합이 발생하면 로컬 클러스터의 워크로드에서 쓰기 처리량이 높거나 링크 상태 문제가 로컬 클러스터의 하나 이상의 워크로드 지연 시간에 영향을 미치고 있음을 의미합니다. 클러스터가 MetroCluster 구성이 아닌 경우 이 아이콘은 표시되지 않습니다.

* *애그리게이트 또는 SSD 애그리게이트 작업*
+
워크로드가 실행되는 스토리지 애그리게이트를 나타냅니다. 애그리게이트 구성 요소에 경합이 발생하면 해당 애그리게이트의 높은 사용률이 하나 이상의 워크로드의 지연 시간에 영향을 미치고 있음을 의미합니다. 애그리게이트는 모든 HDD, HDD와 SSD의 혼합(플래시 풀 애그리게이트), 또는 HDD와 클라우드 계층의 혼합(FabricPool 애그리게이트)으로 구성됩니다. "`SSD 애그리게이트`"는 모든 SSD(올플래시 애그리게이트), 또는 SSD와 클라우드 계층의 혼합(FabricPool 애그리게이트)으로 구성됩니다.

* *클라우드 지연 시간*
+
클러스터와 사용자 데이터가 저장되는 클라우드 계층 간의 I/O 처리에 관련된 클러스터 내 소프트웨어 구성 요소를 나타냅니다. 클라우드 지연 시간 구성 요소에 경합이 발생하면 클라우드 계층에 호스팅된 볼륨에서 대량의 읽기 작업이 하나 이상의 워크로드의 지연 시간에 영향을 미치고 있음을 의미합니다.

* *동기식 SnapMirror*
+
SnapMirror 동기 관계에서 기본 볼륨에서 보조 볼륨으로 사용자 데이터를 복제하는 데 관련된 클러스터의 소프트웨어 구성 요소를 나타냅니다. 동기 SnapMirror 구성 요소에 경합이 발생하면 SnapMirror 동기 작업으로 인한 활동이 하나 이상의 워크로드의 지연 시간에 영향을 미치고 있음을 의미합니다.
