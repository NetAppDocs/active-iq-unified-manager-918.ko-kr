= Active IQ Unified Manager에서 성능 이벤트의 소스 식별
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 이벤트는 클러스터의 워크로드 성능과 관련된 문제입니다. 이러한 이벤트는 응답 시간이 느린 스토리지 오브젝트, 즉 지연 시간이 높은 오브젝트를 식별하는 데 도움이 됩니다. 동시에 발생한 다른 상태 이벤트와 함께 성능 이벤트를 분석하면 응답 시간 지연의 원인이 되거나 영향을 미친 문제를 파악할 수 있습니다.

Unified Manager는 다음 소스로부터 성능 이벤트를 수신합니다:

* *사용자 정의 성능 임계값 정책 이벤트*
+
사용자가 설정한 사용자 지정 임계값에 따른 성능 문제입니다. 예를 들어 애그리게이트 및 볼륨 등 스토리지 오브젝트에 대한 성능 임계값 정책을 구성하여 성능 카운터의 임계값이 초과될 때 이벤트가 생성되도록 합니다.

+
이러한 이벤트를 수신하려면 성능 임계값 정책을 정의하고 스토리지 오브젝트에 할당해야 합니다.

* *시스템 정의 성능 임계값 정책 이벤트*
+
시스템에서 정의된 임계값에 기반한 성능 문제입니다. 이러한 임계값 정책은 일반적인 성능 문제를 해결하기 위해 Unified Manager 설치 시 함께 제공됩니다.

+
이러한 임계값 정책은 기본적으로 활성화되어 있으며, 클러스터를 추가한 직후에 이벤트가 표시될 수 있습니다.

* *동적 성능 임계값 이벤트*
+
IT 인프라의 장애나 오류, 또는 클러스터 리소스를 과도하게 사용하는 워크로드로 인해 발생하는 성능 문제입니다. 이러한 이벤트의 원인은 시간이 지나면서 저절로 해결되거나 복구 또는 구성 변경을 통해 해결할 수 있는 간단한 문제일 수 있습니다. 동적 임계값 이벤트는 ONTAP 시스템의 워크로드가 공유 클러스터 구성 요소를 과도하게 사용하는 다른 워크로드로 인해 속도가 느려졌음을 나타냅니다.

+
이러한 임계값은 기본적으로 활성화되어 있으며, 새 클러스터에서 데이터를 수집한 후 3일 후에 이벤트가 표시될 수 있습니다.
