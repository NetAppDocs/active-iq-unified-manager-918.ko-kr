= Active IQ Unified Manager에서 노드 페일오버 계획을 위한 임계값 정책 생성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
노드 임계값 정책을 생성하면 잠재적인 장애 조치로 인해 인수 노드의 성능이 허용할 수 없는 수준으로 저하될 경우 성능/노드 장애 조치 계획 페이지에서 알림을 받을 수 있습니다.

"`Node HA pair over-utilized`"라는 시스템 정의 성능 임계값 정책은 6회 연속 수집 기간(30분) 동안 임계값을 초과할 경우 경고 이벤트를 생성합니다. HA 쌍을 구성하는 노드들의 총 성능 용량 사용량이 200%를 초과하면 임계값이 초과된 것으로 간주됩니다.

시스템에서 정의한 임계값 정책에 따른 이벤트는 장애 조치로 인해 인수 노드의 지연 시간이 허용할 수 없는 수준으로 증가할 수 있음을 알려줍니다. 특정 노드에 대해 이 정책이 생성한 이벤트를 확인하면 해당 노드의 성능/노드 장애 조치 계획 페이지로 이동하여 장애 조치로 인한 예상 지연 시간 값을 볼 수 있습니다.

시스템에서 정의한 임계값 정책을 사용하는 것 외에도, "`Performance Capacity Used - Takeover`" 카운터를 사용하여 임계값 정책을 생성하고 선택한 노드에 적용할 수 있습니다. 임계값을 200% 미만으로 지정하면 시스템에서 정의한 정책의 임계값이 초과되기 전에 이벤트를 수신할 수 있습니다. 또한 시스템에서 정의한 정책 이벤트가 생성되기 전에 알림을 받으려면 임계값 초과 최소 기간을 30분 미만으로 지정할 수 있습니다.

예를 들어, HA 쌍을 구성하는 노드들의 총 성능 용량 사용량이 10분 이상 175%를 초과할 경우 경고 이벤트를 발생시키는 임계값 정책을 정의할 수 있습니다. 이 정책은 HA 쌍을 이루는 Node1과 Node2에 적용할 수 있습니다. Node1 또는 Node2에 대한 경고 이벤트 알림을 받은 후, 해당 노드의 성능/노드 장애 조치 계획 페이지에서 인수 노드에 미치는 예상 성능 영향을 평가할 수 있습니다. 장애 조치가 발생할 경우 인수 노드에 과부하가 걸리지 않도록 시정 조치를 취할 수 있습니다. 노드들의 총 성능 용량 사용량이 200% 미만일 때 조치를 취하면, 이 기간 동안 장애 조치가 발생하더라도 인수 노드의 지연 시간이 허용할 수 없는 수준에 도달하지 않습니다.
