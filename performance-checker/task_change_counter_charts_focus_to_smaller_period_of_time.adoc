= Active IQ Unified Manager에서 카운터 차트 포커스를 더 짧은 기간으로 변경합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
마우스를 사용하여 시간 범위를 줄여 카운터 차트 창이나 카운터 차트 확대/축소 보기 창에서 특정 기간에 집중할 수 있습니다. 이를 통해 성능 데이터, 이벤트 및 임계값 타임라인의 모든 부분을 더욱 세밀하게 살펴볼 수 있습니다.

.시작하기 전에
이 기능이 활성화되었음을 나타내려면 커서가 돋보기 모양으로 바뀌어 있어야 합니다.

[NOTE]
====
이 기능을 사용하면 타임라인이 더욱 세분화된 표시 방식에 맞춰 변경되지만, *시간 범위* 선택기의 시간 및 날짜 범위는 차트의 원래 값에서 변경되지 않습니다.

====
.단계
. 특정 기간을 확대해서 보려면 돋보기를 사용하여 클릭하고 마우스를 드래그하여 자세히 보고 싶은 영역을 강조 표시하십시오.
+
선택한 기간의 카운터 값이 카운터 차트를 채웁니다.

. *시간 범위* 선택기에서 설정한 원래 기간으로 되돌리려면 *차트 확대/축소 초기화* 버튼을 클릭하십시오.
+
카운터 차트는 원래 상태로 표시됩니다.
