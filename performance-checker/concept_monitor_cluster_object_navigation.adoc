= Active IQ Unified Manager에서 클러스터 오브젝트 탐색 모니터링
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager로 관리되는 모든 클러스터의 모든 오브젝트 성능을 모니터링할 수 있습니다. 스토리지 오브젝트 모니터링을 통해 클러스터 및 오브젝트 성능에 대한 개요를 확인할 수 있으며, 성능 이벤트 모니터링도 포함됩니다. 성능 및 이벤트를 개략적으로 살펴보거나, 오브젝트 성능 및 성능 이벤트에 대한 자세한 내용을 추가로 조사할 수 있습니다.

이는 클러스터 오브젝트 탐색의 여러 가지 예시 중 하나입니다:

. 대시보드 페이지에서 성능 용량 패널의 세부 정보를 검토하여 가장 많은 성능 용량을 사용하는 클러스터를 확인하고 막대 차트를 클릭하여 해당 클러스터의 노드 목록으로 이동합니다.
. 성능 용량 사용량 값이 가장 높은 노드를 찾아 해당 노드를 클릭하십시오.
. 노드/성능 탐색기 페이지에서 보기 및 비교 메뉴의 *이 노드의 애그리게이트*를 클릭합니다.
. 성능 용량을 가장 많이 사용하는 애그리게이트를 찾아 해당 애그리게이트를 클릭합니다.
. 애그리게이트 / 성능 탐색기 페이지에서 보기 및 비교 메뉴의 *이 애그리게이트의 볼륨*을 클릭합니다.
. 가장 많은 IOPS를 사용하는 볼륨을 식별하십시오.


클러스터에서 해당 볼륨이 IOPS의 상당 부분을 사용하지 않도록 QoS 정책이나 성능 서비스 수준 정책을 적용해야 하는지 또는 정책 설정을 변경해야 하는지 여부를 조사해야 합니다.
