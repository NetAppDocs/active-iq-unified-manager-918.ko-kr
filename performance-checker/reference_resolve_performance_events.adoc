= Active IQ Unified Manager에서 성능 이벤트 해결
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
제안된 조치를 사용하여 성능 이벤트를 직접 해결해 볼 수 있습니다. 처음 세 가지 제안은 항상 표시되며, 네 번째 제안 아래의 조치는 표시된 이벤트 유형에 따라 다릅니다.

*이 작업을 수행하는 데 도움을 주세요* 링크는 특정 작업을 수행하는 방법에 대한 지침을 포함하여 각 제안된 작업에 대한 추가 정보를 제공합니다. 일부 작업에는 Unified Manager, ONTAP System Manager, OnCommand Workflow Automation, ONTAP CLI 명령 또는 이러한 툴의 조합을 사용하는 것이 포함될 수 있습니다.
