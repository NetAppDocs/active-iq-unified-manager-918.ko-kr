= Active IQ Unified Manager의 이벤트 관리 인벤토리 페이지에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이벤트 관리 인벤토리 페이지에서는 현재 이벤트 목록과 해당 속성을 확인할 수 있습니다. 이벤트 승인, 해결, 할당 등의 작업을 수행할 수 있습니다. 특정 이벤트에 대한 알림을 추가할 수도 있습니다.

이 페이지의 정보는 가장 최신의 새로운 이벤트가 표시되도록 5분마다 자동으로 새로 고침됩니다.



[[filter-components]]
== 필터 구성 요소

이벤트 목록에 표시되는 정보를 사용자 지정할 수 있습니다. 다음 구성 요소를 사용하여 표시되는 이벤트 목록을 세분화할 수 있습니다.

* 미리 정의된 필터 선택 목록에서 선택할 수 있는 보기 메뉴입니다.
+
여기에는 모든 활성 이벤트(새로 발생한 이벤트 및 승인된 이벤트), 활성 성능 이벤트, 나(로그인한 사용자)에게 할당된 이벤트, 모든 유지 관리 기간 동안 생성된 모든 이벤트 등의 항목이 포함됩니다.

* 전체 또는 부분 검색어를 입력하여 이벤트 목록을 좁힐 수 있는 검색 창입니다.
* 이벤트 목록을 세분화할 수 있도록 사용 가능한 모든 필드와 필드 속성을 선택할 수 있는 필터 창을 실행하는 필터 버튼입니다.




[[command-buttons]]
== 명령 버튼

명령 버튼을 사용하면 다음과 같은 작업을 수행할 수 있습니다:

* *담당자 지정*
+
이벤트를 할당할 사용자를 선택할 수 있습니다. 이벤트를 사용자에게 할당하면 해당 사용자의 이름과 이벤트 할당 시간이 선택된 이벤트 목록에 추가됩니다.

+
** 나
+
현재 로그인한 사용자에게 이벤트를 할당합니다.

** 다른 사용자
+
이벤트를 다른 사용자에게 할당하거나 재할당할 수 있는 소유자 지정 대화 상자를 표시합니다. 소유권 필드를 비워 두어 이벤트 할당을 해제할 수도 있습니다.



* *확인*
+
선택된 이벤트를 확인합니다.

+
이벤트를 승인하면 선택한 이벤트 목록에 사용자 이름과 승인 시간이 추가됩니다. 이벤트를 승인한 경우 해당 이벤트를 관리할 책임이 있습니다.

+
[NOTE]
====
정보 이벤트를 승인할 수 없습니다.

====
* *해결됨으로 표시*
+
이벤트 상태를 해결됨으로 변경할 수 있습니다.

+
이벤트를 해결하면 선택한 이벤트 목록에 사용자 이름과 해결 시간이 추가됩니다. 이벤트에 대한 시정 조치를 완료한 후에는 해당 이벤트를 해결됨으로 표시해야 합니다.

* *알림 추가*
+
선택한 이벤트에 대한 알림을 추가할 수 있는 '알림 추가' 대화 상자가 표시됩니다.

* *보고서*
+
현재 이벤트 보기의 세부 정보를 쉼표로 구분된 값(.csv) 파일 또는 PDF 문서로 내보낼 수 있습니다.

* *열 선택기 표시/숨기기*
+
페이지에 표시할 열을 선택하고 표시 순서를 지정할 수 있습니다.





[[events-list]]
== 이벤트 목록

발생한 시간을 기준으로 정렬된 모든 이벤트의 세부 정보를 표시합니다.

기본적으로 모든 활성 이벤트 보기가 표시되며, 여기에는 지난 7일 동안 발생하고 영향 수준이 사고 또는 위험인 신규 및 확인된 이벤트가 표시됩니다.

* *트리거된 시간*
+
이벤트가 생성된 시간.

* *심각도*
+
이벤트 심각도: 심각(image:../media/sev_critical_um60.png[""]), 오류(image:../media/sev_error_um60.png[""]), 경고(image:../media/sev_warning_um60.png[""]) 및 정보(image:../media/sev_information_um60.gif[""]).

* *상태*
+
이벤트 상태: 신규, 승인됨, 해결됨 또는 더 이상 사용되지 않음.

* *영향 수준*
+
이벤트 영향 수준: 사고, 위험, 이벤트 또는 업그레이드.

* *영향 범위*
+
이벤트 영향 영역: 가용성, 용량, 성능, 보호, 구성 또는 보안.

* *이름*
+
이벤트 이름입니다. 이 이름을 선택하면 해당 이벤트의 상세 정보 페이지가 표시됩니다.

* *소스*
+
이벤트가 발생한 오브젝트의 이름입니다. 이 이름을 선택하여 해당 오브젝트의 상태 또는 성능 세부 정보 페이지를 표시할 수 있습니다.

+
공유 QoS 정책 위반이 발생하면 이 필드에는 가장 많은 IOPS 또는 MB/s를 소비하는 워크로드 오브젝트만 표시됩니다. 이 정책을 사용하는 추가 워크로드는 이벤트 세부 정보 페이지에 표시됩니다.

* *소스 유형*
+
이벤트가 연결된 오브젝트 유형(예: Storage VM, 볼륨 또는 Qtree)입니다.

* *담당자*
+
이벤트가 할당된 사용자의 이름입니다.

* *이벤트 발생 지점*
+
이벤트가 "Active IQ Portal"에서 발생했는지 아니면 "Active IQ Unified Manager"에서 직접 발생했는지 여부.

* *주석 이름*
+
스토리지 오브젝트에 할당된 주석의 이름입니다.

* *참고*
+
이벤트에 추가된 메모의 수.

* *미결제 일수*
+
해당 이벤트가 처음 발생한 이후 경과된 일수입니다.

* *할당된 시간*
+
이벤트가 사용자에게 할당된 이후 경과된 시간입니다. 경과 시간이 일주일을 초과하면 이벤트가 사용자에게 할당된 시점의 타임스탬프가 표시됩니다.

* *확인자*
+
이벤트를 확인한 사용자의 이름입니다. 이벤트가 확인되지 않은 경우 이 필드는 비어 있습니다.

* *확인된 시간*
+
이벤트가 승인된 이후 경과된 시간입니다. 경과 시간이 일주일을 초과하면 이벤트가 승인된 시점의 타임스탬프가 표시됩니다.

* *해결 담당자*
+
이벤트를 해결한 사용자의 이름입니다. 이벤트가 해결되지 않은 경우 이 필드는 비어 있습니다.

* *해결 시간*
+
이벤트가 해결된 이후 경과된 시간입니다. 경과 시간이 일주일을 초과하는 경우, 이벤트가 해결된 시점의 타임스탬프가 표시됩니다.

* *폐기 시간*
+
이벤트 상태가 더 이상 유효하지 않게 된 시점.
