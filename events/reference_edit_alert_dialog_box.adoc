= Active IQ Unified Manager에서 알림 속성 편집
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
알림과 연결된 리소스, 이벤트, 스크립트, 알림 옵션 등 알림 속성을 편집할 수 있습니다.



[[name]]
== 이름

이 영역에서는 알림의 이름과 설명을 편집할 수 있습니다.

* *알림 이름*
+
알림 이름을 편집할 수 있습니다.

* *알림 설명*
+
경고에 대한 설명을 지정할 수 있습니다.

* *경보 상태*
+
이 기능을 사용하면 알림을 활성화하거나 비활성화할 수 있습니다.





[[resources]]
== 리소스

이 영역에서는 알림을 트리거할 개별 리소스를 선택하거나 동적 규칙에 따라 리소스를 그룹화할 수 있습니다. 드롭다운 목록에서 리소스 유형을 선택하여 리소스를 검색하거나 정확한 리소스 이름을 지정하여 특정 리소스를 표시할 수 있습니다.

* *포함*
+
이 기능을 사용하면 알림을 트리거할 리소스를 포함할 수 있습니다. 텍스트 문자열을 지정하여 해당 문자열과 일치하는 리소스를 그룹화하고, 이 그룹을 알림에 포함되도록 선택할 수 있습니다. 예를 들어, 이름에 "`vol0`" 문자열이 포함된 모든 볼륨을 그룹화할 수 있습니다.

* *제외*
+
이 기능을 사용하면 알림을 발생시키지 않으려는 리소스를 제외할 수 있습니다. 예를 들어 이름에 "`xyz`" 문자열이 포함된 모든 볼륨을 제외할 수 있습니다.

+
[NOTE]
====
제외 탭은 특정 리소스 유형의 모든 리소스를 선택한 경우에만 표시됩니다(예: +<<All Volumes>>+ 또는 +<<All Volumes whose name contains 'xyz'>>+).

====




[[events]]
== 이벤트

이 영역에서는 알림을 발생시킬 이벤트를 선택할 수 있습니다. 특정 심각도에 따라 또는 일련의 이벤트에 대해 알림을 발생시킬 수 있습니다.

* *이벤트 심각도*
+
심각도 유형(심각, 오류 또는 경고)에 따라 이벤트를 선택할 수 있습니다.

* *이벤트 이름 포함*
+
이름에 지정된 문자가 포함된 이벤트를 선택할 수 있습니다.





[[actions]]
== 작업

이 영역에서는 알림 방법과 알림 빈도를 지정할 수 있습니다.

* *이 사용자에게 알림*
+
이메일 주소 또는 사용자 이름을 수정하거나, 알림을 받을 새 이메일 주소 또는 사용자 이름을 지정할 수 있습니다.

* *알림 빈도*
+
이벤트가 승인되거나 해결되거나 더 이상 사용되지 않는 상태로 전환될 때까지 관리 서버가 알림을 보내는 빈도를 편집할 수 있습니다.

+
다음과 같은 알림 방법을 선택할 수 있습니다:

+
** 한 번만 알림
** 지정된 빈도로 알림
** 지정된 시간 범위 내에서 지정된 빈도로 알림을 보냅니다


* *SNMP 트랩을 발생시키십시오*
+
이 기능을 사용하면 SNMP 트랩을 전역적으로 구성된 SNMP 호스트로 보낼지 여부를 지정할 수 있습니다.

* *스크립트 실행*
+
이 기능을 사용하면 알림에 스크립트를 연결할 수 있습니다. 이 스크립트는 알림이 생성될 때 실행됩니다.
