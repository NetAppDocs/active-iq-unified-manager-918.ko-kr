= Active IQ Unified Manager의 이벤트 설정 페이지에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이벤트 설정 페이지에는 비활성화된 이벤트 목록이 표시되며, 관련 오브젝트 유형 및 이벤트 심각도 등의 정보를 제공합니다. 또한 이벤트를 전체적으로 비활성화하거나 활성화하는 등의 작업을 수행할 수 있습니다.

이 페이지는 애플리케이션 관리자 또는 스토리지 관리자 역할이 있는 경우에만 액세스할 수 있습니다.



[[command-buttons]]
== 명령 버튼

명령 버튼을 사용하면 선택한 이벤트에 대해 다음과 같은 작업을 수행할 수 있습니다:

* *비활성화*
+
이벤트 비활성화 대화 상자를 실행합니다. 이 대화 상자를 사용하여 이벤트를 비활성화할 수 있습니다.

* *활성화*
+
이전에 비활성화했던 선택한 이벤트를 활성화합니다.

* *업로드 규칙*
+
업로드 규칙 대화 상자를 시작하여 외부 네트워크 액세스가 없는 사이트에서 Active IQ 규칙 파일을 Unified Manager에 수동으로 업로드할 수 있도록 합니다. 이 규칙은 클러스터 AutoSupport 메시지에 대해 실행되어 Active IQ 플랫폼에서 정의한 시스템 구성, 케이블링, 모범 사례 및 가용성에 대한 이벤트를 생성합니다.

* *EMS 이벤트 구독하기*
+
EMS 이벤트 구독 대화 상자를 실행하면 모니터링 중인 클러스터에서 특정 이벤트 관리 시스템(EMS) 이벤트를 구독하여 수신할 수 있습니다. EMS는 클러스터에서 발생하는 이벤트에 대한 정보를 수집합니다. 구독한 EMS 이벤트에 대한 알림이 수신되면 적절한 심각도의 Unified Manager 이벤트가 생성됩니다.





[[list-view]]
== 목록 보기

목록 보기에서는 비활성화된 이벤트에 대한 정보가 표 형식으로 표시됩니다. 열 필터를 사용하여 표시되는 데이터를 사용자 지정할 수 있습니다.

* *이벤트*
+
비활성화된 이벤트의 이름을 표시합니다.

* *심각도*
+
이벤트의 심각도를 표시합니다. 심각도는 심각, 오류, 경고 또는 정보일 수 있습니다.

* *소스 유형*
+
이벤트가 생성된 소스 유형을 표시합니다.
