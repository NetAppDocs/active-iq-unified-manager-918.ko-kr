= Active IQ Unified Manager의 이벤트 심각도 유형에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
각 이벤트는 심각도 유형과 연결되어 있어 즉각적인 시정 조치가 필요한 이벤트의 우선순위를 정하는 데 도움이 됩니다.

* *치명적*
+
문제가 발생했으며, 즉시 시정 조치를 취하지 않으면 서비스 중단으로 이어질 수 있습니다.

+
성능에 중요한 이벤트는 사용자 정의 임계값에서만 전송됩니다.

* *오류*
+
해당 이벤트 소스는 여전히 작동 중이지만, 서비스 중단을 방지하기 위해 시정 조치가 필요합니다.

* *경고*
+
이벤트 소스에서 사용자가 알아야 할 문제가 발생했거나, 클러스터 오브젝트의 성능 카운터가 정상 범위를 벗어났으므로 위험 심각도에 도달하지 않도록 모니터링해야 합니다. 이 정도의 심각도를 가진 이벤트는 서비스 중단을 유발하지 않으며, 즉각적인 조치가 필요하지 않을 수 있습니다.

+
성능 경고 이벤트는 사용자 정의, 시스템 정의 또는 동적 임계값에 따라 전송됩니다.

* *정보*
+
이 이벤트는 새 오브젝트가 발견되거나 사용자 작업이 수행될 때 발생합니다. 예를 들어, 스토리지 오브젝트가 삭제되거나 구성이 변경될 때 심각도 유형이 정보인 이벤트가 생성됩니다.

+
ONTAP에서 구성 변경을 감지하면 정보 이벤트가 직접 전송됩니다.
