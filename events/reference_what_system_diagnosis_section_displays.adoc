= Active IQ Unified Manager의 시스템 진단에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이벤트 세부 정보 페이지의 시스템 진단 섹션에는 해당 이벤트의 원인이 되었을 수 있는 문제를 진단하는 데 도움이 되는 정보가 제공됩니다.

이 영역은 일부 이벤트에서만 표시됩니다.

일부 성능 이벤트는 트리거된 특정 이벤트와 관련된 차트를 제공합니다. 일반적으로 여기에는 지난 10일간의 IOPS 또는 MBps 차트와 지연 시간 차트가 포함됩니다. 이러한 방식으로 배열하면 이벤트가 활성 상태일 때 어떤 스토리지 구성 요소가 지연 시간에 가장 큰 영향을 미치는지 또는 지연 시간의 영향을 받는지 확인할 수 있습니다.

동적 성능 이벤트의 경우 다음 차트가 표시됩니다:

* 워크로드 지연 시간 - 경합 중인 구성 요소에서 상위 피해자, 가해자 또는 샤크 워크로드의 지연 시간 기록을 표시합니다.
* 워크로드 활동 - 경합 중인 클러스터 구성 요소의 워크로드 사용량에 대한 세부 정보를 표시합니다.
* 리소스 활동 - 경합 중인 클러스터 구성 요소의 과거 성능 통계를 표시합니다.


일부 클러스터 구성 요소가 경합하는 경우 다른 차트가 표시됩니다.

다른 이벤트는 시스템이 스토리지 오브젝트에서 수행 중인 분석 유형에 대한 간략한 설명을 제공합니다. 경우에 따라 하나 이상의 줄이 표시될 수 있습니다. 여러 성능 카운터를 분석하는 시스템 정의 성능 정책의 경우 분석된 각 구성 요소마다 한 줄씩 표시됩니다. 이 시나리오에서는 진단 옆에 녹색 또는 빨간색 아이콘이 표시되어 해당 특정 진단에서 문제가 발견되었는지 여부를 나타냅니다.
