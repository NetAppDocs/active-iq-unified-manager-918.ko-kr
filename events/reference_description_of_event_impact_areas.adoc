= Active IQ Unified Manager의 이벤트 영향 영역에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이벤트는 6가지 영향 영역(가용성, 용량, 구성, 성능, 보호 및 보안)으로 분류되므로 사용자는 자신이 책임지는 이벤트 유형에 집중할 수 있습니다.

* *가용성*
+
가용성 이벤트는 스토리지 오브젝트가 오프라인 상태가 되거나, 프로토콜 서비스가 중단되거나, 스토리지 페일오버에 문제가 발생하거나, 하드웨어에 문제가 발생할 경우 알려줍니다.

* *용량*
+
용량 이벤트는 애그리게이트, 볼륨, LUN 또는 네임스페이스가 크기 임계값에 근접하거나 도달한 경우, 또는 증가율이 환경에 비해 비정상적인 경우 알려줍니다.

* *구성*
+
구성 이벤트는 스토리지 오브젝트의 검색, 삭제, 추가, 제거 또는 이름 변경에 대한 정보를 제공합니다. 구성 이벤트는 영향 수준이 이벤트이고 심각도 유형이 정보입니다.

* *성능*
+
성능 이벤트는 모니터링 대상 스토리지 오브젝트의 데이터 저장 입력 또는 검색 속도에 부정적인 영향을 미칠 수 있는 클러스터의 리소스, 구성 또는 활동 상태를 알려줍니다.

* *보호*
+
보호 이벤트는 SnapMirror 관계, 대상 용량 문제, SnapVault 관계 문제 또는 보호 작업 문제와 관련된 인시던트나 위험을 알려줍니다. 보조 볼륨 및 보호 관계를 호스팅하는 모든 ONTAP 오브젝트(특히 애그리게이트, 볼륨 및 SVM)는 보호 영향 영역으로 분류됩니다.

* *보안*
+
보안 이벤트는  https://www.netapp.com/pdf.html?item=/media/10674-tr4569pdf.pdf["NetApp ONTAP 9 보안 강화 가이드"^]에 정의된 매개변수를 기반으로 ONTAP 클러스터, 스토리지 가상 머신(SVM) 및 볼륨의 보안 수준을 알려줍니다.

+
또한 이 영역에는 Active IQ 플랫폼에서 보고되는 업그레이드 이벤트가 포함됩니다.
