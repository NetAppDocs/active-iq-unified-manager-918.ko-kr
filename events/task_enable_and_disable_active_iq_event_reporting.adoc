= Active IQ Unified Manager에서 Active IQ 이벤트 보고 활성화 및 비활성화
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ 플랫폼 이벤트는 기본적으로 Unified Manager 사용자 인터페이스에 생성되어 표시됩니다. 이러한 이벤트에 "노이즈"가 너무 많다고 느끼거나 Unified Manager에서 이러한 이벤트를 보고 싶지 않은 경우 이벤트 생성을 비활성화할 수 있습니다. 이러한 알림 수신을 재개하려는 경우 나중에 다시 활성화할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 역할이 있어야 합니다.

이 기능을 비활성화하면 Unified Manager는 Active IQ 플랫폼 이벤트를 즉시 수신하지 않게 됩니다.

이 기능을 활성화하면 Unified Manager는 클러스터의 시간대를 기준으로 자정 직후부터 Active IQ 플랫폼 이벤트를 수신하기 시작합니다. 시작 시간은 Unified Manager가 각 클러스터로부터 AutoSupport 메시지를 수신하는 시점을 기준으로 합니다.

.단계
. 왼쪽 탐색 창에서 *일반* > *기능 설정*을 클릭합니다.
. *기능 설정* 페이지에서 다음 옵션 중 하나를 선택하여 Active IQ 플랫폼 이벤트를 비활성화 또는 활성화합니다:
+
|===
| 원하신다면... | 그런 다음 이렇게 하십시오... 


 a| 
Active IQ 플랫폼 이벤트 비활성화
 a| 
*Active IQ Portal 이벤트* 패널에서 슬라이더 버튼을 왼쪽으로 이동합니다.



 a| 
Active IQ 플랫폼 이벤트를 활성화합니다.
 a| 
*Active IQ Portal 이벤트* 패널에서 슬라이더 버튼을 오른쪽으로 이동합니다.

|===
