= Active IQ Unified Manager에서 성능 이벤트에 대한 알림 추가
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager에서 수신하는 다른 이벤트와 마찬가지로 개별 성능 이벤트에 대한 알림을 구성할 수 있습니다. 또한 모든 성능 이벤트를 동일하게 처리하고 동일한 담당자에게 이메일을 보내려면 중요 또는 경고 성능 이벤트가 발생할 때 알림을 받도록 단일 알림을 생성할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

아래 예시는 모든 중요 지연 시간, IOPS 및 MBps 이벤트에 대한 이벤트를 생성하는 방법을 보여줍니다. 이와 동일한 방법을 사용하여 모든 성능 카운터에서 이벤트를 선택하고 모든 경고 이벤트에 대해서도 이벤트를 생성할 수 있습니다.

.단계
. 왼쪽 탐색 창에서 *스토리지 관리* > *알림 설정*을 클릭합니다.
. *알림 설정* 페이지에서 *추가*를 클릭합니다.
. *경고 추가* 대화 상자에서 *이름*을 클릭하고 경고의 이름과 설명을 입력합니다.
. *리소스* 페이지에서 어떤 리소스도 선택하지 마십시오.
+
특정 리소스가 선택되지 않았으므로 해당 이벤트가 수신되는 모든 클러스터, 애그리게이트, 볼륨 등에 경고가 적용됩니다.

. *이벤트*를 클릭하고 다음 작업을 수행하십시오:
+
.. 이벤트 심각도 목록에서 *심각*을 선택합니다.
.. 이벤트 이름 포함 필드에 *`latency`*를 입력한 다음 화살표를 클릭하여 일치하는 모든 이벤트를 선택합니다.
.. 이벤트 이름 포함 필드에 *`iops`*를 입력한 다음 화살표를 클릭하여 일치하는 모든 이벤트를 선택합니다.
.. 이벤트 이름 포함 필드에 *`mbps`*를 입력한 다음 화살표를 클릭하여 일치하는 모든 이벤트를 선택합니다.


. *작업*을 클릭한 다음 *알림을 받을 사용자* 필드에서 알림 이메일을 받을 사용자의 이름을 선택하십시오.
. SNMP 트랩 발행 및 스크립트 실행을 위해 이 페이지의 다른 옵션을 구성하십시오.
. *저장*을 클릭합니다.
