= Active IQ Unified Manager의 이벤트 영향 수준에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
각 이벤트는 즉각적인 수정 조치가 필요한 이벤트의 우선 순위를 지정하는 데 도움이 되도록 영향 수준(인시던트, 위험, 이벤트 또는 업그레이드)과 연결됩니다.

* *인시던트*
+
인시던트란 클러스터가 클라이언트에 데이터 제공을 중단하고 데이터 저장 공간이 부족해지는 등의 문제를 야기할 수 있는 일련의 이벤트를 의미합니다. 영향 수준이 '인시던트'인 이벤트는 가장 심각합니다. 서비스 중단을 방지하기 위해 즉각적인 시정 조치를 취해야 합니다.

* *위험*
+
위험이란 클러스터가 클라이언트에게 데이터 제공을 중단하고 데이터 저장 공간이 부족해지는 상황을 초래할 수 있는 일련의 이벤트를 의미합니다. 영향 수준이 위험인 이벤트는 서비스 중단을 야기할 수 있습니다. 시정 조치가 필요할 수 있습니다.

* *이벤트*
+
이벤트는 스토리지 오브젝트 및 해당 속성의 상태 변화입니다. 영향 수준이 이벤트인 이벤트는 정보 제공용이며 수정 조치가 필요하지 않습니다.

* *업그레이드*
+
업그레이드 이벤트는 Active IQ 플랫폼에서 보고되는 특정 유형의 이벤트입니다. 이러한 이벤트는 ONTAP 소프트웨어, 노드 펌웨어 또는 운영 체제 소프트웨어(보안 권고 사항의 경우) 업그레이드가 필요한 문제를 나타냅니다. 일부 문제에 대해서는 즉각적인 시정 조치가 필요할 수 있지만, 다른 문제는 다음 정기 유지 보수 시점까지 기다릴 수 있습니다.
