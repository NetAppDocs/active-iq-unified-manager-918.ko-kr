= 지원되는 Active IQ Unified Manager CLI 명령에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 관리자로서 CLI 명령을 사용하여 클러스터, 애그리게이트, 볼륨, qtree, LUN 등 스토리지 오브젝트에 대한 쿼리를 수행할 수 있습니다. CLI 명령을 사용하여 Unified Manager 내부 데이터베이스와 ONTAP 데이터베이스를 쿼리할 수 있습니다. 또한 작업 시작 또는 종료 시 실행되거나 경고가 트리거될 때 실행되는 스크립트에서 CLI 명령을 사용할 수도 있습니다.

모든 명령 앞에는 반드시 명령어 `um cli login`와 인증을 위한 유효한 사용자 이름 및 비밀번호를 입력해야 합니다.


NOTE: _um run_ 명령어를 실행하려면 계정에 _console_ 애플리케이션 접근 권한이 있는지 확인하십시오.

|===
| CLI 명령 | 설명 | 출력 


 a| 
`um cli login -u <username> [-p <password>]`
 a| 
CLI에 로그인합니다. 보안상의 이유로 "-u" 옵션 뒤에는 사용자 이름만 입력해야 합니다. 이렇게 사용하면 암호를 입력하라는 메시지가 표시되며, 암호는 기록이나 프로세스 테이블에 저장되지 않습니다. 로그인 후 3시간이 지나면 세션이 만료되므로 다시 로그인해야 합니다.
 a| 
해당 메시지를 표시합니다.



 a| 
`um cli logout`
 a| 
CLI에서 로그아웃합니다.
 a| 
해당 메시지를 표시합니다.



 a| 
`um help`
 a| 
1단계 하위 명령을 모두 표시합니다.
 a| 
1단계 하위 명령을 모두 표시합니다.



 a| 
`um run cmd [ -t <timeout> ] <cluster> <command>`
 a| 
하나 이상의 호스트에서 명령을 실행하는 가장 간단한 방법입니다. 주로 ONTAP에서 작업을 가져오거나 수행하기 위한 경고 스크립팅에 사용됩니다. 선택적 타임아웃 인수는 클라이언트에서 명령이 완료될 때까지의 최대 시간 제한(초)을 설정합니다. 기본값은 0(무한 대기)입니다.
 a| 
ONTAP에서 수신한 대로입니다.



 a| 
`um run query <sql command>`
 a| 
SQL 쿼리를 실행합니다. 데이터베이스에서 데이터를 읽는 쿼리만 허용됩니다. 업데이트, 삽입 또는 삭제 작업은 지원되지 않습니다.
 a| 
결과는 표 형식으로 표시됩니다. 빈 세트가 반환되거나 구문 오류 또는 잘못된 요청이 있는 경우 적절한 오류 메시지가 표시됩니다.



 a| 
`um datasource add -u <username> -P <password> [ -t <protocol> ] [ -p <port> ] <hostname-or-ip>`
 a| 
관리되는 스토리지 시스템 목록에 데이터소스를 추가합니다. 데이터소스는 스토리지 시스템과의 연결 방식을 정의합니다. 데이터소스를 추가할 때는 -u(사용자 이름) 및 -P(암호) 옵션을 반드시 지정해야 합니다. -t(프로토콜) 옵션은 클러스터와의 통신에 사용되는 프로토콜(http 또는 https)을 지정합니다. 프로토콜을 지정하지 않으면 두 프로토콜 모두 시도됩니다. -p(포트) 옵션은 클러스터와의 통신에 사용되는 포트를 지정합니다. 포트를 지정하지 않으면 해당 프로토콜의 기본값으로 시도됩니다. 이 명령은 스토리지 관리자만 실행할 수 있습니다.
 a| 
사용자에게 인증서를 수락할지 묻는 메시지를 표시하고 해당 메시지를 출력합니다.



 a| 
`um datasource list [ <datasource-id>]`
 a| 
관리형 스토리지 시스템의 데이터 소스를 표시합니다.
 a| 
다음 값을 표 형식으로 표시합니다: `ID Address Port, Protocol Acquisition Status, Analysis Status, Communication status, Acquisition Message, and Analysis Message`.



 a| 
`um datasource modify [ -h <hostname-or-ip> ] [ -u <username> ] [ -P <password> ] [ -t <protocol> ] [ -p <port> ] <datasource-id>`
 a| 
하나 이상의 데이터 소스 옵션을 수정합니다. 스토리지 관리자만 실행할 수 있습니다.
 a| 
해당 메시지를 표시합니다.



 a| 
`um datasource remove <datasource-id>`
 a| 
Unified Manager에서 데이터 소스(클러스터)를 제거합니다.
 a| 
해당 메시지를 표시합니다.



 a| 
`um option list [ <option> .. ]`
 a| 
set 명령어를 사용하여 구성할 수 있는 모든 옵션을 나열합니다.
 a| 
다음 값을 표 형식으로 표시합니다: `Name, Value, Default Value, and Requires Restart.`



 a| 
`um option set <option-name>=<option-value> [ <option-name>=<option-value> ... ]`
 a| 
하나 이상의 옵션을 설정합니다. 이 명령은 스토리지 관리자만 실행할 수 있습니다.
 a| 
해당 메시지를 표시합니다.



 a| 
`um version`
 a| 
Unified Manager 소프트웨어 버전을 표시합니다.
 a| 
`Version ("9.6")`



 a| 
`um lun list [-q] [ -ObjectType <object-id>]`
 a| 
지정된 오브젝트를 필터링한 후 LUN을 나열합니다. -q는 헤더를 표시하지 않도록 모든 명령에 적용할 수 있습니다. ObjectType은 lun, qtree, cluster, volume, 할당량 또는 svm일 수 있습니다.

예를 들면 다음과 같습니다.

*`um lun list -cluster 1`*

이 예에서 "-cluster"는 objectType이고 "1"은 objectId입니다. 이 명령은 ID가 1인 클러스터 내의 모든 LUN을 나열합니다.
 a| 
다음 값을 표 형식으로 표시합니다: `ID and LUN path.`



 a| 
`um svm list [-q] [ -ObjectType <object-id>]`
 a| 
지정된 오브젝트에 대해 필터링한 후 스토리지 VM을 나열합니다. ObjectType은 lun, qtree, cluster, volume, 할당량 또는 svm일 수 있습니다.

예를 들면 다음과 같습니다.

*`um svm list -cluster 1`*

이 예에서 "-cluster"는 objectType이고 "1"은 objectId입니다. 이 명령은 ID가 1인 클러스터 내의 모든 스토리지 VM을 나열합니다.
 a| 
다음 값을 표 형식으로 표시합니다: `Name and Cluster ID.`



 a| 
`um qtree list [-q] [ -ObjectType <object-id>]`
 a| 
지정된 오브젝트를 기준으로 필터링한 후 qtree를 나열합니다. -q는 헤더를 표시하지 않기 위해 모든 명령에 적용할 수 있습니다. ObjectType은 lun, qtree, cluster, volume, 할당량 또는 svm일 수 있습니다.

예를 들면 다음과 같습니다.

*`um qtree list -cluster 1`*

이 예에서 "-cluster"는 objectType이고 "1"은 objectId입니다. 이 명령은 ID가 1인 클러스터 내의 모든 qtree를 나열합니다.
 a| 
다음 값을 표 형식으로 표시합니다: `Qtree ID and Qtree Name.`



 a| 
`um disk list [-q] [-ObjectType <object-id>]`
 a| 
지정된 오브젝트를 필터링한 후 디스크를 나열합니다. ObjectType은 disk, aggr, node 또는 cluster일 수 있습니다.

예를 들면 다음과 같습니다.

*`um disk list -cluster 1`*

이 예에서 "-cluster"는 objectType이고 "1"은 objectId입니다. 이 명령은 ID가 1인 클러스터 내의 모든 디스크를 나열합니다.
 a| 
다음 값을 표 형식으로 표시합니다 `ObjectType and object-id`.



 a| 
`um cluster list [-q] [-ObjectType <object-id>]`
 a| 
지정된 오브젝트를 필터링한 후 클러스터를 나열합니다. ObjectType은 disk, aggr, node, cluster, lun, qtree, volume, 할당량 또는 svm일 수 있습니다.

예를 들면 다음과 같습니다.

*`um cluster list -aggr 1`*

이 예에서 "-aggr"은 objectType이고 "1"은 objectId입니다. 이 명령은 ID가 1인 애그리게이트가 속한 클러스터 목록을 표시합니다.
 a| 
다음 값을 표 형식으로 표시합니다: `Name, Full Name, Serial Number, Datasource Id, Last Refresh Time, and Resource Key`.



 a| 
`um cluster node list [-q] [-ObjectType <object-id>]`
 a| 
지정된 오브젝트를 필터링한 후 클러스터 노드를 나열합니다. ObjectType은 disk, aggr, node 또는 cluster일 수 있습니다.

예를 들면 다음과 같습니다.

*`um cluster node list -cluster 1`*

이 예에서 "-cluster"는 objectType이고 "1"은 objectId입니다. 이 명령은 ID가 1인 클러스터 내의 모든 노드를 나열합니다.
 a| 
다음 값을 표 형식으로 표시합니다 `Name and Cluster ID`.



 a| 
`um volume list [-q] [-ObjectType <object-id>]`
 a| 
지정된 오브젝트를 필터링한 후 볼륨을 나열합니다. ObjectType은(는) lun, qtree, cluster, volume, 할당량, svm 또는 aggregate일 수 있습니다.

예를 들면 다음과 같습니다.

*`um volume list -cluster 1`*

이 예에서 "-cluster"는 objectType이고 "1"은 objectId입니다. 이 명령은 ID가 1인 클러스터 내의 모든 볼륨을 나열합니다.
 a| 
다음 값을 표 형식으로 표시합니다 `Volume ID and Volume Name`.



 a| 
`um quota user list [-q] [-ObjectType <object-id>]`
 a| 
지정된 오브젝트를 필터링한 후 할당량 사용자를 나열합니다. ObjectType은 qtree, cluster, volume, 할당량 또는 svm일 수 있습니다.

예를 들면 다음과 같습니다.

*`um quota user list -cluster 1`*

이 예에서 "-cluster"는 objectType이고 "1"은 objectId입니다. 이 명령은 ID가 1인 클러스터 내의 모든 할당량 사용자를 나열합니다.
 a| 
다음 값을 표 형식으로 표시합니다 `ID, Name, SID and Email`.



 a| 
`um aggr list [-q] [-ObjectType <object-id>]`
 a| 
지정된 오브젝트를 기준으로 필터링한 후 애그리게이트를 나열합니다. ObjectType은 disk, aggr, node, cluster 또는 volume일 수 있습니다.

예를 들면 다음과 같습니다.

*`um aggr list -cluster 1`*

이 예에서 "-cluster"는 objectType이고 "1"은 objectId입니다. 이 명령은 ID가 1인 클러스터 내의 모든 애그리게이트를 나열합니다.
 a| 
다음 값을 표 형식으로 표시합니다 `Aggr ID, and Aggr Name`.



 a| 
`um event ack <event-ids>`
 a| 
하나 이상의 이벤트를 확인합니다.
 a| 
해당 메시지를 표시합니다.



 a| 
`um event resolve <event-ids>`
 a| 
하나 이상의 이벤트를 해결합니다.
 a| 
해당 메시지를 표시합니다.



 a| 
`um event assign -u <username> <event-id>`
 a| 
사용자에게 이벤트를 할당합니다.
 a| 
해당 메시지를 표시합니다.



 a| 
`um event list [ -s <source> ] [ -S <event-state-filter-list>.. ] [ <event-id> .. ]`
 a| 
시스템 또는 사용자가 생성한 이벤트를 나열합니다. 소스, 상태 및 ID를 기준으로 이벤트를 필터링합니다.
 a| 
다음 값을 표 형식으로 표시합니다 `Source, Source type, Name, Severity, State, User and Timestamp`.



 a| 
`um backup restore -f <backup_file_path_and_name>`
 a| 
.7z 파일을 사용하여 MySQL 데이터베이스 백업을 복원합니다.
 a| 
해당 메시지를 표시합니다.

|===
