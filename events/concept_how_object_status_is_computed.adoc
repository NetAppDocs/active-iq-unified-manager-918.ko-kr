= Active IQ Unified Manager 오브젝트 상태를 계산하는 방법
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
오브젝트 상태는 현재 '새로 생성됨' 또는 '승인됨' 상태인 가장 심각한 이벤트에 따라 결정됩니다. 예를 들어, 오브젝트 상태가 '오류'인 경우 해당 오브젝트의 이벤트 중 하나가 '오류' 심각도 유형을 가집니다. 시정 조치가 완료되면 이벤트 상태는 '해결됨'으로 변경됩니다.
