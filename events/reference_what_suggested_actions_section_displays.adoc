= Active IQ Unified Manager의 권장 조치에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이벤트 세부 정보 페이지의 권장 조치 섹션에서는 이벤트의 가능한 원인을 제공하고 사용자가 스스로 이벤트를 해결할 수 있도록 몇 가지 조치를 제안합니다. 이러한 권장 조치는 이벤트 유형 또는 초과된 임계값 유형에 따라 맞춤 설정됩니다.

이 영역은 일부 이벤트 유형에 한해서만 표시됩니다.

경우에 따라 페이지에 *도움말* 링크가 제공되어 특정 작업을 수행하는 방법에 대한 지침을 포함하여 여러 권장 작업에 대한 추가 정보를 참조할 수 있습니다. 일부 작업에는 Unified Manager, ONTAP System Manager, OnCommand Workflow Automation, ONTAP CLI 명령 또는 이러한 툴의 조합을 사용하는 것이 포함될 수 있습니다.

여기에 제시된 조치는 이 이벤트를 해결하기 위한 지침으로만 간주해야 합니다. 이 이벤트를 해결하기 위한 조치는 사용 환경에 맞춰 결정해야 합니다.

오브젝트와 이벤트를 더 자세히 분석하려면 *워크로드 분석* 버튼을 클릭하여 워크로드 분석 페이지를 표시하십시오.

Unified Manager가 철저하게 진단하고 단일 해결 방법을 제공할 수 있는 특정 이벤트가 있습니다. 사용 가능한 경우 이러한 해결 방법은 *Fix It* 버튼과 함께 표시됩니다. 이 버튼을 클릭하여 Unified Manager가 이벤트를 유발하는 문제를 해결하도록 하십시오.

Active IQ 플랫폼 이벤트의 경우, 이 섹션에는 문제 및 가능한 해결 방법을 설명하는 NetApp 기술 자료 문서에 대한 링크가 포함될 수 있습니다(사용 가능한 경우). 외부 네트워크 액세스가 없는 사이트에서는 기술 자료 문서의 PDF가 로컬에서 열립니다. 이 PDF는 Unified Manager 인스턴스에 수동으로 다운로드하는 규칙 파일의 일부입니다.
