= Active IQ Unified Manager의 동적 성능 이벤트에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
동적 성능 이벤트의 경우, 이벤트 세부 정보 페이지의 시스템 진단 섹션에는 경합 중인 클러스터 구성 요소의 지연 시간 또는 사용량이 가장 높은 상위 워크로드가 나열됩니다.

성능 통계는 성능 이벤트가 감지된 시점부터 해당 이벤트가 마지막으로 분석된 시점까지의 데이터를 기반으로 합니다. 또한 차트에는 경합 중인 클러스터 구성 요소에 대한 과거 성능 통계도 표시됩니다.

예를 들어, 구성 요소 사용률이 높은 워크로드를 식별하여 사용률이 낮은 구성 요소로 이동할 워크로드를 결정할 수 있습니다. 워크로드를 이동하면 현재 구성 요소의 작업량이 줄어들어 구성 요소의 경합이 해소될 수 있습니다. 이 섹션 상단에는 이벤트가 감지되고 마지막으로 분석된 시간 및 날짜 범위가 표시됩니다. 활성 이벤트(새 이벤트 또는 승인된 이벤트)의 경우 마지막 분석 시간이 업데이트됩니다.

지연 시간 및 활동 차트에서 마우스 커서를 차트 위로 가져가면 상위 워크로드 이름이 표시됩니다. 차트 오른쪽에 있는 워크로드 유형 메뉴를 클릭하면 _sharks_, _bullies_ 또는 _victims_ 등 이벤트에서의 역할에 따라 워크로드를 정렬할 수 있으며, 경합 중인 클러스터 구성 요소에서의 지연 시간 및 사용량에 대한 세부 정보를 표시합니다. 실제 값과 예상 값을 비교하여 워크로드가 예상 지연 시간 또는 사용량 범위를 벗어난 시점을 확인할 수 있습니다. 자세한 내용은 link:..//performance-checker/concept_types_of_workloads_monitored_by_unified_manager.html["Unified Manager에서 모니터링하는 워크로드 유형"]을(를) 참조하십시오.

[NOTE]
====
지연 시간의 최대 편차를 기준으로 정렬할 때 시스템 정의 워크로드는 표에 표시되지 않습니다. 지연 시간은 사용자 정의 워크로드에만 적용되기 때문입니다. 지연 시간 값이 매우 낮은 워크로드는 표에 표시되지 않습니다.

====
동적 성능 임계값에 대한 자세한 내용은 link:../performance-checker/concept_analyze_events_from_dynamic_performance_thresholds.html["동적 성능 임계값에서 발생하는 이벤트 분석"]을(를) 참조하십시오.

Unified Manager가 워크로드 순위를 매기고 정렬 순서를 결정하는 방법에 대한 자세한 내용은 link:../performance-checker/concept_how_um_determines_performance_impact_for_incident.html["Unified Manager가 이벤트에 대한 성능 영향을 결정하는 방법"]을(를) 참조하십시오.

그래프의 데이터는 이벤트가 마지막으로 분석된 시점으로부터 24시간 전까지의 성능 통계를 보여줍니다. 각 워크로드의 실제 값과 예상 값은 해당 워크로드가 이벤트에 관여했던 시간을 기준으로 합니다. 예를 들어, 워크로드가 이벤트 감지 후에 이벤트에 관여하게 될 경우, 해당 워크로드의 성능 통계는 이벤트 감지 시점의 값과 일치하지 않을 수 있습니다. 기본적으로 워크로드는 지연 시간의 최대 편차를 기준으로 정렬됩니다.

[NOTE]
====
Unified Manager는 5분 단위의 과거 성능 및 이벤트 데이터를 최대 30일까지만 보관하므로, 이벤트가 30일 이상 경과한 경우 성능 데이터가 표시되지 않습니다.

====
* *워크로드 정렬 열*
+
** *지연 시간 차트*
+
최근 분석에서 해당 이벤트가 워크로드의 지연 시간에 미치는 영향을 표시합니다.

** *구성 요소 사용량 열*
+
경합 중인 클러스터 구성 요소의 워크로드 사용에 대한 세부 정보를 표시합니다. 그래프에서 실제 사용량은 파란색 선으로 표시됩니다. 빨간색 막대는 감지 시간부터 마지막 분석 시간까지의 이벤트 지속 시간을 강조 표시합니다. 자세한 내용은 link:../performance-checker/reference_workload_performance_measurement_values.html["워크로드 성능 측정값"]을 참조하십시오.

+
[NOTE]
====
네트워크 구성 요소의 경우 네트워크 성능 통계는 클러스터 외부 활동에서 가져오므로 이 열은 표시되지 않습니다.

====
** *구성 요소 사용법*
+
네트워크 처리, 데이터 처리 및 애그리게이트 구성 요소의 사용률 이력(백분율) 또는 QoS 정책 그룹 구성 요소의 활동 이력(백분율)을 표시합니다. 네트워크 또는 인터커넥트 구성 요소에 대한 차트는 표시되지 않습니다. 통계를 가리키면 특정 시점의 사용량 통계를 볼 수 있습니다.

** *총 쓰기 MB/s 기록*
+
MetroCluster Resources 구성 요소에만 해당하며, MetroCluster 구성에서 파트너 클러스터로 미러링되는 모든 볼륨 워크로드에 대한 총 쓰기 처리량(MBps)을 표시합니다.

** *이벤트 기록*
+
경합 중인 구성 요소의 과거 이벤트를 나타내기 위해 빨간색으로 음영 처리된 선을 표시합니다. 더 이상 사용되지 않는 이벤트의 경우, 차트에는 선택한 이벤트가 감지되기 전과 해결된 후에 발생한 이벤트가 표시됩니다.
