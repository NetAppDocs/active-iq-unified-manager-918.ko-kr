= Active IQ Unified Manager에서 원치 않는 이벤트 비활성화
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
모든 이벤트는 기본적으로 활성화되어 있습니다. 환경에서 중요하지 않은 이벤트에 대한 알림 생성을 방지하려면 이벤트를 전체적으로 비활성화할 수 있습니다. 알림을 다시 받으려면 비활성화된 이벤트를 활성화할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

이벤트를 비활성화하면 시스템에 이전에 생성된 이벤트는 더 이상 사용되지 않는 것으로 표시되고, 해당 이벤트에 대해 구성된 알림은 트리거되지 않습니다. 비활성화된 이벤트를 활성화하면 다음 모니터링 주기부터 해당 이벤트에 대한 알림이 생성됩니다.

오브젝트에 대한 이벤트(예:  `vol offline` 이벤트)를 비활성화한 후 나중에 이벤트를 다시 활성화하면, Unified Manager는 이벤트가 비활성화된 상태일 때 오프라인 상태가 된 오브젝트에 대해 새 이벤트를 생성하지 않습니다. Unified Manager는 이벤트가 다시 활성화된 후 오브젝트 상태에 변경 사항이 있을 때만 새 이벤트를 생성합니다.

.단계
. 왼쪽 탐색 창에서 *스토리지 관리* > *이벤트 설정*을 클릭합니다.
. *이벤트 설정* 페이지에서 다음 옵션 중 하나를 선택하여 이벤트를 비활성화 또는 활성화하십시오.
+
|===
| 원하신다면... | 그런 다음 이렇게 하십시오... 


 a| 
이벤트 비활성화
 a| 
.. *비활성화*를 클릭합니다.
.. 이벤트 비활성화 대화 상자에서 이벤트 심각도를 선택합니다.
.. 일치하는 이벤트 열에서 이벤트 심각도를 기준으로 비활성화할 이벤트를 선택한 다음 오른쪽 화살표를 클릭하여 해당 이벤트를 비활성화 이벤트 열로 이동합니다.
.. *저장 후 닫기*를 클릭하십시오.
.. 비활성화한 이벤트가 이벤트 설정 페이지의 목록 보기에 표시되는지 확인하십시오.




 a| 
이벤트 활성화
 a| 
.. 활성화하려는 이벤트의 확인란을 선택하십시오.
.. *활성화*를 클릭합니다.


|===
