= Active IQ Unified Manager의 이벤트 정보 섹션에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이벤트 세부 정보 페이지의 이벤트 정보 섹션을 사용하여 이벤트 심각도, 영향 수준, 영향 영역, 이벤트 발생원 등 선택한 이벤트에 대한 세부 정보를 볼 수 있습니다.

이벤트 유형에 적용되지 않는 필드는 숨겨집니다. 다음 이벤트 세부 정보를 볼 수 있습니다.

* *이벤트 발생 시간*
+
이벤트가 생성된 시간.

* *상태*
+
이벤트 상태: 신규, 승인됨, 해결됨 또는 더 이상 사용되지 않음.

* *폐지된 사유*
+
예를 들어 문제가 해결되는 등 이벤트를 폐기하게 만든 작업입니다.

* *이벤트 기간*
+
활성(새롭고 승인된) 이벤트의 경우, 이는 감지 시점과 이벤트가 마지막으로 분석된 시점 사이의 시간입니다. 폐기된 이벤트의 경우, 이는 감지 시점과 이벤트가 해결된 시점 사이의 시간입니다.

+
이 필드는 모든 성능 이벤트에 대해 표시되며, 다른 이벤트 유형의 경우 해결되었거나 더 이상 사용되지 않는 경우에만 표시됩니다.

* *마지막 확인*
+
해당 이벤트가 마지막으로 활성화된 날짜와 시간입니다.

+
성능 이벤트의 경우, 이 필드는 이벤트가 활성화되어 있는 동안 성능 데이터가 새로 수집될 때마다 업데이트되므로 이벤트 트리거 시간보다 최신 값일 수 있습니다. 다른 유형의 이벤트는 신규 또는 승인됨 상태일 때 이 내용이 업데이트되지 않으므로 필드가 숨겨집니다.

* *심각도*
+
이벤트 심각도: 심각(image:../media/sev_critical_um60.png[""]), 오류(image:../media/sev_error_um60.png[""]), 경고(image:../media/sev_warning_um60.png[""]) 및 정보(image:../media/sev_information_um60.gif[""]).

* *영향 수준*
+
이벤트 영향 수준: 사고, 위험, 이벤트 또는 업그레이드.

* *영향 범위*
+
이벤트 영향 영역: 가용성, 용량, 성능, 보호, 구성 또는 보안.

* *소스*
+
이벤트가 발생한 오브젝트의 이름입니다.

+
공유 QoS 정책 이벤트의 세부 정보를 볼 때, 가장 많은 IOPS 또는 MBps를 소비하는 워크로드 오브젝트가 최대 3개까지 이 필드에 나열됩니다.

+
소스 이름 링크를 클릭하여 해당 오브젝트의 상태 또는 성능 세부 정보 페이지를 표시할 수 있습니다.

* *출처 주석*
+
이벤트가 연결된 오브젝트의 어노테이션 이름과 값을 표시합니다.

+
이 필드는 클러스터, SVM 및 볼륨의 상태 이벤트에 대해서만 표시됩니다.

* *소스 그룹*
+
영향을 받는 오브젝트가 속한 모든 그룹의 이름을 표시합니다.

+
이 필드는 클러스터, SVM 및 볼륨의 상태 이벤트에 대해서만 표시됩니다.

* *소스 유형*
+
이벤트가 연결된 오브젝트 유형(예: SVM, 볼륨 또는 Qtree)입니다.

* *클러스터에서*
+
이벤트가 발생한 클러스터의 이름입니다.

+
클러스터 이름 링크를 클릭하면 해당 클러스터의 상태 또는 성능 세부 정보 페이지를 표시할 수 있습니다.

* *영향을 받은 오브젝트 수*
+
이벤트의 영향을 받은 오브젝트의 수.

+
오브젝트 링크를 클릭하면 현재 이 이벤트의 영향을 받는 오브젝트가 표시된 인벤토리 페이지가 나타납니다.

+
이 필드는 성능 이벤트에 대해서만 표시됩니다.

* *영향을 받는 볼륨*
+
이 이벤트의 영향을 받는 볼륨 수.

+
이 필드는 노드 또는 애그리게이트의 성능 이벤트에 대해서만 표시됩니다.

* *트리거된 정책*
+
이벤트를 발생시킨 임계값 정책의 이름입니다.

+
마우스 커서를 정책 이름 위에 올리면 임계값 정책의 세부 정보를 볼 수 있습니다. 적응형 QoS 정책의 경우 정의된 정책, 블록 크기 및 할당 유형(할당된 공간 또는 사용된 공간)도 표시됩니다.

+
이 필드는 성능 이벤트에 대해서만 표시됩니다.

* *규칙 ID*
+
Active IQ 플랫폼 이벤트의 경우, 이는 이벤트를 생성하도록 트리거된 규칙 번호입니다.

* *승인자*
+
이벤트를 확인한 사람의 이름과 이벤트가 확인된 시간.

* *해결자*
+
이벤트를 해결한 사람의 이름과 이벤트 해결 시간.

* *담당자*
+
이벤트를 담당하도록 배정된 사람의 이름.

* *알림 설정*
+
알림에 대한 다음 정보가 표시됩니다:

+
** 선택한 이벤트와 관련된 알림이 없는 경우 *알림 추가* 링크가 표시됩니다.
+
링크를 클릭하면 알림 추가 대화 상자를 열 수 있습니다.

** 선택한 이벤트와 관련된 알림이 하나 있는 경우 알림 이름이 표시됩니다.
+
링크를 클릭하면 알림 편집 대화 상자를 열 수 있습니다.

** 선택한 이벤트와 관련된 알림이 두 개 이상인 경우, 알림 개수가 표시됩니다.
+
링크를 클릭하여 알림 설정 페이지를 열면 이러한 알림에 대한 자세한 내용을 확인할 수 있습니다.



+
비활성화된 알림은 표시되지 않습니다.

* *마지막 알림 전송*
+
가장 최근 알림이 전송된 날짜 및 시간입니다.

* *보내는 사람*
+
경고 알림을 보내는 데 사용된 메커니즘: 이메일 또는 SNMP 트랩.

* *이전 스크립트 실행*
+
경고가 발생했을 때 실행된 스크립트의 이름입니다.
