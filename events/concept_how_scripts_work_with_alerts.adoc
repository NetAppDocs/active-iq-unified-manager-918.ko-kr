= Active IQ Unified Manager에서 스크립트가 경고와 함께 작동하는 방식
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스크립트에 알림을 연결하면 Unified Manager에서 이벤트에 대한 알림이 발생할 때 스크립트가 실행됩니다. 스크립트를 사용하여 스토리지 오브젝트 관련 문제를 해결하거나 이벤트를 생성하는 스토리지 오브젝트를 식별할 수 있습니다.

Unified Manager에서 이벤트에 대한 경고가 생성되면 지정된 수신자에게 경고 이메일이 전송됩니다. 경고를 스크립트와 연결한 경우 해당 스크립트가 실행됩니다. 스크립트에 전달된 인수에 대한 자세한 내용은 경고 이메일에서 확인할 수 있습니다.

[NOTE]
====
사용자 지정 스크립트를 생성하고 특정 이벤트 유형에 대한 알림과 연결한 경우 해당 이벤트 유형에 대해 사용자 지정 스크립트에 따라 작업이 수행되며, *문제 해결* 작업은 기본적으로 관리 작업 페이지 또는 Unified Manager 대시보드에서 사용할 수 없습니다.

====
스크립트는 실행을 위해 다음 인수를 사용합니다:

* `-eventID`
* -`eventName`
* -`eventSeverity`
* -`eventSourceID`
* -`eventSourceName`
* -`eventSourceType`
* -`eventState`
* -`eventArgs`


스크립트에서 인수를 사용하여 관련 이벤트 정보를 수집하거나 스토리지 오브젝트를 수정할 수 있습니다.



[[example-for-obtaining-arguments-from-scripts]]
== 스크립트에서 인수를 얻는 예시

[listing]
----
`print "$ARGV[0] : $ARGV[1]\n"`
`print "$ARGV[7] : $ARGV[8]\n"`
----
경고가 발생하면 이 스크립트가 실행되고 다음과 같은 출력이 표시됩니다:

[listing]
----
-`eventID : 290`
-`eventSourceID : 4138`
----
