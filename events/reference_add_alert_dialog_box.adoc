= Active IQ Unified Manager의 알림 추가 대화 상자에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
특정 이벤트가 생성될 때 알림을 받도록 경고를 생성하여 문제를 신속하게 해결하고 환경에 미치는 영향을 최소화할 수 있습니다. 단일 리소스 또는 리소스 집합에 대해, 그리고 특정 심각도 유형의 이벤트에 대해 경고를 생성할 수 있습니다. 또한 경고의 알림 방법과 빈도를 지정할 수 있습니다.

애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.



[[name]]
== 이름

이 영역에서는 알림의 이름과 설명을 지정할 수 있습니다:

* *알림 이름*
+
알림 이름을 지정할 수 있습니다.

* *알림 설명*
+
경고에 대한 설명을 지정할 수 있습니다.





[[resources]]
== 리소스

이 영역에서는 알림을 트리거할 개별 리소스를 선택하거나 동적 규칙에 따라 리소스를 그룹화할 수 있습니다. _동적 규칙_은 사용자가 지정하는 텍스트 문자열을 기준으로 필터링된 리소스 집합입니다. 드롭다운 목록에서 리소스 유형을 선택하여 리소스를 검색하거나 정확한 리소스 이름을 지정하여 특정 리소스를 표시할 수 있습니다.

스토리지 오브젝트 세부 정보 페이지에서 알림을 생성하는 경우 스토리지 오브젝트가 자동으로 알림에 포함됩니다.

* *포함*
+
알림을 트리거할 리소스를 포함할 수 있습니다. 문자열과 일치하는 리소스를 그룹화하는 텍스트 문자열을 지정하고 이 그룹을 알림에 포함하도록 선택할 수 있습니다. 예를 들어, 이름에 "abc" 문자열이 포함된 모든 볼륨을 그룹화할 수 있습니다.

* *제외*
+
이 기능을 사용하면 알림을 발생시키지 않으려는 리소스를 제외할 수 있습니다. 예를 들어 이름에 "xyz" 문자열이 포함된 모든 볼륨을 제외할 수 있습니다.

+
제외 탭은 특정 리소스 유형의 모든 리소스를 선택한 경우에만 표시됩니다(예: +<<All Volumes>> 또는 <<All Volumes whose name contains 'xyz'>>+).

+
리소스가 지정한 포함 규칙과 제외 규칙을 모두 충족하는 경우 제외 규칙이 포함 규칙보다 우선 적용되어 해당 이벤트에 대한 알림이 생성되지 않습니다.





[[events]]
== 이벤트

이 영역에서는 알림을 생성할 이벤트를 선택할 수 있습니다. 특정 심각도에 따라 또는 이벤트 집합에 대해 알림을 생성할 수 있습니다.

두 개 이상의 이벤트를 선택하려면 Ctrl 키를 누른 상태에서 선택해야 합니다.

* *이벤트 심각도*
+
심각도 유형(심각, 오류 또는 경고)에 따라 이벤트를 선택할 수 있습니다.

* *이벤트 이름 포함*
+
이름에 지정된 문자가 포함된 이벤트를 선택할 수 있습니다.





[[actions]]
== 작업

이 영역에서는 알림이 발생했을 때 알림을 받을 사용자를 지정할 수 있습니다. 알림 방법과 알림 빈도도 지정할 수 있습니다.

* *이 사용자에게 알림*
+
이 기능을 사용하면 알림을 받을 사용자의 이메일 주소 또는 사용자 이름을 지정할 수 있습니다.

+
사용자에게 지정된 이메일 주소를 수정하고 편집을 위해 알림을 다시 열면, 수정된 이메일 주소가 이전에 선택한 사용자에게 더 이상 매핑되지 않기 때문에 이름 필드가 비어 있는 상태로 표시됩니다. 또한 사용자 페이지에서 선택한 사용자의 이메일 주소를 수정한 경우, 수정된 이메일 주소는 선택한 사용자에 대해 업데이트되지 않습니다.

* *알림 빈도*
+
이벤트가 승인되거나, 해결되거나, 더 이상 사용되지 않는 상태로 전환될 때까지 관리 서버가 알림을 보내는 빈도를 지정할 수 있습니다.

+
다음과 같은 알림 방법을 선택할 수 있습니다:

+
** 한 번만 알림
** 지정된 빈도로 알림
** 지정된 시간 범위 내에서 지정된 빈도로 알림을 보냅니다


* *SNMP 트랩을 발생시키십시오*
+
이 확인란을 선택하면 SNMP 트랩을 전역적으로 구성된 SNMP 호스트로 보낼지 여부를 지정할 수 있습니다.

* *스크립트 실행*
+
이 기능을 사용하면 알림에 사용자 지정 스크립트를 추가할 수 있습니다. 이 스크립트는 알림이 생성될 때 실행됩니다.

+
[NOTE]
====
사용자 인터페이스에서 이 기능을 볼 수 없는 경우 관리자가 해당 기능을 비활성화했기 때문입니다. 필요한 경우 *스토리지 관리* > *기능 설정*에서 이 기능을 활성화할 수 있습니다.

====
