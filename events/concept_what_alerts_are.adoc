= Active IQ Unified Manager의 알림에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이벤트는 지속적으로 발생하지만, Unified Manager는 지정된 필터 기준을 충족하는 이벤트에 대해서만 알림을 생성합니다. 공간 임계값 초과 또는 오브젝트 오프라인 상태 발생 시와 같이 알림을 생성할 이벤트를 선택할 수 있습니다. 또한 알림이 트리거될 때 실행될 스크립트를 알림과 연결할 수도 있습니다.

필터 기준에는 오브젝트 클래스, 이름 또는 이벤트 심각도가 포함됩니다.
