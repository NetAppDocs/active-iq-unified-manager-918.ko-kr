= Active IQ Unified Manager에서 유지보수 윈도우 중에 생성된 이벤트 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
필요한 경우 Unified Manager 유지보수 윈도우 동안 모든 스토리지 객체에 대해 생성된 이벤트를 볼 수 있습니다. 유지보수 윈도우가 완료되고 모든 시스템 리소스가 다시 실행되면 대부분의 이벤트는 '사용 중지됨' 상태로 표시됩니다.

.시작하기 전에
이벤트를 사용할 수 있으려면 최소 한 번의 유지보수 윈도우가 완료되어야 합니다.

유지보수 윈도우 중에 발생한 이벤트는 기본적으로 이벤트 관리 인벤토리 페이지에 표시되지 않습니다.

.단계
. 왼쪽 탐색 창에서 *이벤트*를 클릭합니다.
+
기본적으로 모든 활성 이벤트(새 이벤트 및 승인된 이벤트)가 이벤트 관리 인벤토리 페이지에 표시됩니다.

. 보기 창에서 *유지보수 중에 생성된 모든 이벤트* 옵션을 선택합니다.
+
지난 7일 동안 모든 유지보수 윈도우 세션과 모든 클러스터에서 발생한 이벤트 목록이 표시됩니다.

. 단일 클러스터에 여러 번의 유지보수 윈도우가 있었던 경우, *트리거 시간* 달력 아이콘을 클릭하고 보려는 유지보수 윈도우 이벤트의 기간을 선택할 수 있습니다.
