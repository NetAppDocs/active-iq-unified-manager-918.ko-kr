= Active IQ Unified Manager의 이벤트 세부 정보 페이지에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이벤트 세부 정보 페이지에서는 이벤트 심각도, 영향 수준, 영향 영역, 이벤트 소스 등 선택한 이벤트의 세부 정보를 볼 수 있습니다. 또한 문제를 해결하기 위한 가능한 해결 방법에 대한 추가 정보도 확인할 수 있습니다.

* *이벤트 이름*
+
이벤트 이름과 이벤트가 마지막으로 확인된 시간입니다.

+
비성능 이벤트의 경우, 이벤트가 새로 생성됨 또는 승인됨 상태일 때는 마지막으로 확인된 정보를 알 수 없으므로 숨겨집니다.

* *이벤트 설명*
+
이벤트에 대한 간략한 설명입니다.

+
경우에 따라 이벤트 설명에 이벤트가 트리거된 이유가 제공됩니다.

* *경합 중인 구성요소*
+
동적 성능 이벤트의 경우, 이 섹션에는 클러스터의 논리적 및 물리적 구성 요소를 나타내는 아이콘이 표시됩니다. 구성 요소가 경합 중인 경우 해당 아이콘은 원으로 둘러싸여 빨간색으로 강조 표시됩니다.

+
여기에 표시된 구성 요소에 대한 설명은 _클러스터 구성 요소 및 구성 요소 간의 경합 가능성_을 참조하십시오.



이벤트 정보, 시스템 진단 및 권장 조치 섹션은 다른 항목에서 설명합니다.

== 명령 버튼

명령 버튼을 사용하면 다음과 같은 작업을 수행할 수 있습니다:

* *메모 아이콘*
+
이벤트에 대한 메모를 추가하거나 업데이트할 수 있으며, 다른 사용자가 남긴 모든 메모를 확인할 수 있습니다.



*작업 메뉴*

* *저에게 할당*
+
이벤트를 귀하에게 할당합니다.

* *다른 사람에게 할당*
+
이벤트를 다른 사용자에게 할당하거나 재할당할 수 있는 소유자 할당 대화 상자를 엽니다.

+
사용자에게 이벤트를 할당하면 사용자의 이름과 이벤트가 할당된 시간이 선택된 이벤트에 대한 이벤트 목록에 추가됩니다.

+
소유권 필드를 비워 두면 이벤트 할당을 취소할 수도 있습니다.

* *확인*
+
선택한 이벤트를 확인하여 반복적인 경고 알림을 계속 받지 않도록 합니다.

+
이벤트를 승인하면 선택한 이벤트의 이벤트 목록(승인자)에 사용자 이름과 승인 시간이 추가됩니다. 이벤트를 승인하면 해당 이벤트를 관리할 책임이 부여됩니다.

* *해결됨으로 표시*
+
이벤트 상태를 해결됨으로 변경할 수 있습니다.

+
이벤트를 해결하면 선택한 이벤트의 이벤트 목록(Resolved By)에 사용자 이름과 해결 시간이 추가됩니다. 이벤트에 대한 시정 조치를 완료한 후에는 해당 이벤트를 해결됨으로 표시해야 합니다.

* *알림 추가*
+
선택한 이벤트에 대한 알림을 추가할 수 있는 알림 추가 대화 상자를 표시합니다.
