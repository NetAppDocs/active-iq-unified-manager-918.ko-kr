= Active IQ Unified Manager의 MetroCluster 연결 이벤트에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
연결 이벤트는 MetroCluster over FC 및 MetroCluster over IP 구성에서 클러스터 구성 요소 간, 그리고 클러스터 간 연결에 대한 정보를 제공하여 잠재적인 문제를 모니터링할 수 있도록 합니다. 이벤트는 영향 영역별로 그룹화되며 이벤트 및 트랩 이름, 영향 수준, 소스 유형 및 심각도를 포함합니다.



[[events-common-in-both-configurations]]
== 두 구성 모두에서 공통적인 이벤트

이러한 연결 이벤트는 FC 기반 MetroCluster 및 IP 기반 MetroCluster 구성 모두에서 공통적으로 발생합니다.
