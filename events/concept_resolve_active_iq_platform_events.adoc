= Active IQ Unified Manager에서 Active IQ 플랫폼 이벤트 해결
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ 플랫폼의 장애 및 위험은 다른 사용자에게 해결을 위해 할당할 수 있고 동일한 상태를 사용할 수 있기 때문에 다른 Unified Manager 이벤트와 유사합니다. 하지만 *Fix It* 버튼을 사용하여 이러한 유형의 이벤트를 해결하면 몇 시간 내에 해결을 확인할 수 있습니다.

다음 다이어그램은 Active IQ 플랫폼에서 생성된 이벤트를 해결할 때 수행해야 하는 작업(녹색)과 Unified Manager가 수행하는 작업(검은색)을 보여줍니다.

image::../media/aiq_and_um_event_resolution.png[이벤트 해결 시 사용자가 수행해야 하는 작업과 Unified Manager가 수행하는 작업을 보여주는 UI 스크린샷입니다.]

수동으로 문제를 해결할 때는 System Manager 또는 ONTAP 명령줄 인터페이스에 로그인하여 문제를 수정해야 합니다. 클러스터가 자정에 새로운 AutoSupport 메시지를 생성한 후에만 문제를 확인할 수 있습니다.

*Fix It* 버튼을 사용하여 반자동으로 문제를 해결하면 몇 시간 내에 해결 성공 여부를 확인할 수 있습니다.
