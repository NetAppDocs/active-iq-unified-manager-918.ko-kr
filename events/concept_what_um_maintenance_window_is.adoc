= Active IQ Unified Manager 유지보수 윈도우에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
클러스터 유지보수가 예약되어 있고 원치 않는 알림이 쏟아지는 것을 원하지 않는 경우, 특정 기간 동안 이벤트 및 경고를 억제하도록 Unified Manager 유지보수 윈도우를 정의합니다.

유지보수 윈도우가 시작되면 "오브젝트 유지보수 윈도우 시작됨" 이벤트가 이벤트 관리 인벤토리 페이지에 게시됩니다. 이 이벤트는 유지보수 윈도우가 종료되면 자동으로 삭제됩니다.

유지보수 윈도우 동안 해당 클러스터의 모든 오브젝트와 관련된 이벤트는 계속 생성되지만, UI 페이지에는 표시되지 않으며 이러한 이벤트에 대한 경고 또는 기타 유형의 알림도 전송되지 않습니다. 하지만 이벤트 관리 인벤토리 페이지에서 보기 옵션 중 하나를 선택하면 유지보수 윈도우 동안 모든 스토리지 오브젝트에 대해 생성된 이벤트를 볼 수 있습니다.

향후에 시작될 유지보수 윈도우를 예약할 수 있고, 예약된 유지보수 윈도우의 시작 및 종료 시간을 변경할 수 있으며, 예약된 유지보수 윈도우를 취소할 수 있습니다.
