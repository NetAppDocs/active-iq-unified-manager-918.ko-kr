= Active IQ Unified Manager의 이벤트 상태
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이벤트 상태를 통해 적절한 시정 조치가 필요한지 여부를 파악할 수 있습니다. 이벤트는 신규, 승인됨, 해결됨 또는 폐기됨 상태일 수 있습니다. 신규 및 승인된 이벤트는 모두 활성 이벤트로 간주됩니다.

이벤트 상태는 다음과 같습니다:

* *신규*
+
새로운 이벤트의 상태.

* *확인됨*
+
이벤트를 인지했을 때의 상태.

* *해결됨*
+
이벤트가 해결된 것으로 표시되었을 때의 상태입니다.

* *폐기됨*
+
이벤트가 자동으로 수정되거나 이벤트의 원인이 더 이상 유효하지 않을 때의 상태입니다.

+
[NOTE]
====
더 이상 유효하지 않은 이벤트는 확인하거나 해결할 수 없습니다.

====

== 이벤트의 다양한 상태의 예

다음 예제에서는 수동 및 자동 이벤트 상태 변경을 설명합니다.

클러스터에 연결할 수 없음 이벤트가 발생하면 이벤트 상태는 새로 생성됨으로 표시됩니다. 이벤트를 승인하면 이벤트 상태가 승인됨으로 변경됩니다. 적절한 조치를 취한 후에는 이벤트를 해결됨으로 표시해야 합니다. 그러면 이벤트 상태가 해결됨으로 변경됩니다.

클러스터 연결 불가 이벤트가 정전으로 인해 발생한 경우, 전원이 복구되면 관리자 개입 없이 클러스터가 작동을 시작합니다. 따라서 클러스터 연결 불가 이벤트는 더 이상 유효하지 않으며, 다음 모니터링 주기에서 이벤트 상태가 폐기됨으로 변경됩니다.

Unified Manager는 이벤트가 '사용 중지됨' 또는 '해결됨' 상태일 때 알림을 보냅니다. 알림의 이메일 제목과 내용에는 이벤트 상태에 대한 정보가 포함됩니다. SNMP 트랩에도 이벤트 상태에 대한 정보가 포함됩니다.
