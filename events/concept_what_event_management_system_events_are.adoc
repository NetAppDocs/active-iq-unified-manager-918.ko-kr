= Active IQ Unified Manager의 Event Management System 이벤트에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이벤트 관리 시스템(EMS)은 ONTAP 커널의 여러 부분에서 이벤트 데이터를 수집하고 이벤트 전달 메커니즘을 제공합니다. 이러한 ONTAP 이벤트는 Unified Manager에서 EMS 이벤트로 보고될 수 있습니다. 중앙 집중식 모니터링 및 관리를 통해 중요한 EMS 이벤트와 이러한 EMS 이벤트를 기반으로 한 경고 알림의 구성을 간소화할 수 있습니다.

Unified Manager에 클러스터를 추가하면 Unified Manager 주소가 클러스터의 알림 대상으로 추가됩니다. 클러스터에서 이벤트가 발생하면 즉시 EMS 이벤트가 보고됩니다.

Unified Manager에서 EMS 이벤트를 수신하는 방법에는 두 가지가 있습니다:

* 일정 수의 중요한 EMS 이벤트가 자동으로 보고됩니다.
* 개별 EMS 이벤트를 수신하도록 구독할 수 있습니다.


Unified Manager에서 생성되는 EMS 이벤트는 이벤트 생성 방식에 따라 보고 방식이 다릅니다:

|===
| 기능 | 자동 EMS 메시지 | 구독된 EMS 메시지 


 a| 
이용 가능한 EMS 이벤트
 a| 
EMS 이벤트의 하위 집합
 a| 
모든 EMS 이벤트



 a| 
EMS 메시지 발생 시 메시지 이름
 a| 
Unified Manager 이벤트 이름(EMS 이벤트 이름을 변환한 것)
 a| 
"Error EMS received" 형식의 비특정적 메시지입니다. 자세한 메시지는 실제 EMS 이벤트의 점 표기법 형식을 제공합니다.



 a| 
수신된 메시지
 a| 
클러스터가 검색되는 즉시
 a| 
Unified Manager에 필요한 각 EMS 이벤트를 추가한 후, 그리고 다음 15분 폴링 주기 후에



 a| 
이벤트 수명 주기
 a| 
다른 Unified Manager 이벤트와 동일: 새로 생성됨, 승인됨, 해결됨 및 사용 중지됨 상태
 a| 
EMS 이벤트는 클러스터가 새로 고쳐진 후, 즉 이벤트 생성 시점으로부터 15분이 지나면 더 이상 사용되지 않게 됩니다.



 a| 
Unified Manager 작동 중지 시간 동안 발생하는 이벤트를 기록합니다.
 a| 
네, 시스템이 시작될 때 각 클러스터와 통신하여 누락된 이벤트를 가져옵니다
 a| 
아니요



 a| 
이벤트 상세 정보
 a| 
권장되는 시정 조치는 일관된 해결책을 제공하기 위해 ONTAP에서 직접 가져옵니다.
 a| 
이벤트 상세 페이지에서 시정 조치를 사용할 수 없습니다.

|===
[NOTE]
====
새로운 자동 EMS 이벤트 중 일부는 이전 이벤트가 해결되었음을 나타내는 정보 이벤트입니다. 예를 들어, "FlexGroup 구성 요소 공간 상태 모두 정상" 정보 이벤트는 "FlexGroup 구성 요소에 공간 문제가 있음" 오류 이벤트가 해결되었음을 나타냅니다. 정보 이벤트는 다른 이벤트 심각도 유형과 동일한 이벤트 수명 주기를 사용하여 관리할 수 없지만, 동일한 볼륨에서 "`공간 문제`" 오류 이벤트가 다시 발생하면 해당 이벤트는 자동으로 폐기됩니다.
