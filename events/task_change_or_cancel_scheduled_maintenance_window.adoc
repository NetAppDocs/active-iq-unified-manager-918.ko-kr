= Active IQ Unified Manager에서 예약된 유지보수 윈도우 변경 또는 취소
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
향후에 실행되도록 Unified Manager 유지보수 윈도우를 구성한 경우, 시작 및 종료 시간을 변경하거나 유지보수 윈도우가 실행되지 않도록 취소할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

현재 실행 중인 유지보수 윈도우를 취소하는 것은 예정된 유지보수 윈도우 종료 시간 전에 클러스터 유지보수를 완료했고 클러스터에서 이벤트 및 알림을 다시 수신하려는 경우에 유용합니다.

.단계
. 왼쪽 탐색 창에서 *스토리지 관리* > *클러스터 설정*을 클릭합니다.
. 클러스터의 *유지보수 모드* 열에서:
+
|===
| 원하신다면... | 다음 단계를 수행하십시오... 


 a| 
예정된 유지보수 윈도우의 기간 변경
 a| 
.. 슬라이더 버튼 옆에 있는 "예약됨" 텍스트를 클릭합니다.
.. 시작 및/또는 종료 날짜와 시간을 변경하고 *적용*을 클릭하십시오.




 a| 
활성 유지보수 윈도우 기간 연장
 a| 
.. 슬라이더 버튼 옆에 있는 "활성" 텍스트를 클릭하십시오.
.. 종료 날짜와 시간을 변경하고 *적용*을 클릭하십시오.




 a| 
예정된 유지보수 윈도우 취소
 a| 
슬라이더 버튼을 선택하고 왼쪽으로 이동하십시오.



 a| 
활성 유지보수 윈도우 취소
 a| 
슬라이더 버튼을 선택하고 왼쪽으로 이동하십시오.

|===
