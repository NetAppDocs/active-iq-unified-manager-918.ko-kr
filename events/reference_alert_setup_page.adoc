= Active IQ Unified Manager의 경고 설정 페이지에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
알림 설정 페이지에는 알림 목록이 표시되며 알림 이름, 상태, 알림 방법 및 알림 빈도에 대한 정보가 제공됩니다. 이 페이지에서 알림을 추가, 편집, 삭제, 활성화 또는 비활성화할 수도 있습니다.

애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.



[[command-buttons]]
== 명령 버튼

* *추가*
+
새로운 알림을 추가할 수 있는 알림 추가 대화 상자를 표시합니다.

* *편집*
+
선택한 알림을 편집할 수 있는 알림 편집 대화 상자가 표시됩니다.

* *삭제*
+
선택한 알림을 삭제합니다.

* *활성화*
+
선택한 경고가 알림을 보내도록 활성화합니다.

* *비활성화*
+
알림 전송을 일시적으로 중지하려는 경우 선택한 알림을 비활성화합니다.

* *테스트*
+
선택한 알림을 테스트하여 추가 또는 편집된 후 구성을 확인합니다.

* *해결됨 및 더 이상 사용되지 않는 이벤트에 대한 알림*
+
이벤트가 해결됨 또는 사용 중지됨 상태로 변경될 때 알림 전송 여부를 설정할 수 있습니다. 이를 통해 사용자가 불필요한 알림을 받는 것을 방지할 수 있습니다.





[[list-view]]
== 목록 보기

목록 보기에서는 생성된 알림에 대한 정보가 표 형식으로 표시됩니다. 열 필터를 사용하여 표시되는 데이터를 사용자 지정할 수 있습니다. 또한 알림을 선택하여 세부 정보 영역에서 해당 알림에 대한 자세한 정보를 볼 수 있습니다.

* *상태*
+
알림이 활성화(image:../media/alert_status_enabled.gif[""])되는지 또는 비활성화(image:../media/alert_status_disabled.gif[""])되는지 지정합니다.

* *경고*
+
알림의 이름을 표시합니다.

* *설명*
+
알림에 대한 설명을 표시합니다.

* *알림 방법*
+
경고에 대해 선택된 알림 방법을 표시합니다. 이메일 또는 SNMP 트랩을 통해 사용자에게 알림을 보낼 수 있습니다.

* *알림 빈도*
+
이벤트가 승인되거나 해결되거나 사용 중지 상태로 전환될 때까지 관리 서버가 알림을 계속 전송하는 빈도(분)를 지정합니다.





[[details-area]]
== 세부 정보 영역

세부 정보 영역에는 선택한 알림에 대한 자세한 정보가 표시됩니다.

* *알림 이름*
+
알림의 이름을 표시합니다.

* *알림 설명*
+
알림에 대한 설명을 표시합니다.

* *이벤트*
+
알림을 발생시키려는 이벤트를 표시합니다.

* *리소스*
+
알림을 발생시키려는 리소스를 표시합니다.

* *포함 사항*
+
알림을 발생시키려는 리소스 그룹을 표시합니다.

* *제외 항목*
+
알림을 발생시키지 않으려는 리소스 그룹을 표시합니다.

* *알림 방법*
+
경고에 대한 알림 방식을 표시합니다.

* *알림 빈도*
+
이벤트가 확인, 해결되거나 사용 중지 상태로 전환될 때까지 관리 서버가 알림을 계속 전송하는 빈도를 표시합니다.

* *스크립트 이름*
+
선택한 알림과 연결된 스크립트의 이름을 표시합니다. 이 스크립트는 알림이 생성될 때 실행됩니다.

* *이메일 수신자*
+
경고 알림을 수신하는 사용자의 이메일 주소를 표시합니다.
