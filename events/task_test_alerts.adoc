= Active IQ Unified Manager에서 알림 테스트
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
알림을 테스트하여 올바르게 구성했는지 확인할 수 있습니다. 이벤트가 트리거되면 알림이 생성되고 구성된 수신자에게 알림 이메일이 전송됩니다. 테스트 알림을 사용하여 알림이 전송되는지 및 스크립트가 실행되는지 확인할 수 있습니다.

.시작하기 전에
* 수신자의 이메일 주소, SMTP 서버, SNMP 트랩 등 알림 설정을 구성해야 합니다.
+
Unified Manager 서버는 이러한 설정을 사용하여 이벤트가 발생할 때 사용자에게 알림을 보낼 수 있습니다.

* 경고가 발생할 때 실행되도록 스크립트를 할당하고 구성해야 합니다.
* 애플리케이션 관리자 역할이 있어야 합니다.


.단계
. 왼쪽 탐색 창에서 *스토리지 관리* > *알림 설정*을 클릭합니다.
. *알림 설정* 페이지에서 테스트할 알림을 선택한 다음 *테스트*를 클릭합니다.
+
테스트 알림 이메일은 알림을 생성할 때 지정한 이메일 주소로 전송됩니다.
