= Active IQ Unified Manager의 이메일 알림 형식 페이지에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이메일 알림 형식 페이지에는 할당량 관련 문제(소프트 제한 초과 또는 엄격한 제한 도달)가 발생했을 때 사용자 또는 사용자 그룹에게 전송되는 이메일 규칙이 표시됩니다.

이메일 알림은 다음과 같은 사용자 또는 사용자 그룹 할당량 이벤트가 발생한 경우에만 전송됩니다: 사용자 또는 그룹 할당량 디스크 공간 소프트 제한 초과, 사용자 또는 그룹 할당량 파일 수 소프트 제한 초과, 사용자 또는 그룹 할당량 디스크 공간 엄격한 제한 도달, 또는 사용자 또는 그룹 할당량 파일 수 엄격한 제한 도달.

* *에서*
+
이메일이 발송되는 이메일 주소를 표시하며, 이 주소는 수정할 수 있습니다. 기본적으로 알림 페이지에 지정된 이메일 주소가 사용됩니다.

* *주제*
+
알림 이메일의 제목을 표시합니다.

* *이메일 정보*
+
알림 이메일의 텍스트를 표시합니다. 필요에 따라 텍스트를 수정할 수 있습니다. 예를 들어, 할당량 속성과 관련된 정보를 제공하고 키워드 수를 줄일 수 있습니다. 단, 키워드는 수정하지 마십시오.

+
유효한 키워드는 다음과 같습니다:

+
** $EVENT_NAME
+
이메일 알림을 발생시킨 이벤트 이름을 지정합니다.

** $QUOTA_TARGET
+
할당량이 적용될 qtree 또는 볼륨을 지정합니다.

** $QUOTA_USED_PERCENT
+
사용자 또는 사용자 그룹이 사용하는 디스크 엄격한 제한, 디스크 소프트 제한, 파일 엄격한 제한 또는 파일 소프트 제한의 백분율을 지정합니다.

** $QUOTA_LIMIT
+
사용자 또는 사용자 그룹이 도달하여 다음 이벤트 중 하나가 생성되는 디스크 엄격한 제한 또는 파일 엄격한 제한을 지정합니다:

+
*** 사용자 또는 그룹 할당량 디스크 공간 엄격한 제한 도달
*** 사용자 또는 그룹 할당량 디스크 공간 소프트 제한 도달
*** 사용자 또는 그룹 할당량 파일 개수 엄격한 제한 도달
*** 사용자 또는 그룹 할당량 파일 수 소프트 제한 도달


** $QUOTA_USED
+
사용자 또는 사용자 그룹이 사용한 디스크 공간 또는 생성한 파일 수를 지정합니다.

** $QUOTA_USER
+
사용자 또는 사용자 그룹 이름을 지정합니다.

== 명령 버튼

명령 버튼을 사용하면 이메일 알림 형식에 대한 변경 사항을 미리 보거나 저장하거나 취소할 수 있습니다:

* *미리 보기*
+
알림 이메일의 미리보기를 표시합니다.

* *공장 초기 설정으로 복원*
+
알림 형식을 공장 초기 설정값으로 복원할 수 있습니다.

* *저장*
+
알림 형식에 대한 변경 사항을 저장합니다.
