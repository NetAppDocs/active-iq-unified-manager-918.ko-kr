= Active IQ Unified Manager 이벤트 및 성능 데이터를 보존하는 기간을 변경합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
기본적으로 Unified Manager는 모니터링되는 모든 클러스터에 대해 이벤트 데이터와 성능 데이터를 6개월 동안 저장합니다. 이 시간이 지나면 오래된 데이터는 자동으로 삭제되어 새 데이터를 위한 공간을 확보합니다. 이 기본 기간은 대부분의 구성에 적합하지만, 클러스터와 노드가 많은 매우 큰 구성에서는 Unified Manager가 최적으로 작동하도록 보존 기간을 단축해야 할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 역할이 있어야 합니다.

데이터 보존 페이지에서 이 두 가지 유형의 데이터에 대한 보존 기간을 변경할 수 있습니다. 이러한 설정은 이 Unified Manager 인스턴스가 모니터링하는 모든 클러스터의 데이터 보존에 영향을 미칩니다.

[NOTE]
====
Unified Manager는 5분마다 성능 통계를 수집합니다. 매일 5분 단위 통계가 시간별 성능 통계로 요약됩니다. 기본적으로 30일간의 5분 단위 과거 성능 데이터와 6개월간의 시간별 요약 성능 데이터를 보존합니다.

====
저장 공간이 부족하거나 백업 및 기타 작업 완료에 매우 오랜 시간이 걸리는 경우에만 보존 기간을 줄여야 합니다. 보존 기간을 줄이면 다음과 같은 효과가 나타납니다.

* Unified Manager 데이터베이스에서 오래된 성능 데이터는 자정 이후에 삭제됩니다.
* 오래된 이벤트 데이터는 Unified Manager 데이터베이스에서 즉시 삭제됩니다.
* 보존 기간 이전의 이벤트는 사용자 인터페이스에서 더 이상 볼 수 없습니다.
* 시간별 성능 통계가 표시되는 UI의 위치는 보존 기간 이전에는 비어 있습니다.
* 이벤트 보존 기간이 성능 데이터 보존 기간을 초과하는 경우, 성능 슬라이더 아래에 오래된 성능 이벤트에 연결된 차트에 기반 데이터가 없을 수 있다는 경고 메시지가 표시됩니다.


.단계
. 왼쪽 탐색 창에서 *정책* > *데이터 보존*을 클릭합니다.
. *데이터 보존* 페이지에서 이벤트 보존 또는 성능 데이터 보존 영역의 슬라이더 툴을 선택하고 데이터를 보존할 개월 수로 이동한 다음 *저장*을 클릭합니다.
