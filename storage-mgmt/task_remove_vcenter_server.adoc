= Active IQ Unified Manager에서 vCenter Server 제거
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager 인스턴스에서 vCenter 서버를 제거할 수 있습니다. 예를 들어 vCenter 서버 검색에 실패하거나 더 이상 필요하지 않은 경우 vCenter 서버를 제거할 수 있습니다.

vCenter 서버를 제거하면 해당 vCenter에 호스팅된 모든 가상 머신(VM)과 그 구성 데이터도 삭제됩니다. vCenter 서버가 제거되면 관련 오브젝트 및 기간별 데이터와 함께 더 이상 모니터링되지 않습니다. 이러한 변경 사항은 vCenter 및 가상 머신 인벤토리 페이지에 반영됩니다.

.시작하기 전에
vCenter 서버를 제거하기 전에 다음 사항을 확인하십시오:

* 귀하는 애플리케이션 관리자 역할 또는 스토리지 관리자 역할을 보유하고 있습니다.
* vCenter 서버 이름과 해당 서버의 IP 주소를 알고 있어야 합니다.


.단계
. 왼쪽 탐색 창에서 *VMWARE>vCenter*를 클릭합니다.
. vCenters 페이지에서 제거하려는 vCenter 서버를 선택하고 *제거*를 클릭합니다.
. *vCenter 제거* 메시지 대화 상자에서 *확인*을 클릭하여 제거 요청을 확인합니다.
