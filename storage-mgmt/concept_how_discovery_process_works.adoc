= Active IQ Unified Manager에서 클러스터 검색 프로세스가 작동하는 방식에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager에 클러스터를 추가하면 서버가 클러스터 오브젝트를 검색하여 데이터베이스에 추가합니다. 검색 프로세스의 작동 방식을 이해하면 조직의 클러스터와 해당 오브젝트를 관리하는 데 도움이 됩니다.

클러스터 구성 정보를 수집하는 모니터링 간격은 15분입니다. 예를 들어, 클러스터를 추가한 후 Unified Manager UI에 클러스터 오브젝트가 표시되기까지 15분이 소요됩니다. 클러스터를 변경할 때도 이 시간 간격이 적용됩니다. 예를 들어, 클러스터의 SVM에 새 볼륨 두 개를 추가하면 다음 폴링 간격(최대 15분) 후에 UI에 새 오브젝트가 표시됩니다.

다음 이미지는 검색 과정을 보여줍니다:

image::../media/discovery_process_oc_6_0.gif[검색 프로세스 작동 방식]

새 클러스터에 필요한 모든 객체가 검색되면 Unified Manager는 지난 15일간의 성능 기록 데이터를 수집하기 시작합니다. 이러한 통계는 데이터 연속성 수집 기능을 사용하여 수집됩니다. 이 기능을 통해 클러스터가 추가된 직후 2주 이상의 성능 정보를 확인할 수 있습니다. 데이터 연속성 수집 주기가 완료되면 기본적으로 5분마다 실시간 클러스터 성능 데이터가 수집됩니다.

[NOTE]
====
15일간의 성능 데이터 수집은 CPU 사용량이 많으므로, 데이터 연속성 수집 폴링이 너무 많은 클러스터에서 동시에 실행되지 않도록 새 클러스터 추가를 단계적으로 진행하는 것이 좋습니다.

====
