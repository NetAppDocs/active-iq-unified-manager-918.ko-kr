= Active IQ Unified Manager가 가상 머신을 모니터링하는 방법 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
가상 머신(VM) 애플리케이션에서 지연 문제가 발생하는 경우, 원인을 분석하고 해결하기 위해 VM을 모니터링해야 할 수 있습니다. VM은 해당 vCenter Server 및 VM 스토리지를 호스팅하는 ONTAP 클러스터가 Unified Manager에 추가되면 사용할 수 있습니다.

VM의 세부 정보는 *VMWARE* > > *가상 머신* 페이지에서 확인할 수 있습니다. 가용성, 상태, 사용 및 할당된 용량, 네트워크 지연 시간, 그리고 VM, 데이터스토어 및 호스트의 IOPS 및 지연 시간 등의 정보가 표시됩니다. 여러 데이터스토어를 지원하는 VM의 경우, 표에는 지연 시간이 가장 긴 데이터스토어의 메트릭이 표시되며, 별표(*) 아이콘은 추가 데이터스토어를 나타냅니다. 아이콘을 클릭하면 추가 데이터스토어의 메트릭이 표시됩니다. 일부 열은 정렬 및 필터링이 불가능합니다.

[NOTE]
====
VM 및 해당 세부 정보를 보려면 ONTAP 클러스터의 검색(폴링 또는 메트릭 수집)이 완료되어야 합니다. 클러스터가 Unified Manager에서 제거되면 다음 검색 주기 이후에는 해당 VM을 더 이상 사용할 수 없습니다.

====
이 페이지에서는 호스트, 가상 디스크, 연결된 데이터스토어 등 VM과 관련된 구성 요소를 표시하는 VM의 상세 토폴로지도 볼 수 있습니다. 토폴로지 보기에서는 기본 구성 요소가 특정 계층에서 다음 순서로 표시됩니다. *가상 디스크* > *VM* > *호스트* > *네트워크* > *데이터스토어* > *VMDK*.

토폴로지 측면에서 I/O 경로와 구성 요소 수준의 지연 시간을 확인하고 스토리지가 성능 문제의 원인인지 여부를 파악할 수 있습니다. 토폴로지의 요약 보기에는 I/O 경로가 표시되며, IOPS 및 지연 시간 문제가 있는 구성 요소가 강조 표시되어 문제 해결 단계를 결정하는 데 도움이 됩니다. 각 구성 요소를 개별적으로 해당 구성 요소의 지연 시간과 함께 묘사하는 확장된 토폴로지 보기를 사용할 수도 있습니다. 구성 요소를 선택하여 레이어를 통해 강조 표시된 I/O 경로를 확인할 수 있습니다.

== 요약 토폴로지 보기

요약 토폴로지에서 VM을 확인하여 성능 문제를 파악하려면:

. *VMWARE* > *가상 머신*으로 이동하세요.
. 검색 상자에 VM 이름을 입력하여 VM을 검색하십시오. *필터* 버튼을 클릭하여 특정 조건에 따라 검색 결과를 필터링할 수도 있습니다. 하지만 VM을 찾을 수 없는 경우, 해당 vCenter Server가 추가되어 검색되었는지 확인하십시오.
+
[NOTE]
====
vCenter Server는 VM, 클러스터, 데이터스토어, 폴더 또는 파일 등 vSphere 엔터티의 이름에 특수 문자(%, &, *, $, #, @, !, \, /, :, *, ?, "`, <, >, |, ;, ' 등)를 허용합니다. VMware vCenter Server 및 ESX/ESXi Server는 표시 이름에 사용된 특수 문자를 이스케이프 처리하지 않습니다. 그러나 Unified Manager에서 해당 이름을 처리할 때는 다르게 표시됩니다. 예를 들어 vCenter Server에서  `%$VC_AIQUM_clone_191124%`(으)로 이름이 지정된 VM은 Unified Manager에서  `%25$VC_AIQUM_clone_191124%25`(으)로 표시됩니다. 특수 문자가 포함된 이름으로 VM을 쿼리할 때는 이 문제에 유의해야 합니다.

====
. 가상 머신의 상태를 확인하십시오. 가상 머신 상태는 vCenter Server에서 가져옵니다. 다음과 같은 상태를 확인할 수 있습니다. 이러한 상태에 대한 자세한 내용은 VMware 설명서를 참조하십시오.
+
** 정상
** 경고
** 경고
** 모니터링되지 않음
** 알 수 없음


. VM 옆의 아래쪽 화살표를 클릭하면 컴퓨팅, 네트워크 및 스토리지 계층 전반의 구성 요소 토폴로지 요약 보기가 표시됩니다. 지연 시간 문제가 있는 노드가 강조 표시됩니다. 요약 보기에는 구성 요소의 최악의 지연 시간이 표시됩니다. 예를 들어, VM에 가상 디스크가 두 개 이상 있는 경우 이 보기에는 모든 가상 디스크 중 지연 시간이 가장 나쁜 가상 디스크가 표시됩니다.
. 데이터스토어의 지연 시간과 처리량을 일정 기간 동안 분석하려면 데이터스토어 오브젝트 아이콘 상단의 *워크로드 분석기* 버튼을 클릭하십시오. 워크로드 분석 페이지로 이동하여 시간 범위를 선택하고 데이터스토어의 성능 차트를 볼 수 있습니다. 워크로드 분석기에 대한 자세한 내용은 _워크로드 분석기를 사용한 워크로드 문제 해결_을 참조하십시오.

== 확장된 토폴로지 보기

VM의 확장된 토폴로지를 보면 각 구성 요소를 개별적으로 자세히 살펴볼 수 있습니다.

.단계
. 요약 토폴로지 보기에서 *토폴로지 확장*을 클릭합니다. 각 오브젝트에 대한 지연 시간 수치와 함께 각 구성 요소의 상세 토폴로지를 개별적으로 볼 수 있습니다. 데이터스토어 또는 VMDK와 같이 특정 범주에 노드가 여러 개인 경우, 지연 시간이 가장 긴 노드가 빨간색으로 강조 표시됩니다.
. 특정 오브젝트의 IO 경로를 확인하려면 해당 오브젝트를 클릭하여 IO 경로와 해당 매핑을 확인합니다. 예를 들어 가상 디스크의 매핑을 보려면 가상 디스크를 클릭하여 해당 VMDK에 대해 강조 표시된 매핑을 확인합니다. 이러한 구성 요소에 성능 지연이 발생하는 경우 ONTAP에서 더 많은 데이터를 수집하여 문제를 해결할 수 있습니다.
+
[NOTE]
====
VMDK에 대한 메트릭은 보고되지 않습니다. 토폴로지에는 VMDK 이름만 표시되고 메트릭은 표시되지 않습니다.

====
