= Active IQ Unified Manager의 워크로드 대시보드에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
워크로드는 볼륨이나 LUN 등 스토리지 오브젝트의 입출력(I/O) 작업을 나타냅니다. 스토리지 프로비저닝 방식은 예상되는 워크로드 요구 사항을 기반으로 합니다. 워크로드 통계는 스토리지 오브젝트와 트래픽이 발생한 후에만 Active IQ Unified Manager에서 추적합니다. 예를 들어, 워크로드 IOPS 및 지연 시간 값은 사용자가 데이터베이스 또는 이메일 애플리케이션 사용을 시작한 후에 확인할 수 있습니다.

워크로드 페이지에는 Unified Manager에서 관리하는 ONTAP 클러스터의 스토리지 워크로드 요약이 표시됩니다. 이 페이지는 성능 서비스 수준을 준수하는 스토리지 워크로드와 준수하지 않는 스토리지 워크로드에 대한 누적 정보를 한눈에 확인할 수 있도록 제공합니다. 또한 데이터 센터 전체 클러스터의 총 용량, 가용 용량, 사용된 용량 및 성능(IOPS)을 평가할 수 있습니다.

[NOTE]
====
성능 서비스 수준을 준수하지 않거나, 사용할 수 없거나, 어떤 성능 서비스 수준에서도 관리되지 않는 스토리지 워크로드의 수를 평가하고, 해당 워크로드의 준수, 용량 사용률 및 IOPS를 보장하기 위해 필요한 조치를 취하는 것이 좋습니다.

====
워크로드 페이지는 다음 두 섹션으로 구성됩니다:

* 워크로드 개요: Unified Manager에서 관리하는 ONTAP 클러스터의 스토리지 워크로드 수에 대한 개요를 제공합니다.
* 데이터 센터 개요: 데이터 센터 내 스토리지 워크로드의 용량 및 IOPS에 대한 개요를 제공합니다. 관련 데이터는 데이터 센터 수준 및 개별 항목에 대해 표시됩니다.

== 워크로드 개요 섹션

워크로드 개요 섹션에서는 스토리지 워크로드에 대한 누적 정보를 한눈에 확인할 수 있습니다. 스토리지 워크로드의 상태는 할당된 성능 서비스 수준과 할당되지 않은 성능 서비스 수준을 기준으로 표시됩니다.

* *할당됨*: 성능 서비스 수준이 할당된 스토리지 워크로드에 대해 다음과 같은 상태가 보고됩니다:
+
** *준수*: 스토리지 워크로드의 성능은 할당된 성능 서비스 수준을 기준으로 합니다. 스토리지 워크로드가 관련 성능 서비스 수준에 정의된 임계 지연 시간 내에 있으면 "`준수`"로 표시됩니다. 준수 워크로드는 파란색으로 표시됩니다.
** *규격 미준수*: 성능 모니터링 중 스토리지 워크로드의 지연 시간이 관련 성능 서비스 수준에 정의된 임계값 지연 시간을 초과하면 스토리지 워크로드는 "`규격 미준수`"로 표시됩니다. 규격 미준수 워크로드는 주황색으로 표시됩니다.
** *사용 불가*: 스토리지 워크로드는 오프라인 상태이거나 해당 클러스터에 연결할 수 없는 경우 "`사용 불가`"로 표시됩니다. 사용 불가 워크로드는 빨간색으로 표시됩니다.


* *할당되지 않음*: 성능 서비스 수준이 할당되지 않은 스토리지 워크로드는 "`할당되지 않음`"으로 표시됩니다. 이 숫자는 정보 아이콘으로 나타납니다.


총 워크로드 수는 할당된 워크로드와 할당되지 않은 워크로드의 합계입니다.

이 섹션에 표시된 총 워크로드 수를 클릭하면 워크로드 페이지에서 확인할 수 있습니다.

성능 서비스 수준별 적합성 하위 섹션에는 사용 가능한 스토리지 워크로드의 총 수가 표시됩니다:

* 각 유형의 성능 서비스 수준 준수
* 할당된 성능 서비스 수준과 권장되는 성능 서비스 수준 간에 불일치가 있는 경우

== 데이터센터 개요 섹션

데이터 센터 개요 섹션에서는 데이터 센터 내 모든 클러스터의 가용 용량, 사용 용량 및 IOPS를 그래프로 보여줍니다. 이 데이터를 사용하여 스토리지 워크로드의 용량과 IOPS를 관리해야 합니다. 또한 이 섹션에서는 모든 클러스터의 스토리지 워크로드에 대한 다음 정보를 표시합니다:

* 데이터 센터 내 모든 클러스터의 총 용량, 사용 가능 용량 및 사용된 용량
* 데이터 센터 내 모든 클러스터의 총 IOPS, 사용 가능한 IOPS 및 사용된 IOPS
* 각 성능 서비스 수준별 가용 용량 및 사용 용량
* 각 성능 서비스 수준별 가용 및 사용된 IOPS
* 성능 서비스 수준이 할당되지 않은 워크로드에서 사용된 총 공간 및 IOPS


*성능 서비스 수준을 기준으로 데이터 센터 용량 및 성능을 계산하는 방법*

사용 용량과 IOPS는 클러스터 내 모든 스토리지 워크로드의 총 사용 용량 및 성능 측면에서 검색됩니다.

사용 가능한 IOPS는 예상 지연 시간과 노드의 권장 성능 서비스 수준을 기반으로 계산됩니다. 여기에는 예상 지연 시간이 자체 예상 지연 시간보다 작거나 같은 모든 성능 서비스 수준에 대한 사용 가능한 IOPS가 포함됩니다.

사용 가능한 용량은 예상 지연 시간과 애그리게이트에 권장되는 성능 서비스 수준을 기준으로 계산됩니다. 여기에는 예상 지연 시간이 자체 예상 지연 시간보다 작거나 같은 모든 성능 서비스 수준에 대한 사용 가능한 용량이 포함됩니다.
