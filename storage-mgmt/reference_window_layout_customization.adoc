= Active IQ Unified Manager에서 창 레이아웃 사용자 지정
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager를 사용하면 스토리지 및 네트워크 오브젝트 페이지의 정보 레이아웃을 사용자 지정할 수 있습니다. 창을 사용자 지정하여 표시할 데이터와 데이터 표시 방식을 제어할 수 있습니다.

* *정렬*
+
열 머리글을 클릭하여 열 항목의 정렬 순서를 변경할 수 있습니다. 열 머리글을 클릭하면 해당 열에 정렬 화살표(image:../media/sort_asc_um60.gif["열 정렬 아이콘 – 오름차순"] 및 image:../media/sort_desc_um60.gif["열 정렬 아이콘 – 내림차순"])가 나타납니다.

* *필터링*
+
필터 아이콘(image:../media/filtering_icon.gif[""])을 클릭하여 스토리지 및 네트워크 오브젝트 페이지의 정보 표시를 사용자 지정하도록 필터를 적용할 수 있습니다. 제공된 조건과 일치하는 항목만 표시됩니다. 필터는 필터 창에서 적용할 수 있습니다.

+
필터 창을 사용하면 선택한 옵션에 따라 대부분의 열을 필터링할 수 있습니다. 예를 들어, 상태: 모든 볼륨 보기에서 상태 아래의 적절한 필터 옵션을 선택하여 오프라인 상태인 모든 볼륨을 표시할 수 있습니다.

+
모든 목록의 용량 관련 열에는 항상 적절한 단위로 소수점 둘째 자리까지 반올림된 용량 데이터가 표시됩니다. 이는 용량 열을 필터링할 때도 동일하게 적용됩니다. 예를 들어, 상태: 모든 애그리게이트 보기의 총 데이터 용량 열에서 필터를 사용하여 20.45GB보다 큰 데이터를 필터링하면 실제 용량인 20.454GB가 20.45GB로 표시됩니다. 마찬가지로, 20.45GB보다 작은 데이터를 필터링하면 실제 용량인 20.449GB가 20.45GB로 표시됩니다.

+
상태: 모든 애그리게이트 보기의 사용 가능한 데이터 % 열에서 필터를 사용하여 20.45%보다 큰 데이터를 필터링하면 실제 용량인 20.454%가 20.45%로 표시됩니다. 마찬가지로, 20.45%보다 작은 데이터를 필터링하면 실제 용량인 20.449%가 20.45%로 표시됩니다.

* *열 숨기기 또는 표시*
+
열 표시 아이콘(*표시/숨기기*)을 클릭하여 표시할 열을 선택할 수 있습니다. 원하는 열을 선택한 후 마우스를 사용하여 드래그하여 순서를 변경할 수 있습니다.

* *검색*
+
검색 상자를 사용하여 특정 오브젝트 속성을 검색하면 인벤토리 페이지에서 항목 목록을 구체화할 수 있습니다. 예를 들어, "cloud"를 입력하면 볼륨 인벤토리 페이지에서 "cloud"라는 단어가 포함된 모든 볼륨 목록을 볼 수 있습니다.

* *데이터 내보내기*
+
*보고서* 버튼을 클릭하거나(*내보내기* 버튼을 클릭하여 데이터를 쉼표로 구분된 값  `(.csv)` 파일,  `(.pdf)` 문서 또는 Microsoft Excel `(.xlsx)` 파일로 내보낼 수 있음), 내보낸 데이터를 사용하여 보고서를 작성할 수 있습니다.
