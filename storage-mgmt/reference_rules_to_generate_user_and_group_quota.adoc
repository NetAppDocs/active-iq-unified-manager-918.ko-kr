= Active IQ Unified Manager의 할당량 이메일 주소 규칙에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
'사용자 및 그룹 할당량 이메일 주소 생성 규칙' 페이지에서는 클러스터, SVM, 볼륨, qtree, 사용자 또는 사용자 그룹과 연결된 사용자 할당량을 기준으로 이메일 주소를 지정하는 규칙을 생성할 수 있습니다. 할당량이 초과되면 지정된 이메일 주소로 알림이 전송됩니다.



[[rules-area]]
== 규칙 영역

할당량 이메일 주소에 대한 규칙을 정의해야 합니다. 규칙을 설명하는 주석을 추가할 수도 있습니다.



[[how-you-define-rules]]
== 규칙을 정의하는 방법

규칙은 실행하려는 순서대로 입력해야 합니다. 첫 번째 규칙의 조건이 충족되면 해당 규칙에 따라 이메일 주소가 생성됩니다. 조건이 충족되지 않으면 다음 규칙의 조건이 고려되며, 이런 식으로 계속 진행됩니다. 각 줄에는 별도의 규칙이 나열됩니다. 기본 규칙은 목록의 마지막 규칙입니다. 규칙의 우선순위를 변경할 수 있습니다. 하지만 기본 규칙의 순서는 변경할 수 없습니다.

예를 들어, qtree1에 대한 할당량 초과 알림을 받기 위해 qtree1@xyz.com 이메일 주소를 사용하고 나머지 모든 qtree에 대해서는 admin@xyz.com 이메일 주소를 사용하려면 규칙을 다음 순서대로 나열해야 합니다:

* if ( $QTREE == 'qtree1' ) then qtree1@xyz.com
* 만약 ( $QTREE == * )이면 admin@xyz.com


지정한 규칙의 기준이 하나도 충족되지 않으면 기본 규칙이 사용됩니다:

만약 ( $USER_OR_GROUP == * )이면 $USER_OR_GROUP@$DOMAIN

둘 이상의 사용자가 동일한 할당량을 가진 경우, 사용자 이름은 쉼표로 구분된 값으로 표시되며 해당 할당량에 대해서는 규칙이 적용되지 않습니다.



[[how-you-add-comments]]
== 댓글을 추가하는 방법

규칙을 설명하는 주석을 추가할 수 있습니다. 각 주석은 #으로 시작해야 하며, 각 줄에는 별도의 주석을 나열해야 합니다.



[[rules-syntax]]
== 규칙 구문

규칙의 구문은 다음 중 하나여야 합니다:

* 만약 ( `valid variableoperator *`)이면 `email ID@domain name`
+
if는 키워드이고 소문자입니다. 연산자는 ==입니다. 이메일 ID는 임의의 문자, 유효한 변수 $USER_OR_GROUP, $USER 또는 $GROUP, 또는 임의의 문자와 유효한 변수 $USER_OR_GROUP, $USER 또는 $GROUP의 조합을 포함할 수 있습니다. 도메인 이름은 임의의 문자, 유효한 변수 $DOMAIN, 또는 임의의 문자와 유효한 변수 $DOMAIN의 조합을 포함할 수 있습니다. 유효한 변수는 대문자 또는 소문자일 수 있지만 두 가지를 혼합해서 사용할 수는 없습니다. 예를 들어 $domain 및 $DOMAIN은(는) 유효하지만 $Domain은(는) 유효한 변수가 아닙니다.

* if ( `valid variableoperator `string``) then `email ID@domain name`
+
if는 키워드이고 소문자입니다. 연산자는 contains 또는 ==일 수 있습니다. 이메일 ID는 임의의 문자, 유효한 변수 $USER_OR_GROUP, $USER 또는 $GROUP, 또는 임의의 문자와 유효한 변수 $USER_OR_GROUP, $USER 또는 $GROUP의 조합을 포함할 수 있습니다. 도메인 이름은 임의의 문자, 유효한 변수 $DOMAIN, 또는 임의의 문자와 유효한 변수 $DOMAIN의 조합을 포함할 수 있습니다. 유효한 변수는 대문자 또는 소문자일 수 있지만 대문자와 소문자가 혼합되어서는 안 됩니다. 예를 들어 $domain 및 $DOMAIN은(는) 유효하지만 $Domain은(는) 유효한 변수가 아닙니다.





[[command-buttons]]
== 명령 버튼

명령 버튼을 사용하면 생성된 규칙을 저장, 유효성 검사 또는 취소할 수 있습니다:

* *유효성 검사*
+
생성된 규칙의 구문을 검증합니다. 검증 중 오류가 발생하면 오류를 발생시킨 규칙과 오류 메시지가 표시됩니다.

* *공장 초기 설정으로 복원*
+
주소 규칙을 공장 초기값으로 복원할 수 있습니다.

* *저장*
+
규칙의 구문을 검증하고 오류가 없으면 규칙을 저장합니다. 검증 중에 오류가 발생하면 오류를 발생시킨 규칙과 오류 메시지가 표시됩니다.
