= Active IQ Unified Manager에서 스토리지 오브젝트 검색
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
특정 오브젝트에 빠르게 액세스하려면 메뉴 모음 상단의 *모든 스토리지 오브젝트 검색* 필드를 사용할 수 있습니다. 모든 오브젝트를 대상으로 하는 이 전역 검색 방법을 통해 오브젝트 유형별로 특정 오브젝트를 신속하게 찾을 수 있습니다. 검색 결과는 스토리지 오브젝트 유형별로 정렬되며, 드롭다운 메뉴를 사용하여 오브젝트별로 결과를 추가로 필터링할 수 있습니다.

.시작하기 전에
* 이 작업을 수행하려면 운영자, 애플리케이션 관리자 또는 스토리지 관리자 중 하나의 역할을 보유해야 합니다.
* 유효한 검색어는 최소 세 글자 이상이어야 합니다.


드롭다운 메뉴에서 "모두"를 선택하면 전체 검색 결과에 모든 오브젝트 범주에서 찾은 총 결과가 표시되며, 각 오브젝트 범주별로 최대 25개의 검색 결과가 표시됩니다. 드롭다운 메뉴에서 특정 오브젝트 유형을 선택하여 특정 오브젝트 유형 내에서 검색 범위를 좁힐 수 있습니다. 이 경우 반환되는 목록은 상위 25개 오브젝트로 제한되지 않습니다.

검색할 수 있는 오브젝트 유형은 다음과 같습니다.

* 클러스터
* 노드
* 스토리지 VM
* 애그리게이트
* 볼륨
* 큐트리
* SMB 공유
* NFS 공유
* 사용자 또는 그룹 할당량
* LUN
* NVMe 네임스페이스
* 이니시에이터 그룹
* 이니시에이터
* 일관성 그룹


워크로드 이름을 입력하면 해당 볼륨 또는 LUN 범주에 속하는 워크로드 목록이 표시됩니다.

검색 결과에서 오브젝트를 클릭하여 해당 오브젝트의 상태 상세 페이지로 이동할 수 있습니다. 오브젝트에 대한 직접적인 상태 페이지가 없는 경우 상위 오브젝트의 상태 페이지가 표시됩니다. 예를 들어, 특정 LUN을 검색할 경우 해당 LUN이 상주하는 SVM 상세 페이지가 표시됩니다.

[NOTE]
====
포트와 LIF는 글로벌 검색창에서 검색할 수 없습니다.

====
.단계
. 메뉴에서 오브젝트 유형을 선택하여 단일 오브젝트 유형에 대한 검색 결과만 표시되도록 범위를 좁히십시오.
. *모든 스토리지 오브젝트 검색* 필드에 오브젝트 이름의 최소 세 글자를 입력하십시오.
+
이 예시에서는 드롭다운 상자에서 볼륨 오브젝트 유형이 선택되어 있습니다. *모든 스토리지 오브젝트 검색* 필드에 "vol1"을 입력하면 이름에 해당 문자가 포함된 모든 볼륨 목록이 표시됩니다.

+
