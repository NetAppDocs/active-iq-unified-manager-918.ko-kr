= Active IQ Unified Manager에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager(이전 명칭: OnCommand Unified Manager)를 사용하면 단일 인터페이스에서 ONTAP 스토리지 시스템의 상태 및 성능을 모니터링하고 관리할 수 있습니다.

Unified Manager는 다음과 같은 기능을 제공합니다:

* ONTAP 소프트웨어가 설치된 시스템에 대한 검색, 모니터링 및 알림 기능.
* 환경의 용량, 보안 및 성능 상태를 보여주는 대시보드입니다.
* 향상된 알림, 이벤트 및 임계값 인프라.
* IOPS(작업 수), MBps(처리량), 지연 시간(응답 시간), 활용률, 성능 용량, 캐시 비율 등 시간에 따른 워크로드 활동을 보여주는 상세 그래프를 표시합니다.
* 클러스터 구성 요소를 과도하게 사용하는 워크로드와 활동 증가로 인해 성능에 영향을 받는 워크로드를 식별합니다.
* 특정 인시던트 및 이벤트를 해결하기 위해 수행할 수 있는 권장 시정 조치를 제공하며, 일부 이벤트의 경우 문제를 즉시 해결할 수 있는 "해결하기" 버튼을 제공합니다.
* OnCommand Workflow Automation과 통합되어 자동화된 보호 워크플로를 실행합니다.
* Unified Manager에서 직접 LUN 또는 파일 공유 등 새로운 워크로드를 생성하고 성능 서비스 수준을 할당하여 해당 워크로드를 사용하는 애플리케이션에 액세스하는 사용자를 위한 성능 및 스토리지 목표를 정의할 수 있습니다.
