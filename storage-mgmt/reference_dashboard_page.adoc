= Active IQ Unified Manager 대시보드 페이지에 대해 알아보십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
대시보드 페이지에는 모니터링 중인 클러스터의 용량, 성능 및 보안 상태를 개략적으로 표시하는 "패널"이 있습니다. 또한 이 페이지에는 Unified Manager가 특정 이벤트를 해결하기 위해 수행할 수 있는 수정 사항 목록을 보여주는 관리 작업 패널이 있습니다.

대부분의 패널에는 해당 범주의 활성 이벤트 수와 지난 24시간 동안 추가된 새 이벤트 수가 표시됩니다. 이 정보는 이벤트 해결을 위해 추가 분석이 필요한 클러스터를 판단하는 데 도움이 됩니다. 이벤트를 클릭하면 상위 이벤트가 표시되고 해당 범주의 활성 이벤트만 표시되도록 필터링된 이벤트 관리 인벤토리 페이지 링크가 제공됩니다.

대시보드 상단에서 패널에 모니터링되는 모든 클러스터("모든 클러스터")에 대한 정보를 표시할지, 아니면 개별 클러스터에 대한 정보를 표시할지 선택할 수 있습니다. 먼저 모든 클러스터의 상태를 확인한 후, 자세한 정보를 보려면 개별 클러스터로 드릴다운할 수 있습니다.

[NOTE]
====
구성에 따라 아래 나열된 패널 중 일부가 대시보드에 표시됩니다.

====


[[management-actions-panel]]
== 관리 조치 패널

Unified Manager는 특정 문제를 철저하게 진단하고 단일 해결책을 제공할 수 있습니다. 해결책이 있는 경우, 이 패널에 *Fix It* 또는 *Fix All* 버튼과 함께 표시됩니다. 이러한 문제는 ONTAP System Manager 또는 ONTAP CLI를 사용하지 않고도 Unified Manager에서 즉시 해결할 수 있습니다. 모든 문제를 보려면 자세한 내용 보기 link:concept_fix_ontap_issues_directly_from_unified_manager.html["Unified Manager에서 직접 ONTAP 문제를 해결하십시오"]를 클릭하십시오.



[[capacity-panel]]
== 용량 패널

모든 클러스터를 볼 때, 이 패널에는 각 클러스터의 물리적 사용 용량(스토리지 효율성 절감 적용 후)과 물리적 사용 가능 용량(잠재적 스토리지 효율성 절감 제외), 디스크가 가득 찰 것으로 예상되는 기간(일), 그리고 구성된 ONTAP 스토리지 효율성 설정에 따른 데이터 감소율(Snapshot 복사본 제외)이 표시됩니다. 또한 구성된 클라우드 계층의 사용 용량도 표시됩니다. 막대 그래프를 클릭하면 해당 클러스터의 애그리게이트 인벤토리 페이지로 이동합니다. "Days To Full" 텍스트를 클릭하면 남은 용량 일수가 가장 적은 애그리게이트를 나타내는 메시지가 표시됩니다. 애그리게이트 이름을 클릭하면 자세한 내용을 볼 수 있습니다.

단일 클러스터를 볼 때 이 패널에는 로컬 계층의 각 개별 디스크 유형별로 정렬된 데이터 애그리게이트와 클라우드 계층에 대한 물리적 사용 용량 및 물리적 사용 가능 용량이 표시됩니다. 디스크 유형의 막대 차트를 클릭하면 해당 디스크 유형을 사용하는 볼륨의 볼륨 인벤토리 페이지로 이동합니다.



[[performance-capacity-panel]]
== 성능 용량 패널

모든 클러스터를 볼 때, 이 패널에는 각 클러스터의 성능 용량 값(지난 1시간 동안의 평균값)과 성능 용량이 상한선에 도달하기까지 남은 일수(일일 증가율 기준)가 표시됩니다. 막대 그래프를 클릭하면 해당 클러스터의 노드 인벤토리 페이지로 이동합니다. 노드 인벤토리 페이지에는 지난 72시간 동안의 평균 성능 용량이 표시됩니다. "최대 용량 도달까지 남은 일수" 텍스트를 클릭하면 남은 성능 용량 일수가 가장 적은 노드를 알려주는 메시지가 표시됩니다. 자세한 내용을 보려면 노드 이름을 클릭하십시오.

단일 클러스터를 볼 때 이 패널에는 클러스터 성능 용량 사용 비율, 총 IOPS, 총 처리량(MB/s) 값과 이 세 가지 메트릭 각각이 상한에 도달할 것으로 예상되는 날짜까지의 일 수가 표시됩니다.



[[workload-iops-panel]]
== 워크로드 IOPS 패널

단일 클러스터를 볼 때 이 패널에는 특정 IOPS 범위에서 현재 실행 중인 총 워크로드 수가 표시되며, 차트에 마우스 커서를 올리면 각 디스크 유형별 워크로드 수가 표시됩니다.



[[workload-performance-panel]]
== 워크로드 성능 패널

이 패널에는 각 성능 서비스 수준(PSL) 정책에 할당된 적합 워크로드와 부적합 워크로드의 총 개수가 표시됩니다. 또한 PSL이 할당되지 않은 워크로드의 개수도 표시됩니다. 막대 그래프를 클릭하면 워크로드 페이지에서 해당 정책에 할당된 적합 워크로드로 이동합니다. 막대 그래프 뒤에 나오는 숫자를 클릭하면 해당 정책에 할당된 적합 워크로드와 부적합 워크로드로 이동합니다.



[[security-panel]]
== 보안 패널

보안 패널은 현재 보기에 따라 모든 클러스터 또는 단일 클러스터의 상위 수준 보안 상태를 표시합니다. 이 패널에는 다음 내용이 표시됩니다.

* 지난 24시간 동안 수신된 보안 이벤트 목록입니다. 이벤트를 클릭하여 이벤트 세부 정보 페이지에서 자세한 내용을 확인하십시오
* 클러스터 보안 상태(규정 준수 클러스터 및 규정 미준수 클러스터 수)
* 스토리지 VM 보안 상태(규정 준수 및 미준수 스토리지 VM 수)
* 볼륨 암호화 상태(암호화된 볼륨과 암호화되지 않은 볼륨의 개수)
* 볼륨의 랜섬웨어 방지 상태(랜섬웨어 방지 기능이 활성화 또는 비활성화된 볼륨 수)


규정을 준수하는 클러스터와 준수하지 않는 클러스터, 스토리지 VM, 암호화된 볼륨과 암호화되지 않은 볼륨, 그리고 볼륨의 랜섬웨어 방지 상태를 나타내는 막대 그래프를 클릭하면 해당 페이지로 이동하여 필터링된 클러스터, 스토리지 VM 및 볼륨의 보안 세부 정보를 확인할 수 있습니다.

규정 준수는  https://www.netapp.com/pdf.html?item=/media/10674-tr4569pdf.pdf["NetApp ONTAP 9 보안 강화 가이드"^]을(를) 기반으로 합니다. 패널 상단의 오른쪽 화살표를 클릭하여 보안 페이지에서 모든 클러스터의 보안 세부 정보를 확인하십시오. 자세한 내용은 link:../health-checker/task_view_detailed_security_status_for_clusters_and_svms.html["클러스터 및 스토리지 VM의 자세한 보안 상태 보기"]을(를) 참조하십시오.



[[data-protection-panel]]
== 데이터 보호 패널

이 패널은 데이터 센터 내 단일 클러스터 또는 모든 클러스터에 대한 데이터 보호 요약을 표시합니다. 이 패널은 ONTAP에서 지난 24시간 동안 발생한 데이터 보호 이벤트, MetroCluster 이벤트의 총 수 및 활성 이벤트 수를 표시합니다. 각 이벤트의 링크를 클릭하면 이벤트 세부 정보 페이지로 이동합니다. *모두 보기* 링크를 클릭하면 이벤트 관리 인벤토리 페이지에서 모든 활성 보호 이벤트를 볼 수 있습니다. 패널에는 다음 내용이 표시됩니다.

* Snapshot 복사본으로 보호되는 클러스터 또는 데이터 센터 내 모든 클러스터의 볼륨 수입니다.
* SnapMirror 관계로 보호되는 클러스터 또는 데이터 센터 내 모든 클러스터의 볼륨 수입니다. SnapMirror 관계의 경우 소스 클러스터의 볼륨 수가 고려됩니다.
* IP 또는 FC를 통한 MetroCluster 구성으로 보호되는 데이터 센터의 클러스터 수 또는 전체 클러스터입니다.
* 지연 상태에 따른 SnapMirror 복구 시점 목표(RPO) 지연이 있는 볼륨 관계 수.


마우스를 올려 각각의 개수와 범례를 볼 수 있습니다. 패널 상단의 오른쪽 화살표를 클릭하여 데이터 보호 페이지에서 단일 클러스터 또는 모든 클러스터의 세부 정보를 볼 수 있습니다. 또한 다음을 클릭할 수 있습니다:

* 보호되지 않은 볼륨과 Snapshot 사본으로 보호된 볼륨에 대한 막대 차트에서 볼륨 페이지로 이동하여 세부 정보를 확인하십시오.
* MetroCluster 구성으로 보호되거나 보호되지 않는 클러스터의 막대 차트를 통해 클러스터 페이지로 이동하여 세부 정보를 확인하십시오.
* 모든 관계에 대한 막대 차트는 관계 페이지로 이동하며, 해당 페이지에서는 소스 클러스터를 기준으로 세부 정보가 필터링됩니다.


자세한 내용은 link:../data-protection/view-protection-status.html["볼륨 보호 상태 보기"]를 참조하십시오.



[[usage-overview-panel]]
== 사용량 개요 패널

모든 클러스터를 볼 때 가장 높은 IOPS, 가장 높은 처리량(MB/s) 또는 가장 많이 사용된 물리적 용량 순으로 정렬하여 볼 수 있습니다.

단일 클러스터를 볼 때 가장 높은 IOPS, 가장 높은 처리량(MB/s) 또는 가장 많이 사용된 논리 용량 순으로 워크로드를 정렬하여 볼 수 있습니다.
