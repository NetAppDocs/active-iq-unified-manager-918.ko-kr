= Active IQ Unified Manager에서 사용자 및 그룹 할당량 이메일 주소 편집
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
클러스터, 스토리지 가상 머신(SVM), 볼륨, qtree, 사용자 또는 사용자 그룹과 연결된 사용자 할당량에 따라 이메일 주소를 수정할 수 있습니다. 사용자 및 그룹 할당량 이메일 주소 생성 규칙 대화 상자에 지정된 규칙에 따라 생성된 이메일 주소를 재정의하려는 경우 이메일 주소를 수정할 수 있습니다.

.시작하기 전에
* 운영자, 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.
* link:reference_rules_to_generate_user_and_group_quota.html["규칙 생성을 위한 지침"]을(를) 검토했어야 합니다.


이메일 주소를 수정하면 사용자 및 그룹 할당량 이메일 주소 생성 규칙이 더 이상 할당량에 적용되지 않습니다. 지정된 규칙에 따라 생성된 이메일 주소로 알림이 전송되도록 하려면 해당 이메일 주소를 삭제하고 변경 사항을 저장해야 합니다.

.단계
. 왼쪽 탐색 창에서 *스토리지* > *SVMs*를 클릭합니다.
. *상태: 모든 스토리지 VM* 보기에서 SVM을 선택한 다음 *사용자 및 그룹 할당량* 탭을 클릭합니다.
. 탭 행 아래에 있는 *이메일 주소 수정*을 클릭합니다.
. *이메일 주소 수정* 대화 상자에서 적절한 작업을 수행하십시오:
+
|===
| 만약... | 그런 다음... 


 a| 
지정된 규칙에 따라 생성된 이메일 주소로 알림이 전송되기를 원합니다.
 a| 
.. *이메일 주소* 필드에서 이메일 주소를 삭제하십시오.
.. *저장*을 클릭합니다.
.. F5 키를 눌러 브라우저를 새로 고침하여 이메일 주소 편집 대화 상자를 다시 로드하십시오. 지정된 규칙에 따라 생성된 이메일 주소가 *이메일 주소* 필드에 표시됩니다.




 a| 
지정된 이메일 주소로 알림을 보내고자 합니다.
 a| 
.. *이메일 주소* 필드에서 이메일 주소를 수정하십시오.
.. *저장*을 클릭합니다. 사용자 및 그룹 할당량 이메일 주소를 생성하는 규칙이 더 이상 할당량에 적용되지 않습니다.


|===
