= Active IQ Unified Manager 사용자 인터페이스에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 사용자 인터페이스는 주로 모니터링되는 오브젝트를 한눈에 볼 수 있는 대시보드로 구성됩니다. 또한 사용자 인터페이스를 통해 모든 클러스터 오브젝트를 볼 수 있습니다.

원하는 보기 방식을 선택하고 필요에 따라 작업 버튼을 사용할 수 있습니다. 화면 구성은 작업 공간에 저장되므로 Unified Manager를 시작할 때 필요한 모든 기능을 사용할 수 있습니다. 단, 보기 방식을 변경했다가 다시 원래 보기 방식으로 돌아갈 경우, 표시되는 보기 방식이 달라질 수 있습니다.
