= Active IQ Unified Manager에서 모니터링하는 클러스터 목록 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
클러스터 설정 페이지를 사용하여 클러스터 인벤토리를 확인할 수 있습니다. 이름이나 IP 주소 및 통신 상태 등 클러스터에 대한 세부 정보를 볼 수 있습니다.

.시작하기 전에
운영자, 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

.단계
. 왼쪽 탐색 창에서 *스토리지 관리* > *클러스터 설정*을 클릭합니다.
+
Unified Manager로 관리되는 스토리지 환경의 모든 클러스터가 표시됩니다. 클러스터 목록은 컬렉션 상태 심각도 수준 열을 기준으로 정렬됩니다. 열 헤더를 클릭하여 다른 열을 기준으로 클러스터를 정렬할 수 있습니다.
