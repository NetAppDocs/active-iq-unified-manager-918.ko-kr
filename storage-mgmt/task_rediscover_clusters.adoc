= Active IQ Unified Manager에서 클러스터 재검색
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
클러스터 설정 페이지에서 클러스터를 수동으로 다시 탐색하여 클러스터의 상태, 모니터링 상태 및 성능 상태에 대한 최신 정보를 얻을 수 있습니다.

공간이 부족할 때 애그리게이트 크기를 늘리는 등 클러스터를 업데이트하고 변경한 내용을 Unified Manager가 탐색하도록 하려는 경우, 수동으로 클러스터를 다시 탐색할 수 있습니다.

Unified Manager가 OnCommand Workflow Automation(WFA)과 페어링되면 WFA에 캐시된 데이터의 재획득이 트리거됩니다.

.단계
. 왼쪽 탐색 창에서 *스토리지 관리* > *클러스터 설정*을 클릭합니다.
. *클러스터 설정* 페이지에서 *재탐색*을 클릭합니다.
+
Unified Manager는 선택한 클러스터를 다시 탐색하고 최신 상태 및 성능 정보를 표시합니다.
