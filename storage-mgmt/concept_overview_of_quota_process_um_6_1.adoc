= Active IQ Unified Manager 할당량 프로세스에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
할당량은 소프트 또는 하드일 수 있습니다. 소프트 할당량은 지정된 한도를 초과할 경우 ONTAP에서 알림을 보내도록 하며, 하드 할당량은 지정된 한도를 초과할 경우 쓰기 작업이 성공하지 못하도록 합니다.

ONTAP이 사용자 또는 사용자 그룹으로부터 FlexVol 볼륨에 쓰기 요청을 받으면 해당 볼륨에 대해 사용자 또는 사용자 그룹에 대한 할당량이 활성화되어 있는지 확인하고 다음 사항을 판단합니다:

* 엄격한 제한에 도달할지 여부
+
예인 경우, 엄격한 제한에 도달하면 쓰기 작업이 실패하고 하드 할당량 알림이 전송됩니다.

* 소프트 제한이 초과될지 여부
+
예인 경우, 소프트 제한을 초과하면 쓰기 작업이 성공하고 소프트 할당량 알림이 전송됩니다.

* 쓰기 작업이 소프트 제한을 초과하지 않을지 여부
+
예인 경우, 쓰기 작업이 성공하고 알림이 전송되지 않습니다.
