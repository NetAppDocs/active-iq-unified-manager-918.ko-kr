= Active IQ Unified Manager에서 직접 ONTAP 문제 또는 기능 관리
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP System Manager나 ONTAP CLI를 사용할 필요 없이 Unified Manager 사용자 인터페이스에서 직접 특정 ONTAP 문제를 해결하거나 특정 ONTAP 기능을 관리할 수 있습니다. "`관리 작업`" 옵션은 Unified Manager 이벤트를 발생시킨 여러 ONTAP 문제에 대한 해결 방법을 제공합니다.

왼쪽 탐색 창에서 *관리 작업* 옵션을 선택하여 관리 작업 페이지에서 직접 문제를 해결할 수 있습니다. 관리 작업은 대시보드의 관리 작업 패널, 이벤트 세부 정보 페이지, 그리고 왼쪽 탐색 메뉴의 워크로드 분석 선택 항목에서도 사용할 수 있습니다.

Unified Manager는 특정 문제를 철저하게 진단하고 단일 해결책을 제공할 수 있습니다. 랜섬웨어 방지 모니터링 등 특정 ONTAP 기능의 경우, Unified Manager는 내부 검사를 수행하고 특정 조치를 권장합니다. 해결책이 있는 경우, 이러한 해결책은 *Fix It* 버튼과 함께 Management Actions에 표시됩니다. 문제를 해결하려면 *Fix It* 버튼을 클릭합니다. 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

Unified Manager는 요청된 수정 작업을 수행하기 위해 클러스터에 ONTAP 명령을 전송합니다. 수정 작업이 완료되면 이벤트가 폐기됩니다.

일부 관리 작업에서는 *모두 수정* 버튼을 사용하여 여러 스토리지 오브젝트의 동일한 문제를 해결할 수 있습니다. 예를 들어, "볼륨 자동 확장 활성화"에 대한 *모두 수정* 관리 작업을 클릭하여 해결할 수 있는 "볼륨 공간 가득 참" 이벤트가 발생한 볼륨이 5개 있을 수 있습니다. 한 번의 클릭으로 5개의 볼륨에서 이 문제를 해결할 수 있습니다.

자동 복구를 사용하여 관리할 수 있는 ONTAP 문제 및 기능에 대한 자세한 내용은 link:../storage-mgmt/reference_what_ontap_issues_can_unified_manager_fix.html["Unified Manager는 어떤 문제를 해결할 수 있습니까"]을(를) 참조하십시오.
