= Active IQ Unified Manager 도움말 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
도움말에는 Active IQ Unified Manager에 포함된 모든 기능에 대한 정보가 포함되어 있습니다. 목차, 색인 또는 검색 툴을 사용하여 기능 및 사용 방법에 대한 정보를 찾을 수 있습니다.

Unified Manager 사용자 인터페이스의 각 탭과 메뉴 표시줄에서 도움말을 사용할 수 있습니다.

도움말의 검색 툴은 부분 단어에는 작동하지 않습니다.

* 특정 필드 또는 매개변수에 대해 자세히 알아보려면 image:../media/helpicon_um60.gif["상황별 도움말 아이콘"]을(를) 클릭하십시오.
* 도움말의 모든 내용을 보려면 메뉴 모음에서 *image:../media/helpicon_um60.gif["상황별 도움말 아이콘"]* > *도움말/문서*를 클릭하십시오.
+
탐색 창에서 목차의 어느 부분이든 확장하여 더 자세한 정보를 찾을 수 있습니다.

* 도움말 내용을 검색하려면 탐색 창에서 *검색* 탭을 클릭하고, 찾고자 하는 단어 또는 단어 조합을 입력한 다음 *이동!*을 클릭하십시오.
* 도움말 항목을 인쇄하려면 프린터 아이콘을 클릭하십시오.
