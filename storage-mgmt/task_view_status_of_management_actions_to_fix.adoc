= Active IQ Unified Manager에서 수정할 관리 작업의 상태를 봅니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
관리 작업 페이지에서 수정하기로 선택한 모든 관리 작업의 상태를 확인할 수 있습니다. 대부분의 작업은 Unified Manager가 클러스터에 ONTAP 명령을 전송한 후 비교적 빠르게 *완료됨*으로 표시됩니다. 하지만 볼륨 이동 등 일부 작업은 시간이 더 오래 걸릴 수 있습니다.

관리 작업 페이지에는 세 가지 필터가 있습니다:

* *완료됨*은 성공적으로 완료된 관리 작업과 실패한 작업을 모두 보여줍니다. *실패함* 작업은 실패 사유를 제공하므로 수동으로 문제를 해결할 수 있습니다.
* *진행 중*은 현재 실행 중인 관리 조치와 실행 예정인 조치를 모두 보여줍니다.
* *권장* 항목은 모니터링 중인 모든 클러스터에 대해 현재 활성화된 모든 관리 작업을 보여줍니다.


.단계
. 왼쪽 탐색 창에서 *관리 작업*을 클릭합니다. 또는 *대시보드*의 *관리 작업* 패널 상단에 있는 image:../media/more_icon.gif["더보기 아이콘"]을(를) 클릭하고 원하는 보기를 선택합니다.
+
관리 작업 페이지가 표시됩니다.

. *설명* 필드에서 관리 작업 옆에 있는 캐럿 아이콘을 클릭하면 문제에 대한 세부 정보와 문제를 해결하는 데 사용되는 명령을 볼 수 있습니다.
. *실패한* 작업을 확인하려면 *완료* 보기에서 *상태* 열을 기준으로 정렬하십시오. 이와 같은 목적으로 *필터* 툴을 사용할 수 있습니다.
. 실패한 관리 작업에 대한 자세한 정보를 보거나 권장 관리 작업을 수정하려면 관리 작업 옆에 있는 캐럿 아이콘을 클릭한 후 확장된 영역에서 *이벤트 세부 정보 보기*를 클릭할 수 있습니다. 해당 페이지에서 *수정* 버튼을 사용할 수 있습니다.
