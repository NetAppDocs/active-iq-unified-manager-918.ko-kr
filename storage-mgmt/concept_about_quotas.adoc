= Active IQ Unified Manager의 할당량에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
할당량은 사용자, 그룹 또는 qtree가 사용하는 디스크 공간과 파일 수를 제한하거나 추적하는 방법을 제공합니다. 할당량은  `/etc/quotas` 파일을 사용하여 지정합니다. 할당량은 특정 볼륨 또는 qtree에 적용됩니다.
