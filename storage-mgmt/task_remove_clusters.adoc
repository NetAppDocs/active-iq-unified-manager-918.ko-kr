= Active IQ Unified Manager에서 클러스터 제거
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
클러스터 설정 페이지를 사용하여 Unified Manager에서 클러스터를 제거할 수 있습니다. 예를 들어, 클러스터 탐색이 실패하거나 스토리지 시스템을 폐기하려는 경우 클러스터를 제거할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 역할 또는 스토리지 관리자 역할이 있어야 합니다.

이 작업은 선택한 클러스터를 Unified Manager에서 제거합니다. 클러스터가 제거되면 더 이상 모니터링되지 않습니다. 제거된 클러스터에 등록된 Unified Manager 인스턴스도 해당 클러스터에서 등록 해제됩니다.

클러스터를 제거하면 해당 클러스터의 모든 스토리지 오브젝트, 기간별 데이터, 스토리지 서비스 및 Unified Manager의 모든 관련 이벤트도 삭제됩니다. 이러한 변경 사항은 다음 데이터 수집 주기 후에 인벤토리 페이지와 세부 정보 페이지에 반영됩니다.

[NOTE]
====
클러스터를 사용 중지하기 전에 Unified Manager에서 클러스터를 제거해야 합니다. 클러스터 제거를 시도할 때 클러스터가 이미 오프라인 상태이거나 연결할 수 없는 경우 Unified Manager는 클러스터와 통신하여 애플리케이션 레코드 및 구성된 이벤트 관리 시스템(EMS) 구독을 제거할 수 없습니다. 이로 인해 제거 프로세스가 실패하거나 완료되기 전에 응답하지 않게 됩니다.

====
.단계
. 왼쪽 탐색 창에서 *스토리지 관리* > *클러스터 설정*을 클릭합니다.
. 클러스터 설정 페이지에서 제거할 클러스터를 선택하고 *제거*를 클릭합니다.
. *데이터 원본 제거* 메시지 대화 상자에서 *제거*를 클릭하여 제거 요청을 확인합니다.
