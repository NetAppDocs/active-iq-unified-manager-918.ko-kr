= Active IQ Unified Manager에서 NetApp Manageability SDK 로그 순환 문제 해결
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Windows 운영 체제에서 Unified Manager에 ONTAPI API 기반 클러스터를 추가하면  `nmsdk.log` 파일 크기가 증가하여 10MB 크기 제한을 초과합니다.

*원인*

로그 순환이 이루어지지 않으면 이러한 문제가 발생할 수 있습니다.

*시정 조치*

. Unified Manager를 중지하십시오.
. Windows에 Unified Manager를 설치할 때 Logrotate 버전 0.0.0.18을 설치하십시오. 자세한 내용은 link:https://www.netapp.com/pdf.html?item=/media/78941-tr-4945.pdf["NetApp Manageability SDK 기술 보고서 보안 강화 가이드"^]을(를) 참조하십시오.
. Unified Manager를 시작하십시오.
