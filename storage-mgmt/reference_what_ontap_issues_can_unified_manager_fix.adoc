= Active IQ Unified Manager가 해결할 수 있는 ONTAP 문제에 대해 알아보십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager의 자동 문제 해결 기능을 사용하면, Unified Manager를 통해 특정 ONTAP 문제를 해결하거나 랜섬웨어 방지 모니터링 등 특정 ONTAP 기능을 효과적으로 관리할 수 있습니다.

이 표는 Unified Manager 웹 UI의 *Fix It* 또는 *Fix All* 버튼을 통해 직접 관리할 수 있는 ONTAP 문제 또는 기능에 대해 설명합니다.

|===
| 이벤트 이름 및 설명 | 관리 조치 | "Fix It" 작업 


 a| 
볼륨 공간 가득 참

볼륨의 공간이 거의 다 차서 용량 가득 참 임계값을 초과했습니다. 이 임계값은 기본적으로 볼륨 크기의 90%로 설정되어 있습니다.
 a| 
볼륨 자동 확장 활성화
 a| 
Unified Manager는 이 볼륨에 대해 볼륨 자동 확장이 구성되어 있지 않다고 판단하여 필요에 따라 볼륨 용량이 증가하도록 이 기능을 활성화합니다.



 a| 
이노드 가득 참

이 볼륨은 inode가 부족하여 더 이상 새 파일을 저장할 수 없습니다.
 a| 
볼륨의 inode 수를 늘립니다
 a| 
볼륨의 inode 수를 2% 증가시킵니다.



 a| 
스토리지 계층 정책 불일치가 감지되었습니다

해당 볼륨에는 비활성 데이터가 많고 현재 티어링 정책은 "스냅샷 전용" 또는 "없음"으로 설정되어 있습니다.
 a| 
자동 클라우드 계층화 활성화
 a| 
볼륨이 이미 FabricPool에 있으므로, 비활성 데이터가 비용이 더 저렴한 클라우드 계층으로 이동되도록 계층화 정책을 "auto"로 변경합니다.



 a| 
스토리지 계층 불일치가 감지되었습니다

해당 볼륨에는 비활성 데이터가 많지만 클라우드 지원 스토리지 계층(FabricPool)에 저장되어 있지 않습니다.
 a| 
볼륨의 스토리지 계층 변경
 a| 
볼륨을 클라우드 지원 스토리지 계층으로 이동하고 계층화 정책을 "자동"으로 설정하여 비활성 데이터를 클라우드 계층으로 이동합니다.



 a| 
감사 로그 비활성화됨

스토리지 VM에 대해 감사 로그가 활성화되어 있지 않습니다.
 a| 
스토리지 VM에 대한 감사 로깅을 활성화합니다
 a| 
스토리지 VM에 대한 감사 로깅을 활성화합니다.

참고로 스토리지 VM에는 로컬 또는 원격 감사 로그 위치가 이미 구성되어 있어야 합니다.



 a| 
로그인 배너 비활성화됨

클러스터 로그인 배너를 활성화하여 접근 제한 사항을 명확히 함으로써 보안을 강화해야 합니다.
 a| 
클러스터에 대한 로그인 배너를 설정합니다
 a| 
클러스터 로그인 배너를 "`Access restricted to authorized users`"로 설정합니다.



 a| 
로그인 배너 비활성화됨

스토리지 VM의 로그인 배너를 활성화하여 접근 제한 사항을 명확히 함으로써 보안을 강화해야 합니다.
 a| 
스토리지 VM에 대한 로그인 배너를 설정합니다
 a| 
스토리지 VM 로그인 배너를 "승인된 사용자만 액세스 가능"으로 설정합니다.



 a| 
SSH는 안전하지 않은 암호화 방식을 사용합니다

접미사 "-cbc"가 붙은 암호는 안전하지 않은 것으로 간주됩니다.
 a| 
클러스터에서 안전하지 않은 암호화 방식을 제거합니다
 a| 
클러스터에서 aes192-cbc 및 aes128-cbc 등 안전하지 않은 암호화 방식을 제거합니다.



 a| 
SSH는 안전하지 않은 암호화 방식을 사용합니다

접미사 "-cbc"가 붙은 암호는 안전하지 않은 것으로 간주됩니다.
 a| 
스토리지 VM에서 안전하지 않은 암호화 방식을 제거합니다
 a| 
스토리지 VM에서 aes192-cbc, aes128-cbc 등 보안에 취약한 암호를 제거합니다.



 a| 
AutoSupport HTTPS 전송이 비활성화됨

기술 지원에 AutoSupport 메시지를 보내는 데 사용되는 전송 프로토콜은 암호화되어야 합니다.
 a| 
AutoSupport 메시지의 전송 프로토콜을 HTTPS로 설정합니다
 a| 
클러스터에서 AutoSupport 메시지의 전송 프로토콜을 HTTPS로 설정합니다.



 a| 
클러스터 부하 불균형 임계값 초과

클러스터 내 노드 간 부하 불균형을 나타냅니다. 이 이벤트는 노드 간 성능 용량 사용률 차이가 30%를 초과할 때 발생합니다.
 a| 
클러스터 워크로드 균형 조정
 a| 
Unified Manager는 불균형을 줄이기 위해 한 노드에서 다른 노드로 이동할 최적의 볼륨을 식별한 다음 해당 볼륨을 이동합니다.



 a| 
클러스터 용량 불균형 임계값 초과

클러스터 내 애그리게이트 간에 용량이 불균형함을 나타냅니다. 이 이벤트는 애그리게이트 간의 사용 용량 편차가 70%를 초과할 때 발생합니다.
 a| 
클러스터 용량 균형 유지
 a| 
Unified Manager는 불균형을 줄이기 위해 한 애그리게이트에서 다른 애그리게이트로 이동할 최적의 볼륨을 식별한 다음 해당 볼륨을 이동합니다.



 a| 
성능 용량 사용량 임계값 초과

하나 이상의 활성도가 높은 워크로드의 사용률을 줄이지 않으면 노드의 부하가 과도하게 사용될 수 있음을 나타냅니다. 이 이벤트는 노드 성능 용량 사용 값이 12시간 이상 100%를 초과할 때 발생합니다.
 a| 
노드의 과부하 제한
 a| 
Unified Manager는 IOPS가 가장 높은 볼륨을 식별하고, 과거의 예상 및 최대 IOPS 수준을 사용하여 QoS 정책을 적용함으로써 해당 노드의 부하를 줄입니다.



 a| 
동적 이벤트 경고 임계값 초과

일부 워크로드의 비정상적으로 높은 부하로 인해 노드가 이미 과부하 상태에서 작동 중임을 나타냅니다.
 a| 
노드의 과부하를 줄이십시오
 a| 
Unified Manager는 IOPS가 가장 높은 볼륨을 식별하고, 과거의 예상 및 최대 IOPS 수준을 사용하여 QoS 정책을 적용함으로써 해당 노드의 부하를 줄입니다.



 a| 
테이크오버가 불가능합니다

현재 장애 조치가 비활성화되어 있으므로, 장애 발생 또는 재부팅 시 노드를 다시 사용할 수 있을 때까지 해당 노드의 리소스에 접근할 수 없게 됩니다.
 a| 
노드 장애 조치 활성화
 a| 
Unified Manager는 클러스터의 모든 노드에서 장애 조치를 활성화하기 위한 적절한 명령을 전송합니다.



 a| 
옵션 Cf.takeover.on_panic이 OFF로 설정되어 있습니다.

노드셸 옵션 "cf.takeover.on_panic"이 *off*로 설정되어 있어 HA 구성 시스템에서 문제가 발생할 수 있습니다.
 a| 
패닉 상황에서 인수 활성화
 a| 
Unified Manager는 클러스터에 적절한 명령을 보내 이 설정을 *on*으로 변경합니다.



 a| 
노드셸 옵션 snapmirror.enable을 비활성화합니다.

기존 nodeshell 옵션 "snapmirror.enable"이 *on*으로 설정되어 있어 ONTAP 9.3 이상으로 업그레이드한 후 부팅 중에 문제가 발생할 수 있습니다.
 a| 
snapmirror.enable 옵션을 off로 설정합니다.
 a| 
Unified Manager는 클러스터에 적절한 명령을 보내 이 설정을 *끄기*로 변경합니다.



 a| 
Telnet 활성화됨

Telnet은 보안에 취약하고 데이터를 암호화하지 않은 방식으로 전송하기 때문에 잠재적인 보안 문제를 나타냅니다.
 a| 
Telnet 비활성화
 a| 
Unified Manager는 클러스터에 Telnet을 비활성화하는 적절한 명령을 보냅니다.



 a| 
스토리지 VM 랜섬웨어 방지 학습 구성

랜섬웨어 방지 모니터링 라이선스가 있는 클러스터를 주기적으로 확인합니다. 해당 클러스터에서 스토리지 VM이 NFS 또는 SMB 볼륨만 지원하는지 여부를 검증합니다.
 a| 
스토리지 VM을 랜섬웨어 방지 모니터링의  `learning` 모드로 설정하십시오.
 a| 
Unified Manager는 클러스터 관리 콘솔을 통해 스토리지 VM에 대한 랜섬웨어 방지 모니터링을 `learning` 상태로 설정합니다. 스토리지 VM에 새로 생성되는 모든 볼륨에 대한 랜섬웨어 방지 모니터링은 자동으로 학습 모드로 전환됩니다. 이를 통해 ONTAP은 볼륨의 활동 패턴을 학습하고 잠재적인 악성 공격으로 인한 이상 징후를 감지할 수 있습니다.



 a| 
볼륨 랜섬웨어 방지 학습 구성

랜섬웨어 방지 모니터링 라이선스가 있는 클러스터를 주기적으로 확인합니다. 해당 클러스터에서 볼륨이 NFS 또는 SMB 서비스만 지원하는지 여부를 검증합니다.
 a| 
볼륨을 랜섬웨어 방지 모니터링의  `learning` 모드로 설정하십시오.
 a| 
Unified Manager는 클러스터 관리 콘솔을 통해 볼륨에 대한 랜섬웨어 방지 모니터링을 `learning` 상태로 설정합니다. 이를 통해 ONTAP은 볼륨의 활동 패턴을 학습하고 잠재적인 악성 공격으로 인한 이상 징후를 감지할 수 있습니다.



 a| 
볼륨 랜섬웨어 방지 활성화

랜섬웨어 방지 모니터링 라이선스가 있는 클러스터를 주기적으로 확인합니다. 볼륨이 45일 이상 랜섬웨어 방지 모니터링의  `learning` 모드에 있는지 감지하고, 활성 모드로 전환할 가능성을 판단합니다.
 a| 
볼륨을 랜섬웨어 방지 모니터링  `active` 모드로 설정하십시오.
 a| 
Unified Manager는 클러스터 관리 콘솔을 통해 볼륨에 대한 랜섬웨어 방지 모니터링을  `active`(으)로 설정합니다. 이를 통해 ONTAP은 볼륨의 활동 패턴을 학습하고 잠재적인 악성 공격으로 인한 이상 징후를 감지하여 데이터 보호 조치를 위한 경고를 생성할 수 있습니다.



 a| 
볼륨 안티 랜섬웨어 비활성화

랜섬웨어 방지 모니터링 라이선스가 있는 클러스터를 주기적으로 확인합니다. 볼륨에 대한 랜섬웨어 방지 모니터링이 활성화된 동안 반복적인 알림이 발생하는 경우(예: 30일 동안 잠재적 랜섬웨어 공격에 대한 경고가 여러 번 반환되는 경우)를 감지합니다.
 a| 
볼륨에서 랜섬웨어 방지 모니터링 비활성화
 a| 
Unified Manager는 클러스터 관리 콘솔을 통해 볼륨에서 안티 랜섬웨어 모니터링을 비활성화합니다.

|===
