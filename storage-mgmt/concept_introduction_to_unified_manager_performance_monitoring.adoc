= Active IQ Unified Manager의 성능 모니터링에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager(이전 명칭: OnCommand Unified Manager)는 NetApp ONTAP 소프트웨어를 실행하는 시스템에 대한 성능 모니터링 기능과 이벤트 근본 원인 분석을 제공합니다.

Unified Manager는 클러스터 구성 요소를 과도하게 사용하여 클러스터의 다른 워크로드 성능을 저하시키는 워크로드를 식별하는 데 도움을 줍니다. 성능 임계값 정책을 정의하여 특정 성능 카운터에 대한 최대값을 지정하면 임계값이 초과될 때 이벤트가 생성됩니다. Unified Manager는 이러한 성능 이벤트에 대한 알림을 제공하여 시정 조치를 취하고 성능을 정상 수준으로 복구할 수 있도록 합니다. Unified Manager UI에서 이벤트를 보고 분석할 수 있습니다.

Unified Manager는 두 가지 유형의 워크로드 성능을 모니터링합니다:

* 사용자 정의 워크로드
+
이러한 워크로드는 클러스터에 생성한 FlexVol 볼륨과 FlexGroup 볼륨으로 구성됩니다.

* 시스템 정의 워크로드
+
이러한 워크로드는 내부 시스템 활동으로 구성됩니다.
