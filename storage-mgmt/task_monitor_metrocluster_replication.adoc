= Active IQ Unified Manager에서 MetroCluster 복제 모니터링
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
데이터를 미러링하는 동안 논리적 연결의 전반적인 상태를 모니터링하고 진단할 수 있습니다. 애그리게이트, 노드, 스토리지 가상 머신 등 클러스터 구성 요소의 미러링을 방해하는 문제나 위험을 식별할 수 있습니다.

Unified Manager는 시스템 상태 경고를 사용하여 MetroCluster 구성의 구성 요소 및 연결 상태를 모니터링합니다.

.시작하기 전에
MetroCluster 구성의 로컬 및 원격 클러스터를 모두 Unified Manager에 추가해야 합니다.



[[view-replication-for-metrocluster-over-ip-configurations]]
== IP 구성을 통한 MetroCluster의 복제 보기

MetroCluster over IP 구성의 경우, Unified Manager 왼쪽 탐색 창의 다음 보기에서 MetroCluster over IP로 보호되는 클러스터에 대한 토폴로지 픽 뷰에 데이터 복제 상태가 표시됩니다.

* *스토리지* > *클러스터* > *보호: MetroCluster* 보기
* *Protection* > *Relationships* > *Relationship: MetroCluster* 보기


자세한 내용은 link:../storage-mgmt/task_monitor_metrocluster_configurations.html#monitor-connectivity-issues-in-metrocluster-over-ip-configuration["IP 기반 MetroCluster에서 연결 문제 모니터링"]을 참조하십시오.



[[view-replication-for-metrocluster-over-fc-configurations]]
== FC 구성에서 MetroCluster 복제 보기

FC를 통한 MetroCluster 구성의 데이터 복제 문제를 확인하려면 다음 단계를 수행하십시오.

.단계
. 왼쪽 탐색 창에서 *스토리지* > *클러스터*를 클릭합니다.
+
모니터링 중인 클러스터 목록이 표시됩니다.

. *상태: 모든 클러스터* 보기에서 MetroCluster 복제 세부 정보를 보려는 클러스터 이름을 클릭합니다. *클러스터 / 상태 세부 정보* 페이지에서 *MetroCluster 복제* 탭을 클릭합니다.
+
복제될 MetroCluster 구성의 토폴로지는 데이터가 미러링되는 원격 사이트에 대한 정보와 함께 로컬 사이트의 해당 클러스터 오브젝트 영역에 표시됩니다. 아이콘 위에 포인터를 올리면 생성된 이벤트에 대한 자세한 정보를 볼 수 있습니다.



클러스터/상태 세부 정보 페이지에 표시된 정보를 사용하여 복제 문제를 해결할 수 있습니다. MetroCluster 구성에서 미러링 문제를 탐색하는 경우, System Manager에 로그인하거나 ONTAP CLI에 접속하여 문제를 해결해야 합니다.
