= Active IQ Unified Manager의 Fix It 및 Fix All 버튼 옵션에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
관리 작업 페이지에서는 Unified Manager가 이벤트를 통해 알림을 받은 문제를 해결하기 위해 *문제 해결* 또는 *모두 해결* 버튼을 제공합니다.

필요에 따라 버튼을 클릭하여 문제를 해결하는 것이 좋습니다. 하지만 Unified Manager에서 권장하는 방식으로 문제를 해결할지 확신이 서지 않는다면 다음 작업을 수행할 수 있습니다.

|===
| 무엇을 하시겠습니까? | *작업* 


 a| 
Unified Manager를 사용하여 식별된 모든 오브젝트의 문제를 해결하십시오.
 a| 
*모두 수정* 버튼을 클릭하세요.



 a| 
현재로서는 식별된 오브젝트에 대한 문제를 해결하지 말고, 해당 이벤트가 다시 발생할 때까지 이 관리 작업을 숨기십시오.
 a| 
아래쪽 화살표를 클릭하고 *모두 닫기*를 클릭하십시오.



 a| 
식별된 오브젝트 중 일부에 대해서만 문제를 해결합니다.
 a| 
관리 작업 이름을 클릭하여 목록을 확장하고 모든 개별 *Fix It* 작업을 표시합니다. 그런 다음 개별 관리 작업을 수정하거나 무시하는 단계를 따르십시오.

|===
|===
| 무엇을 하시겠습니까? | 작업 


 a| 
Unified Manager를 사용하여 문제를 해결하십시오.
 a| 
*문제 해결* 버튼을 클릭합니다.



 a| 
지금은 문제를 해결하지 말고 이벤트가 다시 발생할 때까지 이 관리 작업을 숨기십시오.
 a| 
아래쪽 화살표를 클릭하고 *닫기*를 클릭합니다.



 a| 
이 문제를 더 잘 이해할 수 있도록 이 이벤트에 대한 세부 정보를 표시하십시오.
 a| 
* *수정하기* 버튼을 클릭하고 나타나는 대화 상자에서 적용될 수정 사항을 확인하십시오.
* 아래쪽 화살표를 클릭하고 *이벤트 상세 보기*를 클릭하여 이벤트 상세 정보 페이지를 표시합니다.


그런 다음 문제를 해결하려면 이 결과 페이지 중 하나에서 *Fix It*을 클릭하십시오.



 a| 
문제를 더 잘 이해할 수 있도록 이 스토리지 오브젝트에 대한 세부 정보를 표시하십시오.
 a| 
성능 탐색기 또는 상태 세부 정보 페이지에서 세부 정보를 표시하려면 스토리지 오브젝트의 이름을 클릭하십시오.

|===
어떤 경우에는 수정 사항이 다음 15분 구성 폴링에 반영됩니다. 다른 경우에는 구성 변경 사항이 확인되고 이벤트가 무효화되기까지 최대 수 시간이 걸릴 수 있습니다.

완료되었거나 진행 중인 관리 작업 목록을 보려면 필터 아이콘을 클릭하고 *완료됨* 또는 *진행 중*을 선택하십시오.

Fix All 작업은 순차적으로 실행되므로 *진행 중* 패널을 보면 일부 오브젝트는 *진행 중* 상태로 표시되고 다른 오브젝트는 *예정됨* 상태로 표시됩니다. 즉, 아직 구현되기를 기다리고 있다는 의미입니다.
