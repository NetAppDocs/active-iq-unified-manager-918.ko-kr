= Active IQ Unified Manager에서 vCenter Server 보기 및 추가
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
가상 머신(VM)의 성능을 확인하고 문제를 해결하려면 연결된 vCenter 서버를 Active IQ Unified Manager 인스턴스에 추가해야 합니다.

.시작하기 전에
vCenter 서버를 추가하거나 보기 전에 다음 사항을 확인하십시오.

* vCenter 서버 이름을 알고 있습니다.
* vCenter Server의 IP 주소를 알고 있고 필요한 자격 증명을 가지고 있습니다. 자격 증명은 vCenter Server 관리자 또는 vCenter Server에 대한 읽기 전용 액세스 권한이 있는 루트 사용자여야 합니다.
* 추가하려는 vCenter Server는 vSphere 6.5 이상 버전을 실행해야 합니다.
+

NOTE: VMware ESXi 및 vCenter Server에 대한 Unified Manager 지원은 영어와 일본어로 제공됩니다.

* vCenter Server의 데이터 수집 설정은  `_Level 3_` 통계 수준으로 설정되어 모니터링되는 모든 오브젝트에 대해 필요한 수준의 메트릭 수집을 보장합니다. 간격 기간은  `_5 minutes_`이어야 하며, 저장 기간은  `_1 day_`이어야 합니다.
+
자세한 내용은 VMware 설명서의 _vSphere 모니터링 및 성능 가이드_의 "`데이터 수집 수준`" 섹션을 참조하십시오.

* 지연 시간 값을 성공적으로 계산하기 위해 vCenter Server의 지연 시간 값은 마이크로초가 아닌 밀리초 단위로 구성됩니다.
* vCenter Server에 데이터스토어를 추가할 때 호스트의 IP 주소 또는 정규화된 도메인 이름(FQDN)을 사용할 수 있습니다. FQDN을 추가하는 경우 Unified Manager 서버에서 해당 도메인 이름을 확인할 수 있는지 확인해야 합니다. 예를 들어 Linux 설치의 경우 도메인 이름이  `/etc/resolv.conf` 파일에 추가되어 있는지 확인하십시오.
* vCenter Server의 현재 시간은 vCenter Server 시간대와 동기화되어 있습니다.
* vCenter Server에 연결할 수 있어야 검색이 성공적으로 완료됩니다.
* Unified Manager에 vCenter Server를 추가할 때 VMware SDK에 대한 읽기 권한이 있어야 합니다. 이는 구성 폴링에 필요합니다.


추가 및 검색된 모든 vCenter Server에 대해 Unified Manager는 vCenter Server 및 ESXi 서버 세부 정보, ONTAP 매핑, 데이터스토어 세부 정보, 호스팅된 VM 수 등 구성 데이터를 수집합니다. 또한 구성 요소의 성능 지표를 수집합니다.

.단계
. *VMWARE* > *vCenter*로 이동하여 vCenter 서버가 목록에 있는지 확인하십시오.
+
[NOTE]
====
vCenter Server를 사용할 수 없는 경우 vCenter Server를 추가해야 합니다.

====
+
.. *추가*를 클릭합니다.
.. vCenter Server에 올바른 IP 주소를 추가하고 해당 장치에 연결할 수 있는지 확인하십시오.
.. vCenter Server에 읽기 전용 액세스 권한이 있는 관리자 또는 루트 사용자의 사용자 이름과 암호를 추가하십시오.
.. 기본값인 443번 포트 이외의 다른 포트를 사용하는 경우 사용자 지정 포트 번호를 추가하십시오.
.. *저장*을 클릭합니다.
+
서버 검색에 성공하면 수락할 수 있는 서버 인증서가 표시됩니다.

+
인증서를 수락하면 vCenter Server가 사용 가능한 vCenter Server 목록에 추가됩니다. 장치를 추가해도 연결된 VM에 대한 데이터 수집은 시작되지 않으며, 데이터 수집은 예약된 간격으로 수행됩니다.



. vCenter Server가 *vCenters* 페이지에 표시되는 경우, 마우스를 *Status* 필드 위에 올려 vCenter Server가 예상대로 작동하는지 또는 경고나 오류가 있는지 상태를 확인하십시오.
+
[NOTE]
====
vCenter Server를 추가하면 다음과 같은 상태를 확인할 수 있습니다. 단, vCenter Server를 추가한 후 해당 VM의 성능 및 지연 시간 데이터가 정확하게 반영되기까지 최대 1시간이 소요될 수 있습니다.

====
+
** 녹색: "정상"으로, vCenter Server가 검색되었고 성능 지표가 성공적으로 수집되었음을 나타냅니다.
** 노란색: "경고" (예: 각 오브젝트에 대한 통계를 얻기 위해 vCenter Server의 통계 수준이 3 이상으로 설정되지 않은 경우)
** 주황색: "오류" (예외, 구성 데이터 수집 실패 또는 vCenter Server에 연결할 수 없음 등 내부 오류를 나타냅니다.) 열 표시 아이콘(*표시/숨기기*)을 클릭하여 vCenter Server 상태에 대한 상태 메시지를 확인하고 문제를 해결할 수 있습니다.


. vCenter 서버에 연결할 수 없거나 자격 증명이 변경된 경우, *vCenter* > *편집*을 선택하여 vCenter 서버 세부 정보를 편집하십시오.
. *VMware vCenter Server 편집* 페이지에서 필요한 변경 작업을 수행하십시오.
. *저장*을 클릭합니다.


*vCenter 서버 데이터 수집 시작*

vCenter Server는 20초 간격으로 실시간 성능 데이터 샘플을 수집하고 이를 5분 간격으로 집계합니다. Unified Manager의 성능 데이터 수집 일정은 vCenter Server의 기본 설정에 기반합니다. Unified Manager는 vCenter Server에서 가져온 5분 간격 샘플을 처리하여 가상 디스크, VM 및 호스트의 IOPS와 지연 시간의 시간당 평균을 계산합니다. 데이터스토어의 경우 Unified Manager는 ONTAP에서 가져온 샘플에서 IOPS 및 지연 시간의 시간당 평균을 계산합니다. 이러한 값은 매시간 정각에 제공됩니다. 성능 지표는 vCenter Server를 추가한 직후에는 사용할 수 없으며, 다음 시간이 시작될 때만 사용할 수 있습니다. 성능 데이터 폴링은 구성 데이터 수집 주기를 완료하면 시작됩니다.

vCenter Server 구성 데이터 폴링 시 Unified Manager는 클러스터 구성 데이터 수집과 동일한 일정을 따릅니다. vCenter Server 구성 및 성능 데이터 수집 일정에 대한 자세한 내용은 "클러스터 구성 및 성능 데이터 수집 활동"을 참조하십시오.
