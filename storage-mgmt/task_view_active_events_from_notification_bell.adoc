= Active IQ Unified Manager의 알림 벨에서 활성 이벤트 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
메뉴 막대의 알림 벨(image:../media/notification_bell.png[""])은 Unified Manager가 추적하는 가장 중요한 활성 이벤트를 빠르게 볼 수 있는 방법을 제공합니다.

활성 이벤트 목록을 통해 모든 클러스터에서 발생한 심각, 오류, 경고 및 업그레이드 이벤트의 총 개수를 확인할 수 있습니다. 이 목록에는 지난 7일간의 이벤트가 포함되며, 정보 이벤트는 포함되지 않습니다. 링크를 클릭하여 가장 관심 있는 이벤트 목록을 표시할 수 있습니다.

클러스터에 연결할 수 없는 경우 Unified Manager는 이 페이지에 해당 정보를 표시합니다. 연결할 수 없는 클러스터에 대한 자세한 정보를 보려면 *세부 정보* 버튼을 클릭하십시오. 이 작업을 수행하면 이벤트 세부 정보 페이지가 열립니다. 관리 스테이션의 공간 부족 또는 RAM 부족 등 스케일 모니터링 문제도 이 페이지에 표시됩니다.

.단계
. 메뉴 표시줄에서 image:../media/notification_bell.png[""]을 클릭합니다.
. 활성 이벤트의 세부 정보를 보려면 "2 용량" 또는 "4 성능" 등의 이벤트 텍스트 링크를 클릭하십시오.
