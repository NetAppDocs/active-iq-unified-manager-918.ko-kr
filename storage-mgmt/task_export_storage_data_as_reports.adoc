= Active IQ Unified Manager에서 스토리지 데이터를 보고서로 내보내기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
다양한 출력 형식으로 스토리지 데이터를 내보낸 다음, 내보낸 데이터를 사용하여 보고서를 작성할 수 있습니다. 예를 들어, 해결되지 않은 중요 이벤트가 10개 있는 경우 이벤트 관리 인벤토리 페이지에서 데이터를 내보내 보고서를 생성한 다음, 문제를 해결할 수 있는 관리자에게 해당 보고서를 보낼 수 있습니다.

*스토리지* 및 *네트워크* 인벤토리 페이지에서 데이터를  `.csv` 파일,  `.xlsx` 파일 또는  `.pdf` 문서로 내보낼 수 있으며, 내보낸 데이터를 사용하여 보고서를 작성할 수 있습니다. 제품 내에는  `.csv` 또는  `.pdf` 파일만 생성할 수 있는 다른 위치도 있습니다.

.단계
. 다음 작업 중 하나를 수행합니다.
+
|===
| 내보내려면... | 이렇게 하세요... 


 a| 
스토리지 오브젝트 인벤토리 세부 정보
 a| 
왼쪽 탐색 메뉴에서 *스토리지* 또는 *네트워크*를 클릭한 다음 스토리지 오브젝트를 선택합니다. 시스템에서 제공하는 보기 중 하나를 선택하거나 직접 생성한 사용자 지정 보기를 선택합니다.



 a| 
QoS 정책 그룹 세부 정보
 a| 
왼쪽 탐색 메뉴에서 *스토리지* > *QoS 정책 그룹*을 클릭합니다.



 a| 
스토리지 용량 및 보호 이력 세부 정보
 a| 
*스토리지* > *애그리게이트* 또는 *스토리지* > *볼륨*을 클릭한 다음 단일 애그리게이트 또는 볼륨을 선택합니다.



 a| 
이벤트 상세 정보
 a| 
왼쪽 탐색 메뉴에서 *이벤트 관리*를 클릭하세요.



 a| 
스토리지 오브젝트 성능 상위 10개 항목 세부 정보
 a| 
*스토리지* > *클러스터* > *성능: 모든 클러스터*를 클릭한 다음 클러스터를 선택하고 *최고 성능* 탭을 선택합니다. 그런 다음 스토리지 오브젝트와 성능 카운터를 선택합니다.

|===
. *보고서* 버튼(또는 일부 UI 페이지에서는 *내보내기* 버튼)을 클릭하십시오.
. 내보내기 요청을 확인하려면 *CSV 다운로드*, *PDF 다운로드* 또는 *Excel 다운로드*를 클릭하십시오.
+
Top Performers 탭에서 현재 보고 있는 단일 클러스터 또는 데이터 센터의 모든 클러스터에 대한 통계 보고서를 다운로드할 수 있습니다.

+
파일이 다운로드되었습니다.

. 적절한 애플리케이션에서 파일을 엽니다.
