= Active IQ Unified Manager의 Linux 호스트 데이터 디렉토리에 공간 추가
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
처음에 Linux 호스트를 설정한 다음 Unified Manager를 설치할 때 Unified Manager를 지원하기 위해  `/opt/netapp/data` 디렉터리에 디스크 공간을 충분히 할당하지 않은 경우, 설치 후  `/opt/netapp/data` 디렉터리의 디스크 공간을 늘려 디스크 공간을 추가할 수 있습니다.

.시작하기 전에
Unified Manager가 설치된 Red Hat Enterprise Linux 시스템에 대한 루트 사용자 액세스 권한이 있어야 합니다.

데이터 디렉터리 크기를 늘리기 전에 Unified Manager 데이터베이스를 백업하는 것이 좋습니다.

.단계
. 디스크 공간을 추가하려는 Linux 머신에 루트 사용자로 로그인합니다.
. 다음 순서대로 Unified Manager 서비스와 관련 MySQL 소프트웨어를 중지하십시오: `systemctl stop ocieau ocie mysqld`
. 현재 `/opt/netapp/data` 디렉토리의 데이터를 저장할 수 있는 충분한 디스크 공간을 확보한 임시 백업 폴더(예: `/backup-data`)를 생성합니다.
. 기존  `/opt/netapp/data` 디렉터리의 내용과 권한 구성을 백업 데이터 디렉터리에 복사합니다:
+
`cp -arp /opt/netapp/data/* /backup-data`

. SE Linux가 활성화된 경우:
+
.. 기존  `/opt/netapp/data` 폴더의 폴더에 대한 SE Linux 유형을 가져옵니다:
+
`se_type=`ls -Z /opt/netapp/data| awk '{print $4}'| awk -F: '{print $3}'| head -1`

+
시스템은 다음과 유사한 확인 메시지를 반환합니다:

+
[listing]
----
echo $se_type
mysqld_db_t
----
.. 백업 디렉터리에 대한 SE Linux 유형을 설정하려면  `chcon` 명령을 실행하십시오:
+
`chcon -R --type=mysqld_db_t /backup-data`



.  `/opt/netapp/data` 디렉토리의 내용을 삭제하십시오:
+
.. `cd /opt/netapp/data`
.. `rm -rf *`


. LVM 명령어를 사용하거나 추가 디스크를 연결하여  `/opt/netapp/data` 디렉터리 크기를 최소 150GB로 확장하십시오.
+
[NOTE]
====
디스크에서 `/opt/netapp/data`를 생성한 경우,  `/opt/netapp/data`를 NFS 또는 CIFS 공유로 마운트하려고 시도해서는 안 됩니다. 이 경우 디스크 공간을 확장하려고 하면  `resize` 및  `extend` 등 일부 LVM 명령이 예상대로 작동하지 않을 수 있기 때문입니다.

====
.  `/opt/netapp/data` 디렉터리 소유자(mysql)와 그룹(root)이 변경되지 않았는지 확인하십시오:
+
`ls -ltr /opt/netapp/ | grep data`

+
시스템은 다음과 유사한 확인 메시지를 반환합니다:

+
[listing]
----
drwxr-xr-x.  17 mysql root  4096 Aug 28 13:08 data
----
. SE Linux가 활성화된 경우  `/opt/netapp/data` 디렉터리의 컨텍스트가 여전히 mysqld_db_t로 설정되어 있는지 확인하십시오:
+
.. `touch /opt/netapp/data/abc`
.. `ls -Z /opt/netapp/data/abc`
+
시스템은 다음과 유사한 확인 메시지를 반환합니다:

+
[listing]
----
-rw-r--r--. root root unconfined_u:object_r:mysqld_db_t:s0 /opt/netapp/data/abc
----


. 이 불필요한 파일로 인해 향후 데이터베이스 오류가 발생하지 않도록 파일 `abc`을 삭제하십시오.
.  `backup-data`에서 확장된  `/opt/netapp/data` 디렉터리로 내용을 다시 복사하십시오:
+
`cp -arp /backup-data/* /opt/netapp/data/`

. SE Linux가 활성화된 경우 다음 명령을 실행하십시오:
+
`chcon -R --type=mysqld_db_t /opt/netapp/data`

. MySQL 서비스를 시작하십시오:
+
`systemctl start mysqld`

. MySQL 서비스가 시작된 후 표시된 순서대로 ocie 및 ocieau 서비스를 시작하십시오:
+
`systemctl start ocie ocieau`

. 모든 서비스가 시작된 후 백업 폴더를 삭제하십시오 `/backup-data`:
+
`rm -rf /backup-data`
