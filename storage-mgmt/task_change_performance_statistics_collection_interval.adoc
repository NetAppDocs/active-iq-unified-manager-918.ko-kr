= Active IQ Unified Manager에서 성능 통계 수집 간격 변경
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
성능 통계의 기본 수집 간격은 5분입니다. 대규모 클러스터에서 기본 시간 내에 수집이 완료되지 않는 경우 이 간격을 10분 또는 15분으로 변경할 수 있습니다. 이 설정은 이 Unified Manager 인스턴스가 모니터링하는 모든 클러스터의 통계 수집에 적용됩니다.

.시작하기 전에
Unified Manager 서버의 유지 관리 콘솔에 로그인하도록 승인된 사용자 ID와 암호가 있어야 합니다.

성능 통계 수집이 제시간에 완료되지 않는 문제는 배너 메시지로 표시됩니다. `Unable to consistently collect from cluster <cluster_name> or Data collection is taking too long on cluster <cluster_name>.`

통계 수집에 문제가 발생하여 필요한 경우에만 수집 간격을 변경해야 합니다. 다른 이유로는 이 설정을 변경하지 마십시오.

[NOTE]
====
이 값을 기본값인 5분에서 변경하면 Unified Manager에서 보고하는 성능 이벤트의 수와 빈도에 영향을 줄 수 있습니다. 예를 들어, 시스템에서 정의한 성능 임계값은 정책이 30분 동안 초과될 때 이벤트를 발생시킵니다. 5분 간격으로 데이터를 수집하는 경우, 정책 초과는 6회 연속 수집 기간 동안 발생해야 합니다. 15분 간격으로 데이터를 수집하는 경우에는 2회 수집 기간 동안만 정책 초과가 발생하면 됩니다.

====
클러스터 설정 페이지 하단에 현재 통계 데이터 수집 간격을 나타내는 메시지가 표시됩니다.

.단계
. SSH를 사용하여 유지보수 사용자 계정으로 Unified Manager 호스트에 로그인합니다.
+
Unified Manager 유지 관리 콘솔 프롬프트가 표시됩니다.

. *성능 폴링 간격 구성*이라고 표시된 메뉴 옵션 번호를 입력한 다음 Enter 키를 누르십시오.
. 메시지가 표시되면 유지 관리 사용자 암호를 다시 입력하십시오.
. 설정하려는 새로운 폴링 간격을 숫자로 입력한 다음 Enter 키를 누르십시오.


Unified Manager의 데이터 수집 간격을 10분 또는 15분으로 변경했고 현재 외부 데이터 공급자(Graphite 등)에 연결되어 있는 경우, 데이터 공급자의 데이터 전송 간격을 Unified Manager의 데이터 수집 간격과 같거나 그 이상으로 변경해야 합니다.
