= Active IQ Unified Manager 버전의 지원되는 업그레이드 경로를 사용합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager는 각 버전별로 특정 업그레이드 경로를 지원합니다.

모든 Unified Manager 버전에서 최신 버전으로의 인플레이스 업그레이드가 가능한 것은 아닙니다. Unified Manager 업그레이드는 N-2 모델로 제한됩니다. 즉, 모든 플랫폼에서 다음 두 버전으로만 업그레이드할 수 있습니다. 예를 들어 Unified Manager 9.14 및 9.16에서만 Unified Manager 9.18으로 업그레이드할 수 있습니다.

지원되는 버전보다 이전 버전을 실행 중인 경우, Unified Manager 인스턴스를 먼저 지원되는 버전 중 하나로 업그레이드한 다음 현재 버전으로 업그레이드해야 합니다.

예를 들어, 설치된 버전이 Unified Manager 9.9이고 Unified Manager 9.14으로 업그레이드하려는 경우, 일련의 업그레이드 절차를 따라야 합니다.

.업그레이드 경로 예시:
. 9.11 -> 9.13 업그레이드
. 9.13 -> 9.14 업그레이드
. 9.13 -> 9.16 업그레이드
. 9.14 또는 9.16 -> 9.18 업그레이드
