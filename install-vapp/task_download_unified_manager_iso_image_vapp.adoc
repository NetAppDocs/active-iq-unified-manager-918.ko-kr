= Active IQ Unified Manager 업그레이드 파일을 다운로드하십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager를 업그레이드하기 전에 NetApp 지원 사이트에서 Unified Manager 업그레이드 파일을 다운로드하십시오.

.시작하기 전에
NetApp 지원 사이트의 로그인 자격 증명이 있어야 합니다.

.단계
. NetApp 지원 사이트에 로그인하십시오:
+
https://mysupport.netapp.com/site/products/all/details/activeiq-unified-manager/downloads-tab["NetApp 지원 사이트"]

. VMware vSphere에서 Unified Manager를 업그레이드하려면 다운로드 페이지로 이동하십시오.
. 업그레이드용  `.iso` 이미지를 다운로드하여 vSphere Client에서 접근 가능한 로컬 디렉터리 또는 네트워크 디렉터리에 저장하십시오.
. 체크섬을 확인하여 소프트웨어가 올바르게 다운로드되었는지 확인하십시오.
