= VMware vSphere에서 Active IQ Unified Manager 시작하기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
루트 인증서,  `README` 파일 및  `OVA` 파일을 포함하는  `.tar` 파일을 다운로드하고 Unified Manager를 가상 어플라이언스로 배포할 수 있습니다.



[[system-requirements]]
== 시스템 요구 사항

* 운영 체제: VMware ESXi 8.0
* RAM: 12 GB
* CPU: 총 9572 MHz
* 여유 디스크 공간: 5GB(씬 프로비저닝), 152GB(씩 프로비저닝)


자세한 시스템 요구 사항은 link:../install-vapp/concept_requirements_for_installing_unified_manager.html["Unified Manager 설치를 위한 요구 사항"] 및 link:http://mysupport.netapp.com/matrix["상호 운용성 매트릭스"]을(를) 참조하십시오.



[[install-active-iq-unified-manager]]
== Active IQ Unified Manager 설치



[[download-the-installer]]
=== 설치 프로그램을 다운로드하십시오

. 루트 인증서,  `README` 파일 및  `OVA` 파일이 포함된  `.tar` 파일을 다운로드합니다.
. vSphere Client에서 접근 가능한 로컬 디렉터리 또는 네트워크 디렉터리에 파일을 저장하십시오.
.  `.tar` 파일을 다운로드한 디렉토리에서  `tar -xvzf ActiveIQUnifiedManager-<version>.tar.gz` 명령을 입력합니다. + 필수  `OVA` 파일, 루트 인증서 및  `README` 파일이 대상 디렉토리에 압축 해제됩니다.




[[verify-integrity]]
=== 무결성 검증

 `OVA` 파일의 무결성은  `README` 파일에 제공된 단계를 따라 확인할 수 있습니다.



[[install-unified-manager]]
=== Unified Manager 설치

. vSphere Client에서 *파일 > OVF 템플릿 배포*를 클릭합니다.
. OVA 파일을 찾아서 마법사를 사용하여 ESXi 서버에 가상 어플라이언스를 배포하십시오.
. 검토 세부 정보 페이지의 게시자 섹션에서 메시지  `Entrust Code Signing - OVCS2 (Trusted certificate)`는 다운로드한 `OVA` 파일의 무결성을 확인합니다. 메시지 `Entrust Code Signing - OVCS2 (Invalid certificate)`의 경우, VMware vCenter Server를 7.0U3E 이상 버전으로 업그레이드하십시오.
. 템플릿 사용자 지정 페이지의 속성 탭에서 수행 중인 설치 유형에 필요한 필드를 입력하십시오:
+
** 정적 구성의 경우 모든 필드에 필수 정보를 입력하십시오. *보조 DNS* 필드에 정보를 추가하는 것은 필수가 아닙니다.
** IPv4를 사용하는 DHCP의 경우, 어떤 필드에도 정보를 입력하지 마십시오.
** IPv6를 사용하는 DHCP의 경우, “자동 IPv6 주소 지정 사용” 확인란을 선택하십시오. 다른 필드에는 정보를 추가하지 마십시오.


. VM의 전원을 켭니다.
. 콘솔 탭을 클릭하여 초기 부팅 프로세스를 확인하십시오.
. 시간대를 구성하십시오.
. Unified Manager 유지 관리 사용자 이름과 암호를 입력하십시오.


설치가 완료되면 Unified Manager 웹 UI에 연결하는 데 필요한 정보가 표시됩니다.
