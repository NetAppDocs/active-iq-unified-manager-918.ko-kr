= Active IQ Unified Manager 가상 머신을 다시 시작합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
유지 관리 콘솔에서 Unified Manager 가상 머신(VM)을 다시 시작할 수 있습니다. 새 보안 인증서를 생성한 후 또는 VM에 문제가 발생한 경우 VM을 다시 시작해야 합니다.

.시작하기 전에
* 가상 어플라이언스의 전원이 켜져 있어야 합니다.
* 유지 관리 사용자로 Unified Manager 유지 관리 콘솔에 로그인해야 합니다.


VMware *게스트 재시작* 옵션을 사용하여 vSphere에서 가상 머신을 재시작할 수도 있습니다. 다음을 참조하십시오. https://developer.broadcom.com/powercli/latest/vmware.vimautomation.core/commands/restart-vmguest/["Broadcom의 VMware vSphere PowerCLI CMDLET 참조에 있는 Restart-VMGuest cmdlet입니다."^]

.단계
. 유지 관리 콘솔에서 *시스템 구성* > *가상 머신 재부팅*을 선택합니다.
. 브라우저에서 Unified Manager 웹 UI를 실행하고 로그인하십시오.
