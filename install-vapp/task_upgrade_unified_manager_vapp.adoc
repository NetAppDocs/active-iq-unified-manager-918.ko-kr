= Active IQ Unified Manager 업그레이드
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager 9.14 또는 9.16 버전에서만 9.18 버전으로 업그레이드할 수 있습니다.

업그레이드 과정 중에는 Unified Manager를 사용할 수 없습니다. Unified Manager를 업그레이드하기 전에 실행 중인 모든 작업을 완료하십시오.

Unified Manager가 OnCommand Workflow Automation 인스턴스와 페어링되어 있고 두 제품 모두에 새 버전의 소프트웨어가 있는 경우, 두 제품의 연결을 해제한 다음 업그레이드를 수행한 후 Workflow Automation 연결을 새로 설정해야 합니다. 두 제품 중 하나만 업그레이드하는 경우에는 업그레이드 후 Workflow Automation에 로그인하여 Unified Manager에서 데이터를 계속 가져오는지 확인해야 합니다.

[NOTE]
====
Unified Manager 9.7에서 업그레이드한 시스템의 경우, Debian 버전의 파일 시스템 변경 사항으로 인해 9.14에서 9.18로 직접 업그레이드할 수 없습니다. 대신 다음 권장 업그레이드 경로를 따르십시오. 9.14 -> 9.16P2 -> 9.18.

====

. 또한 link:task_upgrade_unified_manager_virtual_appliance_vapp.html["Unified Manager 업그레이드"]에 설명된 단계를 따르십시오.
