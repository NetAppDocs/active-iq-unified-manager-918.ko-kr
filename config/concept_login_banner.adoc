= Active IQ Unified Manager에 로그인 배너 추가
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
로그인 배너를 추가하면 조직에서 로그인 및 로그아웃 시 시스템 접근 권한이 있는 사용자, 이용 약관 등 모든 정보를 표시할 수 있습니다.

스토리지 운영자나 관리자 등 모든 사용자는 로그인, 로그아웃 및 세션 시간 초과 시 이 로그인 배너 팝업을 볼 수 있습니다.
