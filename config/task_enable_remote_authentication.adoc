= Active IQ Unified Manager에서 원격 인증 활성화
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 서버가 인증 서버와 통신할 수 있도록 원격 인증을 활성화할 수 있습니다. 인증 서버 사용자는 Unified Manager 그래픽 인터페이스에 액세스하여 스토리지 객체 및 데이터를 관리할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 역할이 있어야 합니다.

[NOTE]
====
Unified Manager 서버는 인증 서버에 직접 연결되어 있어야 합니다. SSSD(System Security Services Daemon) 또는 NSLCD(Name Service LDAP Caching Daemon) 등 로컬 LDAP 클라이언트를 비활성화해야 합니다.

====
Open LDAP 또는 Active Directory를 사용하여 원격 인증을 활성화할 수 있습니다. 원격 인증이 비활성화된 경우 원격 사용자는 Unified Manager에 액세스할 수 없습니다.

원격 인증은 LDAP 및 LDAPS(보안 LDAP)를 통해 지원됩니다. Unified Manager는 보안되지 않은 통신에는 기본 포트로 389를, 보안 통신에는 기본 포트로 636을 사용합니다.

[NOTE]
====
사용자 인증에 사용되는 인증서는 X.509 형식을 준수해야 합니다.

====
.단계
. 왼쪽 탐색 창에서 *일반* > *원격 인증*을 클릭합니다.
. *원격 인증 사용...* 확인란을 선택합니다.
. 인증 서비스 필드에서 서비스 유형을 선택하고 인증 서비스를 구성합니다.
+
[cols="2*"]
|===
| 인증 유형의 경우... | 다음 정보를 입력하세요... 


 a| 
Active Directory
 a| 
** 다음 형식 중 하나로 된 인증 서버 관리자 이름:
+
*** `domainname\username`
*** `username@domainname`
*** `Bind Distinguished Name` (적절한 LDAP 표기법을 사용하여)


** 관리자 암호
** 기본 고유 이름(적절한 LDAP 표기법 사용)




 a| 
Open LDAP
 a| 
** 바인드 고유 이름(적절한 LDAP 표기법 사용)
** 바인드 비밀번호
** 기본 고유 이름


|===
+
Active Directory 사용자 인증에 시간이 오래 걸리거나 시간 초과가 발생하는 경우, 인증 서버의 응답 속도가 느린 것이 원인일 수 있습니다. Unified Manager에서 중첩 그룹 지원을 비활성화하면 인증 시간을 단축할 수 있습니다.

+
인증 서버에 대해 '보안 연결 사용' 옵션을 선택하면 Unified Manager는 SSL(Secure Sockets Layer) 프로토콜을 사용하여 인증 서버와 통신합니다.

. *선택 사항:* 인증 서버를 추가하고 인증을 테스트하십시오.
. *저장*을 클릭합니다.
