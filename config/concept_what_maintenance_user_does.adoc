= Active IQ Unified Manager의 유지 관리 사용자에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
유지보수 사용자는 Red Hat Enterprise Linux 시스템에 Unified Manager를 설치하는 동안 생성됩니다. 유지보수 사용자 이름은 "`umadmin`" 사용자입니다. 유지보수 사용자는 웹 UI에서 애플리케이션 관리자 역할을 가지며, 후속 사용자를 생성하고 역할을 할당할 수 있습니다.

유지 관리 사용자 또는 umadmin 사용자는 Unified Manager 유지 관리 콘솔에도 액세스할 수 있습니다.
