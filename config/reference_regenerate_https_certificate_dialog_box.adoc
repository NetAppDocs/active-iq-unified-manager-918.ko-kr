= Active IQ Unified Manager에서 HTTPS 인증서 재생성 대화 상자
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
HTTPS 인증서 재생성 대화 상자를 사용하면 보안 정보를 사용자 지정한 다음 해당 정보를 사용하여 새 HTTPS 인증서를 생성할 수 있습니다.

현재 인증서 정보가 이 페이지에 표시됩니다.

"\`현재 인증서 속성을 사용하여 재생성\`" 및 "\`현재 인증서 속성 업데이트\`" 옵션을 사용하면 현재 정보로 인증서를 재생성하거나 새 정보로 인증서를 생성할 수 있습니다.

* *일반 이름*
+
필수 항목입니다. 보안을 설정하려는 정규화된 도메인 이름(FQDN)입니다.

+
Unified Manager 고가용성 구성에서는 가상 IP 주소를 사용하십시오.

* *이메일*
+
선택 사항입니다. 소속 기관에 연락할 수 있는 이메일 주소이며, 일반적으로 인증서 관리자 또는 IT 부서의 이메일 주소입니다.

* *회사*
+
선택 사항입니다. 일반적으로 회사 법인명입니다.

* *부서*
+
선택 사항. 회사 내 부서명.

* *도시*
+
선택 사항. 회사 소재 도시.

* *상태*
+
(선택 사항) 회사 소재지(주 또는 도)를 약어 없이 기재해 주십시오.

* *국가*
+
선택 사항. 회사의 소재 국가입니다. 일반적으로 해당 국가의 두 글자 ISO 코드입니다.

* *다른 이름*
+
필수 항목입니다. 기존 localhost 또는 기타 네트워크 주소 외에 이 서버에 액세스하는 데 사용할 수 있는 추가적인 비기본 도메인 이름입니다. 각 대체 이름은 쉼표로 구분하십시오.

+
인증서의 대체 이름 필드에서 로컬 식별 정보를 제거하려면 "`Exclude local identifying information (e.g. localhost)`" 확인란을 선택합니다. 이 확인란을 선택하면 필드에 입력한 내용만 대체 이름 필드에 사용됩니다. 비워 두면 결과 인증서에 대체 이름 필드가 전혀 포함되지 않습니다.

* *키 크기 (키 알고리즘: RSA)*
+
키 알고리즘은 RSA로 설정되어 있습니다. 키 크기는 2048, 3072 또는 4096비트 중에서 선택할 수 있습니다. 기본 키 크기는 2048비트로 설정되어 있습니다.

* *유효기간*
+
기본 유효 기간은 397일입니다. 이전 버전에서 업그레이드한 경우 이전 인증서의 유효 기간이 변경되지 않은 상태로 표시될 수 있습니다.
