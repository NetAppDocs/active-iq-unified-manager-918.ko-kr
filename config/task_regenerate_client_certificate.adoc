= Active IQ Unified Manager에서 클라이언트 인증서 재생성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
유지보수 콘솔을 사용하여 Unified Manager 클라이언트 인증서를 재생성할 수 있습니다. 인증서의 유효 기간은 5년입니다.

.단계
. 유지보수 사용자로 로그인합니다.
. *Regenerate Client Certificate* 를 선택하고 *Enter* 를 누릅니다.
. 시스템에서 인증을 요청하면 필요한 자격 증명을 입력하십시오.
. *재생 확인*을 선택하고 *Enter* 키를 누르십시오.
. 인증서가 다시 생성되면 Unified Manager 서비스를 다시 시작하여 변경 사항을 적용하십시오.
. 업데이트된 인증서를 확인하려면 ONTAP에 로그인하십시오. 클라이언트 인증서 상태와 유효성 상태를 확인하십시오.


*관련 정보*  https://docs.netapp.com/us-en/ontap/authentication/manage-certificates-sm-task.html["System Manager로 ONTAP 인증서 관리"^]
