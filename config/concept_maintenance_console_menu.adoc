= Active IQ Unified Manager의 유지보수 콘솔 메뉴에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
유지 관리 콘솔은 Unified Manager 서버의 특수 기능 및 구성 설정을 유지 관리하고 관리할 수 있는 다양한 메뉴로 구성됩니다.

Unified Manager를 설치한 운영 체제에 따라 유지 관리 콘솔은 다음과 같은 메뉴로 구성됩니다:

* Unified Manager 업그레이드(VMware 전용)
* 네트워크 구성(VMware 전용)
* 시스템 구성(VMware 전용)
+
.. 지원/진단
.. 서버 인증서 재설정
.. 클라이언트 인증서 재생성
.. 백업 복원
.. 외부 데이터 제공자
.. 성능 폴링 간격 구성
.. SAML 인증 비활성화
.. 애플리케이션 포트 보기/변경
.. 디버그 로그 구성
.. MySQL 포트 3306에 대한 접근 제어
.. 종료




특정 메뉴 옵션에 액세스하려면 목록에서 번호를 선택합니다. 예를 들어, 백업 및 복원의 경우 _4_를 선택합니다.
