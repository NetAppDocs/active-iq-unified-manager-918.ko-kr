= Active IQ Unified Manager에서 정책 기반 스토리지 관리 활성화
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
*정책 기반 스토리지 관리* 옵션을 사용하면 서비스 수준 목표(SLO)에 따라 스토리지를 관리할 수 있습니다. 이 옵션은 기본적으로 활성화되어 있습니다.

이 기능을 활성화하면 Active IQ Unified Manager 인스턴스에 추가된 ONTAP 클러스터에 스토리지 워크로드를 프로비저닝하고, 할당된 Performance Service Levels 및 Storage Efficiency Policies를 기반으로 이러한 워크로드를 관리할 수 있습니다.

이 기능은 *일반* > *기능 설정* > *정책 기반 스토리지 관리*에서 활성화 또는 비활성화할 수 있습니다. 이 기능을 활성화하면 다음과 같은 페이지에서 운영 및 모니터링을 할 수 있습니다.

* 프로비저닝(스토리지 워크로드 프로비저닝)
* *정책* > *성능 서비스 수준*
* *정책* > *스토리지 효율성*
* 클러스터 설정 페이지의 성능 서비스 수준별로 관리되는 워크로드 열
* *대시보드*의 워크로드 성능 패널


이 화면을 사용하여 성능 서비스 수준 및 스토리지 효율성 정책을 생성하고 스토리지 워크로드를 프로비저닝할 수 있습니다. 또한 할당된 성능 서비스 수준을 준수하는 스토리지 워크로드와 준수하지 않는 워크로드를 모니터링할 수 있습니다. 또한 Workload Performance 및 Workload IOPS 패널을 통해 데이터 센터 전체 클러스터의 총 용량, 가용 용량 및 사용된 용량과 성능(IOPS)을 프로비저닝된 스토리지 워크로드를 기반으로 평가할 수 있습니다.

이 기능을 활성화하면 *메뉴 모음* > *도움말 버튼* > *API 문서* > *storage-provider* 범주에서 Unified Manager REST API를 실행하여 이러한 기능 중 일부를 수행할 수 있습니다. 또는 호스트 이름이나 IP 주소를 입력하여 +https://<hostname>/docs/api/+ 형식의 URL로 REST API 페이지에 액세스할 수 있습니다.

API에 대한 자세한 내용은 link:../api-automation/concept_get_started_with_um_apis.html["Active IQ Unified Manager REST API 시작하기"]을(를) 참조하십시오.
