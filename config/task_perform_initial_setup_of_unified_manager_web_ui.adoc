= Active IQ Unified Manager 웹 UI의 초기 설정을 수행하십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager를 사용하려면 먼저 NTP 서버, 유지 관리 사용자 이메일 주소, SMTP 서버 호스트, ONTAP 클러스터 추가 등 초기 설정 옵션을 구성해야 합니다.

.시작하기 전에
다음 작업을 수행해야 합니다:

* 설치 후 제공된 URL을 사용하여 Unified Manager 웹 UI를 실행했습니다
* 설치 중에 생성된 유지 관리 사용자 이름과 암호(Linux 설치의 경우 umadmin 사용자)를 사용하여 로그인했습니다.


Active IQ Unified ManagerGetting 시작하기 페이지는 웹 UI에 처음 접속할 때만 나타납니다. 아래 페이지는 VMware에 설치된 경우의 화면입니다.

image::../media/first_experience_wizard.JPG[VMware 설치 페이지를 보여주는 UI 스크린샷입니다.]

나중에 이러한 옵션을 변경하려면 Unified Manager 왼쪽 탐색 창의 일반 옵션에서 원하는 옵션을 선택할 수 있습니다. 참고로 NTP 설정은 VMware 설치에만 해당하며, 나중에 Unified Manager 유지보수 콘솔을 사용하여 변경할 수 있습니다.

.단계
. Active IQ Unified Manager 초기 설정 페이지에서 유지 관리 사용자 이메일 주소, SMTP 서버 호스트 이름 및 추가 SMTP 옵션, 그리고 NTP 서버(VMware 설치에만 해당)를 입력합니다. 그런 다음 *계속*을 클릭합니다.
+
[NOTE]
====
*STARTTLS 사용* 또는 *SSL 사용* 옵션을 선택한 경우, *계속* 버튼을 클릭하면 인증서 페이지가 표시됩니다. 인증서 세부 정보를 확인하고 인증서를 수락하여 웹 UI의 초기 설정을 계속 진행하십시오.

====
. AutoSupport 페이지에서 *동의하고 계속*을 클릭하여 AutoSupport 메시지를 Unified Manager에서 NetAppActive IQ로 보낼 수 있도록 설정하십시오.
+
웹 UI에서 *일반* > *AutoSupport* 옵션을 사용하여 AutoSupport 콘텐츠를 전송하기 위한 인터넷 액세스를 제공하는 프록시를 지정하거나 AutoSupport를 비활성화할 수 있습니다.

. Red Hat 시스템에서 umadmin 사용자 암호를 기본값인 "`admin`" 문자열에서 사용자 지정 문자열로 변경하십시오.
. API 게이트웨이 설정 페이지에서 Unified Manager가 ONTAP REST API를 사용하여 모니터링할 ONTAP 클러스터를 관리할 수 있도록 하는 API 게이트웨이 기능을 사용할지 여부를 선택합니다. 그런 다음 *계속*을 클릭합니다.
+
나중에 웹 UI의 *일반* > *기능 설정* > *API 게이트웨이*에서 이 설정을 활성화 또는 비활성화할 수 있습니다. API에 대한 자세한 내용은 link:../api-automation/concept_get_started_with_um_apis.html["Active IQ Unified Manager REST API 시작하기"]을(를) 참조하십시오.

. Unified Manager에서 관리할 클러스터를 추가한 다음 *다음*을 클릭하십시오. 관리할 각 클러스터에 대해 호스트 이름 또는 클러스터 관리 IP 주소(IPv4 또는 IPv6)와 사용자 이름 및 암호 자격 증명이 있어야 합니다. 사용자는 "`admin`" 역할을 보유해야 합니다.
+
이 단계는 선택 사항입니다. 나중에 웹 UI의 *스토리지 관리* > *클러스터 설정*에서 클러스터를 추가할 수 있습니다.

. 요약 페이지에서 모든 설정이 올바른지 확인하고 *완료*를 클릭하십시오.


시작하기 페이지가 닫히고 Unified Manager 대시보드 페이지가 표시됩니다.
