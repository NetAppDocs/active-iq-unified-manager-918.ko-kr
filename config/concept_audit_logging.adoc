= Active IQ Unified Manager의 감사 로그에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
감사 로그를 사용하여 감사 로그가 손상되었는지 여부를 확인할 수 있습니다. 사용자가 수행한 모든 활동은 모니터링되어 감사 로그에 기록됩니다. 감사는 Active IQ Unified Manager의 모든 사용자 인터페이스 및 공개적으로 노출된 API 기능에 대해 수행됩니다.

*감사 로그: 파일 보기*를 사용하여 Active IQ Unified Manager에서 사용 가능한 모든 감사 로그 파일을 보고 액세스할 수 있습니다. 감사 로그: 파일 보기의 파일은 생성 날짜를 기준으로 나열됩니다. 이 보기에는 시스템의 설치 또는 업그레이드 시점부터 현재까지 캡처된 모든 감사 로그의 정보가 표시됩니다. Unified Manager에서 작업을 수행할 때마다 정보가 업데이트되며 로그에서 확인할 수 있습니다. 각 로그 파일의 상태는 로그 파일의 변조 또는 삭제를 감지하기 위해 적극적으로 모니터링되는 "`File Integrity Status`" 속성을 사용하여 캡처됩니다. 감사 로그가 시스템에서 사용 가능한 경우 감사 로그는 다음 상태 중 하나를 가질 수 있습니다.

[cols="2*"]
|===
| 상태 | 설명 


 a| 
활성
 a| 
현재 로그가 기록되고 있는 파일입니다.



 a| 
정상
 a| 
시스템에 압축되어 저장되어 있는 비활성 파일입니다.



 a| 
변조됨
 a| 
사용자가 파일을 수동으로 편집하여 손상된 파일.



 a| 
MANUAL_DELETE
 a| 
권한 있는 사용자가 삭제한 파일입니다.



 a| 
ROLLOVER_DELETE
 a| 
롤링 구성 정책에 따른 롤오프로 인해 삭제된 파일입니다.



 a| 
UNEXPECTED_DELETE
 a| 
알 수 없는 이유로 삭제된 파일입니다.

|===
감사 로그 페이지에는 다음과 같은 명령 버튼이 포함되어 있습니다:

* 구성
* 삭제
* 다운로드


*DELETE* 버튼을 사용하면 감사 로그 보기에 나열된 감사 로그를 삭제할 수 있습니다. 감사 로그를 삭제할 수 있으며, 선택적으로 파일 삭제 사유를 제공할 수 있어 향후 유효한 삭제인지 판단하는 데 도움이 됩니다. REASON 열에는 삭제 작업을 수행한 사용자의 이름과 함께 사유가 표시됩니다.

[NOTE]
====
로그 파일을 삭제하면 시스템에서 파일이 삭제되지만 DB 테이블의 항목은 삭제되지 않습니다.

====
Active IQ Unified Manager의 감사 로그 섹션에서 *다운로드* 버튼을 사용하여 감사 로그를 다운로드하고 감사 로그 파일을 내보낼 수 있습니다. "`NORMAL`" 또는 "`TAMPERED`"로 표시된 파일은 압축된 `.gzip` 형식으로 다운로드됩니다.

감사 로그 파일은 주기적으로 보관되어 참조를 위해 데이터베이스에 저장됩니다. 보관하기 전에 보안 및 무결성 유지를 위해 감사 로그에 디지털 서명이 적용됩니다.

전체 AutoSupport 번들이 생성될 경우, 지원 번들에는 보관된 감사 로그 파일과 활성 감사 로그 파일이 모두 포함됩니다. 하지만 간소화된 지원 번들이 생성될 경우에는 활성 감사 로그만 포함됩니다. 보관된 감사 로그는 포함되지 않습니다.
