= Active IQ Unified Manager에서 세션 비활성 시간 초과 설정
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager의 비활성 시간 제한 값을 지정하여 일정 시간 동안 활동이 없으면 세션이 자동으로 종료되도록 할 수 있습니다. 기본적으로 시간 제한은 4,320분(72시간)으로 설정되어 있습니다.

.시작하기 전에
애플리케이션 관리자 역할이 있어야 합니다.

이 설정은 로그인한 모든 사용자 세션에 적용됩니다.

[NOTE]
====
Security Assertion Markup Language (SAML) 인증을 활성화한 경우에는 이 옵션을 사용할 수 없습니다.

====
.단계
. 왼쪽 탐색 창에서 *일반* > *기능 설정*을 클릭합니다.
. *기능 설정* 페이지에서 다음 옵션 중 하나를 선택하여 비활성 시간 제한을 지정하십시오:
+
[cols="2*"]
|===
| 원하신다면... | 그런 다음 이렇게 하십시오... 


 a| 
세션이 자동으로 종료되지 않도록 타임아웃을 설정하지 마십시오.
 a| 
* Inactivity Timeout * 패널에서 슬라이더 버튼을 왼쪽으로 이동(끄기)하고 * Apply * 를 클릭합니다.



 a| 
시간 초과 값을 특정 분 수로 설정하십시오.
 a| 
*비활성 시간 제한* 패널에서 슬라이더 버튼을 오른쪽(켜짐)으로 이동하고 비활성 시간 제한 값을 분 단위로 지정한 다음 *적용*을 클릭합니다.

|===
