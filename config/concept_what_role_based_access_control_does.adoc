= Active IQ Unified Manager의 역할 기반 액세스 제어에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
RBAC(역할 기반 액세스 제어)는 Active IQ Unified Manager 서버의 다양한 기능 및 리소스에 대한 액세스 권한을 제어할 수 있는 기능을 제공합니다. RBAC를 통해 관리자는 역할을 정의하여 사용자 그룹을 관리할 수 있습니다. 특정 기능에 대한 액세스를 특정 관리자로 제한해야 하는 경우 해당 관리자 계정을 설정해야 합니다. 관리자가 볼 수 있는 정보와 수행할 수 있는 작업을 제한하려면 생성한 관리자 계정에 역할을 적용해야 합니다.

관리 서버는 사용자 로그인 및 역할 권한에 RBAC를 사용합니다. 관리 서버의 관리자 사용자 액세스 기본 설정을 변경하지 않은 경우, 이를 확인하기 위해 로그인할 필요가 없습니다.

특정 권한이 필요한 작업을 시작하면 관리 서버에서 로그인하라는 메시지가 표시됩니다. 예를 들어 관리자 계정을 생성하려면 애플리케이션 관리자 계정으로 로그인해야 합니다.
