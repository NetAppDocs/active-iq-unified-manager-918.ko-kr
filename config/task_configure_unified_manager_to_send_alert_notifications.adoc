= Active IQ Unified Manager에서 알림 알림을 보내도록 구성합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
환경에서 발생하는 이벤트에 대해 알려주는 알림을 보내도록 Unified Manager를 구성할 수 있습니다. 알림을 보내기 전에 몇 가지 다른 Unified Manager 옵션을 구성해야 합니다.

.시작하기 전에
애플리케이션 관리자 역할이 있어야 합니다.

Unified Manager를 배포하고 초기 구성을 완료한 후, 이벤트 수신을 기반으로 경고를 트리거하고 알림 이메일 또는 SNMP 트랩을 생성하도록 환경을 구성하는 것을 고려해야 합니다.

.단계
. link:task_configure_event_notification_settings.html["이벤트 알림 설정 구성"].
+
환경에서 특정 이벤트가 발생했을 때 경고 알림이 전송되도록 하려면 SMTP 서버를 구성하고 경고 알림을 발송할 이메일 주소를 제공해야 합니다. SNMP 트랩을 사용하려면 해당 옵션을 선택하고 필요한 정보를 제공할 수 있습니다.

. link:task_enable_remote_authentication.html["원격 인증 활성화"].
+
원격 LDAP 또는 Active Directory 사용자가 Unified Manager 인스턴스에 액세스하고 경고 알림을 수신할 수 있도록 하려면 원격 인증을 활성화해야 합니다.

. link:task_add_authentication_servers.html["인증 서버 추가"].
+
인증 서버를 추가하면 인증 서버 내의 원격 사용자가 Unified Manager에 액세스할 수 있습니다.

. link:task_add_users.html["사용자 추가"].
+
로컬 또는 원격 사용자를 여러 유형으로 추가하고 특정 역할을 할당할 수 있습니다. 알림을 생성할 때 알림을 받을 사용자를 지정합니다.

. link:task_add_alerts.html["알림 추가"].
+
알림 전송용 이메일 주소를 추가하고, 알림을 받을 사용자를 추가하고, 네트워크 설정을 구성하고, 환경에 필요한 SMTP 및 SNMP 옵션을 구성한 후에는 알림을 할당할 수 있습니다.
