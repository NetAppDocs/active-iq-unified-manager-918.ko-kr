= Active IQ Unified Manager 감사 로그 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
감사 로그 섹션의 *구성* 버튼을 사용하여 감사 로그 파일에 대한 롤링 정책을 구성하고 감사 로그에 대한 원격 로깅을 활성화할 수 있습니다.

시스템에 저장할 데이터의 양과 빈도에 따라 *최대 파일 크기* 및 *감사 로그 보존 기간(일)*의 값을 설정할 수 있습니다. *총 감사 로그 크기* 필드의 값은 시스템에 있는 전체 감사 로그 데이터의 크기입니다. 롤오버 정책은 *감사 로그 보존 기간(일)*, *최대 파일 크기* 및 *총 감사 로그 크기* 필드의 값에 따라 결정됩니다. 감사 로그 백업 크기가 *총 감사 로그 크기*에 구성된 값에 도달하면 가장 먼저 아카이브된 파일이 삭제됩니다. 즉, 가장 오래된 파일이 삭제됩니다. 하지만 파일 항목은 데이터베이스에서 계속 사용할 수 있으며 "`Rollover Delete`"로 표시됩니다. *감사 로그 보존 기간(일)* 값은 감사 로그 파일이 보존되는 일수입니다. 이 필드에 설정된 값보다 오래된 파일은 롤오버됩니다.

.단계
. *감사 로그* > > *구성*을 클릭합니다.
. *최대 파일 크기*, *총 감사 로그 크기*, *감사 로그 보존 기간(일)*에 값을 입력하십시오.
+
원격 로깅을 활성화하려면 *원격 로깅 활성화*를 선택하십시오.
