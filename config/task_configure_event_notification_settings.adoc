= Active IQ Unified Manager에서 이벤트 알림 설정 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager를 구성하여 이벤트가 발생하거나 사용자에게 이벤트가 할당될 때 경고 알림을 보낼 수 있습니다. 경고를 보내는 데 사용할 SMTP 서버를 구성할 수 있으며, 이메일이나 SNMP 트랩 등 다양한 알림 메커니즘을 설정할 수 있습니다.

.시작하기 전에
다음 정보를 준비해 두셔야 합니다:

* 경고 알림이 전송되는 이메일 주소
+
이메일 주소는 전송된 알림의 "`From`" 필드에 표시됩니다. 어떤 이유로든 이메일이 전달되지 않으면 이 이메일 주소가 배달 실패 메일의 수신자로도 사용됩니다.

* SMTP 서버 호스트 이름과 서버에 접속하기 위한 사용자 이름 및 비밀번호
* SNMP 트랩을 수신할 트랩 대상 호스트의 호스트 이름 또는 IP 주소와 함께 SNMP 버전, 아웃바운드 트랩 포트, 커뮤니티 및 기타 필요한 SNMP 구성 값
+
여러 개의 트랩 대상을 지정하려면 각 호스트를 쉼표로 구분하십시오. 이 경우 버전 및 아웃바운드 트랩 포트 등 다른 모든 SNMP 설정은 목록에 있는 모든 호스트에 대해 동일해야 합니다.



애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

.단계
. 왼쪽 탐색 창에서 *일반* > *알림*을 클릭합니다.
. 알림 페이지에서 적절한 설정을 구성하십시오.
+
*참고:*

+
** 보내는 사람 주소가 "+ActiveIQUnifiedManager@localhost.com+"으로 미리 채워져 있는 경우, 모든 이메일 알림이 성공적으로 전달되도록 실제 사용 가능한 이메일 주소로 변경해야 합니다.
** SMTP 서버의 호스트 이름을 확인할 수 없는 경우, 호스트 이름 대신 SMTP 서버의 IP 주소(IPv4 또는 IPv6)를 지정할 수 있습니다.


. *저장*을 클릭합니다.
. *STARTTLS 사용* 또는 *SSL 사용* 옵션을 선택한 경우, *저장* 버튼을 클릭하면 인증서 페이지가 표시됩니다. 인증서 세부 정보를 확인하고 인증서를 승인하여 알림 설정을 저장하십시오.
+
*인증서 세부 정보 보기* 버튼을 클릭하여 인증서 세부 정보를 볼 수 있습니다. 기존 인증서가 만료된 경우 *STARTTLS 사용* 또는 *SSL 사용* 확인란의 선택을 해제하고 알림 설정을 저장한 다음, *STARTTLS 사용* 또는 *SSL 사용* 확인란을 다시 선택하여 새 인증서를 확인하십시오.
