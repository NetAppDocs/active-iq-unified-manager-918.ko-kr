= Active IQ Unified Manager에서 HTTP 및 HTTPS 프로토콜에 사용하는 포트 변경
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager에서 HTTP 및 HTTPS 프로토콜에 사용하는 기본 포트는 보안을 위해 필요한 경우 설치 후 변경할 수 있습니다. 기본 포트는 HTTP의 경우 80이고 HTTPS의 경우 443입니다.

.시작하기 전에
Unified Manager 서버의 유지 관리 콘솔에 로그인하도록 승인된 사용자 ID와 암호가 있어야 합니다.

[NOTE]
====
Mozilla Firefox 또는 Google Chrome 브라우저를 사용할 때 안전하지 않은 것으로 간주되는 포트가 일부 있습니다. HTTP 및 HTTPS 트래픽에 새 포트 번호를 할당하기 전에 브라우저에서 확인하십시오. 안전하지 않은 포트를 선택하면 시스템에 액세스할 수 없게 될 수 있으며, 이 경우 고객 지원에 문의하여 해결해야 합니다.

====
포트를 변경하면 Unified Manager 인스턴스가 자동으로 다시 시작되므로, 시스템을 잠시 중단할 수 있는 적절한 시점인지 확인하십시오.

. SSH를 사용하여 유지보수 사용자 계정으로 Unified Manager 호스트에 로그인합니다.
+
Unified Manager 유지 관리 콘솔 프롬프트가 표시됩니다.

. *애플리케이션 포트 보기/변경*이라고 표시된 메뉴 옵션 번호를 입력한 다음 Enter 키를 누르십시오.
. 메시지가 표시되면 유지 관리 사용자 암호를 다시 입력하십시오.
. HTTP 및 HTTPS 포트에 대한 새 포트 번호를 입력한 다음 Enter 키를 누르십시오.
+
포트 번호를 비워 두면 프로토콜의 기본 포트가 할당됩니다.

+
포트를 변경하고 Unified Manager를 지금 다시 시작할지 묻는 메시지가 표시됩니다.

. 포트를 변경하고 Unified Manager를 다시 시작하려면 *y*를 입력하십시오.
. 유지보수 콘솔을 종료합니다.


이 변경 후에는 사용자가 Unified Manager 웹 UI에 액세스하기 위해 URL에 새 포트 번호를 포함해야 합니다. 예를 들어 +https://host.company.com:1234+, +https://12.13.14.15:1122+ 또는 +https://[2001:db8:0:1]:2123+와 같습니다.
