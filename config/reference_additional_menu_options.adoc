= Active IQ Unified Manager의 추가 유지 관리 콘솔 메뉴 옵션에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
다음 메뉴 옵션을 사용하면 Unified Manager 서버에서 다양한 관리 작업을 수행할 수 있습니다.

다음과 같은 메뉴를 선택할 수 있습니다:

* *서버 인증서 재설정*
+
HTTPS 서버 인증서를 재생성합니다.

+
Unified Manager GUI에서 *일반* > *HTTPS 인증서* > *HTTPS 인증서 재생성*을 클릭하여 서버 인증서를 다시 생성할 수 있습니다.

* *SAML 인증 비활성화*
+
SAML 인증을 비활성화하여 ID 공급자(IdP)가 Unified Manager GUI에 액세스하는 사용자에게 더 이상 로그인 인증을 제공하지 않도록 합니다. 이 콘솔 옵션은 일반적으로 IdP 서버 또는 SAML 구성의 문제로 인해 사용자가 Unified Manager GUI에 액세스할 수 없는 경우에 사용됩니다.

* *외부 데이터 제공업체*
+
Unified Manager를 외부 데이터 공급자에 연결하는 옵션을 제공합니다. 연결이 설정되면 성능 데이터가 외부 서버로 전송되어 스토리지 성능 전문가가 타사 소프트웨어를 사용하여 성능 지표를 차트로 나타낼 수 있습니다. 다음 옵션이 표시됩니다.

+
** *서버 구성 표시*--외부 데이터 공급자에 대한 현재 연결 및 구성 설정을 표시합니다.
** *서버 연결 추가/수정*--외부 데이터 공급자에 대한 새 연결 설정을 입력하거나 기존 설정을 변경할 수 있습니다.
** *서버 구성 수정*--외부 데이터 공급자에 대한 새 구성 설정을 입력하거나 기존 설정을 변경할 수 있습니다.
** *서버 연결 삭제*--외부 데이터 공급자와의 연결을 삭제합니다.
+
연결이 삭제되면 Unified Manager는 외부 서버와의 연결이 끊어집니다.



* *백업 복원*
+
자세한 내용은 link:../health-checker/concept_manage_backup_and_restore_operations.html["백업 및 복원 작업 관리"] 아래의 항목을 참조하십시오.

* *성능 폴링 간격 구성*
+
Unified Manager가 클러스터에서 성능 통계 데이터를 수집하는 빈도를 구성하는 옵션을 제공합니다. 기본 수집 간격은 5분입니다.

+
대규모 클러스터에서 데이터 수집이 제시간에 완료되지 않는 경우 이 간격을 10분 또는 15분으로 변경할 수 있습니다.

* *애플리케이션 포트 보기/변경*
+
보안상의 이유로 필요한 경우 Unified Manager에서 HTTP 및 HTTPS 프로토콜에 사용하는 기본 포트를 변경할 수 있는 옵션을 제공합니다. 기본 포트는 HTTP의 경우 80, HTTPS의 경우 443입니다.

* *MySQL 포트 3306에 대한 액세스 제어*
+
기본 MySQL 포트 3306에 대한 호스트 액세스를 제어합니다. 보안상의 이유로, Linux, Windows 및 VMware vSphere 시스템에 Unified Manager를 새로 설치할 경우 이 포트를 통한 액세스는 localhost로만 제한됩니다. 이 옵션을 사용하면 localhost와 원격 호스트 간에 이 포트의 가시성을 전환할 수 있습니다. 즉, 환경에서 localhost에 대해서만 이 포트를 사용하도록 설정한 경우 원격 호스트에서도 이 포트를 사용할 수 있도록 설정할 수 있습니다. 반대로 모든 호스트에 대해 이 옵션을 사용하도록 설정한 경우 localhost로만 액세스를 제한할 수 있습니다. 이전에 원격 호스트에서 액세스가 허용된 경우 업그레이드 시나리오에서 구성이 유지됩니다. Windows 시스템에서 포트 가시성을 전환한 후에는 방화벽 설정을 확인하고, MySQL 포트 3306에 대한 액세스가 제한되도록 설정된 경우 방화벽 설정을 해제해야 합니다.

* *종료*
+
유지보수 콘솔 메뉴를 종료합니다.
