= Active IQ Unified Manager에서 Active Directory 또는 OpenLDAP으로 인증
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
관리 서버에서 원격 인증을 활성화하고 관리 서버가 인증 서버와 통신하도록 구성하면 인증 서버 내의 사용자가 Unified Manager에 액세스할 수 있습니다.

다음과 같은 사전 정의된 인증 서비스 중 하나를 사용하거나 사용자 지정 인증 서비스를 지정할 수 있습니다:

* Microsoft Active Directory
+
[NOTE]
====
Microsoft Lightweight Directory Services를 사용할 수 없습니다.

====
* OpenLDAP


필요한 인증 서비스를 선택하고 적절한 인증 서버를 추가하여 인증 서버의 원격 사용자가 Unified Manager에 액세스할 수 있도록 설정할 수 있습니다. 원격 사용자 또는 그룹의 자격 증명은 인증 서버에서 관리됩니다. 관리 서버는 구성된 인증 서버 내의 원격 사용자를 인증하기 위해 Lightweight Directory Access Protocol(LDAP)을 사용합니다.

Unified Manager에서 생성된 로컬 사용자의 경우 관리 서버는 사용자 이름과 암호에 대한 자체 데이터베이스를 유지 관리합니다. 관리 서버는 인증을 수행하며 Active Directory 또는 OpenLDAP를 인증에 사용하지 않습니다.
