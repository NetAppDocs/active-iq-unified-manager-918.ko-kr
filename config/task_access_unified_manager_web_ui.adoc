= Active IQ Unified Manager에서 웹 UI에 액세스합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager를 설치한 후에는 웹 UI에 접속하여 Unified Manager를 설정하고 ONTAP 시스템 모니터링을 시작할 수 있습니다.

.시작하기 전에
* 웹 UI에 처음 접속하는 경우 유지 관리 사용자(또는 Linux 설치의 경우 umadmin 사용자)로 로그인해야 합니다.
* 사용자가 정규화된 도메인 이름(FQDN)이나 IP 주소 대신 짧은 이름을 사용하여 Unified Manager에 액세스하도록 허용하려는 경우, 네트워크 구성에서 이 짧은 이름을 유효한 FQDN으로 확인해야 합니다.
* 서버가 자체 서명된 디지털 인증서를 사용하는 경우 브라우저에 해당 인증서가 신뢰할 수 없다는 경고가 표시될 수 있습니다. 위험을 인지하고 액세스를 계속하거나 서버 인증을 위해 인증 기관(CA)에서 서명한 디지털 인증서를 설치할 수 있습니다.


.단계
. 설치가 완료될 때 표시되는 URL을 사용하여 브라우저에서 Unified Manager 웹 UI를 시작하십시오. 해당 URL은 Unified Manager 서버의 IP 주소 또는 정규화된 도메인 이름(FQDN)입니다.
+
링크는 다음과 같은 형식입니다: `\https://URL`.

. 유지보수 사용자 자격 증명을 사용하여 Unified Manager 웹 UI에 로그인하십시오.



NOTE: 한 시간 내에 웹 UI 로그인 시도가 세 번 연속 실패할 경우 시스템 접속이 차단되며, 시스템 관리자에게 문의해야 합니다. 이는 로컬 사용자에게만 적용됩니다.
