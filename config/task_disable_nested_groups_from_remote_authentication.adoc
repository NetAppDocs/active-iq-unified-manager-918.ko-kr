= Active IQ Unified Manager의 원격 인증에서 중첩 그룹 비활성화
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
원격 인증이 활성화된 경우, 중첩 그룹 인증을 비활성화하여 그룹 구성원이 아닌 개별 사용자만 Unified Manager에 원격으로 인증할 수 있도록 할 수 있습니다. Active Directory 인증 응답 시간을 개선하려는 경우 중첩 그룹을 비활성화할 수 있습니다.

.시작하기 전에
* 애플리케이션 관리자 역할이 있어야 합니다.
* 중첩 그룹 비활성화는 Active Directory를 사용하는 경우에만 적용됩니다.


Unified Manager에서 중첩 그룹 지원을 비활성화하면 인증 시간이 단축될 수 있습니다. 중첩 그룹 지원이 비활성화된 상태에서 원격 그룹을 Unified Manager에 추가하면 개별 사용자는 Unified Manager에 인증하기 위해 해당 원격 그룹의 구성원이어야 합니다.

.단계
. 왼쪽 탐색 창에서 *일반* > *원격 인증*을 클릭합니다.
. *중첩 그룹 조회 사용 안 함* 확인란을 선택하세요.
. *저장*을 클릭합니다.
