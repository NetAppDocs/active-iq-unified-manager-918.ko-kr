= Active IQ Unified Manager에서 애그리게이트 대화 상자 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
애그리게이트 대화 상자를 사용하여 리소스 풀에 추가할 애그리게이트를 선택할 수 있습니다.



[[command-buttons]]
== 명령 버튼

명령 버튼을 사용하면 다음과 같은 작업을 수행할 수 있습니다:

* *추가*
+
선택한 애그리게이트를 리소스 풀에 추가합니다. 애그리게이트가 하나 이상 선택될 때까지 추가 버튼이 활성화되지 않습니다.

* *취소*
+
변경 사항을 취소하고 애그리게이트 대화 상자를 닫습니다.





[[aggregates-list]]
== 애그리게이트 목록

애그리게이트 목록에는 모니터링되는 애그리게이트의 이름과 속성이 (표 형식으로) 표시됩니다.

* *상태*
+
볼륨의 현재 상태를 표시합니다. 상태는 심각(image:../media/sev_critical_um60.png[""]), 오류(image:../media/sev_error_um60.png[""]), 경고(image:../media/sev_warning_um60.png[""]) 또는 정상(image:../media/sev_normal_um60.png[""])일 수 있습니다.

+
상태 위로 포인터를 이동하면 해당 볼륨에 대해 생성된 이벤트에 대한 자세한 정보를 볼 수 있습니다.

* *애그리게이트 이름*
+
애그리게이트의 이름을 표시합니다.

* *상태*
+
애그리게이트의 현재 상태를 표시하며, 상태는 다음 중 하나일 수 있습니다:

+
** 오프라인
+
읽기 또는 쓰기 액세스가 허용되지 않습니다.

** 제한됨
+
제한적인 작업(패리티 재구성 등)은 허용되지만 데이터 액세스는 허용되지 않습니다.

** 온라인
+
이 애그리게이트에 호스팅된 볼륨에 대한 읽기 및 쓰기 액세스가 허용됩니다.

** 생성
+
애그리게이트가 생성되고 있습니다.

** 폐기
+
애그리게이트가 파기되고 있습니다.

** 실패
+
애그리게이트를 온라인 상태로 전환할 수 없습니다.

** 동결됨
+
애그리게이트가 (일시적으로) 요청을 처리하지 않고 있습니다.

** 일관성 없는
+
애그리게이트가 손상된 것으로 표시되었습니다. 기술 지원에 문의해야 합니다.

** Iron 제한
+
애그리게이트에서 진단 툴을 실행할 수 없습니다.

** 마운트
+
애그리게이트가 마운트되는 중입니다.

** 부분적
+
애그리게이트에 대해 최소 하나의 디스크가 발견되었지만 두 개 이상의 디스크가 누락되었습니다.

** 정지
+
애그리게이트가 정지되고 있습니다.

** 정지
+
애그리게이트가 정지되었습니다.

** 되돌려짐
+
애그리게이트 되돌리기가 완료되었습니다.

** 마운트 해제됨
+
애그리게이트가 오프라인 상태입니다.

** 마운트 해제
+
애그리게이트가 오프라인으로 전환되고 있습니다.

** 알 수 없음
+
애그리게이트는 발견되었지만 Unified Manager 서버에서 애그리게이트 정보를 아직 가져오지 못했습니다.



* *클러스터*
+
애그리게이트가 위치한 클러스터의 이름을 표시합니다.

* *노드*
+
애그리게이트를 포함하는 스토리지 컨트롤러의 이름을 표시합니다.

* *총 용량*
+
애그리게이트의 총 데이터 크기(MB, GB 등)를 표시합니다. 기본적으로 이 열은 숨겨져 있습니다.

* *약정 용량*
+
애그리게이트의 모든 볼륨에 대해 할당된 총 공간(MB, GB 등)을 표시합니다. 기본적으로 이 열은 숨겨져 있습니다.

* *사용 용량*
+
애그리게이트에 사용된 공간의 양(MB, GB 등)을 표시합니다.

* *사용 가능 용량*
+
애그리게이트에서 데이터에 사용할 수 있는 공간의 양(MB, GB 등)을 표시합니다. 기본적으로 이 열은 숨겨져 있습니다.

* *사용 가능 %*
+
애그리게이트에서 데이터에 사용할 수 있는 공간의 비율을 표시합니다. 기본적으로 이 열은 숨겨져 있습니다.

* *사용된 %*
+
애그리게이트에서 데이터가 사용하는 공간의 비율을 표시합니다.

* *RAID 유형*
+
선택한 볼륨의 RAID 유형을 표시합니다. RAID 유형은 RAID0, RAID4, RAID-DP, RAID-TEC 또는 혼합 RAID일 수 있습니다.
