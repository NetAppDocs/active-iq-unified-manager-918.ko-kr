= Active IQ Unified Manager에서 SnapVault 정책 생성 대화 상자 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SnapVault 정책 생성 대화 상자를 사용하면 SnapVault 전송의 우선 순위를 설정하는 정책을 만들 수 있습니다. 정책을 사용하면 기본 볼륨에서 보조 볼륨으로의 전송 효율성을 극대화할 수 있습니다.

* *타겟 클러스터*
+
보호 구성 대화 상자의 SnapVault 탭에서 선택한 클러스터의 이름입니다.

* *타겟 SVM*
+
보호 구성 대화 상자의 SnapVault 탭에서 선택한 SVM의 이름입니다.

* *정책명*
+
새 정책에 지정할 이름입니다. 정책 이름은 A부터 Z, a부터 z, 0부터 9, 마침표(.), 하이픈(-), 밑줄(_)로 구성될 수 있습니다.

* *전송 우선순위*
+
전송 실행 우선순위입니다. 보통 또는 낮음 중에서 선택할 수 있습니다. 전송 우선순위가 보통으로 지정된 정책이 적용된 전송 관계는 낮은 우선순위로 지정된 정책이 적용된 관계보다 먼저 실행됩니다. 기본 설정은 보통입니다.

* *코멘트*
+
SnapVault 정책에 대한 설명을 최대 255자까지 추가할 수 있는 선택 입력란입니다.

* *액세스 시간 무시*
+
액세스 시간만 변경된 파일에 대해 증분 전송을 무시할지 여부를 지정합니다.

* *복제 라벨*
+
정책에서 특정 복제 레이블이 있는 ONTAP에서 선택한 Snapshot 복사본과 관련된 규칙을 표에 나열합니다. 다음 정보 및 작업도 사용할 수 있습니다.

+
** 명령 버튼
+
명령 버튼을 사용하면 다음과 같은 작업을 수행할 수 있습니다:

+
*** 추가
+
스냅샷 사본 라벨과 보존 횟수를 생성할 수 있습니다.

*** 보존 횟수 편집
+
기존 Snapshot 사본 레이블의 보존 횟수를 변경할 수 있습니다. 보존 횟수는 1에서 251 사이의 숫자여야 합니다. 모든 규칙에 대한 모든 보존 횟수의 합계는 251을 초과할 수 없습니다.

*** 삭제
+
기존 Snapshot 복사본 레이블을 삭제할 수 있습니다.



** 스냅샷 복사본 레이블
+
스냅샷 복사본 레이블을 표시합니다. 동일한 로컬 스냅샷 복사본 정책이 적용된 볼륨을 하나 이상 선택하면 해당 정책의 각 레이블에 대한 항목이 표시됩니다. 두 개 이상의 로컬 스냅샷 복사본 정책이 적용된 볼륨을 여러 개 선택하면 모든 정책의 모든 레이블이 표에 표시됩니다

** 일정
+
각 Snapshot 복사본 레이블과 연결된 일정을 표시합니다. 레이블에 두 개 이상의 일정이 연결된 경우 해당 레이블의 일정은 쉼표로 구분된 목록으로 표시됩니다. 동일한 레이블을 사용하지만 일정이 서로 다른 여러 볼륨을 선택하면 선택한 볼륨에 두 개 이상의 일정이 연결되어 있음을 나타내기 위해 일정에 "`Various`"가 표시됩니다.

** 타겟 보존 개수
+
SnapVault 보조에 보존된 지정된 레이블이 있는 스냅샷 복사본 수를 표시합니다. 여러 스케줄이 있는 레이블의 보존 횟수는 각 레이블과 스케줄 쌍의 보존 횟수 합계를 표시합니다. 두 개 이상의 로컬 스냅샷 복사본 정책이 있는 여러 볼륨을 선택한 경우 보존 횟수는 비어 있습니다.
