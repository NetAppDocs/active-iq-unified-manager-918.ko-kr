= Active IQ Unified Manager의 리소스 풀 페이지에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
리소스 풀 페이지에는 기존 리소스 풀과 해당 구성원이 표시되며, 프로비저닝 목적으로 리소스 풀을 생성, 모니터링 및 관리할 수 있습니다.



[[command-buttons]]
== 명령 버튼

명령 버튼을 사용하면 다음과 같은 작업을 수행할 수 있습니다:

* *만들기*
+
리소스 풀을 생성하는 데 사용할 수 있는 리소스 풀 생성 대화 상자를 실행합니다.

* *편집*
+
생성하는 리소스 풀의 이름과 설명을 편집할 수 있습니다.

* *삭제*
+
하나 이상의 리소스 풀을 삭제할 수 있습니다.





[[resource-pools-list]]
== 리소스 풀 목록

리소스 풀 목록에는 기존 리소스 풀의 속성이 표 형식으로 표시됩니다.

* *리소스 풀*
+
리소스 풀의 이름을 표시합니다.

* *설명*
+
리소스 풀을 설명합니다.

* *SnapLock 타입*
+
리소스 풀의 애그리게이트에서 사용 중인 SnapLock 유형을 표시합니다. SnapLock 유형의 유효한 값은 Compliance, Enterprise 및 Non-SnapLock입니다. 리소스 풀에는 하나의 SnapLock 유형의 애그리게이트만 포함될 수 있습니다.

* *총 용량*
+
리소스 풀의 전체 용량(MB, GB 등)을 표시합니다.

* *사용 용량*
+
리소스 풀에서 사용되는 공간의 양(MB, GB 등)을 표시합니다.

* *사용 가능 용량*
+
리소스 풀에서 사용 가능한 공간(MB, GB 등)을 표시합니다.

* *사용된 %*
+
리소스 풀에서 사용된 공간의 백분율을 표시합니다.





[[members-list-command-buttons]]
== 멤버 목록 명령 버튼

멤버 목록 명령 버튼을 사용하면 다음과 같은 작업을 수행할 수 있습니다.

* *추가*
+
리소스 풀에 멤버를 추가할 수 있습니다.

* *삭제*
+
리소스 풀에서 하나 이상의 멤버를 삭제할 수 있습니다.





[[members-list]]
== 멤버 목록

리소스 풀이 선택되면 멤버 목록에 리소스 풀 멤버와 해당 속성이 표 형식으로 표시됩니다.

* *상태*
+
멤버 애그리게이트의 현재 상태를 표시합니다. 상태는 위험(image:../media/sev_critical_um60.png[""]), 오류(image:../media/sev_error_um60.png[""]), 경고(image:../media/sev_warning_um60.png[""]) 또는 정상(image:../media/sev_normal_um60.png[""])일 수 있습니다.

* *애그리게이트 이름*
+
멤버 애그리게이트의 이름을 표시합니다.

* *상태*
+
애그리게이트의 현재 상태를 표시하며, 상태는 다음 중 하나일 수 있습니다:

+
** 오프라인
+
읽기 또는 쓰기 액세스가 허용되지 않습니다.

** 온라인
+
이 애그리게이트에 호스팅된 볼륨에 대한 읽기 및 쓰기 액세스가 허용됩니다.

** 제한됨
+
제한적인 작업(패리티 재구성 등)은 허용되지만 데이터 액세스는 허용되지 않습니다.

** 생성
+
애그리게이트가 생성되고 있습니다.

** 폐기
+
애그리게이트가 파기되고 있습니다.

** 실패
+
애그리게이트를 온라인 상태로 전환할 수 없습니다.

** 동결됨
+
애그리게이트가 (일시적으로) 요청을 처리하지 않고 있습니다.

** 일관성 없는
+
애그리게이트가 손상된 것으로 표시되었습니다. 기술 지원에 문의해야 합니다.

** Iron 제한
+
애그리게이트에서 진단 툴을 실행할 수 없습니다.

** 마운트
+
애그리게이트가 마운트되는 중입니다.

** 부분적
+
애그리게이트에 대해 최소 하나의 디스크가 발견되었지만 두 개 이상의 디스크가 누락되었습니다.

** 정지
+
애그리게이트가 정지되고 있습니다.

** 정지
+
애그리게이트가 정지되었습니다.

** 되돌려짐
+
애그리게이트 되돌리기가 완료되었습니다.

** 마운트 해제됨
+
애그리게이트가 마운트 해제되었습니다.

** 마운트 해제
+
애그리게이트가 오프라인으로 전환되고 있습니다.

** 알 수 없음
+
애그리게이트는 발견되었지만 Unified Manager 서버에서 애그리게이트 정보를 아직 가져오지 못했습니다.



+
기본적으로 이 열은 숨겨져 있습니다.

* *클러스터*
+
애그리게이트가 속한 클러스터의 이름을 표시합니다.

* *노드*
+
애그리게이트가 위치한 노드의 이름을 표시합니다.

* *총 용량*
+
애그리게이트의 총 용량(MB, GB 등)을 표시합니다.

* *사용 용량*
+
애그리게이트에 사용된 공간의 양(MB, GB 등)을 표시합니다.

* *사용 가능 용량*
+
애그리게이트에서 사용 가능한 공간의 양(MB, GB 등)을 표시합니다.

* *사용된 %*
+
애그리게이트에서 사용된 공간의 비율을 표시합니다.

* *디스크 종류*
+
RAID 구성 유형을 표시합니다. RAID 구성 유형은 다음 중 하나일 수 있습니다.

+
** RAID0: 모든 RAID 그룹은 RAID0 유형입니다.
** RAID4: 모든 RAID 그룹은 RAID4 유형입니다.
** RAID-DP: 모든 RAID 그룹은 RAID-DP 유형입니다.
** RAID-TEC: 모든 RAID 그룹은 RAID-TEC 유형입니다.
** 혼합 RAID: 애그리게이트에는 서로 다른 RAID 유형(RAID0, RAID4, RAID-DP 및 RAID-TEC)의 RAID 그룹이 포함됩니다. 기본적으로 이 열은 숨겨져 있습니다.
