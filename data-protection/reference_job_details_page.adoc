= Active IQ Unified Manager의 작업 세부 정보 페이지에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
작업 세부 정보 페이지에서는 실행 중이거나 대기 중이거나 완료된 특정 보호 작업에 대한 상태 및 기타 정보를 확인할 수 있습니다. 이 정보를 사용하여 보호 작업 진행 상황을 모니터링하고 작업 실패 문제를 해결할 수 있습니다.



[[job-summary]]
== 직무 요약

작업 요약에는 다음과 같은 정보가 표시됩니다.

* 작업 ID
* 유형
* 상태
* 제출 시간
* 완료 시간
* 기간




[[command-buttons]]
== 명령 버튼

명령 버튼을 사용하면 다음과 같은 작업을 수행할 수 있습니다:

* *새로 고침*
+
작업 목록과 각 작업과 관련된 속성을 새로 고칩니다.

* *작업 보기*
+
작업 페이지로 돌아갑니다.





[[job-tasks-list]]
== 작업 목록

작업 태스크 목록에는 특정 작업과 관련된 모든 태스크와 각 태스크와 관련된 속성이 표 형식으로 표시됩니다.

* *시작 시간*
+
작업이 시작된 날짜와 시간을 표시합니다. 기본적으로 가장 최근 작업이 열 상단에 표시되고 오래된 작업이 하단에 표시됩니다.

* *유형*
+
작업 유형을 표시합니다.

* *상태*
+
특정 작업의 상태:

+
** *완료됨*
+
작업이 완료되었습니다.

** *대기 중*
+
작업이 곧 실행될 예정입니다.

** *실행 중*
+
작업이 실행 중입니다.

** *대기 중*
+
작업이 제출되었으며 일부 관련 작업이 대기열에 추가되어 실행되기를 기다리고 있습니다.



* *상태*
+
작업 상태를 표시합니다:

+
** *오류 (image:../media/sev_error.gif[""])*
+
작업이 실패했습니다.

** *정상 (image:../media/sev_normal.gif[""])*
+
작업이 성공했습니다.

** *건너뛰었습니다(image:../media/icon_skipped.gif[""])*
+
작업이 실패하여 이후 작업을 건너뛰었습니다.



* *기간*
+
작업 시작 이후 경과된 시간을 표시합니다.

* *완료 시간*
+
작업 완료 시간을 표시합니다. 기본적으로 이 열은 숨겨져 있습니다.

* *작업 ID*
+
작업의 개별 작업을 식별하는 GUID를 표시합니다. 이 열은 정렬 및 필터링할 수 있습니다. 기본적으로 이 열은 숨겨져 있습니다.

* *종속성 순서*
+
그래프에서 작업 순서를 나타내는 정수를 표시하며, 첫 번째 작업에는 0이 할당됩니다. 기본적으로 이 열은 숨겨져 있습니다.

* *작업 세부 정보 창*
+
작업 이름, 작업 설명 및 작업이 실패한 경우 실패 이유 등 각 작업 태스크에 대한 추가 정보를 표시합니다.

* *작업 메시지 창*
+
선택한 작업에 특화된 메시지를 표시합니다. 메시지에는 오류 원인 및 해결 방법이 포함될 수 있습니다. 모든 작업에 작업 메시지가 표시되는 것은 아닙니다.
