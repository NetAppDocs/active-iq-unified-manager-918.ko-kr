= Active IQ Unified Manager의 볼륨 상태 세부 정보 페이지에서 SnapMirror 관계 생성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
볼륨/상태 세부 정보 페이지를 사용하여 SnapMirror 관계를 생성하면 데이터 복제를 활성화하여 데이터를 보호할 수 있습니다. SnapMirror 복제를 사용하면 원본 볼륨에서 데이터 손실이 발생할 경우 대상 볼륨에서 데이터를 복원할 수 있습니다.

.시작하기 전에
* 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.
* Workflow Automation을 설정해야 합니다.


다음과 같은 경우에는 *보호* 메뉴가 표시되지 않습니다:

* RBAC 설정에서 이 작업을 허용하지 않는 경우(예: 운영자 권한만 있는 경우)
* 볼륨 ID를 알 수 없는 경우: 예를 들어 클러스터 간 관계가 있고 타겟 클러스터가 아직 검색되지 않은 경우


최대 10개의 보호 작업을 동시에 수행해도 성능 영향은 없습니다. 11개에서 30개 사이의 작업을 동시에 실행할 경우 성능 영향이 발생할 수 있습니다. 30개 이상의 작업을 동시에 실행하는 것은 권장하지 않습니다.

.단계
. *볼륨 / 상태* 세부 정보 페이지의 *보호 탭*에서 토폴로지 보기의 보호하려는 볼륨 이름을 마우스 오른쪽 버튼으로 클릭합니다.
. 메뉴에서 *보호* > *SnapMirror*를 선택합니다.
+
보호 구성 대화 상자가 표시됩니다.

. *SnapMirror*를 클릭하여 *SnapMirror* 탭을 보고 대상 정보를 구성하십시오.
. 필요에 따라 공간 보장을 설정하려면 *고급*을 클릭한 다음 *적용*을 클릭하십시오.
. *보호 구성* 대화 상자에서 *대상 정보* 영역과 *관계 설정* 영역을 모두 작성하십시오.
. *적용*을 클릭합니다.
+
볼륨/상태 상세 정보 페이지로 돌아갑니다.

. *볼륨 / 상태* 세부 정보 페이지 상단에 있는 보호 구성 작업 링크를 클릭합니다.
+
해당 작업의 업무 내용과 세부 정보는 작업 상세 페이지에 표시됩니다.

. *작업* 세부 정보 페이지에서 *새로 고침*을 클릭하여 보호 구성 작업과 관련된 작업 목록 및 작업 세부 정보를 업데이트하고 작업 완료 시점을 확인하십시오.
. 작업이 완료되면 브라우저에서 *뒤로*를 클릭하여 *볼륨 / 상태* 상세 정보 페이지로 돌아가십시오.
+
새로운 관계는 볼륨 / 상태 세부 정보 페이지 토폴로지 보기에 표시됩니다.



구성 중에 지정한 대상 SVM이나 고급 설정에서 활성화한 옵션에 따라 결과적인 SnapMirror 관계는 여러 가지 가능한 변형 중 하나가 될 수 있습니다:

* 소스 볼륨과 동일하거나 더 최신 버전의 ONTAP에서 실행되는 대상 SVM을 지정한 경우, 블록 복제 기반 SnapMirror 관계가 기본 결과가 됩니다.
* 소스 볼륨과 동일하거나 더 최신 버전의 ONTAP에서 실행되는 대상 SVM을 지정했지만 고급 설정에서 버전 유연 복제를 활성화한 경우, 버전 유연 복제가 포함된 SnapMirror 관계가 생성됩니다.
* 이전 버전의 ONTAP 또는 소스 볼륨보다 높은 버전에서 실행되는 대상 SVM을 지정했고 이전 버전이 버전 유연성 복제를 지원하는 경우, 버전 유연성 복제를 사용하는 SnapMirror 관계가 자동으로 생성됩니다.
