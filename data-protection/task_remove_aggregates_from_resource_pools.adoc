= Active IQ Unified Manager의 리소스 풀에서 애그리게이트 제거
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
예를 들어 애그리게이트를 다른 용도로 사용하려는 경우 기존 리소스 풀에서 애그리게이트를 제거할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

리소스 풀 구성원은 리소스 풀이 선택된 경우에만 표시됩니다.

.단계
. 왼쪽 탐색 창에서 *보호* > *리소스 풀*을 클릭합니다.
. 멤버 애그리게이트를 제거할 리소스 풀을 선택하십시오.
+
멤버 애그리게이트 목록이 멤버 창에 표시됩니다.

. 하나 이상의 애그리게이트를 선택하십시오.
+
*제거* 버튼이 활성화되었습니다.

. *제거*를 클릭합니다.
+
경고 대화 상자가 표시됩니다.

. 계속하려면 *예*를 클릭합니다.
+
선택한 애그리게이트가 멤버 창에서 제거됩니다.
