= Active IQ Unified Manager에서 SnapMirror 및 SnapVault 일정 생성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
기본 또는 고급 SnapMirror 및 SnapVault 일정을 생성하여 소스 또는 기본 볼륨에서 자동 데이터 보호 전송을 활성화할 수 있습니다. 이렇게 하면 볼륨의 데이터 변경 빈도에 따라 전송 빈도를 높이거나 낮출 수 있습니다.

.시작하기 전에
* 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.
* 보호 구성 대화 상자의 대상 정보 영역을 이미 완료했어야 합니다.
* 이 작업을 수행하려면 Workflow Automation을 설정해야 합니다.


.단계
. *보호 구성* 대화 상자의 *SnapMirror* 탭 또는 *SnapVault* 탭에서 *관계 설정* 영역의 *일정 생성* 링크를 클릭합니다.
+
일정 생성 대화 상자가 표시됩니다.

. *일정 이름* 필드에 원하는 일정 이름을 입력하세요.
. 다음 중 하나를 선택하십시오.
+
** *기본*
+
기본 간격형 스케줄을 생성할지 선택하십시오.

** *고급*
+
cron 스타일의 스케줄을 생성할지 여부를 선택하세요.



. *Create*를 클릭합니다.
+
새로운 일정은 SnapMirror 일정 또는 SnapVault 일정 드롭다운 목록에 표시됩니다.
