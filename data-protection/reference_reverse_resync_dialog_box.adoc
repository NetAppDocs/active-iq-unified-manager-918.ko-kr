= Active IQ Unified Manager에서 역방향 재동기화
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
원본 볼륨이 비활성화되고 대상이 읽기/쓰기 볼륨으로 변경되어 보호 관계가 끊어진 경우, 역방향 재동기화를 통해 관계의 방향을 반전시켜 대상을 새로운 원본으로, 원본을 새로운 대상으로 만들 수 있습니다.

재해로 인해 보호 관계의 소스 볼륨이 사용 불가능해지면, 소스를 복구 또는 교체하고, 소스를 업데이트하고, 관계를 다시 설정하는 동안 대상 볼륨을 읽기/쓰기 모드로 변환하여 데이터를 제공하는 데 사용할 수 있습니다. 역방향 재동기화 작업을 수행하면 소스에서 공통 Snapshot 복사본의 데이터보다 최신인 데이터가 삭제됩니다.



[[before-reverse-resync]]
== 역방향 재동기화 전

역방향 재동기화 작업 전에 관계의 소스와 대상을 표시합니다.

* *소스 볼륨*
+
역방향 재동기화 작업 전 소스 볼륨의 이름과 위치입니다.

* *타겟 볼륨*
+
역방향 재동기화 작업 전 대상 볼륨의 이름과 위치입니다.





[[after-reverse-resync]]
== 역방향 재동기화 후

예약 재동기화 작업 후 관계의 소스와 대상이 무엇인지 표시합니다.

* *소스 볼륨*
+
역방향 재동기화 작업 후 소스 볼륨의 이름과 위치입니다.

* *타겟 볼륨*
+
역방향 재동기화 작업 후 대상 볼륨의 이름과 위치입니다.





[[command-buttons]]
== 명령 버튼

명령 버튼을 사용하면 다음과 같은 작업을 수행할 수 있습니다:

* *제출*
+
역방향 재동기화 프로세스를 시작합니다.

* *취소*
+
역방향 재동기화 작업을 시작하지 않고 역방향 재동기화 대화 상자를 닫습니다.
