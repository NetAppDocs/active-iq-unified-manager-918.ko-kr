= Active IQ Unified Manager에서 Initialize/Update 대화 상자 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
초기화/업데이트 대화 상자를 사용하면 새 보호 관계에 대한 최초 기본 전송을 수행하거나, 관계가 이미 초기화되어 있고 수동으로 예약되지 않은 증분 업데이트를 수행하려는 경우 관계를 업데이트할 수 있습니다.



[[transfer-options-tab]]
== 전송 옵션 탭

전송 옵션 탭에서는 전송의 초기화 우선순위를 변경하고 전송 중에 사용되는 대역폭을 변경할 수 있습니다.

* *전송 우선순위*
+
전송 실행 우선순위입니다. 보통 또는 낮음 중에서 선택할 수 있습니다. 전송 우선순위를 보통으로 지정한 정책과의 관계는 낮은 우선순위로 지정한 정책과의 관계보다 먼저 실행됩니다. 기본적으로 보통이 선택되어 있습니다.

* *최대 전송 속도*
+
네트워크를 통해 클러스터 간 데이터 전송의 최대 속도를 지정합니다. 최대 전송 속도를 사용하지 않으면 관계 간 기본 전송은 무제한입니다. 최대 전송 속도가 서로 다른 관계를 둘 이상 선택한 경우 다음 최대 전송 속도 설정 중 하나를 지정할 수 있습니다:

+
** 개별 관계 설정 또는 편집 중에 지정된 값을 사용하십시오
+
이 옵션을 선택하면 초기화 및 업데이트 작업 시 각 관계 생성 또는 편집 시 지정된 최대 전송 속도가 사용됩니다. 이 필드는 전송 속도가 서로 다른 여러 관계를 초기화하거나 업데이트할 때만 사용할 수 있습니다.

** 무제한
+
관계 간 전송에 대역폭 제한이 없음을 나타냅니다. 이 필드는 전송 속도가 서로 다른 여러 관계를 초기화하거나 업데이트할 때만 사용할 수 있습니다.

** 대역폭을 다음으로 제한
+
이 옵션을 선택하면 네트워크 대역폭이 지정한 값으로 제한됩니다. 숫자 값을 입력한 후 킬로바이트/초(KBps), 메가바이트/초(MBps), 기가바이트/초(GBps) 또는 테라바이트/초(TBps) 중에서 선택할 수 있습니다. 지정하는 최대 전송 속도는 1 KBps보다 크고 4 TBps보다 작아야 합니다.







[[source-snapshot-copies-tab]]
== 소스 스냅샷 사본 탭

원본 스냅샷 사본 탭에는 기본 전송에 사용되는 원본 스냅샷 사본에 대한 다음 정보가 표시됩니다:

* *소스 볼륨*
+
해당 소스 볼륨의 이름을 표시합니다.

* *타겟 볼륨*
+
선택한 대상 볼륨의 이름을 표시합니다.

* *소스 유형*
+
볼륨 유형을 표시합니다. 유형은 읽기/쓰기 또는 데이터 보호일 수 있습니다.

* *스냅샷 사본*
+
데이터 전송에 사용되는 스냅샷 복사본을 표시합니다. 스냅샷 복사본 값을 클릭하면 소스 스냅샷 복사본 선택 대화 상자가 나타나고, 여기에서 보호 관계 유형 및 수행하는 작업에 따라 전송에 사용할 특정 스냅샷 복사본을 선택할 수 있습니다. 데이터 보호 유형 소스의 경우 다른 스냅샷 복사본을 지정하는 옵션을 사용할 수 없습니다.





[[command-buttons]]
== 명령 버튼

명령 버튼을 사용하면 다음과 같은 작업을 수행할 수 있습니다:

* *취소*
+
선택한 내용을 취소하고 초기화/업데이트 대화 상자를 닫습니다.

* *제출*
+
선택 사항을 저장하고 초기화 또는 업데이트 작업을 시작합니다.
