= Workflow Automation와 Active IQ Unified Manager 간의 연결 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
OnCommand Workflow Automation(WFA)과 Unified Manager 간에 보안 연결을 구성할 수 있습니다. Workflow Automation에 연결하면 SnapMirror 및 SnapVault 구성 워크플로 등 보호 기능은 물론 SnapMirror 관계 관리 명령을 사용할 수 있습니다.

.시작하기 전에
* 설치된 Workflow Automation 버전은 5.1.1P6 이상이어야 합니다.
+
[NOTE]
====
"`WFA pack for managing Clustered Data ONTAP`"은 WFA 5.1.1P6에 포함되어 있으므로 이전처럼 NetAppStorage Automation Store에서 이 팩을 다운로드하여 WFA 서버에 별도로 설치할 필요가 없습니다. https://mysupport.netapp.com/site/products/all/details/ocwfa/downloads-tab["WFA 다운로드"^]

====
* WFA 및 Unified Manager 연결을 지원하려면 Unified Manager에서 생성한 데이터베이스 사용자 이름이 있어야 합니다.
+
이 데이터베이스 사용자는 통합 스키마 사용자 역할을 부여받아야 합니다.

* Workflow Automation에서 관리자 역할 또는 설계자 역할이 부여되어 있어야 합니다.
* Workflow Automation 설정을 위해서는 호스트 주소, 포트 번호 443, 사용자 이름 및 비밀번호가 필요합니다.
* 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.


.단계
. 왼쪽 탐색 창에서 *일반* > *Workflow Automation*을 클릭합니다.
. *Workflow Automation 페이지*의 *Database User* 영역에서 Unified Manager 및 Workflow Automation 연결을 지원하기 위해 생성한 데이터베이스 사용자의 이름을 선택하고 암호를 입력합니다.
. 페이지의 *Workflow Automation 자격 증명* 영역에 Workflow Automation 설정에 사용할 호스트 이름 또는 IP 주소(IPv4 또는 IPv6)와 사용자 이름 및 암호를 입력하십시오.
+
Unified Manager 서버 포트(포트 443)를 사용해야 합니다.

. *저장*을 클릭합니다.
. 자체 서명 인증서를 사용하는 경우 보안 인증서를 승인하려면 *예*를 클릭하십시오.
+
Workflow Automation 페이지가 표시됩니다.

. 웹 UI를 새로고침하고 Workflow Automation 기능을 추가하려면 *예*를 클릭하십시오.
