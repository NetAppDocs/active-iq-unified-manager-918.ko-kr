= Active IQ Unified Manager에서 고급 보조 설정 대화 상자 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
고급 보조 설정 대화 상자를 사용하여 보조 볼륨에서 버전 유연 복제, 다중 복사본 백업 및 공간 관련 설정을 활성화할 수 있습니다. 현재 설정을 변경하거나 활성화 또는 비활성화하려는 경우 고급 보조 설정 대화 상자를 사용할 수 있습니다.

공간 관련 설정은 중복 제거, 데이터 압축, 자동 증가 및 공간 보장 등을 포함하여 저장되는 데이터의 양을 최대화합니다.

대화 상자에는 다음과 같은 필드가 포함되어 있습니다:

* *버전 유연성 복제 활성화*
+
버전 유연성 복제를 통해 SnapMirror를 활성화합니다. 버전 유연성 복제를 사용하면 타겟 볼륨이 소스 볼륨보다 이전 버전의 ONTAP에서 실행 중인 경우에도 소스 볼륨에 대한 SnapMirror 보호가 가능합니다.

+
** 백업 활성화
+
버전 유연성 복제가 활성화된 경우 SnapMirror 소스 데이터의 여러 스냅샷 복사본을 SnapMirror 타겟으로 전송하고 보관할 수 있습니다.



* *중복 제거 활성화*
+
SnapVault 관계의 보조 볼륨에서 중복 데이터 블록을 제거하여 공간을 절약할 수 있도록 중복 제거를 활성화합니다. 공간 절약 효과가 10% 이상이고 데이터 덮어쓰기 속도가 빠르지 않은 경우 중복 제거를 사용할 수 있습니다. 중복 제거는 가상화 환경, 파일 공유 및 백업 데이터에 자주 사용됩니다. 이 설정은 기본적으로 비활성화되어 있습니다. 활성화하면 각 전송 후 이 작업이 시작됩니다.

+
** 압축 활성화
+
투명한 데이터 압축을 활성화합니다. 압축은 공간 절약 효과가 최소 10% 이상이고, 잠재적인 오버헤드가 허용 가능한 수준이며, 비피크 시간대에 압축을 완료할 수 있는 충분한 시스템 리소스가 있는 경우에 사용할 수 있습니다. SnapVault 관계에서는 이 설정이 기본적으로 비활성화되어 있습니다. 압축은 중복 제거가 선택된 경우에만 사용할 수 있습니다.

** 인라인 압축
+
데이터를 디스크에 쓰기 전에 압축하여 즉시 공간을 절약할 수 있습니다. 시스템 사용률이 피크 시간대에 50%를 넘지 않고, 피크 시간대에도 새로운 쓰기 작업과 추가 CPU 사용량을 감당할 수 있는 경우 인라인 압축을 사용할 수 있습니다. 이 설정은 "`Enable Compression`"이 선택된 경우에만 사용할 수 있습니다.



* *자동 성장 활성화*
+
연결된 애그리게이트에 사용 가능한 공간이 있는 한, 여유 공간 비율이 지정된 임계값 미만일 때 타겟 볼륨을 자동으로 확장할 수 있습니다.

* *최대 크기*
+
볼륨이 증가할 수 있는 최대 백분율을 설정합니다. 기본값은 소스 볼륨 크기보다 20% 큰 값입니다. 현재 크기가 최대 자동 증가 백분율보다 크거나 같으면 볼륨이 자동으로 증가하지 않습니다. 이 필드는 자동 증가 설정이 활성화된 경우에만 활성화됩니다.

* *증분 크기*
+
원본 볼륨의 최대 백분율에 도달하기 전에 볼륨이 자동으로 증가하는 백분율 증가분을 지정합니다.

* *공간 보장*
+
보조 볼륨에 충분한 공간이 할당되어 데이터 전송이 항상 성공적으로 이루어지도록 합니다. 공간 보장 설정은 다음 중 하나일 수 있습니다.

+
** 파일
** 볼륨
** None + 예를 들어, 총 50GB의 파일이 포함된 200GB 볼륨이 있지만 해당 파일에 10GB의 데이터만 포함되어 있을 수 있습니다. 볼륨 보장은 소스의 내용과 관계없이 타겟 볼륨에 200GB를 할당합니다. 파일 보장은 소스의 파일에 충분한 공간이 예약되도록 50GB를 할당합니다. 이 시나리오에서 None을 선택하면 소스의 파일 데이터가 사용하는 실제 공간을 위해 타겟에 10GB만 할당됨을 의미합니다.


+
공간 보장은 기본적으로 볼륨으로 설정되어 있습니다.

== 명령 버튼

명령 버튼을 사용하면 다음과 같은 작업을 수행할 수 있습니다:

* *적용*
+
선택한 효율성 설정을 저장하고, 보호 구성 대화 상자에서 *적용*을 클릭할 때 적용합니다.

* *취소*
+
선택 사항을 취소하고 고급 대상 설정 대화 상자를 닫습니다.
