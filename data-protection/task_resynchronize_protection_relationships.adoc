= Active IQ Unified Manager의 볼륨 관계 페이지에서 보호 관계 재동기화
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
볼륨 관계 페이지에서 소스 볼륨이 비활성화된 이벤트를 복구하거나 현재 소스를 다른 볼륨으로 변경하려는 경우 관계를 다시 동기화할 수 있습니다.

.시작하기 전에
* 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.
* Workflow Automation을 설정해야 합니다.


.단계
. *볼륨 관계* 페이지에서 정지된 관계를 가진 하나 이상의 볼륨을 선택하고 도구 모음에서 *다시 동기화*를 클릭합니다.
+
재동기화 대화 상자가 표시됩니다.

. *재동기화 옵션* 탭에서 전송 우선순위와 최대 전송 속도를 선택하십시오.
. *원본 스냅샷 사본*을 클릭한 다음, *스냅샷 사본* 열에서 *기본값*을 클릭합니다.
+
소스 스냅샷 복사 선택 대화 상자가 표시됩니다.

. 기본 스냅샷 복사본을 전송하는 대신 기존 스냅샷 복사본을 지정하려면 *기존 스냅샷 복사본*을 클릭하고 목록에서 스냅샷 복사본을 선택하십시오.
. *제출*을 클릭하십시오.
+
다시 동기화 대화 상자로 돌아갑니다.

. 재동기화할 소스를 두 개 이상 선택한 경우, 기존 Snapshot 복사본을 지정하려는 다음 소스에 대해 *기본값*을 클릭하십시오.
. *제출*을 클릭하여 재동기화 작업을 시작하십시오.
+
재동기화 작업이 시작되면 볼륨 관계 페이지로 돌아가고 페이지 상단에 작업 링크가 표시됩니다.

. *선택 사항:* 각 재동기화 작업의 상태를 추적하려면 *볼륨 관계* 페이지에서 *작업 보기*를 클릭하십시오.
+
필터링된 작업 목록이 표시됩니다.

. *선택 사항:* 브라우저의 *뒤로* 화살표를 클릭하여 *볼륨 관계* 페이지로 돌아갑니다.
+
재동기화 작업은 모든 작업이 성공적으로 완료되면 끝납니다.
