= Active IQ Unified Manager에서 지난 1개월 전송 상태 보기 표시
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
'관계: 지난 1개월 전송 상태' 보기에서는 비동기 관계에 있는 볼륨 및 스토리지 VM의 전송 추세를 일정 기간 동안 분석할 수 있습니다. 이 페이지에는 전송 성공 여부도 표시됩니다.

페이지 상단의 컨트롤을 사용하면 특정 오브젝트를 검색하고, 표시되는 데이터 목록을 좁히기 위한 필터를 생성 및 적용하고, 페이지의 열을 추가/제거/재정렬하고, 페이지의 데이터를  `.csv`,  `.pdf` 또는  `.xlsx` 파일로 내보낼 수 있습니다. 페이지를 사용자 지정한 후 결과를 사용자 지정 보기로 저장하고 이 데이터에 대한 보고서를 정기적으로 생성하여 이메일로 전송하도록 예약할 수 있습니다. *Filter* 옵션을 사용하여 볼륨 또는 스토리지 VM과 같이 선택한 스토리지 시스템만 표시할 수 있습니다. 동일한 보고서가 Storage 페이지에 표시되며 선택한 스토리지 엔티티에 대해서만 표시됩니다. 예를 들어 볼륨 관계를 보려면 *Storage* > *Storage VMs* > *Relationship: Last 1 Month Transfer Status* 메뉴 또는 *Protection* > *Relationships* > *Relationship: Last 1 Month Transfer Status* 메뉴에서 스토리지 VM에 대한 Relationship: Last 1 Month Transfer Status 보고서에 액세스한 다음 *Filter*를 사용하여 볼륨 데이터만 표시할 수 있습니다.

* *소스 볼륨*
+
소스 볼륨 이름을 표시합니다.

* *타겟 볼륨*
+
대상 볼륨 이름을 표시합니다.

* *작업 유형*
+
볼륨 전송 유형을 표시합니다.

* *작업 결과*
+
볼륨 전송이 성공했는지 여부를 표시합니다.

* *전송 시작 시간*
+
볼륨 전송 시작 시간을 표시합니다.

* *전송 종료 시간*
+
볼륨 전송 종료 시간을 표시합니다.

* *전송 소요 시간*
+
볼륨 전송을 완료하는 데 걸린 시간(시간)을 표시합니다.

* *전송 크기*
+
전송된 볼륨의 크기(MB)를 표시합니다.

* *소스 SVM*
+
스토리지 가상 머신(SVM) 이름을 표시합니다.

* *소스 클러스터*
+
소스 클러스터 이름을 표시합니다.

* *타겟 SVM*
+
대상 SVM 이름을 표시합니다.

* *타겟 클러스터*
+
타겟 클러스터 이름을 표시합니다.
