= Active IQ Unified Manager에서 디렉토리 찾아보기 대화 상자 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
원본 소스와 다른 클러스터 및 SVM의 디렉터리로 데이터를 복원하려는 경우 디렉터리 찾아보기 대화 상자를 사용할 수 있습니다. 기본적으로 원본 소스 클러스터와 볼륨이 선택됩니다.

디렉터리 찾아보기 대화 상자를 사용하면 데이터를 복원할 클러스터, SVM, 볼륨 및 디렉터리 경로를 선택할 수 있습니다.

* *클러스터*
+
복원 가능한 클러스터 대상 목록을 표시합니다. 기본적으로 원래 소스 볼륨의 클러스터가 선택됩니다.

* *SVM 드롭다운 목록*
+
선택한 클러스터에서 사용 가능한 SVM 목록을 표시합니다. 기본적으로 원본 소스 볼륨의 SVM이 선택됩니다.

* *볼륨*
+
선택한 SVM의 모든 읽기/쓰기 볼륨 목록을 표시합니다. 볼륨 이름과 사용 가능한 공간으로 필터링할 수 있습니다. 공간이 가장 많은 볼륨이 먼저 표시되고, 그 다음으로 내림차순으로 정렬됩니다. 기본적으로 원본 소스 볼륨이 선택됩니다.

* *파일 경로 입력란*
+
데이터를 복원할 파일 경로를 입력할 수 있습니다. 입력하는 경로는 이미 존재하는 경로여야 합니다.

* *이름*
+
선택한 볼륨에서 사용 가능한 폴더 이름을 표시합니다. 이름 목록에서 폴더를 클릭하면 하위 폴더가 있는 경우 해당 폴더가 표시됩니다. 폴더에 포함된 파일은 표시되지 않습니다. 폴더를 선택한 후 image:../media/icon_upfolder.gif["상위 폴더 아이콘"]을(를) 클릭하면 디렉터리 구조에서 한 단계 위로 이동합니다.





[[command-buttons]]
== 명령 버튼

명령 버튼을 사용하면 다음과 같은 작업을 수행할 수 있습니다:

* *디렉토리 선택*
+
선택한 내용을 적용하고 디렉터리 찾아보기 대화 상자를 닫습니다. 디렉터리가 선택되지 않은 경우 이 버튼은 비활성화됩니다.

* *취소*
+
선택한 항목을 취소하고 디렉터리 찾아보기 대화 상자를 닫습니다.
