= Active IQ Unified Manager의 볼륨/상태 세부 정보 페이지에서 보호 관계 역방향 설정
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
재해로 인해 보호 관계의 소스 볼륨이 사용 불가능해지면, 소스를 복구하거나 교체하는 동안 대상 볼륨을 읽기/쓰기 모드로 변환하여 데이터를 제공할 수 있습니다. 소스 볼륨이 다시 데이터를 수신할 수 있게 되면 역방향 재동기화 작업을 사용하여 관계를 역방향으로 설정하여 소스 볼륨의 데이터와 읽기/쓰기 모드의 대상 볼륨의 데이터를 동기화할 수 있습니다.

.시작하기 전에
* 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.
* Workflow Automation을 설정해야 합니다.
* 해당 관계는 SnapVault 관계가 아니어야 합니다.
* 보호 관계가 이미 존재해야 합니다.
* 보호 관계는 끊어져 있어야 합니다.
* 소스와 대상 모두 온라인 상태여야 합니다.
* 소스는 다른 데이터 보호 볼륨의 대상이 되어서는 안 됩니다.
* 이 작업을 수행하면 소스에서 공통 Snapshot 복사본의 데이터보다 최신인 데이터가 삭제됩니다.
* 역방향 재동기화 관계에서 생성된 정책 및 일정은 원래 보호 관계의 정책 및 일정과 동일합니다.
+
정책과 일정이 없으면 생성됩니다.



.단계
. *볼륨 / 상태* 세부 정보 페이지의 *보호* 탭에서 소스와 대상을 반전시키려는 SnapMirror 관계를 토폴로지에서 찾아 마우스 오른쪽 버튼으로 클릭합니다.
. 메뉴에서 *역방향 재동기화*를 선택합니다.
+
역방향 재동기화 대화 상자가 표시됩니다.

. *역방향 재동기화* 대화 상자에 표시된 관계가 역방향 재동기화 작업을 수행하려는 관계인지 확인한 다음 *제출*을 클릭합니다.
+
역방향 재동기화 대화 상자가 닫히고 볼륨 / 상태 세부 정보 페이지 상단에 작업 링크가 표시됩니다.

. *선택 사항:* 각 역방향 재동기화 작업의 상태를 추적하려면 *볼륨/상태* 세부 정보 페이지에서 *작업 보기*를 클릭하십시오.
+
필터링된 작업 목록이 표시됩니다.

. *선택 사항:* 브라우저의 *뒤로* 화살표를 클릭하여 *볼륨 / 상태* 상세 정보 페이지로 돌아갈 수 있습니다.
+
역방향 재동기화 작업은 모든 작업 태스크가 성공적으로 완료되면 종료됩니다.
