= Workflow Automation에서 Active IQ Unified Manager 데이터 소스 캐싱을 확인합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 데이터 소스 캐싱이 올바르게 작동하는지 여부는 Workflow Automation에서 데이터 소스 획득이 성공했는지 확인하여 판단할 수 있습니다. Workflow Automation을 Unified Manager와 통합할 때 통합 후 Workflow Automation 기능이 사용 가능한지 확인하기 위해 이 작업을 수행할 수 있습니다.

.시작하기 전에
이 작업을 수행하려면 Workflow Automation에서 관리자 역할 또는 설계자 역할이 할당되어 있어야 합니다.

.단계
. Workflow Automation UI에서 *실행* > *데이터 소스*를 선택합니다.
. Unified Manager 데이터 소스 이름을 마우스 오른쪽 버튼으로 클릭한 다음 *지금 가져오기*를 선택합니다.
. 수집이 오류 없이 성공하는지 확인하십시오.
+
Unified Manager와 Workflow Automation 통합이 성공적으로 이루어지려면 획득 오류를 해결해야 합니다.
