= Active IQ Unified Manager에서 고급 대상 설정 대화 상자 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
고급 대상 설정 대화 상자를 사용하여 대상 볼륨에서 공간 보장 설정을 활성화할 수 있습니다. 소스에서 공간 보장이 비활성화되어 있지만 대상에서는 활성화하려는 경우 고급 설정을 선택할 수 있습니다. SnapMirror 관계에서 중복 제거, 압축 및 자동 증가 설정은 소스 볼륨에서 상속되며 변경할 수 없습니다.



[[space-guarantee]]
== 공간 보장

타겟 볼륨에 충분한 공간이 할당되어 데이터 전송이 항상 성공하도록 보장합니다. 공간 보장 설정은 다음 중 하나일 수 있습니다:

* 파일
* 볼륨
* None


예를 들어, 200GB 볼륨에 총 50GB의 파일이 있지만, 실제 데이터 용량은 10GB에 불과한 경우가 있을 수 있습니다. 볼륨 보장은 소스의 내용과 관계없이 타겟 볼륨에 200GB를 할당합니다. 파일 보장은 타겟에 소스 파일을 위한 충분한 공간이 예약되도록 50GB를 할당합니다. 이 시나리오에서 *없음*을 선택하면 소스의 파일 데이터가 실제로 사용하는 공간에 대해 타겟에 10GB만 할당됨을 의미합니다.

공간 보장은 기본적으로 볼륨으로 설정되어 있습니다.
