= Active IQ Unified Manager의 상태: 모든 볼륨 보기에서 SnapMirror 관계 생성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
'상태: 모든 볼륨' 보기를 사용하면 동일한 스토리지 VM에서 둘 이상의 볼륨을 선택하여 여러 SnapMirror 보호 관계를 한 번에 생성할 수 있습니다.

.시작하기 전에
* 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.
* Workflow Automation을 설정해야 합니다.


다음과 같은 경우에는 *보호* 메뉴가 표시되지 않습니다:

* RBAC 설정에서 이 작업을 허용하지 않는 경우(예: 운영자 권한만 있는 경우)
* 볼륨 ID를 알 수 없는 경우: 예를 들어 클러스터 간 관계가 있고 타겟 클러스터가 아직 검색되지 않은 경우


.단계
. *상태: 모든 볼륨* 보기에서 보호할 볼륨을 선택합니다.
+
또는 동일한 SVM에 여러 보호 관계를 생성하려면 상태: 모든 볼륨 보기에서 하나 이상의 볼륨을 선택하고 도구 모음에서 *보호* > *SnapMirror*를 클릭합니다.

+
보호 구성 대화 상자가 표시됩니다.

. *SnapMirror*를 클릭하여 *SnapMirror* 탭을 보고 대상 정보를 구성하십시오.
. 필요에 따라 공간 보장을 설정하려면 *고급*을 클릭한 다음 *적용*을 클릭하십시오.
. *SnapMirror* 탭에서 *목적지 정보* 영역과 *관계 설정* 영역을 작성하십시오.
. *적용*을 클릭합니다.
+
상태: 전체 볼륨 보기 화면으로 돌아갑니다.

. *상태: 모든 볼륨 보기* 상단에 있는 보호 구성 작업 링크를 클릭합니다.
+
보호 관계를 하나만 생성하는 경우 작업 세부 정보 페이지가 표시됩니다. 하지만 보호 관계를 두 개 이상 생성하는 경우에는 해당 보호 작업과 연결된 모든 작업 목록이 표시됩니다.

. 다음 중 하나를 수행하십시오.
+
** 작업이 하나만 있는 경우 *새로 고침*을 클릭하여 보호 구성 작업과 관련된 작업 목록 및 작업 세부 정보를 업데이트하고 작업 완료 시점을 확인하십시오.
** 작업이 두 개 이상인 경우:
+
... 작업 목록에서 작업을 클릭합니다.
... *새로 고침*을 클릭하여 보호 구성 작업과 관련된 작업 목록 및 작업 세부 정보를 업데이트하고 작업 완료 시점을 확인하십시오.
... 필터링된 목록으로 돌아가 다른 작업을 보려면 *뒤로* 버튼을 사용하십시오.






구성 중에 지정한 대상 SVM이나 고급 설정에서 활성화한 옵션에 따라 결과적인 SnapMirror 관계는 여러 가지 가능한 변형 중 하나가 될 수 있습니다:

* 소스 볼륨과 동일하거나 더 최신 버전의 ONTAP에서 실행되는 대상 SVM을 지정한 경우, 블록 복제 기반 SnapMirror 관계가 기본 결과가 됩니다.
* 소스 볼륨과 동일하거나 더 최신 버전의 ONTAP에서 실행되는 대상 SVM을 지정했지만 고급 설정에서 버전 유연 복제를 활성화한 경우, 버전 유연 복제가 포함된 SnapMirror 관계가 생성됩니다.
* 소스 볼륨보다 이전 버전의 ONTAP에서 실행되는 대상 SVM을 지정했고 해당 이전 버전이 버전 유연성 복제를 지원하는 경우, 버전 유연성 복제를 사용하는 SnapMirror 관계가 자동으로 생성됩니다.
