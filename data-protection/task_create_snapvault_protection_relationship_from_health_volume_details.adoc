= Active IQ Unified Manager의 Volume/Health 세부 정보 페이지에서 SnapVault 보호 관계를 생성합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
볼륨/상태 세부 정보 페이지를 사용하여 SnapVault 관계를 생성하면 볼륨에 대한 데이터 백업을 보호 목적으로 활성화할 수 있습니다.

.시작하기 전에
* 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.
* 이 작업을 수행하려면 Workflow Automation을 설정해야 합니다.


다음과 같은 경우에는 *보호* 메뉴가 표시되지 않습니다:

* RBAC 설정에서 이 작업을 허용하지 않는 경우(예: 운영자 권한만 있는 경우)
* 볼륨 ID를 알 수 없는 경우: 예를 들어 클러스터 간 관계가 있고 타겟 클러스터가 아직 검색되지 않은 경우


.단계
. *볼륨 / 상태* 세부 정보 페이지의 *보호* 탭에 있는 토폴로지 보기에서 보호하려는 볼륨을 마우스 오른쪽 버튼으로 클릭합니다.
. 메뉴에서 *보호* > *SnapVault*를 선택합니다.
+
보호 구성 대화 상자가 나타납니다.

. *SnapVault*를 클릭하여 *SnapVault* 탭을 보고 보조 리소스 정보를 구성하십시오.
. 필요에 따라 중복 제거, 압축, 자동 증가 및 공간 보장을 설정하려면 *고급*을 클릭한 다음 *적용*을 클릭하십시오.
. *보호 구성* 대화 상자에서 *대상 정보* 영역과 *관계 설정* 영역을 모두 작성하십시오.
. *적용*을 클릭합니다.
+
볼륨/상태 상세 정보 페이지로 돌아갑니다.

. *볼륨 / 상태* 세부 정보 페이지 상단에 있는 보호 구성 작업 링크를 클릭합니다.
+
작업 상세 정보 페이지가 표시됩니다.

. *새로 고침*을 클릭하여 보호 구성 작업과 관련된 작업 목록 및 작업 세부 정보를 업데이트하고 작업 완료 시점을 확인하십시오.
+
작업이 완료되면 새로운 관계가 볼륨/상태 세부 정보 페이지의 토폴로지 보기에 표시됩니다.
