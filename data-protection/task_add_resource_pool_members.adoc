= Active IQ Unified Manager에서 리소스 풀 구성원 추가
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
리소스 풀은 여러 멤버 애그리게이트로 구성됩니다. 기존 리소스 풀에 애그리게이트를 추가하여 보조 볼륨 프로비저닝에 사용할 수 있는 공간을 늘릴 수 있습니다.

.시작하기 전에
애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

한 번에 리소스 풀에 최대 200개의 애그리게이트만 추가할 수 있습니다. 애그리게이트 대화 상자에 표시되는 애그리게이트는 다른 리소스 풀에 속하지 않습니다.

.단계
. 왼쪽 탐색 창에서 *보호* > *리소스 풀*을 클릭합니다.
. *리소스 풀* 목록에서 리소스 풀을 선택하십시오.
+
리소스 풀 구성원은 리소스 풀 목록 아래 영역에 표시됩니다.

. 리소스 풀 멤버 영역에서 *추가*를 클릭합니다.
+
애그리게이트 대화 상자가 표시됩니다.

. 하나 이상의 애그리게이트를 선택하십시오.
. *추가*를 클릭합니다.
+
대화 상자가 닫히고 선택한 리소스 풀의 멤버 목록에 애그리게이트가 표시됩니다.
