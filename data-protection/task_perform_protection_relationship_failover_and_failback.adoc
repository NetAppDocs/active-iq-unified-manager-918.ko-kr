= Active IQ Unified Manager에서 보호 관계 페일오버 및 페일백 수행
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
보호 관계에서 소스 볼륨이 하드웨어 장애 또는 재해로 인해 사용 중지된 경우 Unified Manager의 보호 관계 기능을 사용하여 보호 대상 볼륨을 읽기/쓰기 가능하게 만들고 소스 볼륨이 다시 온라인 상태가 될 때까지 해당 볼륨으로 페일오버할 수 있습니다. 그런 다음 소스 볼륨이 데이터를 제공할 수 있게 되면 원래 소스 볼륨으로 다시 페일백할 수 있습니다.

.시작하기 전에
* 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.
* 이 작업을 수행하려면 OnCommand Workflow Automation을 설정해야 합니다.


.단계
. link:task_break_snapmirror_relationship_from_health_volume_details.html["SnapMirror 관계를 끊으십시오"].
+
대상을 데이터 보호 볼륨에서 읽기/쓰기 볼륨으로 변환하거나 관계를 반전시키려면 먼저 관계를 해제해야 합니다.

. link:task_reverse_protection_relationships_from_health_volume_details.html["보호 관계 역전"].
+
원본 소스 볼륨을 다시 사용할 수 있게 되면 소스 볼륨을 복원하여 원래 보호 관계를 다시 설정할 수 있습니다. 소스를 복원하기 전에 이전 대상에 기록된 데이터와 동기화해야 합니다. 역방향 재동기화 작업을 사용하여 원래 관계의 역할을 반전시키고 소스 볼륨을 이전 대상과 동기화하여 새 보호 관계를 생성합니다. 새 관계에 대한 새로운 기본 스냅샷 복사본이 생성됩니다.

+
역방향 관계는 계단식 관계와 유사해 보입니다:

+
image::../media/um_toplogy_reverse_resync.gif[역관계 과정을 보여주는 UI 스크린샷입니다.]

. link:task_break_snapmirror_relationship_from_health_volume_details.html["역방향 SnapMirror 관계를 해제합니다"].
+
원본 소스 볼륨이 다시 동기화되어 데이터를 다시 제공할 수 있게 되면, 중단 작업을 사용하여 역방향 관계를 해제하십시오.

. link:task_remove_protection_relationship_voldtls.html["관계를 제거하십시오"].
+
역관계가 더 이상 필요하지 않은 경우, 원래 관계를 다시 설정하기 전에 해당 관계를 제거해야 합니다.

. link:task_resynchronize_protection_relationships_voldtls.html["관계를 재동기화합니다"].
+
재동기화 작업을 사용하여 소스에서 대상으로 데이터를 동기화하고 원래 관계를 다시 설정하십시오.
