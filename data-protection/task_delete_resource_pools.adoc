= Active IQ Unified Manager에서 리소스 풀 삭제
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
더 이상 필요하지 않은 리소스 풀은 삭제할 수 있습니다. 예를 들어, 하나의 리소스 풀에서 멤버 애그리게이트를 다른 여러 리소스 풀로 재분배하여 원래 리소스 풀을 더 이상 사용하지 않게 만들 수 있습니다.

.시작하기 전에
애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

*삭제* 버튼은 하나 이상의 리소스 풀이 선택된 경우에만 활성화됩니다.

.단계
. 왼쪽 탐색 창에서 *보호* > *리소스 풀*을 클릭합니다.
. 삭제할 리소스 풀을 선택하십시오.
. *삭제*를 클릭합니다.
+
리소스 풀이 리소스 풀 목록에서 제거되고 해당 애그리게이트가 멤버 목록에서 제거됩니다.
