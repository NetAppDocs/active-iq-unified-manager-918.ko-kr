= Active IQ Unified Manager에서 작업 중단
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
작업 페이지를 사용하여 작업 완료 시간이 너무 오래 걸리거나, 오류가 너무 많이 발생하거나, 더 이상 필요하지 않은 작업을 중단할 수 있습니다. 작업의 상태와 유형이 중단을 허용하는 경우에만 작업을 중단할 수 있습니다. 실행 중인 모든 작업을 중단할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

.단계
. 왼쪽 탐색 창에서 *보호* > *작업*을 클릭합니다.
. 작업 목록에서 작업을 하나 선택한 다음 *취소*를 클릭하십시오.
. 확인 메시지가 나타나면 *예*를 클릭하여 선택한 작업을 취소하십시오.
