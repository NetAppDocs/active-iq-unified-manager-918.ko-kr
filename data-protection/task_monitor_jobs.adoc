= Active IQ Unified Manager에서 작업 모니터링
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
작업 페이지를 사용하여 작업 상태를 모니터링하고 스토리지 서비스 유형, 상태, 제출 시간, 완료 시간 등 작업 속성을 확인하여 작업이 성공적으로 완료되었는지 여부를 확인할 수 있습니다.

.시작하기 전에
애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

.단계
. 왼쪽 탐색 창에서 *보호* > *작업*을 클릭합니다.
+
작업 페이지가 표시됩니다.

. 현재 실행 중인 작업의 상태를 확인하려면 *상태* 열을 참조하십시오.
. 작업 이름을 클릭하면 해당 작업에 대한 자세한 정보를 볼 수 있습니다.
+
작업 상세 정보 페이지가 표시됩니다.
