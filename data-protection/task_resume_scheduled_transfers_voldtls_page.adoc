= Active IQ Unified Manager의 볼륨/상태 세부 정보 페이지에서 일시 중지된 관계의 전송 재개
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
예약된 전송이 발생하지 않도록 관계를 일시 중지한 후에는 볼륨/상태 세부 정보 페이지에서 *재개* 기능을 사용하여 예약된 전송을 다시 활성화하여 소스 또는 기본 볼륨의 데이터를 보호할 수 있습니다. 전송은 체크포인트가 있는 경우 다음 예약된 전송 간격에서 재개됩니다.

.시작하기 전에
* 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.
* Workflow Automation을 설정해야 합니다.


.단계
. *볼륨 / 상태* 세부 정보 페이지의 *보호* 탭에 있는 토폴로지 보기에서 다시 시작하려는 정지된 관계를 마우스 오른쪽 버튼으로 클릭합니다.
+
또는 *작업* > *관계* 메뉴에서 *재개*를 선택하십시오.

. *재개* 대화 상자에서 *계속*을 클릭합니다.
+
볼륨/상태 상세 정보 페이지로 돌아갑니다.

. 관련 작업 내용을 확인하고 진행 상황을 추적하려면 *볼륨 / 상태* 상세 페이지 상단에 표시된 작업 링크를 클릭하십시오.
. *작업* 세부 정보 페이지에서 *새로 고침*을 클릭하여 보호 구성 작업과 관련된 작업 목록 및 작업 세부 정보를 업데이트하고 작업 완료 시점을 확인하십시오.
+
작업이 완료되면 다음 예정된 전송 간격에 데이터 전송이 재개됩니다.
