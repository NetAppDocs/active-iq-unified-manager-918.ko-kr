= 관계 표시: Active IQ Unified Manager의 모든 관계 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
관계: 모든 관계 보기에는 스토리지 시스템의 보호 관계에 대한 정보가 표시됩니다.

기본적으로 관계 페이지에 액세스하면 볼륨과 스토리지 VM 모두에 대한 최상위 보호 관계가 포함된 보고서가 표시됩니다. 페이지 상단의 컨트롤을 사용하여 특정 보기를 선택하고, 특정 오브젝트를 검색하고, 표시되는 데이터 목록을 좁히기 위한 필터를 생성 및 적용하고, 페이지의 열을 추가/제거/재정렬하고, 페이지의 데이터를 .csv, .pdf 또는 .xlsx 파일로 내보낼 수 있습니다. 페이지를 사용자 지정한 후 결과를 사용자 지정 보기로 저장하고 이 데이터에 대한 보고서를 정기적으로 생성하여 이메일로 전송하도록 예약할 수 있습니다. 기본적으로 *관계* 메뉴를 선택하면 데이터 센터의 볼륨과 스토리지 VM 모두에 대한 보호 관계가 포함된 보고서가 표시됩니다. *필터* 옵션을 사용하여 볼륨만 또는 스토리지 VM만과 같이 선택한 스토리지 시스템만 볼 수 있습니다. 동일한 보고서가 스토리지 페이지에도 표시되며 선택한 스토리지 엔티티에 대해서만 표시됩니다. 볼륨 또는 스토리지 VM 간의 관계를 보려면 *스토리지* > *볼륨* > *관계: 모든 관계* 페이지에 액세스하거나 *보호* > *관계* > *관계: 모든 관계*에 액세스한 다음 *필터*에서 *관계 오브젝트 유형* 옵션을 사용하여 볼륨 또는 스토리지 VM 데이터만 필터링할 수 있습니다.

모든 보호 관계를 나열하는 관계 페이지에는 대상 클러스터에 대한 *View in System Manager* 링크가 있으며, 이 링크를 사용하면 ONTAP System Manager에서 동일한 오브젝트를 볼 수 있습니다.

* *상태*
+
보호 관계의 현재 상태를 표시합니다.

+
상태는 오류(image:../media/sev_error_um60.png[""]), 경고(image:../media/sev_warning_um60.png[""]) 또는 정상(image:../media/sev_normal_um60.png[""]) 중 하나일 수 있습니다.

* *소스 스토리지 VM*
+
소스 SVM의 이름을 표시합니다. SVM 이름을 클릭하면 소스 SVM에 대한 자세한 정보를 볼 수 있습니다.

+
클러스터에 SVM이 존재하지만 Unified Manager 인벤토리에 아직 추가되지 않았거나 클러스터의 마지막 새로 고침 이후에 SVM이 생성된 경우 이 필드는 비어 있습니다. SVM이 존재하는지 확인하거나 클러스터에서 재검색을 수행하여 리소스 목록을 새로 고쳐야 합니다.

* *소스*
+
선택에 따라 보호 중인 소스 볼륨 또는 소스 스토리지 VM이 표시됩니다. 볼륨 또는 스토리지 VM 이름을 클릭하면 해당 볼륨 또는 스토리지 VM에 대한 자세한 정보를 볼 수 있습니다.

+
메시지 `Resource-key not discovered`가 표시되는 경우, 해당 볼륨이 클러스터에 존재하지만 Unified Manager 인벤토리에 아직 추가되지 않았거나 클러스터의 마지막 새로 고침 이후에 생성되었을 수 있습니다. 볼륨이 존재하는지 확인하거나 클러스터에서 재검색을 수행하여 리소스 목록을 새로 고쳐야 합니다.

* *대상 스토리지 VM*
+
대상 SVM의 이름을 표시합니다. SVM 이름을 클릭하면 대상 SVM에 대한 자세한 정보를 볼 수 있습니다.

* *목적지*
+
선택 항목에 따라 대상 볼륨 또는 스토리지 VM의 이름을 표시합니다. 해당 오브젝트 이름을 클릭하여 대상 볼륨 또는 스토리지 VM에 대한 자세한 정보를 볼 수 있습니다.

* *관계 오브젝트 유형*
+
스토리지 VM, 볼륨, 일관성 그룹 등 관계에 사용된 오브젝트 유형을 표시합니다. 일관성 관계에 있는 오브젝트의 경우, 관계 소스와 대상에 일관성 그룹이 표시되며, 이를 클릭하면 LUN 페이지로 이동하여 관계를 볼 수 있습니다.

* *정책*
+
SnapMirror 관계에 대한 보호 정책 이름을 표시합니다. 정책 이름을 클릭하면 해당 정책과 관련된 세부 정보를 볼 수 있으며, 여기에는 다음 정보가 포함됩니다.

+
** 전송 우선순위
+
비동기 작업에서 전송이 실행되는 우선순위를 지정합니다. 전송 우선순위는 Normal 또는 Low입니다. Normal 우선순위 전송은 Low 우선순위 전송보다 먼저 예약됩니다. 기본값은 Normal입니다.

** 액세스 시간 무시
+
SnapVault 관계에만 적용됩니다. 이 설정은 액세스 시간만 변경된 파일을 증분 전송에서 무시할지 여부를 지정합니다. 값은 True 또는 False입니다. 기본값은 False입니다.

** 관계가 동기화되지 않았을 때
+
동기 관계가 동기화될 수 없을 때 ONTAP이 수행하는 작업을 지정합니다. StrictSync 관계는 보조 볼륨과의 동기화에 실패할 경우 기본 볼륨에 대한 액세스를 제한합니다. Sync 관계는 보조 볼륨과의 동기화에 실패하더라도 기본 볼륨에 대한 액세스를 제한하지 않습니다.

** 시도 횟수 제한
+
SnapMirror 관계에 대한 각 수동 또는 예약 전송을 시도할 최대 횟수를 지정합니다. 기본값은 8입니다.

** 댓글
+
선택한 정책에 대한 구체적인 의견을 입력할 수 있는 텍스트 입력란을 제공합니다.

** SnapMirror 라벨
+
Snapshot 복사본 정책과 연결된 첫 번째 일정의 SnapMirror 레이블을 지정합니다. SnapMirror 레이블은 Snapshot 복사본을 SnapVault 대상에 백업할 때 SnapVault 하위 시스템에서 사용됩니다.

** 유지 설정
+
백업 보존 기간을 시간 또는 백업 횟수를 기준으로 지정합니다.

** 실제 스냅샷 사본
+
이 볼륨에서 지정된 레이블과 일치하는 Snapshot 복사본 수를 지정합니다.

** 스냅샷 사본 보존
+
정책의 최대 한도에 도달하더라도 자동으로 삭제되지 않는 SnapVault 스냅샷 복사본의 수를 지정합니다. 값은 True 또는 False입니다. 기본값은 False입니다.

** 보존 경고 임계값
+
최대 보존 한도에 거의 도달했음을 알리는 경고가 전송되는 Snapshot 복사본 제한을 지정합니다.



* *지연 시간*
+
미러의 데이터가 소스보다 뒤처지는 시간을 표시합니다.

+
StrictSync 관계의 경우 지연 시간은 0초에 가깝거나 같아야 합니다.

* *지연 상태*
+
관리되는 관계와 일정이 연결된 관리되지 않는 관계에 대한 지연 상태를 표시합니다. 지연 상태는 다음과 같습니다.

+
** 오류
+
지연 시간은 지연 오차 임계값보다 크거나 같습니다.

** 경고
+
지연 시간이 지연 경고 임계값보다 크거나 같습니다.

** OK
+
지연 시간은 정상 범위 내에 있습니다.

** 해당 없음
+
지연 상태는 일정을 구성할 수 없으므로 동기식 관계에는 적용되지 않습니다.



* *마지막 성공 업데이트*
+
마지막으로 성공한 SnapMirror 또는 SnapVault 작업의 시간을 표시합니다.

+
마지막으로 성공한 업데이트는 동기식 관계에 적용되지 않습니다.

* *구성원 관계*
+
선택한 오브젝트에 볼륨이 있는지 여부를 표시합니다.

* *관계 유형*
+
볼륨 복제에 사용된 관계 유형을 표시합니다. 관계 유형에는 다음이 포함됩니다.

+
** 비동기 미러
** 비동기 볼트
** 비동기 MirrorVault
** StrictSync
** 동기화


* *전송 상태*
+
보호 관계에 대한 전송 상태를 표시합니다. 전송 상태는 다음 중 하나일 수 있습니다.

+
** 중단
+
SnapMirror 전송이 활성화되어 있지만, 체크포인트 제거를 포함할 수 있는 전송 중단 작업이 진행 중입니다.

** 확인 중
+
대상 볼륨에 대한 진단 검사가 진행 중이며 전송이 진행되지 않고 있습니다.

** 마무리 작업
+
SnapMirror 전송이 활성화되었습니다. 현재 볼륨은 증분 SnapVault 전송의 전송 후 단계에 있습니다.

** 유휴
+
전송이 활성화되어 있으며 진행 중인 전송이 없습니다.

** 동기화됨
+
동기 관계에 있는 두 볼륨의 데이터는 동기화됩니다.

** 동기화되지 않음
+
대상 볼륨의 데이터가 소스 볼륨과 동기화되지 않았습니다.

** 준비 중
+
SnapMirror 전송이 활성화되었습니다. 현재 볼륨은 증분 SnapVault 전송을 위한 사전 전송 단계에 있습니다.

** 대기 중
+
SnapMirror 전송이 활성화되었습니다. 현재 진행 중인 전송은 없습니다.

** 정지
+
SnapMirror 전송이 비활성화되었습니다. 진행 중인 전송이 없습니다.

** 정지
+
SnapMirror 전송이 진행 중입니다. 추가 전송은 비활성화되었습니다.

** 전송 중
+
SnapMirror 전송이 활성화되었으며 전송이 진행 중입니다.

** 전환
+
소스 볼륨에서 대상 볼륨으로의 비동기 데이터 전송이 완료되었으며, 동기 작업으로의 전환이 시작되었습니다.

** 대기 중
+
SnapMirror 전송이 시작되었지만 일부 관련 작업이 대기열에 추가되기를 기다리고 있습니다.



* *최종 전송 소요 시간*
+
마지막 데이터 전송이 완료되는 데 걸린 시간을 표시합니다.

+
StrictSync 관계의 경우 전송이 동시에 이루어져야 하므로 전송 시간이 적용되지 않습니다.

* *최종 전송 크기*
+
최근 데이터 전송의 크기를 바이트 단위로 표시합니다.

+
전송 크기는 StrictSync 관계에 적용되지 않습니다.

* *중재자*
+
중재자 상태를 표시합니다.

+
** 해당 없음
+
클러스터가 SnapMirror 활성 동기화를 지원하지 않는 경우.

** 구성되지 않음
+
Unified Manager에 구성되지 않았거나, 구성되었지만 타겟 클러스터만 추가되고 소스 클러스터는 추가되지 않은 경우입니다.

** 미디에이터 IP 주소
+
구성되어 있고 소스 및 타겟 클러스터가 Unified Manager에 모두 추가된 경우입니다.



* *상태*
+
SnapMirror 또는 SnapVault 관계의 상태를 표시합니다. 상태는 초기화되지 않음, SnapMirrored 또는 연결 끊김일 수 있습니다. 소스 볼륨이 선택된 경우 관계 상태는 적용되지 않으므로 표시되지 않습니다.

* *관계 건전성*
+
클러스터의 관계 상태를 표시합니다.

* *비정상 이유*
+
관계가 비정상 상태인 이유입니다.

* *전송 우선순위*
+
전송 실행 우선순위를 표시합니다. 전송 우선순위는 보통 또는 낮음입니다. 보통 우선순위의 전송은 낮은 우선순위의 전송보다 먼저 예약됩니다.

+
동기식 관계의 경우 모든 전송이 동일한 우선순위로 처리되므로 전송 우선순위가 적용되지 않습니다.

* *일정*
+
해당 관계에 할당된 보호 일정의 이름을 표시합니다.

+
이 일정은 동기식 관계에는 적용되지 않습니다.

* *버전 유연성 복제*
+
예, 백업 옵션 포함 예 또는 없음 중 하나를 표시합니다.

* *소스 클러스터*
+
SnapMirror 관계에 대한 소스 클러스터의 FQDN, 약칭 또는 IP 주소를 표시합니다.

* *소스 클러스터 FQDN*
+
SnapMirror 관계의 소스 클러스터 이름을 표시합니다.

* *소스 노드*
+
볼륨의 SnapMirror 관계에 대한 소스 노드 이름 링크를 표시하고, 오브젝트가 스토리지 VM 또는 일관성 그룹인 경우 SnapMirror 관계 노드 개수 링크를 표시합니다.



사용자 지정 보기에서 노드 이름 링크를 클릭하면 해당 일관성 그룹의 볼륨이 SnapMirror 활성 동기화 관계에 속한 스토리지 오브젝트에 대한 보호를 확인하고 확장할 수 있습니다.

노드 개수 링크를 클릭하면 해당 관계와 연결된 노드들이 있는 노드 페이지로 이동합니다. 노드 개수가 0인 경우에는 해당 관계와 연결된 노드가 없으므로 값이 표시되지 않습니다.

* *타겟 노드*
+
볼륨의 SnapMirror 관계에 대한 타겟 노드 이름 링크를 표시하고, 오브젝트가 Storage VM 또는 일관성 그룹인 경우 SnapMirror 관계 노드 수 링크를 표시합니다.

+
노드 개수 링크를 클릭하면 해당 관계와 연결된 노드들이 있는 노드 페이지로 이동합니다. 노드 개수가 0인 경우에는 해당 관계와 연결된 노드가 없으므로 값이 표시되지 않습니다.

* *타겟 클러스터*
+
SnapMirror 관계의 타겟 클러스터 이름을 표시합니다.

* *타겟 클러스터 FQDN*
+
SnapMirror 관계의 타겟 클러스터에 대한 FQDN, 약칭 또는 IP 주소를 표시합니다.

* *보호 수단*
+
