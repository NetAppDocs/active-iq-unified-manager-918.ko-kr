= Active IQ Unified Manager에서 SnapMirror 정책 생성 대화 상자 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SnapMirror 정책 생성 대화 상자를 사용하면 SnapMirror 전송의 우선 순위를 설정하는 정책을 만들 수 있습니다. 정책을 사용하면 소스에서 대상으로의 전송 효율성을 극대화할 수 있습니다.

* *타겟 클러스터*
+
보호 구성 대화 상자의 SnapMirror 탭에서 선택한 클러스터의 이름입니다.

* *타겟 SVM*
+
보호 구성 대화 상자의 SnapMirror 탭에서 선택한 SVM의 이름입니다.

* *정책명*
+
새 정책에 지정할 이름입니다. 정책 이름은 A부터 Z, a부터 z, 0부터 9, 마침표(.), 하이픈(-), 밑줄(_)로 구성될 수 있습니다.

* *전송 우선순위*
+
비동기 작업에서 전송이 실행되는 우선순위입니다. '보통' 또는 '낮음'을 선택할 수 있습니다. 전송 우선순위가 보통으로 지정된 정책이 있는 전송 관계는 전송 우선순위가 낮음으로 지정된 정책이 있는 관계보다 먼저 실행됩니다.

* *코멘트*
+
정책에 대한 의견을 추가할 수 있는 선택 입력란입니다.

* *전송 재개*
+
중단 작업이나 네트워크 장애 등 모든 유형의 오류로 인해 전송이 중단되었을 때 수행할 재시작 작업을 나타냅니다. 다음 중 하나를 선택할 수 있습니다.

+
** 언제나
+
전송을 다시 시작하기 전에 새 Snapshot 복사본을 생성한 다음, 체크포인트가 있는 경우 체크포인트에서 전송을 다시 시작하고, 이어서 새로 생성된 Snapshot 복사본에서 증분 전송을 수행하도록 지정합니다.

** 절대
+
중단된 전송은 절대 다시 시작되지 않도록 지정합니다.

== 명령 버튼

명령 버튼을 사용하면 다음과 같은 작업을 수행할 수 있습니다:

* *취소*
+
선택 항목을 취소하고 보호 구성 대화 상자를 닫습니다.

* *적용*
+
선택하신 사항을 적용하고 보호 프로세스를 시작합니다.
