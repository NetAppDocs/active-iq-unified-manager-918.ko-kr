= Active IQ Unified Manager의 작업 페이지에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
작업 페이지에서는 현재 실행 중인 모든 파트너 애플리케이션 보호 작업과 완료된 작업에 대한 현재 상태 및 기타 정보를 확인할 수 있습니다. 이 정보를 사용하여 현재 실행 중인 작업과 작업 성공 또는 실패 여부를 확인할 수 있습니다.



[[command-buttons]]
== 명령 버튼

명령 버튼을 사용하면 다음과 같은 작업을 수행할 수 있습니다:

* *중단*
+
선택한 작업을 중단합니다. 이 옵션은 선택한 작업이 실행 중인 경우에만 사용할 수 있습니다.

* *재시도*
+
보호 구성 또는 보호 관계 작업 유형의 실패한 작업을 다시 시작합니다. 한 번에 하나의 실패한 작업만 다시 시도할 수 있습니다. 실패한 작업이 두 개 이상 선택된 경우 *다시 시도* 버튼이 비활성화됩니다. 실패한 스토리지 서비스 작업은 다시 시도할 수 없습니다.

* *새로 고침*
+
작업 목록 및 관련 정보를 새로 고칩니다.





[[jobs-list]]
== 작업 목록

작업 목록은 진행 중인 작업 목록을 표 형식으로 표시합니다. 기본적으로 이 목록에는 지난주에 생성된 작업만 표시됩니다. 열 정렬 및 필터링 기능을 사용하여 표시할 작업을 사용자 지정할 수 있습니다.

* *상태*
+
작업의 현재 상태를 표시합니다. 상태는 오류(image:../media/sev_error.gif[""]) 또는 정상(image:../media/sev_normal.gif[""])일 수 있습니다.

* *작업 ID*
+
작업 식별 번호를 표시합니다. 기본적으로 이 열은 숨겨져 있습니다.

+
작업 식별 번호는 고유하며 서버에서 작업을 시작할 때 할당됩니다. 열 필터에서 제공하는 텍스트 상자에 작업 식별 번호를 입력하여 특정 작업을 검색할 수 있습니다.

* *이름*
+
작업명을 표시합니다.

* *유형*
+
작업 유형을 표시합니다. 작업 유형은 다음과 같습니다.

+
** *클러스터 인수*
+
Workflow Automation 작업이 클러스터를 다시 검색하고 있습니다.

** *보호 구성*
+
보호 작업은 cron 스케줄, SnapMirror 정책 생성 등과 같은 Workflow Automation 워크플로를 시작합니다.

** *보호 관계 운영*
+
보호 작업이 SnapMirror 작업을 실행 중입니다.

** *보호 워크플로 체인*
+
Workflow Automation 작업이 여러 워크플로를 실행하고 있습니다.

** *복원*
+
복원 작업이 실행 중입니다.

** *정리*
+
이 작업은 복원 목적으로 더 이상 필요하지 않은 스토리지 서비스 멤버 아티팩트를 정리하는 것입니다.

** *준수*
+
이 작업은 스토리지 서비스 멤버의 구성을 확인하여 규정을 준수하는지 확인하는 것입니다.

** *파기*
+
작업이 스토리지 서비스를 삭제하고 있습니다.

** *가져오기*
+
이 작업은 관리되지 않는 스토리지 객체를 기존 스토리지 서비스로 가져오는 것입니다.

** *수정*
+
이 작업은 기존 스토리지 서비스의 속성을 수정하는 것입니다.

** *구독*
+
이 작업은 스토리지 서비스에 멤버를 가입시키는 것입니다.

** *구독 취소*
+
이 작업은 스토리지 서비스에서 구성원의 구독을 취소하는 중입니다.

** *업데이트*
+
보호 업데이트 작업이 실행 중입니다.

** *WFA 구성*
+
Workflow Automation 작업이 클러스터 자격 증명을 푸시하고 데이터베이스 캐시를 동기화하고 있습니다.



* *상태*
+
작업의 실행 상태를 표시합니다. 상태 옵션은 다음과 같습니다.

+
** *중단됨*
+
해당 작업은 중단되었습니다.

** *중단*
+
작업 중단이 진행 중입니다.

** *완료됨*
+
작업이 완료되었습니다.

** *실행 중*
+
작업이 실행 중입니다.



* *제출 시간*
+
작업이 제출된 시간을 표시합니다.

* *기간*
+
작업 완료에 소요된 시간을 표시합니다. 이 열은 기본적으로 표시됩니다.

* *완료 시간*
+
작업이 완료된 시간을 표시합니다. 기본적으로 이 열은 숨겨져 있습니다.
