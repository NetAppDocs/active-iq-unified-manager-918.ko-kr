= Active IQ Unified Manager에서 실패한 보호 작업 재시도
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
보호 작업 실패를 해결하기 위한 조치를 취한 후에는 *다시 시도*를 사용하여 작업을 다시 실행할 수 있습니다. 작업을 다시 시도하면 원래 작업 ID를 사용하여 새 작업이 생성됩니다.

.시작하기 전에
애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

한 번에 하나의 실패한 작업만 다시 시도할 수 있습니다. 두 개 이상의 작업을 선택하면 *다시 시도* 버튼이 비활성화됩니다. 보호 구성 및 보호 관계 작업 유형의 작업만 다시 시도할 수 있습니다.

.단계
. 왼쪽 탐색 창에서 *보호* > *작업*을 클릭합니다.
. 작업 목록에서 실패한 보호 구성 또는 보호 관계 작업 유형 작업을 하나 선택합니다.
+
*다시 시도* 버튼이 활성화되었습니다.

. *다시 시도*를 클릭하세요.
+
작업이 다시 시작됩니다.
