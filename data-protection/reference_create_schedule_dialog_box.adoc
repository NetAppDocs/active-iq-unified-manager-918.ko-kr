= Active IQ Unified Manager에서 일정 생성 대화 상자 사용
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
'일정 생성' 대화 상자를 사용하여 SnapMirror 및 SnapVault 관계 전송에 대한 기본 또는 고급 보호 일정을 만들 수 있습니다. 데이터 업데이트가 잦은 경우 데이터 전송 빈도를 높이기 위해 새 일정을 만들거나, 데이터 변경 빈도가 낮은 경우에는 전송 빈도를 낮추는 일정을 만들 수 있습니다.

SnapMirror

* *타겟 클러스터*
+
보호 구성 대화 상자의 SnapVault 탭 또는 SnapMirror 탭에서 선택한 클러스터의 이름입니다.

* *일정명*
+
일정에 지정하는 이름입니다. 일정 이름은 A부터 Z, a부터 z, 0부터 9까지의 문자와 다음 특수 문자로 구성될 수 있습니다: ! @ # $ % {caret} & * ( ) _ -. 일정 이름에는 다음 문자를 포함할 수 없습니다: < >.

* *기본 또는 고급*
+
사용하려는 스케줄 모드.

+
기본 모드에는 다음과 같은 요소가 포함됩니다:

+
** 반복
+
예약된 전송이 발생하는 빈도를 지정합니다. 시간별, 일별, 주별 중에서 선택할 수 있습니다.

** 일
+
매주 반복을 선택한 경우 전송이 발생하는 요일입니다.

** 시간
+
매일 또는 매주를 선택한 경우 전송이 발생하는 시간입니다.



+
고급 모드에는 다음과 같은 요소가 포함됩니다:

+
** 개월
+
쉼표로 구분된 숫자 목록으로 연중 월을 나타냅니다. 유효한 값은 0부터 11까지이며, 0은 1월을 나타냅니다. 이 요소는 선택 사항입니다. 이 필드를 비워두면 매달 전송이 이루어짐을 의미합니다.

** 일
+
해당 월의 일을 나타내는 쉼표로 구분된 숫자 목록입니다. 유효한 값은 1부터 31까지입니다. 이 요소는 선택 사항입니다. 이 필드를 비워두면 해당 월의 매일 전송이 발생하는 것으로 간주됩니다.

** 평일
+
요일을 나타내는 쉼표로 구분된 숫자 목록입니다. 유효한 값은 0부터 6까지이며, 0은 일요일을 나타냅니다. 이 요소는 선택 사항입니다. 필드를 비워두면 매일 전송이 발생함을 의미합니다. 요일은 지정되었지만 월의 일자가 지정되지 않은 경우, 매일이 아니라 지정된 요일에만 전송이 발생합니다.

** 시간
+
하루의 시간 수를 쉼표로 구분한 숫자 목록입니다. 유효한 값은 0부터 23까지이며, 0은 자정을 나타냅니다. 이 요소는 선택 사항입니다.

** 분
+
쉼표로 구분된 숫자 목록으로, 한 시간의 분을 나타냅니다. 유효한 값은 0부터 59까지입니다. 이 요소는 필수입니다.
