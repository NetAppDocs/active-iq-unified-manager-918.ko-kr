= Active IQ Unified Manager의 스토리지 관리를 위한 일반적인 API 워크플로우 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
일반적인 워크플로는 클라이언트 애플리케이션 개발자에게 Active IQ Unified Manager API를 클라이언트 애플리케이션에서 호출하여 일반적인 스토리지 관리 기능을 실행하는 방법을 보여주는 예제를 제공합니다. 이 섹션에는 이러한 샘플 워크플로 중 일부가 포함되어 있습니다.

워크플로는 일반적으로 사용되는 스토리지 관리 사용 사례와 함께 사용할 수 있는 샘플 코드를 제공합니다. 각 작업은 하나 이상의 API 호출로 구성된 워크플로 프로세스를 사용하여 설명됩니다.



[[understand-the-api-calls-used-in-the-workflows]]
== 워크플로에서 사용되는 API 호출 이해

Unified Manager 인스턴스에서 모든 REST API 호출의 세부 정보가 포함된 온라인 문서 페이지를 볼 수 있습니다. 이 문서에서는 온라인 문서의 세부 정보를 반복하지 않습니다. 이 문서의 워크플로 샘플에 사용된 각 API 호출에는 문서 페이지에서 호출을 찾는 데 필요한 정보만 포함되어 있습니다. 특정 API 호출을 찾은 후에는 입력 매개변수, 출력 형식, HTTP 상태 코드, 요청 처리 유형 등 호출의 전체 세부 정보를 검토할 수 있습니다.

워크플로 내의 각 API 호출에 대해 다음 정보가 포함되어 있어 문서 페이지에서 해당 호출을 쉽게 찾을 수 있습니다.

* 범주: API 호출은 문서 페이지에서 기능적으로 관련된 영역 또는 범주별로 정리되어 있습니다. 특정 API 호출을 찾으려면 페이지 하단으로 스크롤하여 해당 API 범주를 클릭하십시오.
* HTTP 동사(호출): HTTP 동사는 리소스에 대해 수행되는 작업을 식별합니다. 각 API 호출은 하나의 HTTP 동사를 통해 실행됩니다.
* 경로: 경로는 호출 수행의 일부로 작업이 적용되는 특정 리소스를 결정합니다. 경로 문자열은 핵심 URL에 추가되어 리소스를 식별하는 전체 URL을 구성합니다.
