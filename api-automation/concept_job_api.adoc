= Active IQ Unified Manager에서 API를 사용하여 작업 및 시스템 세부 정보 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
 `management-server` 카테고리의 `jobs` API를 사용하여 비동기 작업의 실행 세부 정보를 볼 수 있습니다.  `management-server` 카테고리의 `system` API를 사용하면 Active IQ Unified Manager 환경의 인스턴스 세부 정보를 볼 수 있습니다.



[[view-jobs]]
== 작업 보기

Active IQ Unified Manager에서 리소스 추가 및 수정 등 작업은 동기 및 비동기 API 호출을 통해 수행됩니다. 비동기 실행이 예약된 호출은 해당 호출을 위해 생성된 Job 오브젝트를 통해 추적할 수 있습니다. 각 Job 오브젝트에는 고유한 식별 키가 있습니다. 각 Job 오브젝트는 작업 진행 상황에 액세스하고 추적할 수 있도록 Job 오브젝트 URI를 반환합니다. 이 API를 사용하여 각 실행에 대한 세부 정보를 검색할 수 있습니다.

이 API를 사용하면 기간별 데이터를 포함하여 데이터 센터의 모든 작업 오브젝트를 조회할 수 있습니다. 기본적으로 모든 작업을 조회하면 웹 UI 및 API 인터페이스를 통해 실행된 최근 20개 작업의 세부 정보가 반환됩니다. 내장 필터를 사용하여 특정 작업을 볼 수 있습니다. 또한 작업 키를 사용하여 특정 작업의 세부 정보를 조회하고 해당 리소스에 대한 다음 작업 세트를 실행할 수 있습니다.

[cols="4*"]
|===
| 범주 | HTTP 동사 | 경로 | 설명 


 a| 
management-server
 a| 
GET
 a| 
`/management-server/jobs`
 a| 
모든 작업의 세부 정보를 반환합니다. 정렬 순서 없이 가장 최근에 제출된 작업 오브젝트가 맨 위에 반환됩니다.



 a| 
management-server
 a| 
GET
 a| 
`/management-server/jobs/\{key}`

해당 작업의 세부 정보를 보려면 Job 오브젝트의 작업 키를 입력하십시오.
 a| 
특정 Job 오브젝트의 세부 정보를 반환합니다.

|===


[[view-system-details]]
== 시스템 세부 정보 보기

 `/management-server/system` API를 사용하면 Unified Manager 환경의 인스턴스별 세부 정보를 조회할 수 있습니다. API는 시스템에 설치된 Unified Manager 버전, UUID, 공급업체 이름, 호스트 OS, Unified Manager 인스턴스에서 실행 중인 서비스의 이름, 설명 및 상태 등 제품 및 서비스에 대한 정보를 반환합니다.

[cols="4*"]
|===
| 범주 | HTTP 동사 | 경로 | 설명 


 a| 
management-server
 a| 
GET
 a| 
`/management-server/system`
 a| 
이 API를 실행하는 데 필요한 입력 매개변수는 없습니다. 기본적으로 현재 Unified Manager 인스턴스의 시스템 세부 정보가 반환됩니다.

|===
