= Active IQ Unified Manager에서 API를 사용하여 Active Directory 매핑 관리
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
여기에 나열된 API를 사용하여 SVM에서 CIFS 공유를 프로비저닝하는 데 필요한 Active Directory 매핑을 관리할 수 있습니다. SVM을 ONTAP과 매핑하려면 Active Directory 매핑을 구성해야 합니다.



[[view-active-directory-mappings]]
== Active Directory 매핑 보기

다음 방법을 사용하여 SVM의 Active Directory 매핑 구성 세부 정보를 볼 수 있습니다. SVM의 Active Directory 매핑을 보려면 SVM 키를 입력해야 합니다. 특정 매핑의 세부 정보를 조회하려면 매핑 키를 입력해야 합니다.

[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
storage-provider
 a| 
GET
 a| 
`/storage-provider/active-directories-mappings`

`/storage-provider/active-directories-mappings/\{key}`

|===


[[add-active-directory-mapping]]
== Active Directory 매핑 추가

다음 방법을 사용하여 SVM에 Active Directory 매핑을 생성할 수 있습니다. 매핑 세부 정보를 입력 매개변수로 입력해야 합니다.

[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
storage-provider
 a| 
POST
 a| 
`/storage-provider/active-directories-mappings`

|===
