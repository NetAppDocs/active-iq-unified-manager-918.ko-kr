= Active IQ Unified Manager API 사용에 대한 권장 사례를 따르십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager에서 API를 사용할 때 특정 권장 사항을 따라야 합니다.

* 유효한 실행을 위해서는 모든 응답 콘텐츠 유형이 다음 형식을 따라야 합니다:
+
[listing]
----
application/json
----
* API 버전 번호는 제품 버전 번호와 관련이 없습니다. Unified Manager 인스턴스에서 사용 가능한 최신 API 버전을 사용해야 합니다. Unified Manager API 버전에 대한 자세한 내용은 "`REST API versioning in Active IQ Unified Manager`" 섹션을 참조하십시오.
* Unified Manager API를 사용하여 배열 값을 업데이트할 때는 전체 값 문자열을 업데이트해야 합니다. 배열에 값을 추가할 수는 없습니다. 기존 배열만 교체할 수 있습니다.
* 메트릭 API의 IOPS 및 성능과 같은 double 값을 제외한 모든 쿼리 매개변수에 파이프(|) 및 와일드카드(+*+) 등의 필터 연산자를 사용할 수 있습니다.
* 필터 연산자 와일드카드(+*+)와 파이프(|)를 조합하여 오브젝트를 쿼리하는 것은 피하십시오. 잘못된 수의 오브젝트가 검색될 수 있습니다.
* 필터에 값을 사용할 때는 값에  `?` 문자가 포함되지 않도록 하십시오. 이는 SQL 인젝션 위험을 완화하기 위한 것입니다.
* 모든 API에 대한  `GET` (all) 요청은 최대 1000개의 레코드를 반환한다는 점에 유의하십시오.  `max_records` 매개변수를 1000보다 높은 값으로 설정하여 쿼리를 실행하더라도 1000개의 레코드만 반환됩니다.
* 관리 기능을 수행하려면 Unified Manager UI를 사용하는 것이 좋습니다.
