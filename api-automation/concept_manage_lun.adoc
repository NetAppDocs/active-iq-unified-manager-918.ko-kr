= Active IQ Unified Manager에서 API를 사용하여 LUN 관리
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
 `/storage-provider/luns` API를 사용하여 데이터 센터 환경의 LUN을 보고, 추가하고, 수정하고, 삭제할 수 있습니다.

LUN을 프로비저닝하기 전에 SVM이 지원되는 프로토콜을 사용하여 생성 및 프로비저닝되었는지 확인하십시오. 프로비저닝 중에 성능 서비스 수준(PSL) 또는 스토리지 효율성 정책(SEP)을 할당하는 경우, LUN을 생성하기 전에 PSL 또는 SEP가 생성되어 있어야 합니다.



[[view-luns]]
== LUN 보기

다음 방법을 사용하여 Unified Manager 환경의 LUN을 확인할 수 있습니다. Active IQ Unified Manager에 ONTAP 클러스터를 데이터 소스로 추가하면 해당 클러스터의 스토리지 워크로드가 Unified Manager 인스턴스에 자동으로 추가됩니다. 이 API는 Unified Manager 인스턴스에 자동 및 수동으로 추가된 모든 LUN을 검색합니다. LUN 키를 사용하여 이 API를 실행하면 특정 LUN의 세부 정보를 확인할 수 있습니다.

[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
storage-provider
 a| 
GET
 a| 
`/storage-provider/luns`

`/storage-provider/luns/\{key}`

|===


[[add-luns]]
== LUN 추가

다음 방법을 사용하여 SVM에 LUN을 추가할 수 있습니다.

[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
storage-provider
 a| 
POST
 a| 
`/storage-provider/luns`

|===
[NOTE]
====
cURL 요청에서 선택적 매개변수 volume_name_tag에 값을 제공하면 해당 값이 LUN 생성 시 볼륨 이름 지정에 사용됩니다. 이 태그를 사용하면 볼륨을 쉽게 검색할 수 있습니다. 요청에 볼륨 키를 제공하면 태깅 과정이 생략됩니다.

====


[[delete-luns]]
== LUN 삭제

다음 방법을 사용하여 특정 LUN을 삭제할 수 있습니다. 특정 LUN을 삭제하려면 LUN 키를 제공해야 합니다.

[NOTE]
====
ONTAP에서 볼륨을 생성한 후 Unified Manager를 통해 해당 볼륨에 LUN을 프로비저닝한 경우, 이 API를 사용하여 모든 LUN을 삭제하면 해당 볼륨도 ONTAP 클러스터에서 삭제됩니다.

====
[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
storage-provider
 a| 
삭제
 a| 
`/storage-provider/luns/\{key}`

|===


[[modify-luns]]
== LUN 수정

다음 메서드를 사용하여 LUN을 수정하고 속성을 업데이트할 수 있습니다. 특정 LUN을 수정하려면 LUN 키를 제공해야 합니다. 또한 업데이트할 LUN 속성과 해당 값을 입력해야 합니다. 이 API를 사용하여 LUN 어레이를 업데이트하려면 "`API 사용 권장 사항`"의 권장 사항을 검토하십시오.

[NOTE]
====
이 API를 한 번 호출할 때는 하나의 속성만 업데이트할 수 있습니다. 여러 속성을 업데이트하려면 이 API를 여러 번 실행해야 합니다.

====
|===


| 범주 | HTTP 동사 | 경로 


 a| 
storage-provider
 a| 
PATCH
 a| 
`/storage-provider/luns/\{key}`

|===
