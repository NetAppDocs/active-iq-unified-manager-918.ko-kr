= Active IQ Unified Manager 게이트웨이 API를 사용하여 ONTAP 볼륨 문제 해결
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
게이트웨이 API는 ONTAP API를 호출하여 ONTAP 스토리지 오브젝트에 대한 정보를 조회하고 보고된 문제를 해결하기 위한 시정 조치를 취하는 게이트웨이 역할을 합니다.

이 워크플로는 ONTAP 볼륨이 용량에 거의 도달했을 때 이벤트가 발생하는 샘플 사용 사례를 다룹니다. 또한 Active IQ Unified Manager와 ONTAP REST API를 조합하여 호출함으로써 이 문제를 해결하는 방법을 보여줍니다.

[NOTE]
====
워크플로 단계를 실행하기 전에 다음 사항을 확인하십시오.

* 게이트웨이 API와 사용 방법에 대해 알고 계실 것입니다. 자세한 내용은 link:concept_gateway_apis.html["프록시 액세스를 통해 ONTAP API에 액세스하기"]을(를) 참조하십시오.
* ONTAP REST API 사용법을 알고 있습니다. ONTAP REST API 사용에 대한 자세한 내용은 https://docs.netapp.com/us-en/ontap-automation/index.html["ONTAP 자동화 문서"]을(를) 참조하십시오.
* 당신은 애플리케이션 관리자입니다.
* REST API 작업을 실행하려는 클러스터는 ONTAP 9.5 이상에서 지원되어야 하며, 해당 클러스터가 HTTPS를 통해 Unified Manager에 추가되어야 합니다.


====
다음 다이어그램은 ONTAP 볼륨 용량 사용 문제 해결을 위한 워크플로의 각 단계를 보여줍니다.

image::../media/api_gateway_ontap_workflow.gif[Unified Manager 및 ONTAP API 단계를 보여주는 다이어그램으로, 볼륨 용량 경고 문제를 해결하기 위한 것입니다.]

이 워크플로는 Unified Manager 및 ONTAP REST API의 호출 지점을 모두 포함합니다.

. 볼륨 용량 사용률을 알리는 이벤트에서 볼륨 이름을 확인하십시오.
. name 매개변수의 값으로 볼륨 이름을 사용하여 다음 Unified Manager API를 실행하여 볼륨을 쿼리합니다.
+
[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
데이터센터
 a| 
GET
 a| 
`/datacenter/storage/volumes`

|===
. 출력에서 클러스터 UUID와 볼륨 UUID를 가져옵니다.
. Unified Manager 웹 UI에서 *일반* > *기능 설정* > *API 게이트웨이*로 이동하여 API 게이트웨이 기능이 활성화되어 있는지 확인하십시오. 이 기능이 활성화되어 있지 않으면 게이트웨이 범주에 속하는 API를 호출할 수 없습니다. 비활성화되어 있는 경우 기능을 활성화하십시오.
. 클러스터 UUID를 사용하여 API 게이트웨이를 통해 ONTAP API /`storage/volumes/{uuid}`를 실행합니다. 볼륨 UUID가 API 매개변수로 전달되면 쿼리는 볼륨 세부 정보를 반환합니다.
+
API 게이트웨이를 통해 ONTAP API를 실행하는 경우, Unified Manager 자격 증명이 내부적으로 인증을 위해 전달되므로 개별 클러스터 액세스를 위해 추가 인증 단계를 수행할 필요가 없습니다.

+
[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
Unified Manager: 게이트웨이

ONTAP: 스토리지
 a| 
GET
 a| 
게이트웨이 API: `/gateways/\{uuid}/\{path}`

ONTAP API: `/storage/volumes/\{uuid}`

|===
+
[NOTE]
====
/gateways/\{uuid}/\{path}에서 \{uuid}의 값은 REST 작업을 수행할 클러스터 UUID로 교체해야 합니다. \{path}는 ONTAP REST URL /storage/volumes/\{uuid}로 교체해야 합니다.

====
+
첨부된 URL은 다음과 같습니다: `/gateways/\{cluster_uuid}/storage/volumes/\{volume_uuid}`

+
GET 작업을 실행하면 생성되는 URL은 다음과 같습니다: `GEThttps://<hostname\>/api/gateways/<cluster_UUID\>/storage/volumes/\{volume_uuid\}`

+
*cURL 명령어 예시*

+
[listing]
----
curl -X GET "https://<hostname>/api/gateways/1cd8a442-86d1-11e0-ae1c-9876567890123/storage/volumes/028baa66-41bd-11e9-81d5-00a0986138f7"
-H "accept: application/hal+json" -H "Authorization: Basic <Base64EncodedCredentials>"
----
. 출력 결과를 바탕으로 크기, 사용량 및 필요한 개선 조치를 결정합니다. 이 워크플로에서는 볼륨 크기를 조정하는 것이 개선 조치입니다.
. 클러스터 UUID를 사용하고 API 게이트웨이를 통해 다음 ONTAP API를 실행하여 볼륨 크기를 조정하십시오. 게이트웨이 및 ONTAP API의 입력 매개변수에 대한 자세한 내용은 5단계를 참조하십시오.
+
[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
Unified Manager: 게이트웨이

ONTAP: 스토리지
 a| 
PATCH
 a| 
게이트웨이 API: `/gateways/\{uuid}/\{path}`

ONTAP API: `/storage/volumes/\{uuid}`

|===
+
[NOTE]
====
클러스터 UUID 및 볼륨 UUID와 함께 볼륨 크기를 조정하기 위한 size 매개변수 값을 입력해야 합니다. 값은 반드시 _바이트 단위로_ 입력해야 합니다. 예를 들어 볼륨 크기를 100GB에서 120GB로 늘리려면 쿼리 끝에 size 매개변수 값을 입력합니다: `-d {\"size\": 128849018880}"`

====
+
*cURL 명령어 예시*

+
[listing]
----
curl -X PATCH "https://<hostname>/api/gateways/1cd8a442-86d1-11e0-ae1c-9876567890123/storage/volumes/028baa66-41bd-11e9-81d5-00a0986138f7" -H
    "accept: application/hal+json" -H "Authorization: Basic <Base64EncodedCredentials>" -d
    {\"size\": 128849018880}"
----
+
JSON 출력에는 작업 UUID가 반환됩니다.

. 작업 UUID를 사용하여 작업이 성공적으로 실행되었는지 확인하십시오. 클러스터 UUID 및 작업 UUID를 사용하여 API 게이트웨이를 통해 다음 ONTAP API를 실행하십시오. 게이트웨이 및 ONTAP API의 입력 매개변수에 대한 자세한 내용은 5단계를 참조하십시오.
+
[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
Unified Manager: 게이트웨이

ONTAP: 클러스터
 a| 
GET
 a| 
게이트웨이 API: `/gateways/\{uuid}/\{path}`

ONTAP API: `/cluster/jobs/\{uuid}`

|===
+
반환되는 HTTP 코드는 ONTAP REST API의 HTTP 상태 코드와 동일합니다.

. 크기가 조정된 볼륨의 세부 정보를 조회하려면 다음 ONTAP API를 실행하십시오. 게이트웨이 및 ONTAP API의 입력 매개변수에 대한 자세한 내용은 5단계를 참조하십시오.
+
[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
Unified Manager: 게이트웨이

ONTAP: 스토리지
 a| 
GET
 a| 
게이트웨이 API: `/gateways/\{uuid}/\{path}`

ONTAP API: `/storage/volumes/\{uuid}`

|===
+
출력 결과에는 볼륨 크기가 120 GB로 증가한 것으로 표시됩니다.
