= Active IQ Unified Manager API를 사용하여 애그리게이트의 공간 문제 파악
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager에서 데이터 센터 API를 사용하여 볼륨의 공간 가용성 및 활용률을 모니터링할 수 있습니다. 볼륨의 공간 문제를 파악하고 과다 사용 또는 과소 사용 중인 스토리지 리소스를 식별할 수 있습니다.

애그리게이트용 데이터 센터 API는 사용 가능한 공간과 사용된 공간, 공간 절약 효율성 설정과 관련된 정보를 검색합니다. 지정된 속성을 기준으로 검색된 정보를 필터링할 수도 있습니다.

애그리게이트의 공간 부족 여부를 확인하는 한 가지 방법은 환경에 자동 크기 조정 모드가 활성화된 볼륨이 있는지 확인하는 것입니다. 그런 다음 과도하게 사용되고 있는 볼륨을 식별하고 필요한 수정 조치를 취해야 합니다.

다음 순서도는 자동 크기 조정 모드가 활성화된 볼륨에 대한 정보를 검색하는 과정을 보여줍니다:

image::../media/space_utilization.gif[클러스터 애그리게이트에서 자동 크기 조정 모드가 활성화된 과다 사용 볼륨을 식별하기 위한 순서도]

이 절차는 클러스터가 이미 ONTAP에서 생성되었고 Unified Manager에 추가되었다고 가정합니다.

. 값을 알고 있지 않다면 클러스터 키를 가져오십시오:
+
[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
데이터센터
 a| 
GET
 a| 
`/datacenter/cluster/clusters`

|===
. 클러스터 키를 필터 매개변수로 사용하여 해당 클러스터의 애그리게이트를 쿼리합니다.
+
[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
데이터센터
 a| 
GET
 a| 
`/datacenter/storage/aggregates`

|===
. 응답에서 애그리게이트의 공간 사용량을 분석하고 어떤 애그리게이트에 공간 문제가 있는지 확인합니다. 공간 문제가 있는 각 애그리게이트에 대해 동일한 JSON 출력에서 애그리게이트 키를 가져옵니다.
. 각 집계 키를 사용하여 autosize.mode 매개변수 값이  `grow.`인 모든 볼륨을 필터링합니다.
+
[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
데이터센터
 a| 
GET
 a| 
`/datacenter/storage/volumes`

|===
. 어떤 볼륨이 과도하게 사용되고 있는지 분석하십시오.
. 볼륨의 공간 문제를 해결하기 위해 애그리게이트 간 볼륨 이동 등 필요한 수정 조치를 수행하십시오. 이러한 조치는 ONTAP 또는 Unified Manager 웹 UI에서 수행할 수 있습니다.
