= Active IQ Unified Manager에서 제공되는 REST 서비스 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager API를 사용하기 전에 제공되는 REST 서비스 및 작업에 대해 알아두어야 합니다.

API 서버 구성에 사용되는 프로비저닝 및 관리 API는 읽기(GET) 또는 쓰기(POST, PATCH, DELETE) 작업을 지원합니다. 다음은 API에서 지원하는 GET, PATCH, POST, DELETE 작업의 몇 가지 예입니다:

* GET 예:  `GET /datacenter/cluster/clusters` 데이터 센터의 클러스터 세부 정보를 검색합니다.  `GET` 작업에서 반환되는 최대 레코드 수는 1000개입니다.
+
[NOTE]
====
API를 사용하면 지원되는 속성을 기준으로 레코드를 필터링, 정렬 및 순서 지정할 수 있습니다.

====
* POST 예시: `POST /datacenter/svm/svms` 사용자 지정 스토리지 가상 머신(SVM)을 생성합니다.
* PATCH의 예: `PATCH /datacenter/svm/svms/{key}` 고유 키를 사용하여 SVM의 속성을 수정합니다.
* DELETE의 예:  `DELETE /storage-provider/access-endpoints/{key}`는 고유 키를 사용하여 LUN, SVM 또는 파일 공유에서 액세스 엔드포인트를 삭제합니다.


API를 사용하여 수행할 수 있는 REST 작업은 운영자, 스토리지 관리자 또는 애플리케이션 관리자 사용자 역할에 따라 다릅니다.

[cols="2*"]
|===
| 사용자 역할 | 지원되는 REST 메서드 


 a| 
운영자
 a| 
데이터에 대한 읽기 전용 액세스. 이 역할을 가진 사용자는 모든 GET 요청을 실행할 수 있습니다.



 a| 
스토리지 관리자
 a| 
모든 데이터에 대한 읽기 액세스. 이 역할을 가진 사용자는 모든 GET 요청을 실행할 수 있습니다.

또한, 관리, 스토리지 서비스 오브젝트 및 스토리지 관리 옵션 등 특정 활동을 수행하기 위한 쓰기 권한(PATCH, POST 및 DELETE 요청 실행)이 있습니다.



 a| 
애플리케이션 관리자
 a| 
모든 데이터에 대한 읽기 및 쓰기 권한이 있습니다. 이 역할을 가진 사용자는 모든 기능에 대해 GET, PATCH, POST 및 DELETE 요청을 실행할 수 있습니다.

|===
모든 REST 작업에 대한 자세한 내용은 _온라인 API 문서_를 참조하십시오.
