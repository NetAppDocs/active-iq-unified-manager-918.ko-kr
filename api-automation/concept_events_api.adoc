= Active IQ Unified Manager에서 API를 사용하여 이벤트 및 알림 관리
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
 `management-server` 범주의 `events`, `alerts` 및 `scripts` API를 사용하면 Active IQ Unified Manager 환경에서 이벤트, 알림 및 알림과 관련된 스크립트를 관리할 수 있습니다.



[[view-and-modify-events]]
== 이벤트 보기 및 수정

Unified Manager는 Unified Manager에서 모니터링 및 관리하는 클러스터에 대해 ONTAP에서 생성된 이벤트를 수신합니다. 이러한 API를 사용하면 클러스터에 대해 생성된 이벤트를 확인하고, 이벤트를 해결하고 업데이트할 수 있습니다.

 `GET` 메서드를  `/management-server/events` API에 대해 실행하면 기간별 데이터를 포함하여 데이터 센터의 이벤트를 쿼리할 수 있습니다. 이름, 영향 수준, 영향 영역, 심각도, 상태, 리소스 이름, 리소스 유형 등 기본 제공 필터를 사용하여 특정 이벤트를 볼 수 있습니다. 리소스 유형 및 영역 매개 변수는 이벤트가 발생한 스토리지 오브젝트에 대한 정보를 반환하며, 영향 영역은 가용성, 용량, 구성, 보안, 보호, 성능 등 이벤트가 발생한 문제에 대한 정보를 반환합니다.

이 API에 대한 PATCH 작업을 실행하면 이벤트에 대한 해결 워크플로를 활성화할 수 있습니다. 이벤트를 자신 또는 다른 사용자에게 할당하고 이벤트 수신을 확인할 수 있습니다. 이벤트 발생 원인이 된 문제를 해결하기 위해 리소스에 대한 단계를 수행한 후, 이 API를 사용하여 이벤트를 해결됨으로 표시할 수 있습니다.

이벤트에 대한 자세한 내용은 link:../events/concept_what_active_iq_platform_events_are.html["Active IQ 플랫폼 이벤트에 대해 알아보십시오."]을 참조하십시오.

[cols="4*"]
|===
| 범주 | HTTP 동사 | 경로 | 설명 


 a| 
management-server
 a| 
GET
 a| 
`/management-server/events`
`/management-server/events/{key}`
 a| 
Get ALL 메서드를 실행하면 응답 본문에 데이터 센터의 모든 이벤트에 대한 세부 정보가 포함됩니다. 특정 키를 사용하여 이벤트 세부 정보를 검색하면 특정 이벤트의 세부 정보를 확인하고 해당 리소스에 대해 다음 작업을 실행할 수 있습니다. 응답 본문에는 해당 이벤트의 세부 정보가 포함됩니다.



 a| 
management-server
 a| 
PATCH
 a| 
`management-server/events/{key}`
 a| 
이 API를 실행하여 이벤트를 할당하거나 상태를 '승인됨' 또는 '해결됨'으로 변경할 수 있습니다. 또한 이 메서드를 사용하여 자신 또는 다른 사용자에게 이벤트를 할당할 수도 있습니다. 이 작업은 동기식으로 수행됩니다.

|===


[[manage-alerts]]
== 알림 관리

이벤트는 자동으로 지속적으로 생성됩니다. Unified Manager는 특정 필터 기준을 충족하는 이벤트에 대해서만 알림을 생성합니다. 알림을 생성할 이벤트를 선택할 수 있습니다.  `/management-server/alerts` API를 사용하면 특정 이벤트 또는 특정 심각도 유형의 이벤트가 발생할 때 자동으로 알림을 보내도록 알림을 구성할 수 있습니다.

알림에 대한 자세한 내용은 link:../events/concept_what_alerts_are.html["알림에 대해 알아보기"]을 참조하십시오.

[cols="4*"]
|===
| 범주 | HTTP 동사 | 경로 | 설명 


 a| 
management-server
 a| 
GET
 a| 
`/management-server/alerts`
`/management-server/alerts/{key}`
 a| 
경고 키를 사용하여 환경의 모든 기존 경고 또는 특정 경고를 조회하십시오. 경고 설명, 조치, 알림이 전송되는 이메일 ID, 이벤트, 심각도 등 환경에서 생성된 경고에 대한 정보를 볼 수 있습니다.



 a| 
management-server
 a| 
POST
 a| 
`/management-server/alerts`
 a| 
이 방법을 사용하면 특정 이벤트에 대한 알림을 추가할 수 있습니다. 알림 이름, 알림이 적용되는 물리적 또는 논리적 리소스나 이벤트, 알림 활성화 여부, SNMP 트랩 발생 여부를 추가해야 합니다. 작업, 알림 이메일 ID, 스크립트 세부 정보(알림 스크립트를 추가하는 경우) 등 알림을 생성하려는 추가 세부 정보를 추가할 수 있습니다.



 a| 
management-server
 a| 
PATCH 및 DELETE
 a| 
`management-server/events/{key}`
 a| 
이러한 방법을 사용하여 특정 알림을 수정 및 삭제할 수 있습니다. 설명, 이름, 알림 활성화 및 비활성화 등 다양한 속성을 수정할 수 있습니다. 알림이 더 이상 필요하지 않은 경우 삭제할 수 있습니다.

|===

NOTE: 알림을 추가할 리소스를 선택할 때 클러스터를 리소스로 선택하더라도 해당 클러스터 내의 스토리지 오브젝트가 자동으로 선택되는 것은 아니라는 점에 유의하십시오. 예를 들어 모든 클러스터의 모든 중요 이벤트에 대한 알림을 생성하면 클러스터의 중요 이벤트에 대한 알림만 수신하게 됩니다. 노드, 애그리게이트 등의 중요 이벤트에 대한 알림은 수신하지 않습니다.



[[manage-scripts]]
== 스크립트 관리

 `/management-server/scripts` API를 사용하면 경고가 트리거될 때 실행되는 스크립트와 경고를 연결할 수도 있습니다. 스크립트를 사용하여 Unified Manager에서 여러 스토리지 오브젝트를 자동으로 수정하거나 업데이트할 수 있습니다. 스크립트는 경고와 연결됩니다. 이벤트가 경고를 트리거하면 스크립트가 실행됩니다. 사용자 지정 스크립트를 업로드하고 경고가 생성될 때 해당 실행을 테스트할 수 있습니다. Unified Manager에서 이벤트에 대한 경고가 발생할 때 스크립트가 실행되도록 경고를 스크립트와 연결할 수 있습니다.

스크립트에 대한 자세한 내용은 link:../events/concept_manage_scripts.html["스크립트 관리"]을(를) 참조하십시오.

[cols="4*"]
|===
| 범주 | HTTP 동사 | 경로 | 설명 


 a| 
management-server
 a| 
GET
 a| 
`/management-server/scripts`
 a| 
이 API를 사용하여 환경에 있는 모든 기존 스크립트를 쿼리합니다. 표준 필터 및 정렬 작업을 사용하여 특정 스크립트만 확인합니다.



 a| 
management-server
 a| 
POST
 a| 
`/management-server/scripts`
 a| 
이 API를 사용하여 스크립트에 대한 설명을 추가하고 알림과 연결된 스크립트 파일을 업로드하십시오.

|===
