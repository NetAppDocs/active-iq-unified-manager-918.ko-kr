= Active IQ Unified Manager에서 API를 사용하여 액세스 엔드포인트 관리
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 가상 머신(SVM), LUN 및 파일 공유를 프로비저닝하려면 액세스 엔드포인트 또는 논리 인터페이스(LIF)를 생성해야 합니다. Active IQ Unified Manager 환경에서 SVM, LUN 또는 파일 공유에 대한 액세스 엔드포인트를 보고, 생성하고, 수정하고, 삭제할 수 있습니다.



[[view-access-endpoints]]
== 액세스 엔드포인트 보기

Unified Manager 환경의 액세스 엔드포인트 목록은 다음 방법을 사용하여 확인할 수 있습니다. 특정 SVM, LUN 또는 파일 공유의 액세스 엔드포인트 목록을 조회하려면 해당 SVM, LUN 또는 파일 공유의 고유 식별자를 입력해야 합니다. 특정 액세스 엔드포인트의 세부 정보를 확인하려면 고유 액세스 엔드포인트 키를 입력할 수도 있습니다.

[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
storage-provider
 a| 
GET
 a| 
`/storage-provider/access-endpoints`

`/storage-provider/access-endpoints/\{key}`

|===


[[add-access-endpoints]]
== 액세스 엔드포인트를 추가합니다

사용자 지정 액세스 엔드포인트를 생성하고 필요한 속성을 할당할 수 있습니다. 생성하려는 액세스 엔드포인트의 세부 정보를 입력 매개변수로 입력해야 합니다. 이 API, System Manager 또는 ONTAP CLI를 사용하여 각 노드에 액세스 엔드포인트를 생성할 수 있습니다. 액세스 엔드포인트 생성 시 IPv4 및 IPv6 주소 모두 지원됩니다.

[NOTE]
====
LUN 및 파일 공유를 성공적으로 프로비저닝하려면 노드당 최소 액세스 엔드포인트 수를 설정하여 SVM을 구성해야 합니다. SVM은 노드당 최소 2개의 액세스 엔드포인트로 구성해야 하며, 하나는 CIFS 및/또는 NFS 프로토콜을 지원하고 다른 하나는 iSCSI 또는 FCP 프로토콜을 지원해야 합니다.

====
[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
storage-provider
 a| 
POST
 a| 
`/storage-provider/access-endpoints`

|===


[[delete-access-endpoints]]
== 액세스 엔드포인트 삭제

다음 방법을 사용하여 특정 액세스 엔드포인트를 삭제할 수 있습니다. 특정 액세스 엔드포인트를 삭제하려면 액세스 엔드포인트 키를 입력 매개변수로 제공해야 합니다.

[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
storage-provider
 a| 
삭제
 a| 
`/storage-provider/access-endpoints/\{key}`

|===


[[modify-access-endpoints]]
== 액세스 엔드포인트 수정

다음 방법을 사용하여 액세스 엔드포인트를 수정하고 속성을 업데이트할 수 있습니다. 특정 액세스 엔드포인트를 수정하려면 액세스 엔드포인트 키를 제공해야 합니다. 또한 업데이트하려는 속성과 해당 값을 입력해야 합니다.

[cols="3*"]
|===
| 범주 | HTTP 동사 | 경로 


 a| 
storage-provider
 a| 
PATCH
 a| 
`/storage-provider/access-endpoints/\{key}`

|===
