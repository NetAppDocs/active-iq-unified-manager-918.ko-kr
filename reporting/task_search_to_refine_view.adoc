= Active IQ Unified Manager에서 검색하여 보기를 구체화합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
원하는 보기가 나타나면 검색 필드를 사용하여 결과를 추가로 구체화하고 보고서에 포함할 결과에 집중할 수 있습니다.

.단계
. 보고서의 기본으로 사용할 사용자 지정 보기 또는 기본 보기를 엽니다.
. 검색 필드에 입력하여 보기에 나열된 데이터를 세분화합니다. 표시된 모든 열에 부분 데이터를 입력할 수 있습니다. 예를 들어 이름에 "US_East"가 포함된 노드를 검색하려는 경우 전체 노드 목록을 세분화할 수 있습니다.
+
검색 결과는 사용자 지정 보기에 저장되며 결과로 생성되는 예약된 보고서에 사용됩니다.

. 변경 사항을 저장하려면 저장되지 않은 뷰의 이름을 지정하세요.
