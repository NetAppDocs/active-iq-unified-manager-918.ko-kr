= Active IQ Unified Manager에서 기본 엑스포트 정책을 사용하는 볼륨을 보는 보고서 생성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
기본 내보내기 정책을 사용하는 볼륨을 찾기 위한 보고서를 생성할 수 있습니다.

.시작하기 전에
* 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.


다음 단계를 따라 기본 내보내기 정책을 사용하는 볼륨에 대한 사용자 지정 보기를 만들고 해당 보기에 대한 보고서 생성을 예약하십시오.

.단계
. 왼쪽 탐색 창에서 *스토리지* > *NFS 공유*를 클릭합니다.
. 보고서에서 원하지 않는 열을 제거하려면 *표시/숨기기*를 선택하세요.
. "\`Export Policy\`" 열을 "\`볼륨\`" 열 근처로 드래그합니다.
. 필터 아이콘을 클릭하고 다음 필터를 추가한 다음 *필터 적용*을 클릭하십시오:
+
** 엑스포트 정책에는 기본값이 포함되어 있습니다.


. 뷰에 표시되는 내용을 반영하는 특정 이름(예: "`기본 내보내기 정책이 적용된 볼륨`")으로 뷰를 저장하고 확인 표시(image:../media/blue_check.gif[""])를 클릭합니다.
. 인벤토리 페이지에서 *예약 보고서* 버튼을 클릭하십시오.
. 새 보고서의 일정 특성을 정의할 수 있도록 *일정 추가*를 클릭하여 보고서 일정 페이지에 새 행을 추가하십시오.
. 보고서 일정의 이름을 입력하고 나머지 보고서 필드를 모두 작성한 다음 행 끝에 있는 확인 표시(image:../media/blue_check.gif[""])를 클릭하십시오.
+
보고서는 테스트 목적으로 즉시 전송됩니다. 이후 보고서는 생성된 후 지정된 빈도로 나열된 수신자에게 이메일로 전송됩니다.



보고서에 나타난 결과를 바탕으로 사용자 지정 내보내기 정책을 구성하는 것이 좋을 수 있습니다.
