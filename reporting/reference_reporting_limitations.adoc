= Active IQ Unified Manager의 보고 제한 사항 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
새로운 Active IQ Unified Manager 보고 기능에는 몇 가지 제한 사항이 있으므로 이 점을 유의하시기 바랍니다.



[[existing-reports-from-previous-versions-of-unified-manager]]
== Unified Manager 이전 버전의 기존 보고서

Unified Manager 9.5 이하 버전에서 생성 및 가져온 기존 보고서(.rptdesign 파일)의 일정과 수신자만 편집할 수 있습니다. Unified Manager 9.5 이하 버전에 포함된 표준 보고서를 사용자 지정한 경우, 이러한 사용자 지정 보고서는 새 보고 툴로 가져오지 않습니다.

.rptdesign 파일에서 가져온 기존 보고서를 편집해야 하는 경우 다음 중 하나를 수행하고 가져온 보고서를 제거하십시오:

* 새로운 보기를 생성하고 해당 보기에서 보고서를 예약합니다(권장)
* 보고서 위로 마우스를 가져가 SQL을 복사한 다음 외부 툴을 사용하여 데이터를 가져옵니다


기본 보기는 별도의 사용자 지정 없이 보고서로 생성할 수 있습니다. 새로운 보고 솔루션을 사용하여 사용자 지정 보고서를 다시 만들 수 있습니다.



[[schedule-and-report-relationship]]
== 일정 및 보고서 관계

저장된 보고서마다 다양한 수신자 조합으로 여러 개의 일정을 만들 수 있습니다. 하지만 일정을 여러 보고서에 재사용할 수는 없습니다.



[[report-protection]]
== 보고서 보호

적절한 권한을 가진 사용자는 누구나 보고서를 편집하거나 삭제할 수 있습니다. 다른 사용자가 저장된 보기나 일정을 삭제하거나 변경하는 것을 막을 방법은 없습니다.



[[event-reports]]
== 이벤트 보고서

이벤트 보기를 사용자 지정하고 결과 보고서를 CSV 형식으로 다운로드할 수는 있지만, 이벤트 보고서를 반복적으로 생성하고 배포하도록 예약할 수는 없습니다.



[[report-attachments]]
== 보고서 첨부파일

보고서는 이메일 본문에 포함하여 보낼 수 없습니다. 대신, 보고서는 PDF, Excel 또는 CSV 첨부 파일로만 전송됩니다.
