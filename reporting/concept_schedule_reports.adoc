= Active IQ Unified Manager에서 보고서 예약
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
보고서로 재사용하고 공유할 뷰가 준비되면 Active IQ Unified Manager를 사용하여 예약할 수 있습니다. 예약된 보고서를 관리하고 각 보고서 일정에 대한 수신자와 배포 빈도를 변경할 수 있습니다.

Unified Manager에서 대부분의 뷰 또는 인벤토리 페이지를 예약할 수 있습니다. 예외는 이벤트로, CSV 파일로 다운로드할 수 있는 보고서이지만 재생성 및 공유를 위해 이벤트를 예약할 수는 없습니다. 또한 대시보드, 즐겨찾기 또는 구성 페이지는 다운로드하거나 예약할 수 없습니다.

Active IQ Unified Manager 9.8부터 Microsoft® Excel 형식으로 보기를 다운로드하고 사용자 지정할 수 있습니다. 복잡한 정렬, 계층형 필터, 피벗 테이블, 차트 등 고급 Excel 기능을 사용할 수 있습니다. 결과 Excel 보고서가 만족스러우면 보고서가 예약되고 공유될 때마다 사용할 수 있도록 Excel 파일을 업로드할 수 있습니다.

기본 제공되는 보기 또는 사용자 지정 보기를 예약할 수 있습니다. 전송할 파일 형식은 CSV, PDF 또는 XSLX 중에서 선택할 수 있습니다. 보고서를 처음 예약할 때는 보고서를 다운로드하고 수신자가 보게 될 보고서를 확인할 수 있도록 본인을 유일한 수신자로 지정할 수 있습니다.
