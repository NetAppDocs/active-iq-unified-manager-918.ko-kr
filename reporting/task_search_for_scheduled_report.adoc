= Active IQ Unified Manager에서 예약된 보고서 검색
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
예약된 보고서는 이름, 보기 이름, 오브젝트 유형 또는 수신자별로 검색할 수 있습니다.

. 왼쪽 탐색 창에서 *스토리지 관리* > *보고서 일정*을 클릭합니다.
. *예약된 보고서 검색* 텍스트 필드를 사용하세요.
+
[cols="2*"]
|===
| 다음 기준으로 보고서를 찾으려면... | 시도해 보십시오 ... 


 a| 
일정명
 a| 
보고서 일정 이름의 일부를 입력하세요.



 a| 
뷰 이름
 a| 
보고서 보기 이름의 일부를 입력하십시오. 기본 보기와 사용자 지정 보기가 보기 목록에 나타납니다.



 a| 
받는 사람
 a| 
이메일 주소의 일부를 입력하세요.



 a| 
파일 유형
 a| 
"PDF", "CSV" 또는 "XLSX"를 입력하세요.

|===
. 열 머리글을 클릭하여 일정 이름이나 형식 등 해당 열을 기준으로 보고서를 오름차순 또는 내림차순으로 정렬할 수 있습니다.
