= Active IQ Unified Manager에서 씬 프로비저닝이 비활성화된 볼륨 식별
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
볼륨이 씬 프로비저닝되지 않은 경우, 볼륨 생성 시 정의된 대로 디스크의 전체 공간을 차지합니다. 씬 프로비저닝이 비활성화된 볼륨을 식별하면 특정 볼륨에서 씬 프로비저닝을 활성화할지 여부를 결정하는 데 도움이 됩니다.

.시작하기 전에
* 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.


아래 단계를 따라 필요한 열을 올바른 순서로 표시하는 사용자 지정 보기를 만든 다음, 해당 보기에 대한 보고서 생성을 예약하세요.

.단계
. 왼쪽 탐색 창에서 *스토리지* > *볼륨*을 클릭합니다.
. 보기 메뉴에서 *용량* > *모든 볼륨*을 선택하십시오.
. 보고서에서 원하지 않는 열을 제거하려면 *표시/숨기기*를 선택하세요.
. "`사용된 데이터 %`" 및 "`씬 프로비저닝`" 열을 "`사용 가능한 데이터 용량`" 열 근처로 드래그 앤 드롭합니다.
. 필터 아이콘을 클릭하고 *씬 프로비저닝*이 *아니요*인 다음 필터를 추가한 다음 *필터 적용*을 클릭합니다.
. "`Used Data %`" 열의 맨 위를 클릭하여 비율이 가장 높은 볼륨이 목록 맨 위에 표시되도록 결과를 정렬합니다.
. 예를 들어 "`Vols no thin provisioning`"과 같이 뷰에 표시되는 내용을 반영하는 이름으로 뷰를 저장합니다.
. 인벤토리 페이지에서 *예약 보고서* 버튼을 클릭하십시오.
. *일정 추가*를 클릭하여 *보고서 일정* 페이지에 새 행을 추가하고 새 보고서의 일정 특성을 정의하십시오.
. 보고서 일정의 이름을 입력하고 나머지 보고서 필드를 모두 작성한 다음 행 끝에 있는 확인 표시(image:../media/blue_check.gif[""])를 클릭하십시오.
+
보고서는 테스트 목적으로 즉시 전송됩니다. 이후 보고서는 생성된 후 지정된 빈도로 나열된 수신자에게 이메일로 전송됩니다.



보고서에 나타난 결과를 바탕으로 특정 볼륨에 대해 씬 프로비저닝을 활성화하는 것이 좋을 수 있습니다.
