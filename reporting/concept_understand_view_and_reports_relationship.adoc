= Active IQ Unified Manager에서 뷰와 보고서 관계 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
보기 및 인벤토리 페이지는 다운로드하거나 예약하면 보고서가 됩니다.

뷰 및 인벤토리 페이지를 사용자 지정하고 저장하여 재사용할 수 있습니다. Unified Manager에서 볼 수 있는 거의 모든 항목을 저장, 재사용, 사용자 지정, 예약 및 보고서로 공유할 수 있습니다.

보기 드롭다운 메뉴에서 삭제 아이콘이 있는 항목은 사용자 또는 다른 사용자가 생성한 기존 사용자 지정 보기입니다. 아이콘이 없는 항목은 Unified Manager에서 제공하는 기본 보기입니다. 기본 보기는 수정하거나 삭제할 수 없습니다.

[NOTE]
====
* 목록에서 사용자 지정 보기를 삭제하면 해당 보기를 사용하는 모든 Excel 파일이나 예약된 보고서도 함께 삭제됩니다.
* 사용자 지정 보기를 변경하면, 해당 보기를 사용하는 보고서는 보고서 일정에 따라 다음에 보고서가 생성되고 이메일로 전송될 때 변경 사항을 반영합니다. 보기를 변경할 때는 변경 사항이 보고서에 사용되는 관련 Excel 사용자 지정과 호환되는지 확인하십시오. 필요한 경우 Excel 파일을 다운로드하여 필요한 변경 사항을 적용한 후, 보기에 대한 새 Excel 사용자 지정으로 업로드하여 Excel 파일을 업데이트할 수 있습니다.


====
image::../media/view_drop_down_3.png[View 드롭다운의 UI 스크린샷입니다.]

애플리케이션 관리자 또는 스토리지 관리자 역할을 가진 사용자만 삭제 아이콘을 볼 수 있고, 보기를 변경 또는 삭제하거나, 예약된 보고서를 변경 또는 삭제할 수 있습니다.
