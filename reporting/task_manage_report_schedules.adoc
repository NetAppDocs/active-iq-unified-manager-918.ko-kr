= Active IQ Unified Manager에서 보고서 일정 관리
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
보고서 일정 페이지에서 보고서 일정을 관리할 수 있습니다. 기존 일정을 보고, 수정하고, 삭제할 수 있습니다.

[NOTE]
.시작하기 전에
====
보고서 예약 페이지에서는 새 보고서를 예약할 수 없습니다. 예약된 보고서는 오브젝트 인벤토리 페이지에서만 추가할 수 있습니다.

====
* 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.


.단계
. 왼쪽 탐색 창에서 *스토리지 관리* > *보고서 일정*을 클릭합니다.
. 보고서 일정 페이지에서:
+
[cols="2*"]
|===
| 원하신다면... | 그런 다음... 


 a| 
기존 일정 보기
 a| 
스크롤 막대와 페이지 컨트롤을 사용하여 기존 보고서 목록을 스크롤하십시오.



 a| 
기존 일정 수정
 a| 
.. 사용하려는 일정의 더보기 아이콘 image:../media/more_icon.gif[""] 을 클릭합니다.
.. *편집*을 클릭합니다.
.. 필요한 변경 사항을 적용하세요.
.. 변경 사항을 저장하려면 확인 표시를 클릭하세요.




 a| 
기존 일정을 삭제합니다
 a| 
.. 사용하려는 일정의 더보기 아이콘 image:../media/more_icon.gif[""] 을 클릭합니다.
.. *삭제*를 클릭합니다.
.. 결정을 확정하세요.


|===
