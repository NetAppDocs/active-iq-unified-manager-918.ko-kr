= Active IQ Unified Manager에서 일별로 그룹화된 볼륨 전송을 보기 위한 보고서 생성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
일별로 그룹화된 볼륨 전송을 보기 위한 보고서를 생성할 수 있습니다.

.시작하기 전에
* 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.


다음 단계를 따라 일별로 그룹화된 볼륨 전송에 대한 사용자 지정 보기를 만든 다음 해당 보기에 대한 보고서 생성을 예약하십시오.

.단계
. 왼쪽 탐색 창에서 *스토리지* > *볼륨*을 클릭합니다.
. 보기 메뉴에서 *관계* > *최근 1개월 전송률*을 선택합니다.
. "`Day`" 열의 맨 위를 클릭하여 볼륨 전송을 일별로 정렬하십시오.
. 예를 들어 "`일별 볼륨 전송`"과 같이 뷰에 표시되는 내용을 반영하는 특정 이름으로 뷰를 저장하십시오.
. 인벤토리 페이지에서 *예약 보고서* 버튼을 클릭하십시오.
. 보고서 일정의 이름을 입력하고 나머지 보고서 필드를 모두 작성한 다음 행 끝에 있는 확인 표시(image:../media/blue_check.gif[""])를 클릭하십시오.
+
보고서는 테스트 목적으로 즉시 전송됩니다. 이후 보고서는 생성된 후 지정된 빈도로 나열된 수신자에게 이메일로 전송됩니다.



보고서에 표시된 결과를 바탕으로 일별 볼륨 전송을 조사할 수 있습니다.
