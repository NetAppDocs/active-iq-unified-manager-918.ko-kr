= Active IQ Unified Manager에서 데이터 필터링
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
결과가 보고서 요구 사항과 일치하도록 데이터를 필터링하십시오. 필터링을 통해 관심 있는 데이터만 표시할 수 있습니다.

.단계
. 원하는 결과를 집중적으로 보려면 필터 아이콘을 클릭하여 필터를 추가한 다음 *필터 적용*을 클릭하십시오.
+
image::../media/filter_cold_data_2.png[필터를 추가하고 적용하는 방법을 보여주는 UI 스크린샷입니다.]

. 변경 사항을 저장하려면 저장되지 않은 뷰의 이름을 지정하세요.
