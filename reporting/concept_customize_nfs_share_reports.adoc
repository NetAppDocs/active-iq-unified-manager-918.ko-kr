= Active IQ Unified Manager에서 NFS 공유 보고서 사용자 지정
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NFS 공유 보고서를 사용자 지정하여 스토리지 시스템의 볼륨에 대한 NFS 내보내기 정책 및 규칙 정보를 분석할 수 있습니다. 예를 들어, 마운트 경로에 액세스할 수 없는 볼륨과 기본 내보내기 정책이 적용된 볼륨을 표시하도록 보고서를 사용자 지정할 수 있습니다.
