= Active IQ Unified Manager의 샘플 사용자 지정 보고서 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
이러한 샘플 맞춤형 보고서는 잠재적인 문제를 파악하고 문제가 발생하기 전에 대응하는 데 일반적으로 사용됩니다.

이 섹션의 보고서 목록은 완전한 것이 아니며 시간이 지남에 따라 계속 추가될 예정입니다. 문서에 대한 피드백을 제공하여 이 섹션에 추가할 사용자 지정 보고서를 제안할 수 있습니다.

[NOTE]
====
보고서를 관리하려면 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

====
