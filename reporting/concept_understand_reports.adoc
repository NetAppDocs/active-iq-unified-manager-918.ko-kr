= Active IQ Unified Manager의 보고서 이해
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
보고서는 스토리지, 네트워크, 서비스 품질 및 보호 관계에 대한 자세한 정보를 표시하여 잠재적인 문제를 발생하기 전에 파악하고 해결하는 데 도움을 줍니다.

뷰를 사용자 지정하면 나중에 사용할 수 있도록 고유한 이름으로 저장할 수 있습니다. 해당 뷰를 기반으로 보고서를 예약하여 정기적으로 실행하고 다른 사람과 공유할 수 있습니다. 또한 뷰를 Excel 파일로 다운로드하여 고급 Excel 기능을 사용하여 사용자 지정한 다음 해당 파일을 Unified Manager에 다시 업로드할 수 있습니다. 해당 뷰를 사용하여 보고서를 예약하면 업로드한 Excel 파일을 사용하여 공유 가능한 강력한 보고서를 생성합니다.

보고서 일정 페이지에서 예약된 모든 보고서를 관리할 수 있습니다.

[NOTE]
====
보고서를 관리하려면 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

====
보고서를 쉼표로 구분된 값(CSV), Excel 또는 PDF 파일로 다운로드할 수 있습니다.
