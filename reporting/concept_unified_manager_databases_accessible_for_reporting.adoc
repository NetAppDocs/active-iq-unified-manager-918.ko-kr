= Active IQ Unified Manager에서 사용자 지정 보고를 위한 데이터베이스 액세스
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager는 모니터링 대상 클러스터의 데이터를 저장하기 위해 MySQL 데이터베이스를 사용합니다. 데이터는 MySQL 데이터베이스의 다양한 스키마에 저장됩니다.

다음 데이터베이스의 모든 테이블 데이터를 이용할 수 있습니다:

[cols="2*"]
|===
| 데이터베이스 | 설명 


 a| 
netapp_model
 a| 
ONTAP 컨트롤러의 오브젝트에 대한 데이터입니다.



 a| 
netapp_model_view
 a| 
ONTAP 컨트롤러의 오브젝트에 대한 데이터로, 보고서 툴 활용에 적합합니다.



 a| 
netapp_performance
 a| 
클러스터별 성능 카운터.



 a| 
ocum
 a| 
Unified Manager 애플리케이션 데이터 및 정보는 UI 필터링, 정렬 및 일부 파생 필드 계산을 지원합니다.



 a| 
ocum_report
 a| 
인벤토리 구성 및 용량 관련 정보에 대한 데이터입니다.



 a| 
ocum_report_birt
 a| 
인벤토리 구성 및 용량 관련 데이터에 대한 뷰로, 보고 툴에서 사용하기에 적합합니다.



 a| 
opm
 a| 
성능 구성 설정 및 임계값 정보입니다.



 a| 
scalemonitor
 a| 
Unified Manager 애플리케이션의 상태 및 성능 문제에 대한 데이터입니다.



 a| 
vmware_model
 a| 
NetApp 스토리지에 호스팅된 데이터스토어용 VMware 오브젝트 데이터입니다.



 a| 
vmware_model_view
 a| 
NetApp 스토리지에 호스팅된 데이터스토어의 VMware 오브젝트 데이터에 대한 보기로, 보고 툴 사용에 적합합니다.



 a| 
vmware_performance
 a| 
NetApp 스토리지에 호스팅된 데이터스토어에 대한 VMware 성능 카운터 데이터입니다.

|===
보고서 사용자(보고서 스키마 역할을 가진 데이터베이스 사용자)는 이러한 테이블의 데이터에 접근할 수 있습니다. 이 사용자는 Unified Manager 데이터베이스에서 직접 보고서 및 기타 데이터베이스 뷰에 대한 읽기 전용 액세스 권한을 갖습니다. 단, 이 사용자는 사용자 데이터 또는 클러스터 자격 증명 정보가 포함된 테이블에는 접근할 권한이 없습니다.
