= Active IQ Unified Manager에서 보고서 사용자 지정
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP 클러스터 관리에 필요한 모든 정보를 포함하는 보고서를 만들 수 있도록 보기를 사용자 지정하는 방법은 여러 가지가 있습니다.

기본 인벤토리 페이지 또는 사용자 지정 보기로 시작한 다음 열을 추가하거나 제거하고, 열 순서를 변경하고, 데이터를 필터링하거나, 특정 열을 기준으로 오름차순 또는 내림차순으로 정렬하여 페이지를 사용자 지정하십시오.

Unified Manager 9.8부터는 고급 기능을 사용하여 뷰를 사용자 지정할 수 있도록 Excel로 다운로드할 수도 있습니다. 완료되면 사용자 지정된 Excel 파일을 업로드하십시오. 해당 뷰를 사용하여 보고서를 예약하면 사용자 지정된 Excel 파일을 사용하여 공유할 수 있는 강력한 보고서가 생성됩니다.

Excel을 사용하여 보고서를 사용자 지정하는 방법에 대한 자세한 내용은 _Microsoft Excel 보고서 샘플_을 참조하십시오.

[NOTE]
====
보고서를 관리하려면 애플리케이션 관리자 또는 스토리지 관리자 역할이 있어야 합니다.

====
